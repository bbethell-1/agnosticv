Learn event-driven concepts and build event-driven architectures with Red Hat Integration.

This catalog item presents a series of hands-on modules that are designed to familiarize participants with event-driven concepts and give them a taste of using the new Red Hat Integration stack for building event-driven architectures.

This asset covers the following topics:

  • How to connect enterprise on-premise software and container-native applications using Red Hat Integration
  • Technologies to implement different event and messaging connectivity patterns
  • The AMQ streams (Apache Kafka) component of Red Hat AMQ and the basics of its components
  • How to run AMQ streams on Red Hat OpenShift Container Platform, the enterprise Kubernetes
  • Event-driven microservices benefits and patterns
  • How to implement an event management bus using Red Hat Application Services

Relevant provisioning information is sent in the final email.

Duration: Each module can typically be completed in 60-90 minutes, with an additional 20 minutes for the slides introducing the content.

Audience: Developers, architects, data integrators

Product(s): Red Hat AMQ Online, Red Hat Fuse Online, Red Hat OpenShift Container Platform 4.x

Technologies: Debezium, AMQ streams, Camel K
