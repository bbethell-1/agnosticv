Multi-Cloud GitOps With ODF

Solution Patterns document and demonstrate how the Red Hat Portfolio can solve common scenarios and use cases to help our customers in therir cloud adoption and application modernization journey.

Example applications are provided for demonstration purposes and can be modified/replaced to suite customers and/or market segments with similar business problems.

Read more about Solution Patterns.

This Solution Pattern is a foundational architecture that uses Advanced Cluster Management and ArgoCD to deliver application subscriptions and the associated configuration defined in Git to a heirarchy of OpenShift clusters. It deploys Openshift Data Foundation using GitOps.

This is achieved by

  • Providing Helm templates that allow the namespaces and applications that need to be delivered to a set of managed cluster to be defined
  • Using the ArgoCD "app-of-app" pattern to deliver the applications to each cluster
  • Using Advanced Cluster Management to deliver the top-level ArgoCD application to managed clusters
  • Integrating with Hashicorp vault to securely deliver secrets to managed clusters from the central hub

Use cases

  • Using GitOps to deploy ODF in multiple clouds.
  • Using a GitOps approach to roll out and maintain application subscriptions and the associated configuration
  • Using a GitOps approach to centrally manage multiple clusters and including workloads
  • How to securely manage secrets across multi-cloud deployments.

Deployment Instructions

This item currently requires you to manually deploy the workloads. You can find instructions on deploying the Multi-Cloud GitOps with ODF.

Environment

  • 3 Master Nodes (m5.xlarge)
  • 3 Worker Nodes (m5.4xlarge)
  • Cluster version: 4.10 (latest stable)
  • Let's Encrypt certificates enabled for default ingress
