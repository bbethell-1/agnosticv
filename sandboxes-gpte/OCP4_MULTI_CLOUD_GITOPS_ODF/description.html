Use a Solution Pattern to deliver app subscriptions and configurations to OpenShift® clusters.

Solution Patterns document and demonstrate how Red Hat products can help customers in their cloud adoption and application modernization journey by solving common scenarios and use cases.

This workshop provides example applications for demonstration purposes. You can modify or replace the examples to suit customers and/or market segments with similar business problems.

The Solution Pattern in this workshop is a foundational architecture that uses Red Hat® Advanced Cluster Management and Red Hat OpenShift GitOps to deliver application subscriptions, and the associated configuration defined in Git, to a heirarchy of OpenShift clusters. It deploys OpenShift Data Foundation using OpenShift GitOps.

This is achieved as follows:

  • Provides Helm templates that allow the namespaces and applications that need to be delivered to a set of managed cluster to be defined.
  • Uses the OpenShift GitOps "app-of-app" pattern to deliver the applications to each cluster.
  • Uses Red Hat Advanced Cluster Management to deliver the top-level OpenShift GitOps application to managed clusters.
  • Integrates with HashiCorp Vault to securely deliver secrets to managed clusters from the central hub.

Products: Red Hat OpenShift Container Platform, Red Hat OpenShift GitOps (ArgoCD), Red Hat Advanced Cluster Management, HashiCorp Vault, External Secrets, Red Hat OpenShift Data Foundation

Specifications

  • 3 Leader nodes (m5.xlarge)
  • 3 Worker nodes (m5.4xlarge)
  • Cluster version: 4.10 (latest stable)
  • Let's Encrypt certificates enabled for default ingress

Use cases:

  • Using OpenShift GitOps to deploy OpenShift Data Foundation in multiple clouds.
  • Using a GitOps approach to roll out and maintain application subscriptions and the associated configuration.
  • Using a GitOps approach to centrally manage multiple clusters and include workloads.
  • Managing secrets securely across multi-cloud deployments.
