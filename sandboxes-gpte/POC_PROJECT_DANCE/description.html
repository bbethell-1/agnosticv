Demonstration Title: On-Prem Red Hat Trusted Pipeline

Description

This demonstration, titled "On-Prem Red Hat Trusted Pipeline", showcases the integration and application of Red Hat's diverse suite of tools and technologies, specifically designed to create a secure, efficient, and developer-friendly software development lifecycle (SDLC) in an on-premises environment.

Red Hat Products

  • Red Hat Developer Hub: Provides a self-service portal to accelerate developer onboarding.
  • Red Hat Trusted Application Pipeline (RHTAP): Central to ensuring security and efficiency in the SDLC.
  • Red Hat Trusted Artifact Signer: Enhances the security and integrity of software artifacts.
  • Red Hat Trusted Profile Analyzer: Analyzes and ensures robust security profiles for applications.
  • Red Hat Advanced Cluster Security (ACS): Offers comprehensive security for Kubernetes clusters.
  • Red Hat OpenShift Pipelines: Supports continuous integration and deployment with powerful CI/CD capabilities.
  • Red Hat GitOps: Facilitates efficient and consistent software deployment through GitOps methodologies.
  • Red Hat Quay: Provides a secure and scalable container image registry.
  • Red Hat OpenShift Dev Spaces: Streamlines the setup of development environments.
  • Red Hat OpenShift: A leading enterprise platform for container orchestration.

Demo Duration

Planned to last between 45 to 60 minutes, providing an in-depth look at the solutions and practices.

Audience

Intended for Enterprise Architects, IT Managers, VP Operations, Chief Information Security Officers (CISOs), and professionals interested in secure and efficient development practices.

Customer Engagements

Guidance on interacting and engaging with customers during the demonstration.

Focus on Security and Efficiency

Highlights the integration of security measures throughout the SDLC.

Developer-Centric Approach

Emphasizes reducing the cognitive load for developers, allowing them to focus more on creating business-driven outcomes.

Implementation of DevSecOps Principles

Demonstrates the "shift-left" and "shift-down" security approaches, embedding security checks early in the development process.

Innovative Features

Introduces Software Catalog, Documentation as Code, and golden path templates, showcasing innovative approaches to streamline development processes.
