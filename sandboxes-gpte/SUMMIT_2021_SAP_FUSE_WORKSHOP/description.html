The SAP Fuse workshop shows you how you can deploy your applications on Openshift using technologies like serverless and connect them to the SAP core (SAP S/4HAnA or classic SAP Netweaver)so that they can communicate and data be consumed in both directions

Please Note:
  • Training - Single seat/use. Intended to be used for self led hands on training or as a limited demonstration. No SFDC info required.
  • Small - Up to 14 seats/users. Intended for small hands on workshops. A generic-user account is required. SFDC is required and will be validated prior to provisioning.
  • Large - 15 and over seats/users; 11 through 14 are included (max varies by workshop). Intended for large hands on workshops. A generic-user account is required and need to be requested using the Support URL shown below. SFDC is required and will be validated prior to provisioning.

Cluster Specification

  • 3 Control Plane Nodes (AWS instance type: m5.2xlarge)
  • 3 Worker Nodes (AWS instance type: m5.4xlarge)
  • 1 Bastion Node (AWS instance type: t3.medium
  • Cluster Version: 4.x
  • Authentication Enabled (htpasswd - refer to your provisioning e-mail for details)

Access Information

You will receive an email with both the cluster admin credentials as well as administrative credentials and the URL for access.
