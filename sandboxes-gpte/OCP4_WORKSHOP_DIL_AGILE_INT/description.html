Day in the Life - Agile Integration Workshop

This item is a refresh of the RHMI v 1.5.2 basd DIL Agile Integration workshop. The use cases and labs are the same, but refreshed to work on the latest OpenShift Container Platform & Integration product versions.

This workshop provisions the following:

  • OpenShift Container Platform 4.6
  • Red Hat 3scale API Management 2.9
  • Red Hat Single Sign On 7.4
  • Red Hat Fuse 7.7
  • Red Hat API Designer 7.7
  • Red Hat Fuse Online 7.7
  • Microcks 1.1.0
  • Eclipse Che 7.22
  • Gogs (Persistent) 0.11.34
  • Gogs (Persistent) 0.11.34
  • Apache camelK 1.2.1
  • Integreatly Solution Explorer 2.22

Cluster Specification

  • Nodes: 3 master, 1 infra, num-of-users/5 worker nodes
  • Storage: NFS with 100 persistent volumes

Access Guide

You have full admin access to the provisioned workshop cluster and can find all details needs to access your cluster in the following document:
https://bit.ly/2zjCIgQ

User accounts & access to required projects are created for the Number of users specified. Each user can login to their account with the userid and password credentials. The SSO is provisioned for sign up to 3scale, SSO realm, Gogs, Che and Fuse Online for the user with their userid and password.

Users get started with the lab by logging into the Solution Explorer with their credentials. To start the workshop, share the Solution Explorer link and assigned userid & password to each user.
