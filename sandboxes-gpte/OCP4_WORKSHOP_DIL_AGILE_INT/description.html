Explore use cases with Red Hat OpenShift Container Platform and Red Hat Integration.

This catalog item is a refresh of the Day in the Life Agile Integration workshop based on Red Hat Management Integration version 1.5.2. The use cases and exercises are the same but have been refreshed to work on the latest OpenShift Container Platform and Red Hat Integration product versions.

This workshop provisions the following:

  • OpenShift Container Platform 4.6
  • Red Hat 3scale API Management 2.9
  • Version 7.4 of single sign-on (SSO) tools in Red Hat
  • Red Hat Fuse 7.7
  • Red Hat OpenShift API Designer 7.7
  • Red Hat Fuse Online 7.7
  • Microcks 1.1.0
  • Eclipse Che 7.22
  • Gogs (Persistent) 0.11.34
  • Apache CamelK 1.2.1
  • Integreatly Solution Explorer 2.22

Specifications

Cluster specification:

  • Nodes: Three master, one infra, number of users/5 worker nodes
  • Storage: NFS with 100 persistent volumes

City specification: Enter a city name of at least five characters.

Supporting Materials

Video demo

Access guide: You have full admin access to the provisioned workshop cluster and can find all the details needed to access your cluster in the guide.

User accounts

User accounts and access to required projects are created for the number of users specified. Each user can log in to their account with their userid and password credentials. The SSO is provisioned for signup to 3scale API Management, SSO realm, Gogs, Che, and Fuse Online for the user with their userid and password.

Users get started with the lab by logging into the Solution Explorer with their credentials. To start the workshop, share the Solution Explorer link and assigned userid and password with each user.

Provisioning time: Typically, approximately 120 minutes
