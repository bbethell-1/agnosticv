Vote App Openshift GitOps Demo

The aim of this demo is to show how to interconnect Tekton Continuous Integration (CI) capabilities to Argo CD enhanced features for Continuous Delivery (CD) with Red Hat OpenShift.

The flow of this demo is:

  • Create and start manually or automatically OpenShift Pipelines to build container images.
  • Edit code from CodeReady Workspaces.
  • Scan container images with Quay.io.
  • Sync application with OpenShift GitOps in Dev and Prod environments.

The demo is based on the Vote App 2-tier app (Python Flask frontend + Go backend).
