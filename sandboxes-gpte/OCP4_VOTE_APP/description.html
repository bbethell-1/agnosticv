Vote App Openshift GitOps Demo

This lab will guide you through the process of Inner and Outer loop development.

The Inner Loop part is done with OpenShift Dev Spaces to code, test, build and push changes to a Git repository.

The Outer Loop part is done with the interconnection of OpenShift Pipeline and OpenShift GitOps to build, deploy and sync apps in development and production environments.

Through this lab, you’ll learn how to set up and manage the entire application lifecycle within a Red Hat OpenShift cluster with a nice demo.

The flow of this demo is:

  • Create and start manually or automatically OpenShift Pipelines to build container images.
  • Edit code from OpenShift DevSpaces.
  • Sync application with OpenShift GitOps in Dev and Prod environments.

The demo is based on the Vote App 2-tier app (Python Flask frontend + Go backend).
