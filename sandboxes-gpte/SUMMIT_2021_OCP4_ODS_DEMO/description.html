Building AI / ML Models leveraging Red Hat OpenShift Data Science

As more and more enterprises build machine language (ML) models for intelligent applications (using tooling like Jupyter, PyTorch, and TensorFlow), deploying those models with CI/CD pipelines is becoming common practice. This hands-on lab walks participants through a traditional machine learning workflow, and shows how the new Red Hat OpenShift Data Science service can be used to engineer, train, and deploy an ML model, working with a real business use case. Lab activities include:
  • Experience the workflow of creating and using Jupyter notebooks on OpenShift
  • Import data from S3
  • Train and test a ML model
  • Deploy the model as a service

You will leave the workshop with an understanding of how to develop, test and train machine learning workloads using open source tools and Red Hat OpenShift Data Science.
