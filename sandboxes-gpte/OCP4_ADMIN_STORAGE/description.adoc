Learn administrative concepts in Red Hat OpenShift Container Platform 4. This asset describes a full-day experience introducing OpenShift Container Platform 4 administrative concepts. It contains several modules, most of which are standalone. When you request access to this asset, you receive one OpenShift Container Platform 4 cluster for each user specified.

*NOTE: This workshop doesn't have a 24/7 pre-rendered lab guide available. If you want to demonstrate to customers, you can either showcase the content from the GitHub source material or order/deploy your own cluster.*

*Product(s):* Red Hat OpenShift Container Platform
