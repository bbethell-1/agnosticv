Learn administrative concepts in Red Hat OpenShift Container Platform 4.

This asset describes a full-day experience introducing OpenShift Container Platform 4 administrative concepts. It contains several modules, most of which are standalone.

When you request access to this asset, you receive one OpenShift Container Platform 4 cluster for each user specified.

NOTE: The Windows Container Module has been temporarily removed.
