3scale - OpenShift Service Mesh Integration Demo

This demo provides an OpenShift cluster with OpenShift Service Mesh, Kiali, Jaeger, Red Hat SSO and 3scale API Management. The demo also includes a sample Microservices application (BookInfo), and the setting up of Service Mesh and API Management configurations in order to run the example.

The demo provides a guided instructions to run the following scenarios:

  • .Use Istio Ingress Gateway to access BookInfo gateway URL.
  • Use APIcast API Gateway to access the BookInfo URL secured through the API Gateway.
  • Use 3scale Istio Adapter to access the BookInfo URL through the Istio Ingress Gateway, secured with 3scale user key authentication.
  • Configure Red Hat SSO to use OIDC (Open ID Connect) Authentication to access the BookInfo URL using 3scale Istio Adapter
    • and Istio Ingress Gateway.

Cluster Specification

  • OpenShift Container Platform 4.7
  • Red Hat 3scale API Management 2.10
  • Red Hat Single Sign On 7.4
  • OpenShift Service Mesh 2.0
  • Kiali
  • Jaeger
  • Terminal
  • Integreatly Solution Explorer 2.22
