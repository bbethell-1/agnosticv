Explore scenarios using Red Hat 3scale API Management and Red Hat OpenShift Service Mesh. This demo provides an OpenShift cluster with OpenShift Service Mesh, Kiali, Jaeger, single sign-on (SSO) tools from Red Hat, and 3scale API Management. The demo includes a sample Microservices application (BookInfo) and shows setting up OpenShift Service Mesh and 3scale API Management configurations to run the example. The demo provides guided instructions to run the following scenarios:

* Use the Istio Ingress Gateway to access the BookInfo gateway URL.
* Use the APIcast API Gateway to access the BookInfo URL secured through the APIcast API Gateway.
* Use 3scale WebAssembly Module to access the BookInfo URL through the Istio Ingress Gateway, secured with 3scale user key authentication.
* Configure SSO to use Open ID Connect (OIDC) authentication to access the BookInfo URL using 3scale WebAssembly Module and the Istio Ingress Gateway.

*Product(s):* Red Hat 3scale API Management
