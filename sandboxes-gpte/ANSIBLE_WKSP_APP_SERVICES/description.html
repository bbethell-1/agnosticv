This workshop demonstrates how to use Red Hat Ansible Automation for Runtimes to manage the installation, configuration and lifecycle management of Red Hat JBoss Enterprise Application Platform (EAP). By using Red Hat certified Ansible collections, you will install and configure a highly available environment of EAP that is supported by a Load Balancer instance within Red Hat JBoss Core Services to share traffic across the EAP instances. In addition, you will also deploy and configure an instance of a PostgreSQL database to coincide with the deployment of an application which is also managed through Ansible Automation.

What you will learn:

  • Capabilities provided by Red Hat Ansible Automation for Runtimes to manage Red Hat JBoss Enterprise Application Platform.
  • Ansible Collections
  • Installing and configuring Red Hat JBoss Enterprise Application Platform using certified Ansible collections
  • Deploying JBoss EAP Applications on the JBoss EAP instances
  • Installing and configuring a PostgreSQL database using automation
  • Installing and configuring Red Hat JBoss Core Services to support load balancing traffic between Red Hat JBoss EAP instances
  • Application lifecycle management using Ansible automation
  • Application testing and validation approaches

Requesting this catalog items will provide you with a bastion machine running Visual Studio Code Server that can be used in the workshop. In addition, four (4) machines will be made available as automation targets for the various resources implemented throughout the workshop.
