= OpenShift 4 Disconnected Workshop
Welcome to the OpenShift 4 Disconnected Workshop! Here you'll learn to install and operate an OpenShift 4 cluster in a disconnected network, or one without access to the Internet (even through a proxy or firewall). This changes the way the cluster operates because things like container images, operator updates, and patches must be brought into the environment via mirroring.

== Workshop Architecture
This service is based on the AWS Blank Open Environment from RHDP, and it uses a VPC with private subnets protected by a Squid proxy to simulate the disconnected side. We'll create everything you're going to need during the workshop, including:

* A *web-based terminal* with the `aws` CLI pre-installed
* A **VPC** with public and private subnets to simulate the airgap
* A *prep system* on the connected side to download content and tooling
* A *bastion server* on the disconnected side which will both:
** Host the mirror registry, and
** Facilitate an IPI cluster install
