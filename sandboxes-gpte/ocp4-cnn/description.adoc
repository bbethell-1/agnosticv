== Overview

This catalog item deploys the CCN Road Show for the Developer Track on a dedicated OpenShift Container Platform 4 cluster. It uses the AgnosticD deployer and provides a shared cluster environment where each participant receives unique credentials.

Please be aware that this is new software and you may encounter bugs or random deployment failures. If you experience an issue, please try provisioning again.

=== Key Features

* **Dedicated OCP Cluster**: A single cluster is provisioned for all workshop participants.
* **Pre-provisioned Workspaces**: Each participant's Red Hat Dev Spaces workspace is pre-provisioned and started automatically to save time.
* **Centralized Infrastructure**: All infrastructure pods (Keycloak, Gogs, etc.) are deployed in the `labs-infra` project.

=== Access & Provisioning

* **Provisioning Time**: Approximately 75 minutes.
* **Confirmation Email**: After ordering, you will receive an email with links for participants and separate admin credentials for cluster management.
* **Note**: Provisioning time may increase depending on the number of participant seats ordered, as developer workspaces are started in the background.
