Deploy the Containers and Cloud-Native (CCN) Road Show for Dev Track using AgnosticD.

This catalog item deploys the CCN RoadShow for Dev Track on Red Hat Openshift Container Platform 4 using the AgnosticD deployer.

Please note that this is new software and as such, you might run into some bugs, or deployments might fail randomly. If you experience this, please try provisioning again.

All infra pods--for example, Red Hat Dev Spaces, keycloak, gogs--are deployed in the "labs-infra" project.

Here are the modules that you deliver in the Dev Track:

  • Module 1: Optimizing Existing Applications
  • Module 2: Debugging, Monitoring, and Continuous Delivery
  • Module 3: Control Cloud Native Apps with Service Mesh
  • Module 4: Advanced Cloud Native with Event-Driven Serverless

Requesting this catalog item provides you with a single dedicated OpenShift Container Platform 4 cluster that each participant shares. The cluster uses per-participant credentials for OpenShift Container Platform and Red Hat Dev Spaces. Each participant's developer workspace is pre-provisioned and started up in Red Hat Dev Spaces so they can get started quickly.

After you order this catalog item, you receive an email with links to connect to the workshop that you can share with participants, along with admin credentials in case you need to log in and do housekeeping or other changes.

Note that developer workspaces are started in the background. Depending on how many participant seats you order, it might take longer to complete provisioning.

The source material also has instructions to render the lab guide without ordering this catalog item, if you want to see what participants will see and experience.
