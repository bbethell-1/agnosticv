A Validated Pattern that assists with image-based medical diagnosis. Validated Patterns are living GitOps-based architectures which focus on customer solutions that involve multiple Red Hat products and ongoing CI to avoid bitrot. This Validated Pattern highlights an architecture that uses Machine Learning to assist with image-based medical diagnosis. This approach enables doctors to provide faster results to patients and to focus on cases where their training adds the most value. Red Hat provides example applications that you can modify or replace to suit customers and market segments with similar business problems. This demo provides a specific example for analyzing chest xrays for signs of pneumonia. This analysis is achieved by: Ingesting chest xrays into a Ceph object store Posting notifications of new results to a Kafka topic Using a KNative Eventing Listener to listen for notifications and trigger a KNative Serving function Using an ML-trained model to assess the xray for risk of pneumonia Including a Grafana dashboard to display the pipeline in real time, along with images incoming, processed and anonymized, as well as full metrics

*Products:* Red Hat OpenShift Container Platform, Red Hat OpenShift GitOps (ArgoCD), Red Hat Advanced Cluster Management, Red Hat AMQ Streams (Apache Kafka Event Broker), Red Hat OpenShift Data Foundation, Red Hat OpenShift Serverless, Open Data Hub, and Grafana

===== Specifications

* 3 Leader Nodes (m5.2xlarge)
* 2 Worker Nodes (m5.4xlarge)
* Cluster version: 4.9.z (latest stable)
* Let's Encrypt certificates enabled for default ingress
