= Azure Red Hat OpenShift (ARO4) Workshop

This catalog item deploys Azure Red Hat OpenShift on OpenShift 4 (ARO4) for the purposes of running workshops for qualified opportunities.

READ AND UNDERSTAND THE LAB GUIDE BEFORE DEPLOYING.

== Workshop Characteristics

Azure Red Hat OpenShift link:https://docs.microsoft.com/en-us/azure/openshift/intro-openshift[overview, window="_blank"]

* 3 masters, 3 computes. Masters are Standard_D8s_v3, Workers are Standard_D4s_v3.
* Region: North America, Europe, APAC

== Provisioning Time

~35 min

== Default Lifespan of Environment

* 2 Days
* Extensions Available - Yes

== Default Runtime of Environment

* Environment does not Idle

== Access Information

Cluster web console are sent in the final email, credentials are in the Lab Guide
