This workshop creates Base RHODS environment on ROSA(Red Hat OpenShift Service on AWS) cluster. You can use this base environment for creating and running RHODS related use cases on ROSA.

This workshop includes :

OpenShift Container Platform

Red Hat OpenShift Data Science

OpenShift Cluster configured on ROSA

Red Hat OpenShift Pipelines

Red Hat OpenShift GitOps

Red Hat OpenShift Serverless

Web Terminal

Gitea

Access Information:

You will receive an email with link to your RHDP service, select that link and access the credentials to access the lab.

Use cognito to login to the OpenShift UI.

Provisioning Time:

Approximately 1 hour 20 mints
