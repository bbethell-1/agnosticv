Build a cloud-native application and get experience with Red Hat products and services.

This catalog items guides you through the process of building a cloud-native application that uses two Red Hat OpenShift Container Platform clusters. You get hands-on experience using OpenShift Container Platform, Red Hat OpenShift Service Mesh (Istio, etc.), Red Hat OpenShift Serverless (Knative and CamelK), and the AMQ streams technology in Red Hat AMQ (Apache Kafka).

Topics include:

  • The benefits of using OpenShift Service Mesh for microservices
  • How to use CamelK for event-processing data from AMQ streams
  • How Knative can drive efficient use of resources on OpenShift Container Platform
