This session guides participants through the process of building a cloud-native application that uses two OpenShift clusters. The session provides hands-on experience using Red Hat OpenShift Container Platform, Red Hat OpenShift Service Mesh (Istio, etc.), Red Hat OpenShift Serverless (Knative and CamelK), and the AMQ streams technology in Red Hat AMQ (Apache Kafka).

Session topics include the benefits of using a Service Mesh for MicroServices, how to use CamelK for event-processing data from AMQ streams, and how Knative can drive efficient use of resources on OpenShift Container Platform.
