= Red Hat Virtualization on ROSA

The Red Hat Virtualization on ROSA demo showcases the integration of Red Hat OpenShift Virtualization with Red Hat OpenShift Service on AWS (ROSA), utilizing the Hosted Control Plane architecture. This demo environment is pre-configured with OpenShift Data Foundation and the Red Hat OpenShift Virtualization Operator, providing a seamless experience for running and managing virtual machine (VM) workloads alongside container workloads.

== Demo Overview

Red Hat OpenShift Virtualization is an add-on to Red Hat OpenShift Service on AWS that empowers users to handle VM workloads using Kubernetes custom resources. This demo illustrates how OpenShift Virtualization adds new objects to your ROSA cluster, enabling a range of virtualization tasks such as:

* Creating and managing both Linux and Windows virtual machines.
* Running pod and VM workloads together in a single cluster.
* Connecting to virtual machines via various consoles and CLI tools.
* Importing and cloning existing virtual machines.
* Managing network interface controllers and storage disks attached to virtual machines.
* Live migrating virtual machines between nodes to ensure continuous availability and performance.

For detailed steps and configurations, please refer to the https://github.com/your-repository-link[GitHub repository] which provides comprehensive instructions and resources for running this demo environment.
