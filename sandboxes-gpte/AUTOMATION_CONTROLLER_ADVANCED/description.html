Ansible Automation Controller for Advanced Users

With the release of Red Hat Ansible Automation Platform 2, Ansible Automation controller is the new name of Ansible Tower. As this workshop is for experienced Ansible users, you'll learn more about capabilities for Ansible automation controller. You'll configure the Automation controller without utilizing the UI and become familiar with the clustering feature and instance groups. You'll get an overview of Automation Mesh, smart and dynamic inventories are demystified, you’ll explore the automation controller API and then work on setting up a well-structured Git repository for use with Automation controller. Experienced Ansible Automation Platform users with an inside look at the capabilities of the automation controller.
