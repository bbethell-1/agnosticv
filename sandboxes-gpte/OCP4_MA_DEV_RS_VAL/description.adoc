Learn about Modern App Development. You can select which modules you want to run for your event. In this one-day hands-on workshop with multiple modules, participants will learn about modern app development across the following 6 modules.

== Important Note

It is advised to not stop your workshop cluster before your workshop as you might have a few issues restarting the virtual machines or pods when you restart the workshop cluster. Please create a ticket to request disabling auto stop https://red.ht/rhpds-help[here^]
