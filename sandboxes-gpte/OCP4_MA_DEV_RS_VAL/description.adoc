= Modern App Development Roadshow (Restricted)

[IMPORTANT]
====
Restricted to users of rhpds-mad-test only
====

Learn about Modern App Development. You can select which modules you want to run for your event.

In this one-day hands-on workshop with multiple modules, participants will learn about modern app development across the following 7 modules:

. Module 1: Assessment and Analysis
. Module 2: Refactor and Deployment
. Module 3: Enable CI/CD Pipeline and GitOps
. Module 4: Manage and Secure APIs
. Module 5: Build Event-driven Architecture
. Module 6: Create an Intelligent Application
. Module 7: Accelerating Software Development with Red Hat Developer Hub

== Important Note

It is advised to not stop your workshop cluster before your workshop as you might have a few issues restarting the virtual machines or pods when you restart the workshop cluster. Please create a ticket to request disabling auto stop link:https://red.ht/rhpds-help[here, window="_blank"].
