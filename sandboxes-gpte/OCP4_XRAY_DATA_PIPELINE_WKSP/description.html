In this lab you’ll learn how to create a data pipeline that is able to ingest chest XRay images, classify them according to the risk of pneumonia using a trained machine learning model, and anonymize them to retrain the model! But don’t worry, no prior AI/ML knowledge is required. This pipeline will allow you to use different tools from Red Hat’s portfolio like OpenShift Data Foundation, OpenShift Serverless, AMQ Streams... Note: the lab can be used both as a demo (everything is fully deployed for the first user), or as a workshop where multiple students will learn how to build the pipeline.
