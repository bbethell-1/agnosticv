XRay Data Pipeline workshop

This workshop demonstrates how to create a Data Pipeline that ingests chest XRay images, classifies them according to the risk of pneumonia inferred using a machine learning model, and anonymizes them to retrain the model. But do not worry, no prior AI/ML knowledge is required!

This pipeline will allow you to use different tools from Red Hat’s portfolio like:

  • OpenShift Data Foundation
  • OpenShift Serverless
  • AMQ Streams
  • Open Data Hub

Important notes

  • This workshop can be used both as a demo, or as a real workshop where multiple students will learn how to build the pipeline.
    When ordering the lab, select your number of users plus one. A workshop environment will be deployed for all of the users on a shared OpenShift cluster, but the first environment will also have to full content pre-executed. This environment can therefore be used as a ready-to-use demo of the pipeline.
    This also means that if you want to only show a demo of the pipeline, without the workshop part, you can simply order it for one user, it will be quicker to deploy.
  • When ordering the lab, please select the Small size to get at least 3 worker nodes as they are necessary to install OpenShift Data Foundation.
  • Deployment time: 1-3 hours depending on the number of users (do not exceed 50!)
