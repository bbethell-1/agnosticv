In this lab you’ll learn how to create a data pipeline that is able to ingest chest XRay images, classify them according to the pneumonia or Covid19 risk using a trained machine learning model, anonymize them, retrain the model, and finally automatically redeploy this new model! But don’t worry, no prior AI/ML knowledge is required.
This pipeline will allow you to use different tools from Red Hat’s portfolio like OpenShift Container Storage, OpenShift Serverless, AMQ Streams...
