In this lab you’ll learn how to create a Data pipeline that is able to ingest chest XRay images, classify them according to the risk of pneumonia using a trained machine learning model, and anonymize them to retrain the model! But don’t worry, no prior AI/ML knowledge is required.

This pipeline will allow you to use different tools from Red Hat’s portfolio like OpenShift Data Foundation, OpenShift Serverless, AMQ Streams...

Note: the lab can be used both as a demo, or as a workshop where multiple students will learn how to build the pipeline.
When ordering the lab, select the number of users. The Lab environment will be deployed for all of them, but the first one will also have to full Lab content pre-executed. This first environment can then be used as a demo for the working pipeline.
This also means that if you want to only show a demo of the pipeline you can simply order it for one user, it will be quicker to deploy.
