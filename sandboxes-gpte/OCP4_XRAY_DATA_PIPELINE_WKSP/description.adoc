Create a data pipeline that ingests, classifies, and anonymizes chest X-ray images. This catalog items demonstrates how to create a data pipeline that ingests chest X-ray images, classifies them according to the risk of pneumonia inferred using a machine learning (ML) model, and anonymizes them to retrain the model. No prior artificial intelligence (AI) or ML knowledge is required. This pipeline allows you to use the following tools:

* Red Hat OpenShift Data Foundation
* Red Hat OpenShift Serverless
* The AMQ streams component of Red Hat AMQ
* Open Data Hub open source project

This asset can be used either as a demo or as a real workshop where multiple students learn how to build the pipeline. When ordering the lab:

* Select your number of users plus one. A workshop environment is deployed for all of the users on a shared Red Hat OpenShift Container Platform cluster, but the first environment needs to be full content pre-executed. This environment can therefore be used as a ready-to-use demo of the pipeline. If you want to only show a demo of the pipeline, without the workshop part, you can simply order it for one user. This makes deployment faster.
* Select the *Small* size to get at least three worker nodes, as they are necessary to install OpenShift Data Foundation.
