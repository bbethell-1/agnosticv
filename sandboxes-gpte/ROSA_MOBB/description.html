Building a Modern Application Platform with AWS & ROSA

Welcome to the Building a Modern Application Platform workshop. In this workshop participants will learn the building blocks of modern application platform and leverage Amazon Web Services (AWS) and Red Hat OpenShift Service on AWS (ROSA) to build a modern application platform.

Deployment parameters: You can customize the workshop based on the following parameters when ordering the workshop:

  • ROSA Token: You may provide your own token from https://console.redhat.com. If you do not provide your own token, you will not be able to see the deployed ROSA clusters in your Red Hat Console.
  • Region: You may choose any region close to you.
  • Deploy ROSA: Leaving this box unchecked will allow the workshop participats to install ROSA themselves. Checking this box will deploy a classic ROSA cluster.
  • Deploy ROSA using a Hosted Control Plane: When checked will deploy a ROSA cluster with a Hosted Control Plane. Only used when "Deploy ROSA" is checked.
  • Set up cluster admin in ROSA: Create a cluster administrator user. If unchecked workshop participants will be able to create their own cluster admin user. Only used when "Deploy ROSA" is checked.
The Workshop Guide will adjust based on the parameters you choose (for example if you choose "Deploy ROSA" then the workshop guide will not include the section on deploying ROSA). ATTENTION: The workshop guide is written for Classic ROSA - if you deploy with a Hosted Control Plane some instructions will be different.

Deployment time:

  • ROSA not installed: Approximately 10 minutes.
  • ROSA Classic installed: Approximately 15 minutes.
  • ROSA with Hosted Control Plane installed: Approximately 35 minutes.

Who this workshop is for: This workshop is aimed at Platform Engineers, DevOps Engineers, CLoud Operations, Architects, and Developers that want to learn what makes a modern application platform, and how they can leverage cloud services to streamline the delivery and operations of their application platforms.

What to expect: During the workshop, we will take you through a series of hands on exercises to help you understand some of the concepts of modern application platforms.

Attendees will learn:

  1. How to deploy a Red Hat OpenShift Service on AWS (ROSA) cluster (optional based on deployment options)
  2. Complete Day 2 operations tasks including: configuring node and cluster scaling policies, configuring managed upgrades, configuring single-sign-on for the cluster using Amazon Cognito, and forwarding logs to Amazon CloudWatch.
  3. Deploy an application that uses AWS IAM Roles for Service Accounts and AWS STS to connect to an Amazon DynamoDB table.
  4. Make an application on OpenShift scalable and resistant to node failures and upgrades
  5. Deploy an application using CI/CD tooling, including OpenShift GitOps and Source-to-Image, and use labels for deterministic app placement on nodes.
  6. Learn how to use OpenShift Service Mesh for application observability and tracing
After completing this workshop, attendees will understand the concepts of modern application platforms, and will have begun to lay the foundations in their provided AWS infrastructure.
