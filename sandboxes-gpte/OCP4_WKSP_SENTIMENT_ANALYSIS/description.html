Building sentiment analysis with Kafka and AI/ML

A great introduction to the "power of together" of Kafka and AIML using Red Hat technologies. This intro is followed with a live demo demo based showing a use case of sentiment analysis for a fictitious retail customer. Participants will be invited to join in the live demo while showcasing this use case.

Cluster Specification

  • 3 Masters Nodes (AWS instance type: m5.2xlarge)
  • Number of nodes dependant on the size ordered (AWS instance type: m5.4xlarge)
  • Cluster Version: 4.12.x
  • Authentication Enabled (htpasswd - refer to your provisioning e-mail for details)
  • Let’s Encrypt Certificates enabled on Ingress Controllers
  • RHODS
