Welcome to Advanced Ansible Network Automation Workshop where you will learn advanced Ansible automation techniques for managing networking, meaning, switches and routers mainly. This includes how to approach configuration management, where the students learn techniques that scales to many tens of thousands of devices. It also teaches how to deal with different common operational tasks that network engineers deal with most commonly, such as troubleshooting, backups and more.

What is the difference between the normal Ansible networking workshop and this? This workshop teaches advanced best practice methods to manage network elements - focusing on what network engineers do on the daily,. The normal Ansible networking workshop only briefly introduces automation for network devices. The workshop was created as a strategic customer of ours requested a deep dive course for network automation. It's been run multiple times for different customers successfully.
