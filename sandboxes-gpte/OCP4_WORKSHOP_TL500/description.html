TL500 DevOps Culture and Practice Workshop

This workshop sets up the OpenShift infrastructure so you can run the TL500 DevOps Culture and Practice Enablement technical exercises as a workshop yourself.
Requesting this catalog item will provide you with a single dedicated OpenShift 4 cluster that includes the Enablement Framework software.
An instance of FreeIPA is deployed within the cluster with pre-provisioned learner users that is integrated into the cluster single sign on and deployed tooling.
Once you order this catalog item, you'll receive an email with links to connect to the workshop, along with admin credentials.
All of the instructions for using this workshop are published here
