The Open Environments project gives Red Hatters on demand access to a number of different cloud services. These timebound sandboxes offer access to many of the clouds that our customers use, and will enable associates to test, create, and demo the technologies needed to help make our customers and account teams successful. These Sandboxes will allow users to do things not previously offered.

This catalog item will deploy a Red Hat OpenShift Service on AWS (ROSA) cluster.

You are provided with
  • A bastion host that has the ROSA CLI pre installed and configured
  • SSH credentials for the bastion host
  • A basic ROSA cluster already built and running with node scaleup disabled
  • The ROSA cluster URL and cluster-admin credentials
Environment Specifications
  • Red Hat OpenShift Hub Cluster
    • m5.2xlarge Leader Nodes: 3
    • m5.xlarge Worker Nodes: 2
    • r5.xlarge Infra Nodes: 2
Additional Info

You can SSH into the bastion host and run the ROSA cli commands as documented here You can also log into the cluster web UI using the provided credentials.

WARNING: Do NOT use the rosa logout command or you will lose connectivity to your cluster rendering it useless! When this service is retired in RHPDS, the ROSA cluster will be automatically torn down for you. You do not need to do this manually.
