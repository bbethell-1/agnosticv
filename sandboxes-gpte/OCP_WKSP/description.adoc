Provision a cluster in Red Hat OpenShift Container Platform with basic customizations.

This asset provides an OpenShift Container Platform cluster with basic customizations on an AWS infrastructure for running hands-on-labs, workshops, and similar events where no specialized environment is available.

Refer to the catalog for specialized workshops such as Containers and Cloud-Native Roadshow, OpenShift Getting Started Workshops, and so on.

== Products

* Red Hat OpenShift Container Platform

== Specifications

* Number of controllers: 3
* Number of workers: depends on the number of users specified (3 min + 1 per 5 users)
* Cluster versions available:
** 4.16
** 4.17
** 4.18
** 4.20 (default)
* Authentication enabled (refer to your provisioning email for details regarding the actual credentials)
* Certificates enabled on ingress controllers

[NOTE]
====
OpenShift 4.19 has been removed as an option from this item due to a bug that prevents
the cluster from starting when it was stopped during the first 24 hours.

If you need a 4.19 cluster, you can order an Open Environment and deploy it yourself.
====
