=== Purpose

This is an internal component catalog item. It provides an AWS Blank Open Environment with restricted sandbox API reservation policy. It is referenced as a sub-component by catalog items that need controlled sandbox allocation.

=== Do Not Order Directly

If you need an AWS Open Environment, use the standard *AWS Blank Open Environment* (SANDBOX_OPEN) catalog item instead.
