= Workshop: Using GitOps to Control and Customize your OpenShift Clusters and Applications

This workshop provides a comprehensive introduction to the basics of OpenShift GitOps and Argo CD.

By the end of the workshop the attendees will understand GitOps, concepts such as Argo CD Sync Waves, RBAC and the "App of Apps" pattern, how to use Kustomize and Helm with OpenShift GitOps, and how to to manage cluster-scoped and application-scoped resources on their OpenShift cluster. A full breakdown of the lab can be seen link:https://redhat-scholars.github.io/summit-2023-gitops-lab-guide/summit-2023-gitops-workshop-guide/main/m1-overview/intro.html[here in the instructions, window="_blank"].

This workshop provisions an OpenShift cluster for each attendee. Make sure to check the *Enable workshop user interface* at provisioning time and to increase the *Workshop User Count* to your desired capacity when ordering the item.
