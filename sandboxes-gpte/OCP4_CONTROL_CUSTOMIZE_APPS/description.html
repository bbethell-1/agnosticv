Using GitOps to Control and Customize your OpenShift Clusters and Applications

The OpenShift GitOps Workshop takes users through the basics of using the OpenShift GitOps solution. It includes exercises on simple deployments with GitOps, how to use Kustomize, and how to use Sync Waves and Hooks.

The workshop uses a single, shared cluster for all users and pre-provisions an Argo CD instance along with distinct namespaces for each user.

Cluster Specification

  • 3 Masters Nodes (AWS instance type: m5.2xlarge)
  • Number of nodes dependant on the size ordered (AWS instance type: m5.4xlarge)
  • Cluster Version: 4.10.x
  • Authentication Enabled (htpasswd - refer to your provisioning e-mail for details)
  • LimitRanges enabled
  • Let’s Encrypt Certificates enabled on Ingress Controllers

Access Guide

You have full admin access to the provisioned workshop cluster, which is a vanilla OpenShift 4.10 cluster.
