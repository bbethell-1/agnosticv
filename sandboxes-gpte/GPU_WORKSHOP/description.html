OpenShift NVIDIA GPU Workshop

OpenShift Workshop provisions an OpenShift cluster with NVIDIA V100 Tensor Core GPUs and basic customizations on AWS infrastructure for running hands-on-labs, workshops and similar events where Machine Learning and AI workloads are being demonstrated.

This is a general purpose AI/ML workshop and overtime more specialized ones will be developed to highlight specific use cases using Open Data Hub and/or our partners technology stacks.

Cluster Specification

  • 3 Control plane nodes (AWS instance type: m5a.2xlarge)
  • 2+ compute nodes (AWS instance type: p3.2xlarge)
  • Cluster Version: 4.6.x
  • Authentication Enabled (htpasswd - refer to your provisioning e-mail for details)
  • LimitRanges enabled
  • Let’s Encrypt Certificates enabled on Ingress Controllers
