Explore an environment for Red Hat Advanced Cluster Security for Kubernetes.

Using the latest product environment (LPE), this catalog item presents an environment for Red Hat Advanced Cluster Security (RHACS) for Kubernetes.

Product(s): Red Hat Advanced Cluster Security Cloud Service

Specifications

Cluster specification:

  • Red Hat OpenShift Container Platform cluster version: 4.13
  • Authentication enabled
  • RHACS version 4.2
  • Let’s Encrypt certificates enabled on ingress controllers

Access information: You receive an email with:

  • The cluster admin credentials
  • Administrative credentials and the URL to access the RHACS portal

Provisioning time: Typically 1 hour
