This environment is purpose build for demos of Red Hat Advanced Cluster Security for Kubernetes.

*Demo Script*: Please review and use the https://docs.google.com/document/d/1nwCp0oVcVwHwkc6iGtyOijng6NRpRv3eZoZHuuN1jUw/edit?usp=sharing[ACS 4.7 Demo Script] for a complete walthrough of the product and a great start for demoing the product with customers

*Product(s)*: Red Hat Advanced Cluster Security Cloud Service

.Cluster specification:
* RHACS version 4.7
* Red Hat OpenShift Container Platform cluster version: 4.18
* Authentication enabled
* Let's Encrypt certificates enabled on ingress controllers

.Important notes:
* Please FOLLOW ALL OF THE SETUP INSTRUCTIONS in the demo script.
* Review all of the information in the demo script file before starting the demo.
* These environments are only available for a limited amount of time after they are provisioned. Please be mindful of stop and delete times.

Accessing the environment:

.You receive an email with:
* The cluster admin credentials and the OpenShift Console URL
* RHACS admin credentials and the RHACS Central URL
* SSH credentials with the Bastion host address URL

*Provisioning time*: 1-1.5 hours
