Introducing llm-d: Your Production-Ready Path to Scalable LLM Inference

Understand llm-d well lit paths:
Intelligent inference scheduling over any vLLM deployment
Prefill /Decode disaggregation
Wide expert parallelism for DeepSeek R1 (EP/DP)
Ability to Perform llm-d-based distributed inference deployments
Compare performance scaling characteristics of naive vLLM scaling and well-lit paths for distributed inference
Be well versed in advanced LLM inference topics e.g. 
KV Cache
Prefill / Decode
Wide Expert Parallelism / Data Parallelism
Describe llm-d use cases e.g. 
High-traffic multi-tenant LLM service (MaaS)
Large model / long-context / high latency sensitivity workloads
Improved latency & throughput for chat or agent platforms

There will be an expectation that attendees already understand vLLM and generative AI inference in practice. We will focus on llm-d in the session, and will not start with foundational understanding objectives like learning transformers, basics of vLLM KV Cache, basic benchmarks for generative AI inference including concepts such as TTFT and ITL, etc.
