This is the environment to showcase how to build the Edge Applications: A Retail Odyssey with Red Hat OpenShift, AI/ML, and Application Services.

== Cluster Specification

* 3 Masters  Nodes (AWS instance type: m5.2xlarge)
* Number of nodes dependant on the size ordered (AWS instance type: m5.4xlarge)
* Cluster Version: 4.13.x
* Nvidia GPU ((AWS instance type: g5.2xlarge)
* Authentication Enabled (htpasswd - refer to your provisioning e-mail for details)
* Let’s Encrypt Certificates enabled

== Red Hat Products

* Red Hat OpenShift AI
* Red Hat OpenShift Data Science
* Red Hat OpenShift GitOps
* AMQ Streams
* AMQ Broker
* Apache Camel K
* Edge-to-Core Data Pipelines
