== Openshift Security Roadshow

The Openshift Security Roadshow is a comprehensive hands-on lab to dive into why Red Hat OpenShift is a trusted, consistent, comprehensive platform for building, deploying, managing, and protecting applications running anywhere. It focuses on Red Hat Advanced Cluster Security and teaches the basics of Kubernetes and container security.

== Lab outline

Module 00 - Setup

* Install demo applications
* Navigating the lab
* Creating and downloading applications
* Setting up a simple pipeline

Module 01 - Visibility

* Understanding dashboards, policies, risks

Module 02 - Vulnerability management

* Understanding vulnerabilities
* Triaging vulnerabilities
* Vulnerability workflow

Module 03 - Risk profiling

* Understanding Kubernetes security misconfigurations
* Review how ACS prioritizes risk 
* Create workflows to deal with “high-risk” issues

Module 04 - Policy Management

* Review policy management and understand inform vs. enforce options
* Create build, deploy and runtime policies

Module 05 - CI/CD integration/automation

* Integrate build, and deploy policies into a pipeline

Module 06 - Compliance

* Install and integrate the compliance operator
* Review the compliance dashboard
* Implement policies to ensure application compliance

Module 07 - Notifications

* Setup reoccurring reports based on groups/labels
* Setup break glass alerts in the event of outage/issues

Module 08 - API walkthrough

* Looking for information on how customers will use the API?
* What are they trying to solve?

Module 09 - Networking

* Review how to create and enforce network policies
* Use the roxctl CLI to generate network policies

Module 10 - Cloud Service and Secured Cluster installation 

* Sign up for the RHACS free trial
* Utilize the init bundle and secured cluster services to onboard an EKS cluster.
