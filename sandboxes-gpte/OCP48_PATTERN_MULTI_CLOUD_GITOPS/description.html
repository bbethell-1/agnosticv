Red Hat Validated Patterns

Multi-Cloud GitOps

Validated Patterns are a living GitOps based architectures with a focus on customer solutions involving multiple Red Hat products, and ongoing CI to avoid bitrot.

Example applications are provided for demonstration purposes and can be modified/replaced to suite customers and/or market segments with similar business problems.

Read more about Validated Patterns.

This Validated Pattern is a foundational architecture that uses Advanced Cluster Management and ArgoCD to deliver application subscriptions and the associated configuration defined in Git to a heirarchy of OpenShift clusters.

This is achieved by

  • Providing Helm templates that allow the namespaces and applications that need to be delivered to a set of managed cluster to be defined
  • Using the ArgoCD "app-of-app" pattern to deliver the applications to each cluster
  • Using Advanced Cluster Management to deliver the top-level ArgoCD application to managed clusters
  • Integrating with Hashicorp vault to securely deliver secrets to managed clusters from the central hub

Read more about the Multi-Cloud GitOps Pattern.

Use cases

  • Using a GitOps approach to roll out and maintain application subscriptions and the associated configuration
  • Using a GitOps approach to centrally manage multiple clusters and including workloads
  • How to securely manage secrets across multi-cloud deployments.

Red Hat products and solutions

  • Red Hat OpenShift GitOps (ArgoCD)
  • Red Hat Advanced Cluster Management
  • Hashicorp Vault
  • External Secrets

Deployment Instructions

This item currently requires you to manually deploy the workloads. You can find instructions on deploying the Multi-Cloud GitOps demo TBD.

Environment

  • 3 Master Nodes (m5a.2xlarge)
  • 2 Worker Nodes (m5a.2xlarge)
  • Cluster version: 4.8.z (latest stable)
  • Let's Encrypt certificates enabled for default ingress
