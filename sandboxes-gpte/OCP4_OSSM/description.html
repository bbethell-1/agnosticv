Use this lab to get guidance through an opinionated view on how an enterprise, with multiple business divisions, would organise stakeholders to deliver a Service Mesh Application Service capability to its platform and applications taking them from Development all the way to Production.

The OSSM has excellent documentation to help become familiar with the various components and capabilities which can be delivered via the mesh. However, these guides are missing a set of real-world fully-implemented requirements that would give patterns of design, governance and best practices, while also reflecting on possible shortcomings and decisions to be made.

These labs will take the participants through the Travel Agency company’s efforts to capture requirements, distribute user responsibilities in delivering the Travel Demo application to production within Service Mesh.

You will deliver and get hands-on experience with:

  • Designing the Service Mesh Perimeter
  • Defining a Service Mesh Operating Model
  • Creating a Service Mesh Development Environment
  • Using the Observability Stack as different Enterprise Personas
  • Setting Up a Production Environment including:
    • Storage for the components
    • Scaling various service mesh components
    • External Jaeger
    • Securing the components
  • Setting up Authn & Authz on Gateways with MTLS and JWT Token
  • Applying business authorisation restrictions
  • Applying corporate CA certificates for mesh encryption
  • Day-2 Operations on the mesh

Duration: 2-3 hours

Audience: Experienced with Istio
