This demo and hands-on lab will guide you through an opinionated view on how an enterprise, with multiple business divisions, would organise stakeholders to deliver a Service Mesh Application Service capability to its platform and applications taking them from development all the way to production.

You will deliver and get hands-on experience with:

* Designing the Service Mesh perimeter
* Defining a Service Mesh operating model
* Creating a Service Mesh development environment
* Using the observability stack as different enterprise personas
* Setting up a production environment including:
  ** Long-term persistence storage for Service Mesh control plane components
  ** Scaling Service Mesh control &amp; data plane (istiod, gateways, etc.)
  ** External Jaeger with Elastic Search storage
  ** Jaeger Agent sidecar for production
  ** Securing the components
* Setting up Authn &amp; Authz on Gateways with MTLS and JWT Token
* Applying business authorisation restrictions
* Applying corporate CA certificates for mesh encryption
* Day-2 operations on the mesh
