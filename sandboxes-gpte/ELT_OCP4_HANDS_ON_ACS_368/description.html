Hands-On with RHACS 3.68

This is an OpenShift environment running RHACS with a number of demo apps deployed into the cluster. The labs will:

  • Highlight new features in 3.68
  • Review the primary use cases of RHACS

Cluster Specification

  • 1 Control Plane/Worker Node (AWS instance type: m5a.4xlarge)
  • Cluster Version: 4.9
  • Authentication Enabled (htpasswd - refer to your provisioning e-mail for details)
  • Let’s Encrypt Certificates enabled on Ingress Controllers

Access Information

You will receive an email with both the cluster admin credentials as well as administrative credentials and the URL to access Stackrox.
