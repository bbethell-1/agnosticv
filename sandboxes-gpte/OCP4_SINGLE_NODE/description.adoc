This asset provisions an OpenShift cluster with basic customization on AWS infrastructure. You can use this cluster for hands-on labs, workshops, and other events when a specialized environment is not available. For specialized workshops (such as Containers and Cloud-Native Roadshow, OpenShift Getting Started Workshops, etc.), use the dedicated catalog item for that workshop.
