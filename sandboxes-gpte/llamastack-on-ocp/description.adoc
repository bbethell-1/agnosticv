This lab provides a comprehensive, hands-on experience developing intelligent AI agents with OpenShift, Llama Stack and MCP (Model Context Protocol).
You will learn to build agents capable of utilizing both internal knowledge bases and external web resources, as well as interacting directly with a live OpenShift environment.
All of this will be done through a series of progressive Jupyter notebooks on Red Hat OpenShift AI (RHOAI).

NOTE: This is an *alpha* release. Please log feedback and issues using the link in the Support section below.

=== Objectives:

* Integrate RAG, AI agents, and MCP tools to build sophisticated automated systems, such as an incident response system within OpenShift. 
* Gain practical experience using AI agents for effective communication and task automation within platforms like Slack and OpenShift, using MCP tools.

=== Products & Tools

* OpenShift 4.18
* OpenShift AI
* Llama Stack
* OpenShift MCP Server
* Slack MCP Server
* Geo-location Custom Tool
* Web Search Tool
* RAG tool
