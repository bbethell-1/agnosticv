Learn about Modern App Development. You can select which modules you want to run for your event.

In this one-day hands-on workshop with multiple modules, participants will learn about modern app development across the following 6 modules.

Important Note

It is advised to not stop your workshop cluster before your workshop as you might have a few issues restarting the virtual machines or pods when you restart the workshop cluster. Please create a ticket to request disabling auto stop here

Agenda:

  1. Module 1: Assessment and Analysis
  2. Module 2: Refactor and Deployment
  3. Module 3: Enable CI/CD Pipeline and GitOps
  4. Module 4: Manage and Secure APIs
  5. Module 5: Build Event-driven Architecture
  6. Module 6: Create an Intelligent Application
  7. Module 7: Accelerating Software Development with Red Hat Developer Hub

Duration: One day (e.g. 7 hrs)

Audience: Developer, Architect, and Data Scientist

Products: Red Hat OpenShift Container Platform, Red Hat Runtimes, Red Hat Application Foundation and more.

Specifications

This demo deploys a shared OpenShift cluster on AWS.
