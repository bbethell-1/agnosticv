FSI Open API Sandbox

The Red Hat branded Open API Sandbox is a predefined stack and APIs based on UK CMA open banking standards with mock data. Other specifications from bodies, such as STET and BIAN are also expected to be made available. A Red Hat branded 3scale developer portal is made available to explore and try the predefined APIs against sample data that is hosted on a RedHat Managed Integration environment. Back end APIs and mock data are deployed to illustrate the full power of a modern platform for microservices.

This workload provisions all the required infrastructure for the Red Hat FSI Open API Sandbox on OpenShift 4. The following are provisioned:

  • 3scale Operator
  • 3scale API Manager 2.9 (using RWO System Storage or S3 compatible provider)
    • Gateway Operator 2.9
    • Portal Endpoint secret for connecting to corresponding 3scale tenant admin
    • Staging API Gateway
  • Microcks Operator 0.3.0
    • Microcks instance
  • The AgnosticD Minio role (a S3 compatible provider)
  • Preconfigured Open APIs solution scenario
    • ActiveDocs configuration of standard APIs from UK Open Banking
    • Mock data used to provide endpoints responses
    • 3scale API CRDs (Backend and Product)
    • Developer Portal customized

    Expected engagement journey with targeted Open Banking prospects:

    1. Sandbox: Free to use service to build awareness, collect leads and generate new opportunities.
    2. Pilot: A timed evaluation for qualified opportunities to evaluate the service/software
      • Nodes: 1 master, 1 infra, num-of-users/7 nodes
      • Storage: NFS with 100 persistent volumes
