Linux containers provide convenient application packaging and runtime isolation in multi-tenant environments. The security implications of running containerized applications, however, are often taken for granted. For example, it is very easy to pull container images from the internet and run them in an enterprise environment without examining their content and authenticity.

This lab provides a series of hands-on exercises that introduce the concepts, challenges, and best practices associated with deploying containers in a secure fashion.

This lab session is a low-level, hands-on introduction to container security using the container tools included with Red Hat Enterprise Linux 8.
