Hands-On with RHACS

This is an environment for the class: Hands-On with Red Hat Advanced Cluster Security The labs include:

  • Course Introduction: Introduce RHACS and its core security features and vision
  • Detail the primary use cases of RHACS through hands-on activities:
    • Vulnerability Management
    • Risk Profiling
    • Network Segmentation
    • Violations
    • Policies
    • Compliance
  • Provide several exercises for the student to implement policy at Build, Deploy, and Run time
    • Build Time Policies
    • Deploy Time Policies
    • Run Time Policies

Cluster Specification

  • 1 Control Plane/Worker Node (AWS instance type: m5a.4xlarge)
  • Cluster Version: 4.9
  • Authentication Enabled (htpasswd - refer to your provisioning e-mail for details)
  • RHACS 3.68 installed
  • RHACS demo apps installed
  • RHACS tekton pipeline demo installed
  • Let’s Encrypt Certificates enabled on Ingress Controllers

Access Information

You will receive an email with both the cluster admin credentials as well as administrative credentials and the URL to access RHACS portal.

Access Guide

You can find this class at in the Red Hat Learning management system.
