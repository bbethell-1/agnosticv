Explore security features, use cases, and policies for Red Hat Advanced Cluster Security.

The labs include:

  • Course introduction: Introduces Red Hat® Advanced Cluster Security (RHACS) and its core security features and vision.
  • Use cases: Provides details for primary use cases of RHACS through hands-on activities:
    • Vulnerability management
    • Risk profiling
    • Network segmentation
    • Violations
    • Policies
    • Compliance
  • Policy implementation: Provides several exercises to practice implementing policies at Build, Deploy, and Run time.

Products: Red Hat OpenShift® Container Platform and Red Hat Advanced Cluster Security

Specifications

  • 1 Control plane/Worker node (AWS instance type: m5.4xlarge)
  • Cluster version: 4.12
  • Authentication enabled (htpasswd - Refer to your provisioning email for details.)
  • RHACS 4.3 installed
  • RHACS demo apps installed
  • RHACS tekton pipeline demo installed
  • Let’s Encrypt certificates enabled on Ingress controllers

Supporting Materials

Access information: You will receive an email with both the cluster admin credentials as well as administrative credentials and the URL to access the RHACS portal.

Access guide: You will also receive the lab instructions (bookbag) link in the same email.

Provisioning time: Typically 1 hour.
