== Introduction

This Catalog Item hosts Hands-on Disaster Recovery of OpenShift containers and VMs with Trident protect.

== What Content Is Covered In This Lab?

These are the *five* main sections that will be covered:

* Install and configure Trident in OpenShift
* Provision workloads
* Install and configure Trident Protect
* Backup and Restore the container workload
* Disaster Recovery for the VM workload

== Version Information

This edition of the OpenShift Virtualization and Portworx Demo has been developed using the following software versions:

* NetApp ONTap and Trident Protect 2.26
* Red Hat OpenShift 4.18
* Red Hat OpenShift Virtualization 4.18
