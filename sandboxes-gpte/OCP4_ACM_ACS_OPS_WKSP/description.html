Modern App Dev Roadshow - Ops Track

This catalog item deploys a shared OpenShift Container Platform cluster on AWS to run the Modern App Dev Roadshow - Ops Track.

The Ops Track of the Modern App Dev Roadshow is a one-day interactive workshop. The workshop consists of a series of modules, with the majority focusing on various operations tasks for an OpenShift administrator. There are also modules on ACS vulnerability management, ACS DevSecOps practices, and ACM multicluster management. It is important to note that the ACM and ACS modules can be taken independently from the Admin Operations modules.

If you are organizing this workshop as an event, please request RHDP to enable the "enable workshop user interface" button for a seamless experience. If you have any further questions or need assistance, please feel free to contact the MAD Roadshow Support Gchat space at https://chat.google.com/room/AAAALnl9R7w?cls=7.
