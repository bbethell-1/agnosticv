== Red Hat SSO Workshop

This lab offers attendees an intro-level, hands-on session with Red Hat SSO. From the first line of code to making services to consuming them and finally to assembling everything and deploying it on Openshift.

*What you will learn?*

* Basic SSO config, admin setup, email integration​
* Securing a simple app made in Java script/html, how realms work etc​
* OpenID connect, tokens, Github integration and customization of variables​
* User group and management​
* working with multiple identity providers​
* Creating new browser flows, OTP token authentication, theme customization, SSO customization using templates​
* Creating and securing a Quarkus service​

Requesting this catalog item will provide you with a dedicated OpenShift 4 cluster each participant will share using per-participant credentials for OpenShift and CodeReady Workspaces. Each participant's developer workspace will be pre-provisioned and started up in CodeReady Workspaces so they can get started quickly. Once you order this catalog item, you'll receive an email with links to connect to the workshop, which you will share with participants, along with admin credentials in case you need to log in and do housekeeping or other changes. Note that developer workspaces are started in the background, and depending on how many participant seats you order, it may take longer to complete provisioning.

*Next Steps* Once ordered via this catalog item, wait for a confirmation email that the lab was successfully provisioned, and then use the links in the email to get started.
