Manage Red Hat OpenShift Container Platform clusters with the NGINX Ingress Operator.

In this catalog item, you use the NGINX Ingress Operator to handle networking for apps running in OpenShift Container Platform. This hands-on asset comes with the NGINX Ingress Operator installed and licensed.

NGINX is the most-used open source reverse proxy server in the world. NGINX’s new offering reimagines NGINX technology for Kubernetes-based deployments in the form of NGINX Ingress. NGINX Ingress brings the trusted speed and ease of use of NGINX technology into the world of Kubernetes. The NGINX Ingress Operator for OpenShift Container Platform makes NGINX Ingress certified to run on OpenShift Container Platform, fully supported, and installable with a click.

This asset provides a fully deployed and running NGINX Ingress deployment on OpenShift Container Platform and covers the following topics:
  • Quick overview of how to interact with OpenShift Container Platform
  • NGINX Ingress deployment
  • Deploying an application for demoing purposes
  • Demoing use cases for NGINX Ingress
  • Demoing the NGINX dashboard
