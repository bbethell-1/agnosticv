== NGINX Demo & Workshop

=== Handling Cluster Traffic in OpenShift with the NGINX INgress Operator

In this Red Hat OpenSHift Container Platform (OCP) workshop, you will use the NGINX Ingress Operator to handle networking for apps running in OCP. This lab is 30 minutes, hands-on, and comes with the NGINX Ingress Operator Installed and licensed. NGINX is the most used open source reverse proxy server in the world. NGINX’s new offering reimagines NGINX technology for the kubernetes-based deployments in the form of NGINX Ingress. NGINX Ingress brings the trusted speed and ease of use of an NGINX technology into the world of kubernetes and the NGINX Ingress Operator for OCP makes NGINX Ingress certified to run on OCP, fully supported, and installable with a click

This workshop provides a fully deployed and running NGINX Ingress deployment on OCP and will cover the following topics: Quick overview of how to interact with OpenShift. NGINX Ingress deployment. Deploying an application for demoing purposes. Demonstrating use cases for NGINX Ingress. Demoning the NGINX dashboard.
