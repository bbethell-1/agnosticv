Showcases the integration of Red Hat OpenShift Virtualization with Red Hat OpenShift Service on AWS (ROSA), utilizing the Hosted Control Plane architecture.
This demo environment is pre-configured with OpenShift Data Foundation and the Red Hat OpenShift Virtualization Operator, providing a seamless experience for running and managing virtual machine (VM) workloads alongside container workloads.

Red Hat OpenShift Virtualization is an add-on to Red Hat OpenShift Service on AWS that empowers users to handle VM workloads using Kubernetes custom resources.
This demo illustrates how OpenShift Virtualization adds new objects to your ROSA cluster, enabling a range of virtualization tasks such as:

1. **Manual Migration:** Using Migration Toolkit for Virtualization (MTV) to manually migrate virtual machines.
2. **Automated Migration:** Utilizing Ansible Automation Platform (AAP) to automate the migration setup process, demonstrating what migrating VMs at scale looks like.

== Disclaimer

Due to AWS capacity issues, adding metal nodes may sometimes cause the demo environment to fail to provision. If this occurs, please order in another region and try again.
