Red Hat OpenShift Service on AWS (ROSA) enables enterprise-grade security for containerized workloads through a defense-in-depth strategy combining OpenShift's Kubernetes capabilities with native AWS security services. This hands-on workshop teaches secure workload identity management using IAM Roles for Service Accounts (IRSA), AWS service integrations, network policies, and runtime security with Red Hat Advanced Cluster Security for Kubernetes. Learners deploy applications with zero static credentials, implement centralized logging with CloudWatch, manage external secrets, and detect vulnerabilities at runtime.

== Detailed Overview

* *Lab 3: Configure CloudWatch Logging*
** Integrate ROSA with Amazon CloudWatch using OpenShift Logging 6.x
** Implement Loki stack for efficient log storage
** Achieve compliance through centralized audit logging

* *Lab 4: Deploy Application with IRSA*
** Eliminate static credentials using IAM Roles for Service Accounts
** Deploy cloud-native applications with secure AWS service integration
** Configure DynamoDB access without embedded credentials

* *Lab 5: Implement AWS Secrets Manager*
** Separate sensitive data from application code
** Mount external secrets using CSI driver
** Reduce attack surface through external secrets management

* *Lab 6: AWS Controllers for Kubernetes (ACK)*
** Provision AWS infrastructure using GitOps workflows
** Deploy S3 buckets through Kubernetes-native APIs
** Implement Infrastructure as Code patterns

* *Lab 7: Network Policies*
** Implement zero-trust networking and microsegmentation
** Configure pod-to-pod communication security
** Apply defense-in-depth network controls

* *Labs 8-9: Red Hat Advanced Cluster Security (RHACS)*
** Explore RHACS for vulnerability management and compliance
** Detect and prevent Log4Shell vulnerability at runtime
** Implement policy enforcement for critical CVEs

* *Lab 10: Amazon Cognito Integration*
** Configure enterprise SSO for federated authentication
** Integrate ROSA with Amazon Cognito identity provider
** Enable centralized identity management
