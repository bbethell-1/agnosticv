= OpenShift Disconnected Workshop

Welcome to the *OpenShift Disconnected Workshop*!

Here you will learn to install and operate an OpenShift 4 cluster in a disconnected network, or one
without access to the Internet (even through a proxy or firewall). This changes the way the cluster
operates because things like container images, operator updates, and patches must be brought into
the environment via mirroring.
