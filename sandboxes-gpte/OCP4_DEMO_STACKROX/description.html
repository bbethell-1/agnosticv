OpenShift 4 + Stackrox 3 Demo

This is an OpenShift environment running Stackrox with a number of demo apps deployed into the cluster. The Stackrox demo will explore the various security-related features as it relates to the deployed demo components, using the Stackrox web interface.

Cluster Specification

  • 3 Control Plane Nodes (AWS instance type: m5a.2xlarge)
  • 2 Worker Nodes (AWS instance type: m5.xlarge)
  • Cluster Version: 4.7
  • Authentication Enabled (htpasswd - refer to your provisioning e-mail for details)
  • Let’s Encrypt Certificates enabled on Ingress Controllers

Access Information

You will receive an email with both the cluster admin credentials as well as administrative credentials and the URL to access Stackrox.
