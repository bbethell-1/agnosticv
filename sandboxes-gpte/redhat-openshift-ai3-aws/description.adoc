This environment provides OpenShift 3.0 deployed on a Single-Node OpenShift (SNO) running on a GPU instance.
With OpenShift AI 3.0 now generally available, you can use this to demonstrate explore this version of OpenShift AI.

There is a guide provided that will walk you through how to deploy and configure this on your own. 

[IMPORTANT]
====
OpenShift AI 3.0 is GA, but this is an early release of this catalog item so that you can use it sooner.
The demo guide and experience will be refined and updated over the coming days and weeks.
====

== Products

* OpenShift Container Platform 4.20 (SNO)
* OpenShift AI 3.x

[WARNING]
====
This is a SNO deployment on a GPU instance.
These cost more to run, so please order the size you need and do not keep your environment running.
====
