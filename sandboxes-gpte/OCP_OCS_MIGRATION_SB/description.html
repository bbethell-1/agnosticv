Move application workloads between clusters with Red Hat OpenShift Container Platform 3.

This catalog item migrates application workloads from Cluster A to Cluster B, including the UI, controller, Velero/Restic, plug-ins, and so on. This application is available for installation through OperatorHub/Operator Lifecycle Manager (OLM).

This item requires migration toolkit for containers services for both OpenShift Container Platform 3 and OpenShift Container Platform 4.
