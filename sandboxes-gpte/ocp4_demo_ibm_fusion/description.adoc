== OpenShift Container Platform with IBM Fusion
    
This catalog item deploys an OpenShift Container Platform Cluster on AWS with Virtualization enabled and IBM Fusion deployed.
No demo instructions are provided at this time - but users can use the installed Fusion to play with / demo the IBM Fusion capabilities to provide storage for an OpenShift Cluster.

After provisioning the IBM Fusion Operator is installed and the ODF Storage System has been deployed which provides the following storage classes:

* ocs-storagecluster-ceph-rbd
* ocs-storagecluster-ceph-rbd-virtualization
* ocs-storagecluster-cephfs
* openshift-storage.noobaa.io

The IBM Fusion Administration Console is available from the Application Picker at the top right of the OpenShift Console. The credentials are the same as for the cluster administrator.

== Information about this catalog item

Software included in this environment:

* OpenShift 4.18 (latest in stable branch)
* OpenShift Virtualization 4.18 (latest in stable channel)
* Certificates via Cert Managaer
* IBM Fusion (latest available, 2.10 at the time of publishing) which installs ODF 4.18.
