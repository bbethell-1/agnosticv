
== OpenShift Container Platform with IBM Fusion

No demo instructions are provided at this time - but users can use the installed Fusion to play with / demo the IBM Fusion capabilities to provide storage for an OpenShift Cluster.

== Environment Access Details

=== OpenShift Admin Console

Your OpenShift cluster console is: {openshift_cluster_console_url}

Admin login is available with:

* Username: {openshift_cluster_admin_username}
* Password: {openshift_cluster_admin_password}

== IBM Fusion

The IBM Fusion Administration Console is available from the Application Picker at the top right of the OpenShift Console.

The credentials are the same as for the cluster administrator:

* Username: {openshift_cluster_admin_username}
* Password: {openshift_cluster_admin_password}

IBM Fusion documentation is avavailable https://www.ibm.com/docs/en/fusion-software/2.10.0[here^]
