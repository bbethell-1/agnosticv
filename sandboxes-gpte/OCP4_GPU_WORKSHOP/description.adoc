= OpenShift GPU Workshop

[IMPORTANT]
====
*AWS g6 Instance Availability*

This catalog item requires AWS g6 instances, which may have limited availability in some regions.

If you experience a deployment failure, please try provisioning again in a different region. The *us-east-1* and *us-east-2* regions currently have the best capacity.
====

Provides an OpenShift cluster with NVIDIA V100 Tensor Core GPUs on AWS infrastructure.

This asset provisions an OpenShift cluster with NVIDIA V100 Tensor Core GPUs and basic customizations on AWS infrastructure. You can use this cluster for running demos, hands-on-labs, workshops, and similar events that demonstrate Machine Learning and AI workloads.

This is general AI/ML content. We are developing more specialized content that highlights specific use cases that employ Open Data Hub and/or our partners' technology stacks.

== Products

Red Hat OpenShift Container Platform

== Specifications

* 3 Control plane nodes (AWS instance type: m5.2xlarge)
* 2+ Compute nodes (AWS instance type: p3.2xlarge)
* Cluster version: 4.10.x
* Authentication enabled (htpasswd - refer to your provisioning email for details)
* LimitRanges enabled
* Let's Encrypt Certificates enabled on Ingress controllers
