= LB2288: Defense in Depth: Advanced Security for Container Workloads on ROSA

== Overview

Defense in Depth: Advanced Security for Container Workloads on ROSA teaches secure workload identity management using Red Hat OpenShift Service on AWS (ROSA) with Hosted Control Plane and AWS integrations. This workshop covers IAM Roles for Service Accounts (IRSA), AWS service integrations including CloudWatch and Secrets Manager, network policies, and runtime security with Red Hat Advanced Cluster Security for Kubernetes (RHACS). This lab is part of Red Hat One 2026.

== Guide

link:https://rhpds.github.io/secure-workload-identity-management-showroom[Open Guide^,role=params-link]

== Featured Products and Technologies

* Red Hat OpenShift Service on AWS (ROSA) with Hosted Control Plane 4.19
* Red Hat Advanced Cluster Security for Kubernetes (RHACS) 4.9
* AWS Services (CloudWatch, Secrets Manager, ACK, Cognito)
* IAM Roles for Service Accounts (IRSA)

== Agenda

* Lab 1: Explore your ROSA environment
* Lab 2: Access your ROSA cluster
* Lab 3: Configure CloudWatch logging for ROSA
* Lab 4: Deploy application with IRSA
* Lab 5: Implement AWS Secrets Manager with ROSA
* Lab 6: Using AWS Controllers for Kubernetes on ROSA
* Lab 7: Network Policies on ROSA
* Lab 8: Introduction to Red Hat Advanced Cluster Security (RHACS)
* Lab 9: RHACS Log4Shell Vulnerability Detection and Prevention
* Lab 10: Integrating ROSA with Amazon Cognito
