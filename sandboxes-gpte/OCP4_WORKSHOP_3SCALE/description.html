3scale Workshop


Description

This workshop covers the basics of how to utilize 3scale to expose and manage API's

Labs available:

  • Lab 1 - API Design
  • Lab 2 - API Mocking
  • Lab 3 - Managing API Endpoints
  • Lab 4 - API Security
  • Lab 5 - API Developer Portal
  • Lab 6 - Testing the web application
  • Lab 7 - Deploying APIcast Using the Operator
  • Lab 8 - Using 3scale Service Discovery
For more information check: https://github.com/redhat-na-ssa/workshop_3scale
