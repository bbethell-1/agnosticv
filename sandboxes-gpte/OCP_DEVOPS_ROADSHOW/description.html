The OpenShift DevOps Roadshow is a day long workshop for customers to learn more about securely doing DevOps with the Red Hat product stack,

This catalog item walks users through the process of using OpenShift Pipelines, OpenShift GitOps, Red Hat Quay, Red Hat Advanced Cluster Security, Red Hat Build of Keycloak, and others to create a security focused DevOps experience.

This asset uses a single shared cluster for all users and pre-provisions shared resources (ACS, Keycloak, Argo CD) as well as individual resources (Sonarqube, Nexus) for each user.

Specifications

  • Three controller nodes (AWS instance type: m5.2xlarge)
  • Total number of nodes dependent on the size ordered (AWS instance type: m5.4xlarge)
  • Cluster version: 4.15.x
  • Authentication enabled via Keycloak
  • Provisioned through OpenShift GitOps./li>
  • Let's Encrypt certificates enabled on Ingress controllers

Supporting Materials

Access guide: You have full admin access to the provisioned workshop cluster, which is a vanilla OpenShift Container Platform 4.10 cluster.
