The OpenShift DevSecOps Roadshow is a day long workshop for customers to learn more about securely doing DevSecOps with the Red Hat product stack.

[WARNING]
****
**⚠️ IMPORTANT:** This workshop requires manual configuration steps that could not be automated. Please carefully review the *https://docs.google.com/document/d/1QnrAewf5kywna_h8LLftgeLUKjjk1csteahnL7rtGUQ/edit?tab=t.0#heading=h.ckkd5vswm4e5[Lab guide]* for detailed instructions.
****

This catalog item walks users through the process of using OpenShift Pipelines, OpenShift GitOps, Red Hat Quay, Red Hat Advanced Cluster Security, Red Hat Build of Keycloak, and others to create a security focused DevSecOps experience.

This asset uses a single shared cluster for all users and pre-provisions shared resources (ACS, Keycloak, Argo CD) as well as individual resources (Sonarqube, Nexus) for each user.

== Specifications

* Three controller nodes (AWS instance type: m5.2xlarge)
* Total number of nodes dependent on the size ordered (AWS instance type: m5.4xlarge)
* Cluster version: 4.16.x
* Authentication enabled via Keycloak
* Provisioned through OpenShift GitOps./li>
* NetZero certificates enabled on Ingress controllers, ACS and Keycloak
* Includes OpenShift Pipelines, GitOps, ACS, Quay, Keycloak and RHTAS as an integrated solution
* Gitea is used for source control
