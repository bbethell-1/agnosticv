== Red Hat Developer Hub Workshop
This catalog item provisions a shared OpenShift cluster, Red Hat Developer Hub, and services like ArgoCD and Tekton, for up to 30 users.  The workshop is based on examples from link:https://developers.redhat.com/e-books/developer-portals[_Developer Portals: Prepare to Perform with Red Hat Developer Hub_].

The exercises in this workshop build a world map application that you can pan, zoom, and click to investigate arbitrary points of interest.

You’ll construct the map application from a set of templates that define and deploy foundation components. You’ll use Red Hat Developer Hub’s Software Catalog, API index, and other facilities to streamline implementing the application, extending it with new features, and building and running its iterations.

The scaffolding to support the three-part architecture of the map application is split between two RHDH Software Templates. The first template deploys the backend application together with its database. The second template creates the framework for the frontend and API client.

Along the way, you’ll explore the Software Catalog to understand RHDH’s focused view on the component topology, CI and CD processes, source code changes, and APIs that matter to your application.

*IMPORTANT:* Enable the "Workshop User Interface" option during provisioning to generate a workshop URL to share with attendees. This url will provide a login prompt and a link to the "Lab User Interface", which will supply each attendee with unique onboarding information.
