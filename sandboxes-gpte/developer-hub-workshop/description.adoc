== Red Hat Developer Hub Workshop
This catalog item provisions a shared OpenShift cluster, Red Hat Developer Hub, and ancillary services like ArgoCD and Tekton, for up to 30 users.  Workshop materials are based on examples from link:https://developers.redhat.com/e-books/developer-portals["Developer Portals: Prepare to Perform with Red Hat Developer Hub"].

NOTE: Enable the "Workshop User Interface" option to generate a workshop url that can be shared with your attendees.  This url will provide a login prompt and a link to the "Lab User Interface", which will supply each attendee with unique onboarding information.

The exercises in this lab center on a world map application that you can pan, zoom, and click to investigate arbitrary points of interest.

You’ll construct the world map application from a set of templates that define and deploy foundation components. You’ll use Red Hat Developer Hub’s Software Catalog, API index, and other facilities to streamline implementing the application and extending it with new features.

The scaffolding to support the three-part architecture of the map application is split between two RHDH Software Templates. The first template deploys the backend application together with its database. The second template creates the framework for the frontend and API client.

Along the way, you’ll explore the Software Catalog to understand RHDH’s focused view on the component topology, CI and CD processes, source code changes, and APIs that matter to your application.

Audience: Developers, Platform Engineers, Operations, Cluster Administrators
