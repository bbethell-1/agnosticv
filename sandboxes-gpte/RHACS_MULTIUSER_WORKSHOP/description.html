This is an environment for Red Hat Advanced Cluster Security for Kubernetes Multi-User Worksop

Cluster Specification

  • OpenShift Cluster Version: 4.12
  • 1 Control Plane/Worker Node (AWS instance type: m5.4xlarge)
  • Authentication Enabled (htpasswd - refer to your provisioning e-mail for details)
  • Let’s Encrypt Certificates enabled on Ingress Controllers

Access Information

You will receive an email with both the cluster admin credentials as well as administrative credentials and the URL to access RHACS portal.

Provisioning Time
Approximately 1 hour
