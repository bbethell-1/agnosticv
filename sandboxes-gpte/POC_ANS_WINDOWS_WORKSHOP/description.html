This workshop is a hands-on training program focused on using Ansible to manage Windows systems. Participants will have the opportunity to practice their new skills through hands-on exercises and real-world scenarios, and will leave the workshop with a solid understanding of how to use Ansible to manage Windows systems. Participants will learn the basics of Ansible, including how to automate common Windows administration tasks, deploy software and updates, and manage configuration.

The workshop will also serve as a proof-of-concept (PoC) for using openshift-gitops to deploy AAP2 on OpenShift and AgD to create Virtual Machines on Cloud Provider for each participant. This PoC will lay down the foundation for future Ansible workshops.
