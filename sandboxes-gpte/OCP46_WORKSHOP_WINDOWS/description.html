OpenShift 4 Windows Containers Demo provides an OpenShift 4 cluster running the OVN Network SDN. It also has Hybrid Overlay customizations needed for Windows. The Windows Containers Operator is already installed and the Windows node is installed and added to the cluster. This Demo is suitable for those wanting to quickly demo the capabilities of Windows Containers on OpenShift or for Developers needing an environment to develop against.

Cluster Specification

  • Nodes: 3 masters, 2 RHCOS workers, and 1 Windows Server 2019 worker.
  • Windows Container Image prepulled
  • Windows Quickstart Guide

Access Guide

You have full admin access to the provisioned workshop cluster and can find all details needed in the email that will be sent to you. You can find "Windows Containers Quickstart Guide" link on the "Details" page after successful provision.
