The "OpenShift 4 Windows Containers Demo" is an instructional demo that guides you through the process of running Windows applications on OpenShift 4.12. During this demo, you'll become proficient in utilising the Windows Machine Config Operator (WMCO) and the OVN Network SDN for setting up and overseeing Windows nodes and containers within an OpenShift cluster. Additionally, you'll gain experience deploying a sample Windows application by employing a DeploymentConfig and a Service.

Important Updates

Note: that we've made changes and improvements to the NetCandyStore modules. We've also pushed an updated demo to OCP 4.12. Alongside these updates, a new set of instructions is now available. Please be aware that, starting from version 4.11, the external Prometheus console has been phased out. This workshop is not intended to be used with Prometheus or Grafana.
