= Red Hat OpenShift Lightspeed Demo
  [Your OpenShift virtual assistant powered by AI]

This environment provides a single-node cluster with Red Hat OpenShift Lightspeed (Your OpenShift virtual assistant powered by AI
) installed and attached to a model provider. It can be used to show the various assistant features of Red Hat OpenShift Lightspeed.

There is a 'broken' project with a 'broken-pod' intentionally in pending state so that you can use that pod to demonstrate how Red Hat OpenShift Lightspeed can be a virtual assistant and able to analyze this broken pod.

Note: If you get an error to connect to backend AI service, kindly DELETE the 'lightspeed-app-server-xxxxxx' pod in 'openshift-lighspeed' project. It will restart the pod again and will connect to the backend AI services. Please DO NOTE delete the other two pods in the same project.
