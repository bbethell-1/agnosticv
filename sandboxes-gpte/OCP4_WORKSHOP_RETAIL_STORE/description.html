Perform workshop tasks for a retail industry use case using a retail store application.

This catalog item provides the environment for the Retail Store Application - Retail Industry Use Case-based Workshop.

Product(s): Red Hat OpenShift Data Science

Specifications

This workshop includes:

  • Red Hat OpenShift Container Platform cluster version 4.10
  • Red Hat OpenShift Data Science
  • AWS OpenShift cluster

Access information: You will receive an email with:

  • The cluster admin credentials
  • Administrative credentials and the URL to access the portal in Red Hat OpenShift Data Science

Provisioning time: Typically, approximately 1 hour, with an additional 20 to 30 minutes for the "jupyterhub" image build
