Learn about using Prisma Cloud Compute self-hosted software on Red Hat OpenShift.

Prisma Cloud Compute Edition is self-hosted software that you can use to protect hosts, containers, and serverless functions running in any cloud, including on-premise and even fully air-gapped environments.

This catalog item provides a fully deployed and running Prisma Cloud Console, Defender, and demo application and covers the following topics:

  • Prisma Cloud Compute at a glance
  • Accessing the Prisma Cloud Compute Console
  • A tour of the microservices demo application, Sock Shop
  • Compliance and mlware scanning
  • Runtime defense with ATT&CK Explorer
  • Understanding alerts

If deployment fails, please try again. If it does not succeed after three attempts, please create a service ticket by sending an email to Red Hat support.

Audience: Developers, Operations, Security
