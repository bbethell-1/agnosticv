Get hands-on experience with the new OpenShift APIs for Data Protection (OADP).

This catalog items provide hands-on exposure to the new OADP through a series of activities to back up and restore application workloads, both stateful and stateless, on the same cluster in Red Hat OpenShift Container Platform. The application is available for installation through OperatorHub/Operator Lifecycle Management (OLM). You must access OpenShift Container Platform 4 services from Red Hat Product Demo Service (RHPDS).

Goals:

  • Back up and restore applications on OpenShift Container Platform 4 clusters using the OADP provided by OpenShift Container Platform 4, leveraging both the UI and the API.
  • Learn tips, techniques, and best practices for debugging failed backups and restores.
