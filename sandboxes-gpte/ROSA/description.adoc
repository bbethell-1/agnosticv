This catalog item will deploy a Red Hat OpenShift Service on AWS (ROSA) cluster.

You are provided with:
* A bastion host that has the ROSA CLI pre installed and configured
* SSH credentials for the bastion host
* A basic ROSA cluster already built and running with node scaleup *disabled*
* The ROSA cluster URL and cluster-admin credentials
* Your ROSA Environment Consists of:
** 3 m5.2xlarge master nodes
** 2 m5.xlarge worker nodes
** 2 r5.xlarge infra nodes

You can SSH into the bastion host and run the ROSA cli commands as documented xref:https://www.google.com/url?q=https://docs.openshift.com/rosa/rosa_cli/rosa-manage-objects-cli.html&sa=D&source=editors&ust=1628615249845000&usg=AOvVaw0_y1XiZuK9CEwH1zQQcSM7[here].
You can also log into the cluster web UI using the provided credentials.

WARNING: Do NOT use the `rosa logout` command or you will lose connectivity to your cluster rendering it useless!

When this service is retired in RHPDS, the ROSA cluster will be automatically torn down for you. You do not need to do this manually.
