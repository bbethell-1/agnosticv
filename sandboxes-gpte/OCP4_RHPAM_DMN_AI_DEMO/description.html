RHPAM 7: CC Dispute - DMN AI (PMML) Demo


Introduction
Demo that shows how AI Machine Learning models defined in PMML (Predictive Model Markup Language) can be combined with the DMN (Decision Model & Notation) models. The demo shows how declarative models can be combined with machine learned models to evaluate decisions in a Credit Card Dispute case. The combination of these 2 types of models allows users to use predictive models based on historical data with declarative decisions defined by business and IT. We also show that combining PMML with DMN models allows us to use the standard RHPAM DMN Test Scenario Tooling to test our predictive models. Finally, by using the Prometheus extension functionality of Red Hat Process Automation Manager, we can define custom Prometheus metrics that, for example, capture and monitor the results of our DMN and PMML decisions. Integrating Grafana with Prometheus allows us to create dashboards that, for example, visualize the distribution of the decisions or our models.
