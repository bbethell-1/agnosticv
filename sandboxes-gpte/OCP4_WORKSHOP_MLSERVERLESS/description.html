This is a full day, hands-on workshop built by RedHatGov. Technologies covered include OpenShift Serverless/Knative, AMQ Streams/Kafka, CodeReady Workspaces, and OpenShift Container Storage. The workshop is ideal for developers, operations professionals, architects and technical managers who are interested in getting hands on and exploring the benefits of using serverless technology. Users will learn the basics of running serverless applications on Red Hat OpenShift. They will also build a new user experience using serverless and machine learning. They will get hands-on experience with: * Serverless introduction and basics * Machine learning inferencing in serverless code * How serverless fosters innovation * Event driven architecture * Developing cloud native code and updating services * Observability and metrics in serverless The lab guide is provisioned using homeroom and a username distribution app. Participants login to the username distribution app to receive a user account on the cluster and a link to the workshop.
