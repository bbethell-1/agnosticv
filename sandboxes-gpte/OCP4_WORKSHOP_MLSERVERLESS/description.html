Review technologies including Red Hat OpenShift Serverless/Knative and AMQ streams/Kafka.

This catalog item presents a full day, hands-on workshop built by RedHatGov. Users learn the basics of running serverless applications on Red Hat OpenShift Container Platform. They also build a new user experience using serverless and machine learning. They get hands-on experience with:

  • Serverless introduction and basics
  • Machine learning inferencing in serverless code
  • How serverless fosters innovation
  • Event-driven architecture
  • Developing cloud-native code and updating services
  • Observability and metrics in serverless

Audience: Developers, operations professionals, architects, and technical managers who are interested in exploring the benefits of using serverless technology

Product(s): Red Hat OpenShift Serverless/Knative, Red Hat OpenShift Data Foundation

Technologies: AMQ streams/Kafka, CodeReady Workspaces

Supporting Materials

Lab guide: The lab guide is provisioned using homeroom and a username distribution app. Participants log in to the username distribution app to receive a user account on the cluster and a link to the workshop.
