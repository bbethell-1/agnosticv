This asset provisions an OpenShift cluster with basic customization on AWS infrastructure.

You can use this cluster for hands-on labs, workshops, and other events when a specialized environment is not available.

For specialized workshops (such as Containers and Cloud-Native Roadshow, OpenShift Getting Started Workshops, etc.), use the dedicated catalog item for that workshop.

Specifications

  • 3 Leader nodes (AWS instance type: m5.2xlarge)
  • Number of nodes dependant on the size ordered (AWS instance type: m5.4xlarge)
  • Cluster version: 4.12.x
  • Authentication enabled (htpasswd - refer to your provisioning email for details)
  • LimitRanges enabled
  • Let’s Encrypt Certificates enabled on Ingress controllers
