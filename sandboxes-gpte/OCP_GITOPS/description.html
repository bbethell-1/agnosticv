Run deployments with Red Hat OpenShift GitOps and review Kustomize, sync waves, and hooks.

This catalog item walks you through the basics of using the OpenShift GitOps solution. It includes exercises on simple deployments with GitOps as well as how to use Kustomize, sync waves, and hooks.

This asset uses a single shared cluster for all users and preprovisions an Argo CD instance along with distinct namespaces for each user.

Specifications

  • Three controller nodes (AWS instance type: m5.2xlarge)
  • Total number of nodes dependent on the size ordered (AWS instance type: m5.4xlarge)
  • Cluster version: 4.10.x
  • Authentication enabled (refer to your provisioning email for details regarding the "htpasswd")
  • LimitRanges enabled
  • Let's Encrypt certificates enabled on Ingress controllers

Supporting Materials

Access guide: You have full admin access to the provisioned workshop cluster, which is a vanilla OpenShift Container Platform 4.10 cluster.
