Building sentiment analysis with Kafka and AI/ML and leveraging MLOps

A great introduction to the "power of together" of Kafka and AIML using Red Hat technologies. This intro is followed with a live demo demo based showing a use case of sentiment analysis for a fictitious retail customer. Participants will be invited to join in the live demo while showcasing this use case. This solution pattern showcases an architecture which is scalable and efficient system capturing and responding to streaming data using Kafka as the streaming platform and AIML. With Event-Driven Architecture this system can connect to, and consume from a number of systems, services and data sources by responding to triggering events. You will also get to understand how MLOps plays a vital role in the whole DevOps requirements for an Enterprise. This solution also shows how Retail Discount Coupon App can leverage machine learning object detection model and also leverage the MLOps using modern gitops methodology to manage the life cycle of a machine learning model.

Cluster Specification

  • 3 Masters Nodes (AWS instance type: m5.2xlarge)
  • Number of nodes dependant on the size ordered (AWS instance type: m5.4xlarge)
  • Cluster Version: 4.12.x
  • Authentication Enabled (htpasswd - refer to your provisioning e-mail for details)
  • Let’s Encrypt Certificates enabled on Ingress Controllers
  • Red Hat OpenShift Data Science
  • Kafka Streams
  • OpenShift Serverless
  • OpenShift Gitops (ArgoCD)
  • OpenShift Pipelinesi (Tekton)
  • OpenShift Data Foundations
  • InfluxDB
  • Grafana
