Provision a dedicated cluster with Red Hat OpenShift Service Mesh and related services.

Using the latest product environment (LPE), this catalog item provisions a dedicated cluster in Red Hat OpenShift Container Platform with OpenShift Service Mesh and related services. Each service is installed in its latest stable version.

Specifications

Dedicated OpenShift Container Platform cluster with:

  • OpenShift Service Mesh
  • Kiali
  • Distributed tracing (formerly Jaeger)
  • Elasticsearch

The final provisioning email includes information on accessing the above services. Please use your Red Hat Product Demo System (RHPDS) credentials if prompted to do so.

The ServiceMeshControlPlane (SMCP) is automatically installed in the "istio-system" namespace. Use the Kiali route to access the web interface and validate the OpenShift Service Mesh installation. A basic control plane is provided, but feel free to extend to your needs by modifying the SMCP custom resource definition (CRD).

Supporting Materials

You will need to add your services to OpenShift Service Mesh. For instructions, review the latest OpenShift Container Platform documentation.
