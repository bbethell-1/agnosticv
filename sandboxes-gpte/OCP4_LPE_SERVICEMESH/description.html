Latest Product Environment: Red Hat OpenShift Service Mesh

This catalog item provisions a dedicated OpenShift cluster with the following:

  • Red Hat OpenShift Service Mesh
  • Kiali
  • OpenShift Distrubuted Tracing (Jaeger)
  • OpenShift Elasticsearch

Each service of the services above will be installed in its latest stable version.

The final provisioning e-mail will have information on accessing the above applications. Please use your RHPDS credentials if prompted to do so.

ServiceMeshControlPlane

The SMCP is automatically installed in the istio-system namespace. Use the Kiali route to access the web interface and validate the Service Mesh installation. A basic control plane is provided, feel free to extend to your needs by modifying the smcp CRD.

Adding services to the Service Mesh

You will need to add your services to the Service Mesh. Follow the OpenShift latest documenation for the next steps.
