== Uplift and Shift

Give your virtual machines features once exclusive to containers without changing a thing.

OpenShift Virt on ROSA provides advanced application telemetry, autoscaling, infratructure automation, and reduces toil.

Don't Lift and Shift: Uplift and Shift.

This version of the lab runs on ROSA.
Stay tuned for more cloud platforms!
