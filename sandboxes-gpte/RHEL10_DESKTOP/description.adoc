Provides a baseline Red Hat Enterprise Linux(R) (RHEL) 10 environment. It is intended for technical exploration, development, and familiarization with the RHEL 10 operating system.

This is a sandbox environment for you to use.

NOTE: You can find a rendered version of the guide https://rhpds.github.io/showroom-rhel10-desktop/modules/index.html[here^], but your deployment will come with a customized guide to use.
