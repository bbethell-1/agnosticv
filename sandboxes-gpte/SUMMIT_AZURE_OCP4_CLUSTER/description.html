This catalog item deploys OpenShift 4 on Microsoft Azure using the openshift-installer’s Full Stack Installation (IPI) method for the purposes of running workshops for qualified opportunities.

Workshop characteristics:

  • 3 masters (D8s_v3), a customizable number of workers (D4s_v3, dependent on the user number entered in dialog).
  • Cluster Features: Persistent Storage, HTpasswd Authentication, Lets Encrypt certificates on choice, Terminal enabled.
  • You have the ability to demonstrate upgrades.
  • Region:
    • North America
    • Europe
    • APAC
  • Provisioning time: ~75 minutes
  • Credentials for kubeadmin and other relevant information are sent in the final email
  • After you order your environment, you can manage it by logging into this system and select Services -> My Services -> [This service] -> App Control
  • The ordered environment will cease to run unless you use Extend Runtime in App Control.
  • The ordered environment will cease to exist at the Expiration Date time stamp provided unless you use Extend Lifetime in App Control.
