This lab is a guided exercise for deploying Red Hat Quay on OpenShift using Operators. You will also reconfigure the Red Hat Quay deployment using the OpenShift console/CLI and understand how the Operator handles the reconfiguration and implements it seamlessly.

Below are the topics covered:

  • Install the ODF Operator
  • Create a NooBaa(MCG) deployment backed by local PVs
  • Install the Red Hat Quay Operator
  • Change server hostname
  • Use custom certificate
  • Enable proxy caching
  • Enable storage quota and consumption tracking
  • Disable the Python updater for Clair database
  • Increase the PVC size for the Postgres database of Quay
  • Increase the size of the PVs backing NooBaa's S3 endpoint

    • The instructions are here https://github.com/redhat-gpte-devopsautomation/quay-on-ocp/tree/main/workshop/content
