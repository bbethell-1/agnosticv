Multi Cluster DevSecOps Pattern

The Demo Narrative

Red Hat Products:

  • Red Hat OpenShift Container Platform (Kubernetes)
  • Red Hat Advanced Cluster Management (Open Cluster Management)
  • Red Hat OpenShift GitOps (ArgoCD)
  • Red Hat OpenShift Pipelines (Tekton)
  • Red Hat Quay (container image registry with security features enabled)
  • Red Hat Open Data Foundation (highly available storage)
  • Red Hat Advanced Cluster Security (scanning and monitoring)

Other technologies & products:

  • Hashicorp Vault community edition (secrets management)

Description:

This demo is designed to showcase how Red Hat's multicluster DevSecOps solution can help enterprise architects, IT managers, and VP operations to effectively secure their cloud native applications and platform. It demonstrates the use of GitOps approach to keep in control of configuration and operations, centrally manage multiple clusters, build and deploy workloads across clusters using modern CI/CD, and deploy different security products into the pattern. The demo uses a variety of Red Hat products, including OpenShift Container Platform, Advanced Cluster Management, OpenShift GitOps, OpenShift Pipelines, Quay, Open Data Foundation, and Advanced Cluster Security, as well as other technologies like Hashicorp Vault.

Duration

The duration of the demo is 20 minutes

Audience

It is targeted to Enterprise Architects, IT Managers, and VP Operations.
