Dynatrace with OpenShfit Workshop

Description

Dynatrace provides software intelligence to simplify enterprise cloud complexity and accelerate digital transformation. With AI and complete automation, Dynatrace's all-in-one platform provides not just data but answers about the performance of applications, the underlying infrastructure, and the experience of all users.

With OneAgent, Dynatrace has pioneered and expanded the collection of observability data in highly dynamic cloud environments. When an organization installs OneAgent, it automatically detects all applications, containers, services, processes, and infrastructure in real-time with zero manual configuration or code changes. System components are automatically configured to collect metrics, logs, traces, and a broader view of your environment. This includes a full topological model with entity relationships, code-level detail, and user experience - all in context.

In this workshop, you will deploy a Node.js application and learn to utilize the power of OpenShift 4 to build, deploy, and scale said application. Additionally, you will learn how to deploy and leverage the Dynatrace Operator to seamlessly integrate observability into Openshift via the Dynatrace platform.

Who should attend:

  • Anyone who has had any exposure to Containers
  • Architects
  • Developers
  • Technical leads
  • Operations Engineers

What you will learn:

  • Deploying Dynatrace Operator and integration with Kubernetes events
  • Source to Image (S2I)
  • Rollbacks, Replication, and Recovery
  • Using Labels
  • Blue/Green Deployments
