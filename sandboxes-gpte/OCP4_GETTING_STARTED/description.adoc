This workshop is intended to give you a hands on introduction to using OpenShift from the perspective of a developer.
For developers looking to kickstart their projects, OpenShift enables efficient application development through streamlined workflows and validated integrations.

A sample lab guide link:https://redhat-scholars.github.io/openshift-starter-guides/rhs-openshift-starter-guides/4.11/index.html[can be found here, window="_blank"].

There are 4 programming language variants of the workshop:

* Java
* Node.js
* Python
* .NET

When provisioning completes, look for the service details in RHDP or the email you get from us.

== Provisioning Time

The deployment will take *approximately 75 minutes* to complete.
