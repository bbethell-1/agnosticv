== Test Container on OpenShift

Testcontainers is an open source framework for providing throwaway, lightweight instances of databases, message brokers, web browsers, or anything else that can run in a container.
Test Containers on OpenShift allows developers to launch test containers in an OpenShift cluster instead of in their local environments.  This is very useful for developers in restricted environments where they are unable to run local instances of podman or docker.

This demo environment is designed to demonstrate the inner loop and outer loop development phases.
For "inner loop", developers can run a local maven build and watch testcontainers being deployed in OpenShift rather than their local environment.
For "outer loop", developers can use a pipeline to perform maven tests on a Java application and watch testcontainers being deployed on OpenShift.
