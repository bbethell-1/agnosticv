OpenShift 4 Application Modernization Demo

This catalog item deploys a Shared cluster on AWS to show the OpenShift 4 Application Modernization Demo.

A single pair of VMs is created on RHV to enable the instructor to demonstrate using MTV.

The demo/lab instructions are on the cluster.
