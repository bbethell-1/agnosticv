This catalog item deploys an OpenShift cluster to use during the OpenShift 4 Application Modernization ILT.

A single pair of VMs is created on RHV to enable the instructor to demonstrate using the Migration Toolkit for Virtualization (MTV).

Software deployed:

  • OpenShift 4.11
  • OpenShift Data Foundations
  • OpenShift Virtualization
  • OpenShift Pipelines
  • OpenShift GitOps
  • Migration Toolkit for Virtualization (MTV)
  • Migration Toolkit for Applications (MTA)
  • Gitea
  • Code Server

This catalog item can also be used to demonstrate any application modernization task in detail with customers.

The lab instructions are on the cluster and are also available here.
