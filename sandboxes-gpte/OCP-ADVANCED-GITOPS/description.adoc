Learn advanced GitOps techniques in this hands-on workshop that will be applicable to both operations and developers teams.

*Note: This workshop is in alpha*

This workshop is intended as a 201 workshop to be taken after the 
https://catalog.demo.redhat.com/catalog?search=GitOps&item=babylon-catalog-prod%2Fsandboxes-gpte.ocp-gitops.prod[OpenShift GitOps Workshop]. 
It covers the following topics:

* Argo CD RBAC
* Configuring OpenShift GitOps (Health Checks, Enabling ApplicationSets, Enabling Terminal)
* Using App-of-Apps and ApplicationSets

===== Specifications

* Three controller nodes (AWS instance type: m5.2xlarge)
* Total number of nodes dependent on the size ordered (AWS instance type: m5.4xlarge)
* Cluster version: 4.18.x
* Authentication enabled (refer to your provisioning email for details regarding the "htpasswd")
* LimitRanges enabled
* Let's Encrypt certificates enabled on Ingress controllers
