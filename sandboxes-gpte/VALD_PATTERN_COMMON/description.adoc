A *Validated Pattern* delivering subscriptions and configs from Git to Red Hat&#174; OpenShift&#174; clusters.

Validated Patterns are living GitOps-based architectures which focus on
customer solutions that involve multiple Red Hat products and ongoing CI to
avoid bitrot.

Red Hat provides example for demonstration purposes. You can
modify or replace the examples to suit customers and market segments with similar
business problems.

This Validated Pattern highlights an architecture that uses Advanced
Cluster Management and Red Hat OpenShift GitOps (based on the ArgoCD project) to deliver application subscriptions and the
associated configuration, defined in Git, to a hierarchy of OpenShift clusters.

This is achieved by:

* Providing Helm templates that allow the namespaces and applications that need to be delivered to a set of managed clusters to be defined
* Using the OpenShift GitOps "app-of-app" pattern to deliver the applications to each cluster
* Using Advanced Cluster Management to deliver the top-level OpenShift GitOps application to managed clusters
* Integrating with Hashicorp Vault to securely deliver secrets to managed clusters from the central hub

== Specifications

* 3 Leader Nodes (m5a.2xlarge)
* 3 Worker Nodes (m5a.4xlarge)
* Cluster version: 4.20 (default)
* Let's Encrypt certificates enabled for default ingress
