Deploying Sigstore with Trusted Artifact Signer Workshop

Key Areas of Focus

Red Hat Trusted Artifact Signer (RHTAS): A part of Red Hat's Trusted Software Supply Chain portfolio, RHTAS is a production-ready deployment of the Sigstore project. It empowers software developers and consumers to securely sign and verify software artifacts.

This enhances the security of software development and distribution processes.

Enterprise Contract: A Cloud Native Computing Foundation (CNCF) project, Enterprise Contract is crucial for verifying the provenance of software artifacts. It enforces policies for Supply Chain Levels for Software Artifacts (SLSA) compliance.

Its seamless integration into existing CI/CD workflows and adoption by Red Hat for its internal next-generation build system ensures the secure and compliant construction of images.

Participants in the workshop will also gain access to a simplified install script. This script aids in deploying and configuring these technologies. It is especially beneficial for implementations in a Red Hat OpenShift environment, demonstrating the practical application of these security solutions in real-world settings.
