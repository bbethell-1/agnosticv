= On-Prem Red Hat Trusted Application Pipeline

== Description
The demo, titled *"On-Prem Red Hat Trusted Application Pipeline"*, showcases the integration and application of Red Hat's diverse suite of tools and technologies, specifically designed to create a secure, efficient, and developer-friendly Software Development Lifecycle (SDLC) in an on-premises environment.

This demo introduces the flexibility of utilizing either *Tekton* or *Jenkins* as the Continuous Integration (CI) solution. By default, *Tekton* serves as the primary CI tool, providing seamless and efficient pipeline management. However, based on customer needs, an optional *Jenkins module* is available to demonstrate its integration with RHTAP. This adaptability ensures the demo caters to varied organizational preferences for CI tools.

The demo also includes an option to provision with *OpenShift AI*, incorporating AI themes and Large Language Models (LLMs) for advanced capabilities. This enhancement builds on the existing Secure Supply Chain foundation by integrating AI capabilities. Customers can opt for the AI theme, utilizing GPUs at an additional cost, or choose a standard environment for resource efficiency.

For more details, visit the following link: https://rhpds.github.io/showroom-rhtap/modules/index.html

== Demo Startup
Allow 10 to 15 minutes after the status displays 'Running' for all OpenShift resources to become fully operational. For assistance, refer to the *Troubleshooting* page on the showroom link.

== AI with LLMs Integration
The demo now includes an AI integration option that leverages *Red Hat OpenShift AI* and supports Retrieval-Augmented Generation (RAG). This feature enhances AI responses with context-specific information by integrating external data sources for accuracy and relevance.

The integration supports open LLMs such as *Llama*, *Mistral*, or *Granite*, allowing you to start with a foundation model without the need for training from scratch. These models can be lifecycled, managed, served, and monitored by OpenShift AI, maintaining your private data's security within your datacenter or VPC.
