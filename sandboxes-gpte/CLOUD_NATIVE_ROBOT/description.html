This catalog item deploys OpenShift for the Cloud Native Robotz Hackathon

More details of the cluster are below:

  • Provisioning time: ~75 minutes
  • Credentials and other relevant information are available at the service detail page at https://demo.redhat.com
  • Provisioning guide available TBD
  • After you order your environment, you can manage it by logging into this system and select Services -> [This service] -> Details
  • Public Lab guide
  • The environment Runtime is 6 hours and Lifetime is 2 Days

Requesting this catalog item will provide you with a single dedicated OpenShift 4 cluster that each participant will share. It will be using per-participant credentials for OpenShift. Each participant has access to a web console so they'll be able to get started quickly. Once you order this catalog item, all details are available at https://demo.redhat.com. To provide the credentials to each participant we strongly recommend to use the Workshop feature of demo.redhat.com.
