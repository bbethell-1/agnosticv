Red Hat Validated Patterns

Medical Diagnosis

Validated Patterns are a living GitOps based architectures with a focus on customer solutions involving multiple Red Hat products, and ongoing CI to avoid bitrot.

Example applications are provided for demonstration purposes and can be modified/replaced to suite customers and/or market segments with similar business problems.

Read more about Validated Patterns.

This Validated Pattern highlights an architecture that uses Machine Learning to assist with image based medical diagnosis at the edge, providing faster results to patients and allowing doctors to focus on cases where their training adds the most value.

The specific example included is analysis of chest xrays for signs of pneumonia.

This is achieved by

  • Ingesting chest xrays into a Ceph object store
  • Posting notifications of new results to a Kafka topic.
  • Using a KNative Eventing Listener to listen for notifications and trigger a KNative Serving function.
  • Using an ML-trained model to assess the xray for risk of Pneumonia
  • Including a Grafana dashboard to display the pipeline in real time, along with images incoming, processed and anonymized, as well as full metrics.

Use cases

Deployment Instructions

This item currently requires you to manually deploy the workloads. You can find instructions on deploying the Medical Diagnosis demo TBD.

Environment

  • 3 Master Nodes (m5a.2xlarge)
  • 2 Worker Nodes (m5a.4xlarge)
  • Cluster version: 4.8.z (latest stable)
  • Let's Encrypt certificates enabled for default ingress
