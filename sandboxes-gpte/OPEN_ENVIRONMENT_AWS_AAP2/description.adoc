== Ansible Automation Platform on AWS - Open Environment

=== Welcome to the Red Hat Ansible Automation Platform on Amazon AWS RHPDS

This Environment gives Red Hatters on demand access to an AWS environment with access to the Ansible Automation Platform on AWS service offering. This time bound sandbox offers access to experience the Ansible Automation Platform on AWS. You as a Red Hat associate will be enabled to to test, create, and demo this offering! YOU will help make our customers and account teams successful. This AWS sandbox will allow users to do things not previously offered.

Always remember, “With Great Power, Comes Great Responsibility”

Note:

By ordering this sandbox, the user takes full responsibility for the running of their environment:

* The costs of services ordered
* The security of any credentials provided
* Approval and permission for usage
* Reporting of any issues or anomalies due to usage
* Adherence to Red Hat Compliance and Ethics Policies
* This is for INTERNAL use only and not to be shared with customers or partners

Current Offering:

* Red Hat Ansible Automation Platform on AWS.  (You will deploy AAP from the AWS Marketplace in the AWS account provided)

Provisioning Time? (To get the AWS environment)

* ~ 30 Min
* Once you are in the AWS environment it will take about 60 minutes to deploy AAP on AWS from the AWS Marketplace. The guide listed below provides you instructions on how to perform this deployment.

Default Lifespan of Environment?

* 2 Days
* Extensions Available - YES
