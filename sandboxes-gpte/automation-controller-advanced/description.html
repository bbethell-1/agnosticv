With the release of Red Hat Ansible Automation Platform 2, Red Hat Ansible Tower was renamed the automation controller. This workshop provides experienced Ansible Automation Platform users with an inside look at the capabilities of the automation controller.

Topics include configuring the automation controller without the UI, the clustering feature, instance groups, and smart and dynamic inventories. The workshop also explores the automation controller API and how to set up a well-structured Git repository for use with the automation controller.
