Gives developers a hands-on introduction to Red Hat® OpenShift® Container Platform. This workshop provides a hands-on introduction to using Red Hat OpenShift from the perspective of a developer. For developers looking to kickstart their projects, Red Hat OpenShift enables efficient application development through streamlined workflows and validated integrations. There are 4 programming language variants of the workshop:

* Java
* Node.js
* Python
*. NET

*Duration:* 2 Hours

*Audience:* Developers

*Products:* Red Hat OpenShift Container Platform

===== Supporting Materials

*Workshop slides:* The slides are located https://docs.google.com/presentation/d/1YYfWptUbyCwEfhDxVsVMJ9igNKek3NEX_ynFBVPcbVM/edit?usp=sharing[here^].

*Lab guide:* A sample lab guide is located https://openshift-labs.github.io/starter-guides-html/[here^].

*Environment access:* When provisioning completes, look for an email from RHPDS, and take note of the Homeroom URL. Lab content is under the *labs* project. You need to share the Homeroom *Route* URL with your attendees. Attendees need to provide a username and password to gain access. Available usernames correspond to the number of users requested when you ordered the environment:*Usernames:* user1.. userN*Password:* openshift If a user totally destroys their environment, they can log out and then choose a different user by clicking the menu in the upper-right corner of the Homeroom interface. They can also clear cookies.

*More information:* Source code, issues tracking, and further documentation are available https://github.com/openshift-labs/starter-guides/[here^].

*Support:* If you have any issues or errors, check this https://docs.google.com/document/d/1kNE7OW9kvnbYrfknsHIIWsUOPhWNbzeZKHcXS25DgMM/edit#heading=h.inf51xbvd9mg[Troubleshooting guide^].

*Provisioning time*: Typically 75 minutes.
