OpenShift Service Mesh Workshop

This is a full day, hands-on workshop built by RedHatGov. Technologies covered include Service Mesh 2.x, Kiali, Jaeger, Grafana, and Red Hat Single Sign On. Users will learn to operate and manage a service mesh for a microservices application. They will get hands-on with:

  • Building containers for microservices
  • Leveraging a service mesh to improve operational observability and debug performance issues
  • Leveraging a service mesh to address microservices challenges including dynamic network routing, circuit breaking, and fault injection
  • Leveraging a service mesh to implement mutual TLS, authorization, and egress security rules

Administration

The lab guide is provisioned using homeroom and a username distribution app. Participants login to the username distribution app to receive a user account on the cluster and a link to the workshop. The number of available usernames corresponds to the number of users requested when you ordered the environment. Navigate to the homeroom project and look for the username-distribution route URL. Give this route to workshop participants.

More info about how to access the workshop can be found here.

This lab is accompanied by the Presentation and Admin Guide.
