Learn to operate and manage a service mesh for a microservices application. This is a full-day, hands-on workshop built by Red Hat Government (RedHatGov). Technologies covered include Red Hat® OpenShift® Service Mesh 2.x, Kiali, Jaeger, Grafana, and Red Hat's single sign-on tools. Participants learn to operate and manage a service mesh for a microservices application. The workshop provides hands-on experience with the following:

* Building containers for microservices
* Leveraging a service mesh to improve operational observability and debug performance issues
* Leveraging a service mesh to address microservices challenges including dynamic network routing, circuit breaking, and fault injection
* Leveraging a service mesh to implement mutual TLS, authorization, and egress security rules

*Duration:* 1 day

*Products:* Red Hat OpenShift Service Mesh

*Access:* The lab guide is provisioned using homeroom and a username distribution app. Participants log in to the username distribution app to receive a user account on the cluster and a link to the workshop. The number of available usernames corresponds to the number of users requested when you ordered the environment. Navigate to the *homeroom* project, look for the *username-distribution* route URL, and give this route to the workshop participants. More info about how to access the workshop can be found https://github.com/RedHatGov/service-mesh-workshop-dashboard#access-info[here^].
