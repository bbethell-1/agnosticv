Set up Red Hat OpenShift Container Platform to run ML500 MLOps Enablement enablement technical exercises. This catalog item sets up the OpenShift Container Platform infrastructure that lets you run the https://rhoai-mlops.github.io/lab-instructions/#/[ML500 MLOps Enablement with OpenShift AI technical exercises^] yourself. Requesting this catalog item provides you with a single dedicated OpenShift Platforn Continer 4 cluster that includes the https://github.com/rhoai-mlops/deploy-lab[lab deployment^] components. After you order this catalog item, you receive a confirmation email that the lab was successfully provisioned. The email contains links to connect to the workshop, along with admin and user credentials. Use the links to get started.
