This is a demo to creates RHODS environment on AWS with NVIDIA GPUs on two worker nodes. You can use this base environment for creating and running RHODS related use cases on AWS with GPU requirements or demonstration.

This workshop includes :

OpenShift Container Platform : 4.12.12

Red Hat OpenShift Data Science : Latest

OpenShift Pipelines: 1.10

Gitea Operator: 1.20.0

OpenShift Cluster configured on AWS

NVIDIA Tesla V100 GPU's configured as worker nodes - 2 of these

Node Feature Discovery and NVIDIA GPU Operator's installed and configured so that RHODS can directly consume the GPU's while creating jupyterhub notebook"

Additional Information

When you login to RHODS and create jupyterhub or workbench, you will be able to select gpu for your workload/workbench.This is an environment which can be used as a demo for workloads related to RHODS with GPUs.

Basic Instructions for the demo

You can use this repo to have some basic programs running to test GPUs in RHODs jupyterhub notebook: Basic Instructions to Test GPUs in RHODS

Access Information:

You will receive an email with both the cluster admin credentials as well as administrative credentials and the URL to access Red Hat OpenShift Data Science portal.
