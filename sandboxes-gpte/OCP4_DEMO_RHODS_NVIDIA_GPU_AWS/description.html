This is a demo to creates RHOAI environment on AWS with NVIDIA GPUs on two worker nodes. You can use this base environment for creating and running RHOAI related use cases on AWS with GPU requirements or demonstration.

This workshop includes :

OpenShift Container Platform : 4.18

Red Hat OpenShift AI : 2.19.0

Authorino

OpenShift Pipelines

OpenShift GitOps

Serverless and Service Mesh Operators

Gitea Operator

Web Terminal

OpenShift Cluster configured on AWS

NVIDIA NVIDIA L4 Tensor Core GPUs configured as worker nodes - 2 of these

Node Feature Discovery and NVIDIA GPU Operator's installed and configured so that RHOAI can directly consume the GPU's while creating jupyterhub notebook"

Additional Information

When you login to RHOAI and create jupyterhub or workbench, you will be able to select gpu for your workload/workbench.This is an environment which can be used as a demo for workloads related to RHOAI with GPUs.

Basic Instructions for the demo

You can use this repo to have some basic programs running to test GPUs in RHOAIs jupyterhub notebook: Basic Instructions to Test GPUs in RHOAI

Access Information:

You will receive an email with both the cluster admin credentials as well as administrative credentials and the URL to access Red Hat OpenShift AI portal.
