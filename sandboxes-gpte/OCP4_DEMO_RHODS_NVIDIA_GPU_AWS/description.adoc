This provides an OpenShift AI environment on AWS with a selectable NVIDIA GPU. You can use this base environment for creating and running RHOAI related use cases on AWS with GPU requirements.

== Products and Environment

* OpenShift Container Platform 4.18
* Red Hat OpenShift AI 2.25
* NVIDIA L4 Tensor Core GPUs

IMPORTANT: This catalog item requires AWS gpu instances, which may have limited availability in some regions. This is out of our control and you may experience deployment failures if you try to provision in a region with limited capacity.

== Guide

This is a sandbox environment for you to explore, build, and test in. There is no lab or demo guide provided.
