= Ansible plug-ins for Red Hat Developer Hub Demo.

Welcome to the demo of Ansible plug-ins for Red Hat Developer Hub! Red Hat Developer Hub is an enterprise-grade, open developer platform that helps organizations build and deploy applications faster, with better quality. Red Hat Developer Hub is based on Project Janus, a framework for building developer portals. Project Janus is a powerful and flexible framework that provides a solid foundation for building secure, scalable, and easy-to-use developer portals.

In this demo, we will scaffold and develop an Ansible playbook project using Ansible plug-ins for Red Hat Developer Hub. These plug-ins integrate Ansible Automation Platform with Red Hat Developer Hub, offering an Ansible-first UI experience designed to streamline automation workflows. The goal is to provide a unified platform for automation developers, encompassing learning, orientation, and the creation and development of Ansible projects. This approach leverages platform engineering principles to create a single Internal Developer Portal (IDP) for managing Ansible within organizations, facilitating a robust Community of Practice (COP) for automation.
