This lab offers attendees an intro-level, hands-on session with Red Hat Data Grid. From the first line of code to making services to consuming them and finally to assembling everything and deploying it on Openshift. Using Red Hat Data Grid Operator to install it and configure. It illustrates what Cache is, how to program with a distributed cache, and how to build applications and best practices on designing applications with Cache.

Red Hat Data Grid 8.0 provides a distributed in-memory, NoSQL datastore solution. Your applications can access, process, and analyze data at in-memory speed to deliver a superior user experience. Whether you are using legacy applications or a new breed of microservices and functions, Red Hat Data Grid 8.0 will enable your applications to perform better with its in-memory solution.

What you will learn?

  • What's new in Red Hat Data Grid 8.2
  • What is a Cache, and how to start with the common use cases
  • Embedded Cache
  • Clustering in a Cache scenario and how it works
  • Remote Cache and how to take benefit of Red Hat Data Grid
  • Using the Red Hat Data Grid Operator
  • Learn about Red Hat Data Grid server REST API.
  • Externalize sessions with Spring sessions
  • You will build applications with known frameworks like Quarkus and Spring.
  • And much more…​

Requesting this catalog item will provide you with a single dedicated OpenShift 4 cluster which each participant will share, using per-participant credentials for OpenShift and CodeReady Workspaces. Each participant's developer workspace will be pre-provisioned and started up in CodeReady Workspaces so they'll be able to get started quickly. Once you order this catalog item, you'll receive an email with links to connect to the workshop which you will share with participants, along with admin credentials in case you need to log in and do housekeeping or other changes. Note that developer workspaces are started in the background and depending on how many participant seats you order, it may take longer to complete provisioning.
