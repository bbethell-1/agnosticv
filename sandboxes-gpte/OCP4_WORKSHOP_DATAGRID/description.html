Install, configure, make and consume services with, and deploy Red Hat Data Grid.

This catalog item presents an introductory level, hands-on session with Red Hat Data Grid--from the first line of code, to using Red Hat Data Grid Operator to install and configure Red Hat Data Grid, to making and consuming services, to assembling everything and deploying it on Red Hat Openshift Container Platform. The asset illustrates what the cache is, how to program with a distributed cache, and how to build applications and best practices on designing applications with the cache.

Red Hat Data Grid 8 provides a distributed, in-memory, NoSQL datastore solution. Your applications can access, process, and analyze data at in-memory speed to deliver a superior user experience. Whether you are using legacy applications or a new breed of microservices and functions, Red Hat Data Grid 8 enables your applications to perform better with its in-memory solution.

This item covers the following topics:

  • What is new in Red Hat Data Grid 8
  • What is a cache, and how to get started with common use cases
  • Embedded cache
  • Clustering in a cache scenario and how it works
  • Remote cache and how to take advantange of Red Hat Data Grid
  • Using Red Hat Data Grid Operator
  • Understanding the server REST API in Red Hat Data Grid
  • Externalizing sessions with Spring sessions
  • Building applications with known frameworks like Quarkus and Spring

Requesting this catalog item provides you with a single dedicated OpenShift Container Platform 4 cluster that each participant shares, using per-participant credentials for OpenShift Container Platform and CodeReady Workspaces. Each participant's developer workspace is pre-provisioned and started up in CodeReady Workspaces so they can get started quickly.

Developer workspaces are started in the background. Depending on how many participant seats you order, it might take longer to complete provisioning.

After you order this catalog item, wait for a confirmation email that the lab was successfully provisioned, and then use the links in the email to get started.
