= Airsol Sentiments and Baggage Claim Workshop

Explore how the fictional insurance company Airsol is using OpenShift AI to improve its customer sentiments and baggage claims processing. During this immersive experience, you’ll get to use and deploy different AI models, as well as use multiple features of OpenShift AI. You well get exposed to LLMs and RAG, Image Detection, as well as deploy the application that ties it all together.

Once the environment is provisoned, you will have showroom link with all the instructions to walk through the workshop.
