Red Hat OpenShift AI on ROSA demonstrates how AI/ML technologies can be combined to solve a real-world insurance business problem. Using the fictitious Parasol Insurance scenario, learners apply large language models, retrieval-augmented generation, and computer vision to automate insurance claim processing. The workshop runs on a managed ROSA HCP cluster with OpenShift AI, Amazon Bedrock, and a full set of supporting services provisioned and ready to use.

== Lab Guide

You can find a preview version of the link:https://rh-mobb.github.io/ai-on-rosa-workshop[lab guide^] here.

== Detailed Overview

* *Module 1: Setting the Stage*
** Understand the Parasol Insurance scenario and business problem
** Review the current manual claims process and its limitations
** See AI/ML prototype results presented to a board of directors

* *Module 2: Getting Connected*
** Access the ROSA cluster and OpenShift AI dashboard
** Create a data science project and Jupyter workbench
** Validate the lab environment is ready

* *Module 3: Notebook-Based LLM Exploration*
** Use Jupyter notebooks to query LLMs via Amazon Bedrock
** Apply summarization and information extraction to insurance claims
** Implement retrieval-augmented generation (RAG) and prompt engineering

* *Module 4: Computer Vision — Image Processing*
** Apply YOLOv8 for car and accident recognition in claim photos
** Retrain the model and serve it via OpenShift AI model serving
** Combine image and text outputs into a unified claims pipeline

* *Module 5: Full Application Deployment*
** Explore the Parasol Insurance application architecture
** Deploy the application using OpenShift GitOps and Pipelines
** Process end-to-end insurance claims through the AI-powered interface
