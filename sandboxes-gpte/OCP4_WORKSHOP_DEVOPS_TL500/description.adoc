Set up Red Hat OpenShift Container Platform to run DevOps enablement technical exercises.

This catalog item sets up the OpenShift Container Platform infrastructure that lets you run the link:https://rht-labs.com/tech-exercise/#/[TL500 DevOps Culture and Practice Enablement technical exercises, window="_blank"] yourself.

Requesting this catalog item provides you with a single dedicated OpenShift Platforn Continer 4 cluster that includes the link:https://github.com/rht-labs/enablement-framework[enablement framework, window="_blank"] software.

An instance of FreeIPA is deployed within the cluster, which has preprovisioned learner users. This is integrated with the cluster single sign-on and deployed tooling.

After you order this catalog item, you receive a confirmation email that the lab was successfully provisioned. The email contains links to connect to the workshop, along with admin credentials. Use the links to get started.
