== AWS Sandbox

=== Welcome to the Red Hat Open Environment Project

* The costs of services ordered

* This is for internal use only and not to be shared with customers or partners

=== Available Sandboxes

* AWS - Blank Sandbox
* IBM - Blank Sandbox

=== Access

* API and CLI access to AWS
* No pre-provisioned nodes or services
* All Services are available through AWS

=== Provisioning Time

~ 10 Min

=== Lifetime

* 7 Days
* Extensions Available - Yes

=== Auto-Stop Configuration

* By default environment stops after *10h*
* All instances within the account are automatically stopped
* Auto-stop can be disabled

=== Support Information

There is limited support for the Open Environment Sandboxes. UPDATE: Auto-stop is now enabled by default. You can disable auto-stop for your service in the Services view. Default runtime is now 10h. Instances will be stopped after 10h.
