Learn about the automation controller in Red Hat Ansible Automation Platform.

With the release of Red Hat Ansible Automation Platform version 2, the Ansible Tower component was renamed automation controller. In this catalog item, advanced users learn more about the capabilities of the automation controller.

  • Configure the automation controller without using the UI.
  • Become familiar with the clustering feature and instance groups.
  • Get an overview of the automation mesh, smart and dynamic inventories, and the automation controller API.
  • Set up a well-structured Git repository for use with the automation controller.

Product(s): Red Hat Ansible Automation Platform
