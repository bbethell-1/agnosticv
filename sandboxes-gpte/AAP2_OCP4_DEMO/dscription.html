This lab provides a sandbox for demo, development, and expiramentaion with the ansible/product-demos project.

There are two recomended ways to use this asset:

  • As is: Using the project as is provides with you a community of demos for a variety of differnt use cases to minimize the required effort for high impact customer demos.
  • Customized: Not all customers are the same and many require customizations to meet their requirements. This environment is built in a way to allow the use of git ops to rapidly prototype custom customer scenarios. See the project documentation for details on how use in this way.

Documentation: Product-Demos GitHub

Duration: Varies from 1 hour customer demo to multi-day customization or hackathon

Audience: Automation Sellers and Technical Specialists

Product(s): Red Hat Ansible Automation Platform, OpenShift, Linux, Windows

Specifications

  • 1x Automation Controller on OCP4
  • 1x OpenShift4 Cluster
  • AWS Open Environment for provisioning of resources needed for the demo

Supporting Materials

Access guide: After you complete provisioning, you receive an email with a website containing a user credential and access to the following:

  • Automation Controller Web UI
  • OpenShift Console/API
  • AWS Console
  • RHEL bastion host

The website provided with this information is dynamically created upon provisioning.

Lab materials: This sandbox is a "choose your own adventure" style lab. It is intented to provide you the tools needed to deliver high impact demos and automation solutions. Therefore, an official lab guide is not provided. Instead, review the documentation from the Product-Demos GitHub for guidence on how to best utilize the project.

Support resources:

  • Red Hat employees can join the Google Chat ansible/product-demos chat room.
  • For issues with workshop content, material, and so on, please open an issue on GitHub.
  • For issues with Red Hat Product Demo System (RHPDS), urgent upcoming workshops, and so on, please open an issue here.

Provisioning time: Typically, ~1 hour
