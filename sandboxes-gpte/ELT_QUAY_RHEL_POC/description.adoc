=== Deploy Red Hat Quay on RHEL

This lab is a guided exercise for installing Red Hat Quay and Clairv4 on RHEL. Although this is for proof-of-concept (non production) purpose, this lab helps you understand the individual components of Red Hat Quay and how they work together.

Below are the topics covered:

* Configure the RHEL server with prerequisites
* Configure the postgres database
* Configuring Redis
* Red Hat Quay configuration setup
* Deploy Red Hat Quay
* Deploy Red Hat Quay with SSL certificates
* Setup Quay Superuser
* Setup repository mirroring
* Deploy and run Clairv4
