= Parasol Insurance AI Workshop - Putting predictive and generative AI to work

Explore how the fictional insurance company, Parasol, uses OpenShift AI to improve its claims processing. In this immersive experience, you will have the opportunity to deploy and work with different AI models while utilizing various features of OpenShift AI.

== Very Important for Deployment
After the initial deployment from the demo environment, please allow at least **20-30 minutes** (more for a large number of users) for ArgoCD to set up all users and workloads on the cluster. You can monitor the progress by opening ArgoCD from the OpenShift console (top right menu, log in with OpenShift admin credentials).

This is a Rolling Sync, with Applications being deployed one after another. Some Applications take a long time, like the LLM deployment (ic-shared-llm-app, 10-15 minutes). If some ArgoCD Applications get stuck for too long (no sync happening any more on any Application), you can click on "SYNC APPS" to continue the process.

== Key highlights of this workshop include
* Exposure to Large Language Models (LLMs) and Retrieval-Augmented Generation (RAG).
* Image detection models to analyze and process claims data.
* Hands-on deployment of an application that integrates these AI technologies for a cohesive business solution.

This workshop provides a glimpse into how AI/ML technologies can be applied to real-world business problems like insurance claim processing. Please note, while the models and techniques used in this lab are illustrative of a prototype, they are not designed for a production environment.
