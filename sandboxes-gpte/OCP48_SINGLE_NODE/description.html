OpenShift 4.8 Single Node Workshop

OpenShift 4.8 Single Node Workshop provisions an OpenShift cluster with basic customizations on AWS infrastructure for running hands-on-labs, workshops and similar events where no specialized environment is available.

For specialized workshops (such as Containers and Cloud-Native Roadshow, OpenShift Getting Started Workshops, etc.) please use the dedicated catalog item.
