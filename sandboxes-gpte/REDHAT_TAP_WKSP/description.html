Workshop Title: On-Prem Red Hat Trusted Application Pipeline Workshop

Description

This workshop, titled "On-Prem Red Hat Trusted Application Pipeline", showcases the integration and application of Red Hat's diverse suite of tools and technologies, specifically designed to create a secure, efficient, and developer-friendly software development lifecycle (SDLC) in an on-premises environment.

Red Hat Products

  • Red Hat Developer Hub: Provides a self-service portal to accelerate developer onboarding.
  • Red Hat Trusted Application Pipeline (RHTAP): Central to ensuring security and efficiency in the SDLC.
  • Red Hat Trusted Artifact Signer: Enhances the security and integrity of software artifacts.
  • Red Hat Trusted Profile Analyzer: Analyzes and ensures robust security profiles for applications.
  • Red Hat Advanced Cluster Security (ACS): Offers comprehensive security for Kubernetes clusters.
  • Red Hat OpenShift Pipelines: Supports continuous integration and deployment with powerful CI/CD capabilities.
  • Red Hat GitOps: Facilitates efficient and consistent software deployment through GitOps methodologies.
  • Red Hat Quay: Provides a secure and scalable container image registry.
  • Red Hat OpenShift Dev Spaces: Streamlines the setup of development environments.
  • Red Hat OpenShift: A leading enterprise platform for container orchestration.
