Understand and use command-line activities to implement the automation controller. For users who are new to Red Hat Ansible Automation Platform, this catalog item presents the basics of understanding foundational command-line activities and applies this information to implement the Ansible Automation Platform automation controller to your enterprise use cases. 

You write your first Ansible playbook, work on Jinja templates, and implement higher-level Ansible roles. You also work with the automation controller and learn about inventory and credential management, projects, job templates, surveys, workflows and more.
