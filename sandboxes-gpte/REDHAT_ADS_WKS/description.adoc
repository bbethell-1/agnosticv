= Red Hat Advanced Developer Suite - Software Supply Chain (Workshop)

Imagine you're a developer tasked with building new features, but you're constantly slowed down by manual security reviews,
complex toolchains, and waiting for infrastructure to be provisioned. How can you deliver value quickly without compromising
on security?

This project is a hands-on, story-driven workshop that puts you in the shoes of a developer facing this exact challenge. It
introduces the *Red Hat Advanced Developer Suite - Software Supply Chain*, a powerful solution designed to secure
your software supply chain and empower you to build and deploy applications with both speed and confidence.

As the hero of the story, you'll learn how to transform your development process by using the key components of the suite:

* *Red Hat Developer Hub:* Your journey begins here, at a centralized portal that provides a "golden path" for development.
  Instead of waiting for weeks, you'll use pre-configured software templates to create new, production-ready applications in
  minutes, with all the security and compliance standards built-in from the start.

* *Red Hat Trusted Profile Analyzer:* Think of this as an automated security expert embedded in your workflow. As you build
  your application, it continuously scans your code and dependencies for known vulnerabilities, giving you immediate feedback
  and ensuring that only secure code moves forward.

* *Red Hat Trusted Artifact Signer:* Once your application is built and scanned, this tool acts as a digital notary. It
  cryptographically signs your software artifacts, creating a tamper-proof seal that guarantees they are authentic and have not
  been altered. This signature becomes a crucial part of your secure software supply chain.

To bring this all to life, the workshop offers two distinct, hands-on learning paths that both embrace a modern *pipeline-as-code*
approach, where your CI/CD process is defined and versioned just like your application code.

== The OpenShift Pipelines (Tekton) Path

Explore a cutting-edge, Kubernetes-native approach to CI/CD. You'll define your pipelines declaratively with Tekton, creating
a flexible and powerful automation workflow that is perfectly integrated with the cloud-native ecosystem.

== The Jenkins Path

For teams with existing investments in Jenkins, this path shows you how to supercharge your familiar workflows. You'll learn
how to integrate Jenkins seamlessly into the *RHADS for Software Supply Chain* ecosystem, enhancing it with the same powerful
security and automation capabilities.

By the end of this workshop, you won't just have learned about a set of tools; you'll have experienced a fundamental shift in
the development process—one where security is an integrated partner, not a bottleneck, allowing you to innovate securely and
at scale.
