CCN Roadshow for Dev Track Openshift


This catalog item deploys Containers and Cloud-Native RoadShow for Dev Track on Openshift 4 using the AgnosticD

Please note that this is still new software and as such, you may run into some bugs.

Deployments may still fail randomly. If you experience this, please try provisioning again.

All infra pods (i.e. codeready workshpaces, keycloak, gogs) are deployed in the labs-infra project.

Here are modules that you will deliver in the Dev Track

  • Module 1: Optimizing Existing Applications
  • Module 2: Debugging, Monitoring and Continuous Delivery
  • Module 3: Control Cloud Native Apps with Service Mesh
  • Module 4: Advanced Cloud Native with Event-Driven Serverless
More details of the CCN RoadShow Dev Track cluster are below:
  • Region: NOW SELECTABLE!
    • Americas - AWS zone (us-east-2)
    • EMEA - AWS zone (eu-west-1)
    • APAC - AWS zone (ap-southeast-1)
  • Provisioning time: ~75 minutes
  • Credentials and other relevant information are sent in the final email
  • RHPDS Provisioning guide available here
  • After you order your environment, you can manage it by logging into this system and select Services -> My Services -> [This service] -> App Control
  • The environment Runtime is 2 hours and Lifetime is 2 Days
Requesting this catalog item will provide you with a single dedicated OpenShift 4 cluster that each participant will share. It will be using per-participant credentials for OpenShift and CodeReady Workspaces. Each participant's developer workspace will be pre-provisioned and started up in CodeReady Workspaces so they'll be able to get started quickly. Once you order this catalog item, you'll receive an email with links to connect to the workshop which you will share with participants, along with admin credentials in case you need to log in and do housekeeping or other changes. Note that developer workspaces are started in the background and depending on how many participant seats you order, it may take longer to complete provisioning.

The source material also has instructions to render the lab guide (without ordering this catalog item), to see what participants will see and experience.
