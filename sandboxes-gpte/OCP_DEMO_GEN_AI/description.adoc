= Generative AI Demo with Red Hat OpenShift AI

Experience the transformative power of AI with the "Generative AI Demo with Red Hat OpenShift AI." This demonstration leverages the robust capabilities of Red Hat OpenShift AI on the stable, secure OpenShift Container Platform. Dive into advanced AI applications and see how they can revolutionize various industries.

The environment provisions two LLM's (Mistral), one with and another without RAG.
You get chatbot to query and get responses. The one with RAG / LLM will get you accurate information based on what you feed into the RAG database. RAG database is Postgresql with vector extensions and chatbot frontend is Gradio.

There are two persona based pipeline flow, one admin way and another one data scientist way. Both are using OpenShift AI UI to show seamless integration with OpenShift and OpenShift Pipelines (Tekton). This demonstration shows this unique value proposition of OpenShift AI integrated with OpenShift and its components like OpenShift Pipelines which is becomes very important aspect when discussing our Hybrid Cloud Strategy.

== Key Components of the Demo
* *Red Hat OpenShift Container Platform 4.18*: Establishes a secure, stable foundation for containerized applications.
* *Red Hat OpenShift AI*: Red Hat® OpenShift® AI is a flexible, scalable artificial intelligence (AI) and machine learning (ML) platform that enables enterprises to create and deliver AI-enabled applications at scale across hybrid cloud environments.
* *Node Feature Discovery and NVIDIA GPU Operators*: Optimally configured to harness NVIDIA GPUs directly, enhancing the performance of AI-driven applications.
* *Red Hat OpenShift Data Foundation*: Offers scalable and secure data management solutions.
* *Red Hat OpenShift Pipelines * and *Red Hat OpenShift GitOps*: These tools automate and streamline CI/CD workflows, enhancing developer efficiency.
* *Gitea Operator*: Supports robust Git repository management within your development environment.
* *Red Hat OpenShift Serverless* and *Red Hat OpenShift Service Mesh*: Facilitate the building and operating scalable, secure microservices.

== Special Features
* *Generative AI and Retrieval-Augmented Generation (RAG)*: Harness the power of LLMs with RAG to explore advanced AI functionalities.
* *GPU-Enhanced Performance*: You can directly utilize configured NVIDIA GPUs for computationally intensive tasks in your JupyterHub notebook or AI workbench.

== Provisioning and Access
* *Environment Setup*: Configured on AWS with a combination of NVIDIA GPU and m5 worker nodes.
* *Access Details*: Cluster admin and Red Hat OpenShift AI portal access credentials will be provided via email after the demo environment is provisioned.
* *Setup Time*: Approximately 2 hours.
