Deploy a cluster with Red Hat Advanced Cluster Management for Kubernetes and HyperShift. This catalog item deploys a cluster in Red OpenShift Container Platform 4 on AWS with Red Hat Advanced Cluster Management for Kubernetes (RHACM) and hosted control planes, which are based on the Hypershift project and are in Technology Preview. It provides instructions for the following scenarios:

* Explore the preinstalled environment.
* Explore the cluster that was previously deployed using hosted control planes.
* Deploy an additional cluster using hosted control planes.
* Deploy an application to both clusters using RHACM.
* Destroy the additional cluster.
* Create another cluster with separate steps for the AWS infrastructure using the cluster itself.
* Destroy that cluster again.

*Product(s):* Red Hat OpenShift Container Platform

===== Specifications

The cluster has the following properties:

* OpenShift Container Platform 4.14
* RHACM 2.9 installed and configured
* A small cluster that has been predeployed using hosted control planes
