This catalog item deploys an OpenShift 4 cluster on AWS with Red Hat Advanced Cluster Management for Kubernetes and HyperShift Technology Preview.
It has the following properties:

  • OpenShift Container Platform 4.11.
  • Red Hat Advanced Cluster Management for Kubernetes (RHACM) 2.6 installed and configured.
  • Technology Preview for HyperShift enabled and configured on RHACM.
  • A small cluster has been pre-deployed using HyperShift.

The instructions on how to use this envrionment are located at OpenShift Origin Labs - HyperShift.
The instructions cover the following scenarios:

  • Explore the pre-installed environment.
  • Deploy a cluster using HyperShift.
  • Deploy an application to both clusters using RHACM.
  • Background on how HyperShift was installed and configured on the environment.
