Red Hat Advanced Cluster Management with HyperShift

This catalog item deploys an OpenShift 4 cluster on AWS with Red Hat Advanced Cluster Management for Kubernetes. It also has the Technology Preview for HyperShift enabled and configured. Finally it has a small cluster already pre-deployed using HyperShift. You can deploy more HyperShift clusters from the bastion VM if necessary.

The lab instructions are at https://github.com/redhat-cop/openshift-lab-origin/blob/master/HyperShift/Hypershift.adoc.
