This catalog item deploys an OpenShift 4 cluster on AWS with Red Hat Advanced Cluster Management for Kubernetes and Hosted Control Planes (Hypershift) Technology Preview.
It has the following properties:

  • OpenShift Container Platform 4.12.
  • Red Hat Advanced Cluster Management for Kubernetes (RHACM) 2.7 installed and configured.
  • Technology Preview for Hosted Control Planes (HyperShift) enabled and configured on RHACM.
  • A small cluster has been pre-deployed using Hosted Control Planes.

The instructions on how to use this envrionment are located at OpenShift Origin Labs - HyperShift.
The instructions cover the following scenarios:

  • Explore the pre-installed environment.
  • Explore the previously deployed cluster using Hosted Control Planes.
  • Deploy an additional cluster using Hosted Control Planes.
  • Deploy an application to both clusters using RHACM.
  • Destroy the additional cluster.
  • Create another cluster with seperate steps for AWS infrastructureusing and the cluster itself.
  • Destroy that cluster again.
