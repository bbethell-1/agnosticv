This is a demo of migrating and managing virtual machines with *OpenShift Virtualization*.

This demo has three parts:

* Manually migrating virtual machines from VMware to OpenShift Virtualization with *Migration Toolkit for Virtualization (MTV)*.
* Automating the migration setup process using *Ansible Automation Platform (AAP)*, showcasing what migrating VMs at scale looks like.
* VM monitoring with *Advanced Cluster Management (ACM)*.
