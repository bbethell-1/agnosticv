Industrial Edge

Red Hat Validated Patterns

Red Hat Validated Patterns are XYZ. Read more about them here.
 
In this Validated Pattern, you will deploy and demonstrate a horizontal solution for IoT Edge use cases. The specific example is live defect detection based on sensor data in an industrial setting, but it could easily be applicable to other verticals.

Use cases

  • How to use a GitOps approach to keep in control of configuration and operations
  • How to centrally manage multiple clusters and including workloads
  • How to build and deploy workloads across multiple clusters using modern CI/CD tools
  • How to train AI/ML models in the public cloud with data from the private cloud and bring the executable model back to on prem
  • IoT Edge

Red Hat products and solutions

  • Red Hat OpenShift (Kubernetes++)
  • Red Hat Advanced Cluster Management (Open Cluster Management)
  • OpenShift GitOps (ArgoCD)
  • OpenShift Pipelines (Tekton)
  • Red Hat Quay (Container image registry)
  • Red Hat AMQ (Apache ActiveMQ)
  • Red Hat AMQ Streams (Apache Kafka Event Broker)
  • Red Hat Integration (Apache Camel-K)
  • Open Data Hub

Deployment Instructions

This item currently requires you to manually deploy the workloads. You can find instructions on deploying the Industrial Edge demo here.

Environment

  • 3 Master Nodes (m5a.2xlarge)
  • 2 Worker Nodes (m5a.4xlarge)
  • Cluster version: 4.8.z (latest stable)
  • Let's Encrypt certificates enabled for default ingress
