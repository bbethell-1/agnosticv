A Validated Pattern for managing edge clusters that perform live defect detection.

Validated Patterns are living GitOps-based architectures which focus on customer solutions that involve multiple Red Hat products and ongoing CI to avoid bitrot.

This Validated Pattern highlights an architecture that uses Machine Learning to centrally manage edge clusters that perform live defect detection based on a stream of IoT sensor data.

This demo provides example applications that you can modify or replace to suit customers and market segments with similar business problems. It includes a developer workflow for building and delivering updated images that interface with the sensors and provide a live view of their output.





Products: Red Hat OpenShift (Kubernetes++), Red Hat Advanced Cluster Management (Open Cluster Management), OpenShift GitOps (ArgoCD), OpenShift Pipelines (Tekton), Red Hat Quay (Container image registry), Red Hat AMQ (Apache ActiveMQ), Red Hat AMQ Streams (Apache Kafka Event Broker), Red Hat Integration (Apache Camel-K), Open Data Hub

Environment Specifications

  • 3 Master Nodes (m5.2xlarge)
  • 2 Worker Nodes (m5.4xlarge)
  • Cluster version: 4.8.z (latest stable)
  • Let's Encrypt certificates enabled for default ingress
