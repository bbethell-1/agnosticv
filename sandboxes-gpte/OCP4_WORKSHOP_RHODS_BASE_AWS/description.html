This workshop creates Base RHODS environment on OCP cluster running on AWS. You can use this base environment for creating and running RHODS related workshops. This workshop includes : OpenShift Cluster Version: 4.12 Red Hat OpenShift Data Science OpenShift Cluster configured on AWS Access Information: You will receive an email with both the cluster admin credentials as well as administrative credentials and the URL to access Red Hat OpenShift Data Science portal.
