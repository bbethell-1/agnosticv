This is a demo to creates RHODS environment on AWS with Habana Intel based GPU/Accelerators as worker nodes.. You can use this base environment for creating and running RHODS related use cases on AWS with Habna Gaudi accelerator requirements or demonstration.

This workshop includes :

OpenShift Container Platform : 4.12.15

Red Hat OpenShift Data Science : Latest

OpenShift Pipelines: 1.10

Gitea Operator: 1.20.0

OpenShift Cluster configured on AWS

Habana Gaudi GPU's/Accelerators configured as worker nodes using dl1.24xlarge instance type on AWS

Node Feature Discovery, Kernel Module Management and Habana Accelerator Operator's installed and configured so that RHODS can directly consume the GPU's while creating jupyterhub notebook"

Additional Information

When you login to RHODS and create jupyterhub or workbench, you will be able to select gpu for your workload/workbench.This is an environment which can be used as a demo for workloads related to RHODS with Habana Gaudi Accelerators
