Learn how to use progressive delivery with Argo Rollouts.

This catalog item walks you through the basics of using Argo Rollouts to provide progressive delivery of applications. It includes exercises on blue-green and canary strategies as well as automated testing with analyses.

This asset uses a single shared cluster for all users and pre-provisions Argo Rollout instances along with distinct namespaces for each user.

Specifications

  • Three controller nodes (AWS instance type: m5.2xlarge)
  • Total number of nodes dependent on the size ordered (AWS instance type: m5.4xlarge)
  • Cluster version: 4.13.x
  • Authentication enabled (refer to your provisioning email for details regarding the "htpasswd")
  • LimitRanges enabled
  • Let's Encrypt certificates enabled on Ingress controllers

Supporting Materials

Access guide: You have full admin access to the provisioned workshop cluster, which is a vanilla OpenShift Container Platform 4.10 cluster.
