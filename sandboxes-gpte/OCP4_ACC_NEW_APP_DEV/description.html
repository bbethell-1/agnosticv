Accelerate (New) Application Development - Sales Play Demo

This demo covers the top challenges addressed by the Sales play:

  • The ability to win, serve and retain customers depends on delivering new capabilities through secure software applications rapidly and continuously.
  • IT organizations need to provide their developers with the flexibility to securely build, deploy, run, and scale applications across the hybrid cloud.

The demo is being broken down into THREE sections:

Enabling Immediate Productivity
This section targets developers. "How they can achieve immediate productivity with built-in capabilities using the languages they are already familiar with.”

Automating Guardrails for Consistent Security and Operation Control
This section is for DevOps, Platform Engineers, SRE and Ops. The Red Hat solution "eases the operation and management of clusters distributed across a hybrid cloud environment, while maintaining security, consistency, and operational control.”

Building a Flexible Architecture
This section is for Software & Platform Architects. How to architect systems using microservices, API and event driven architectures, all on one platform.

Full Documentation

Full documentation, including information about its purpose, how to run the demo, scenarios that can be demoed, videos, and supporting slides.
