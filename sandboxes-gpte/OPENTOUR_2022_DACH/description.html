This catalog item deploys OpenShift with ServiceMesh, GitOps and Pipelines for the ContainerDays 2023 Workshop.

From zero to production: Microservices in k8s, built with Tekton, managed by ArgoCD and using Istio New technologies can be overwhelming, especially if you combine them. In this session, we break down the complexity into simple, easy, understandable steps. Let's walk together through the journey from building a microservice with a pipeline and deploy it via GitOps to Kubernetes. With the move to microservice architectures came the challenges of distributed computing. Although required patterns such as circuit breakers or client-side load balancing could be solved with libraries like Netflix Hystrix or the Spring Cloud framework, infrastructure-related code still had to be written instead of being able to focus on the business logic. Service meshes now solve typical problems in the areas of resiliency, security, observability, routing and more. So we add Istio Service Mesh to our Kubernetes cluster and the microservices, to get rid of infrastructure-related code in our apps. After the Workshop, you have a solid understanding of Tekton/Pipeline and ArgoCD/GitOps in theory and practice. And what an Istio/Service Mesh is and how you can use it. Especially, you'll be able to use the traffic shaping, observability and resiliency features of a Service Mesh. What helps to understand and adapt the techniques for your environment. Hands-on environment with a Kubernetes Cluster, Tekton, ArgoCD and Service Mesh provided for all workshop participants to follow along.
