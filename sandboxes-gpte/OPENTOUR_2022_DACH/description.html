This catalog item deploys OpenShift with ServiceMesh, GitOps and Pipelines for the Open Tour 2022 Developer Track.

Please note that this is still new software, prepared for an event series and not general use, and as such, you may run into some bugs.

Deployments may still fail randomly. If you experience this, please try provisioning again.

For every user are two projects created, one with -app ending and one with -system ending. In -system all Service Mesh related operators are installed and -app is for deploying the sample applications.

More details of the Open Tour 2022 Developer Track cluster are below:

  • Provisioning time: ~75 minutes
  • Credentials and other relevant information are sent in the final email
  • RHPDS Provisioning guide available here
  • After you order your environment, you can manage it by logging into this system and select Services -> My Services -> [This service] -> App Control
  • The environment Runtime is 2 hours and Lifetime is 2 Days

Requesting this catalog item will provide you with a single dedicated OpenShift 4 cluster that each participant will share. It will be using per-participant credentials for OpenShift. Each participant has access to a web console so they'll be able to get started quickly. Once you order this catalog item, you'll receive an email with links to connect to the workshop which you will share with participants, along with admin credentials in case you need to log in and do housekeeping or other changes.
