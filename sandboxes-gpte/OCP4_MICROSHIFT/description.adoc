Experiment with MicroShift on OpenShift with Red Hat Advanced Cluster Management

== More Details

MicroShift is a lightweight Kubernetes distribution designed for developing and deploying containerized applications.

In this catalog item, a MicroShift instance is deployed on an OpenShift Container Platform cluster as a KubeVirt VM. The OpenShift Container Platform cluster is configured as the hub cluster, and Red Hat Advanced Cluster Management (RHACM) is used to manage the MicroShift instance as a managed cluster.

The MicroShift instance is installed on a standard Red Hat Enterprise Linux (RHEL) image and launched as a KubeVirt VM on the OpenShift Container Platform cluster. After the MicroShift instance is up and running, a demo application is deployed on it via RHACM.

There are no specific instructions for using this catalog item. Feel free to experiment and refer to your own environment for more details.
