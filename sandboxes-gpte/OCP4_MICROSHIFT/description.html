MicroShift on Kubevirt VM managed by Red Hat Advanced Cluster Management


MicroShift is a lightweight Kubernetes distribution designed for developing and deploying containerized applications.


In this setup, a MicroShift instance is deployed on an OpenShift cluster as a Kubevirt VM. The OpenShift cluster is configured as the Hub cluster, and Red Hat Advanced Cluster Management (RHACM) is used to manage the MicroShift instance as a managed cluster.


The MicroShift instance is installed on a standard RHEL image and launched as a Kubevirt VM on an OpenShift cluster. Once the MicroShift instance is up and running, a demo application is deployed on it via RHACM.


To access all the resources, users can refer to the details provided after the environment is provisioned.
