Deploy a MicroShift instance on a cluster in Red Hat OpenShift Container Platform.

MicroShift is a lightweight Kubernetes distribution designed for developing and deploying containerized applications.

In this catalog item, you deploy a MicroShift instance on an OpenShift Container Platform cluster as a Kubevirt VM. The OpenShift Container Platform cluster is configured as the hub cluster, and Red Hat Advanced Cluster Management (RHACM) is used to manage the MicroShift instance as a managed cluster.

The MicroShift instance is installed on a standard Red Hat Enterprise Linux (RHEL) image and launched as a Kubevirt VM on the OpenShift Container Platform cluster. After the MicroShift instance is up and running, a demo application is deployed on it via RHACM.

To access all the resources, refer to the email you receive after the environment is provisioned.

Product(s): Red Hat OpenShift Container Platform
