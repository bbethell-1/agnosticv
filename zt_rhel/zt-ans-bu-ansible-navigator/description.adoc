== Automation content navigator (ansible-navigator)

https://github.com/ansible/ansible-navigator[ansible-navigator, window=_blank] is the new command-line tool that provides a more cohesive and consistent experience for automation creators.


https://github.com/ansible/ansible-navigator[ansible-navigator, window=_blank] is included in Ansible Automation Platform 2 and leverages your existing CLI knowledge *(ansible-playbook)* while also introducing enhancements for containerized execution.


In this series of challenges, we'll install https://github.com/ansible/ansible-navigator[ansible-navigator, window=_blank] and run through simple use-cases to highlight it's functionality and enhancements.
