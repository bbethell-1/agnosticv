*Overview*

User accounts are an easy way to give users their own file storage locations,
manage permissions, and track who made changes on a system.
Spending some time customizing these accounts up front ensures that your system
stays organized and users do not cause issues for each other.

*Goal:*

Learn how to create and customize user accounts to manage file storage, permissions, and activity tracking, ensuring an organized and efficient system.

*Concepts included in this scenario:*

* Create user accounts with useradd
* Set account passwords
* Add groups
* Modify group members
* Remove users

*Lab Duration:*

10 minutes
