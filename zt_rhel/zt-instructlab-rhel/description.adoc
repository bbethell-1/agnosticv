*Overview*


Learn about LLM customization using InstructLab for model fine-tuning. You'll gain hands-on experience working with open source models & integrating unique domain knowledge into an LLM through a practical exploration of the CLI tool.

*Goal:*

After completing this scenario, users will be able to install the InstructLab CLI tools, download and serve models, and interact with them through a terminal based chat.

*Concepts included in this scenario:*

* Setup and work with the InstructLab CLI utility
* Download models from Hugging Face
* Serve and chat with a local & private LLM
* Generate synthetic data through a taxonomy-based approach
* Test out the newly tuned model & see the results

*Lab Duration:*

15 minutes
