*Overview*

It is common for multiple users to potentially have access to the same files. This means that understanding file permissions is a foundational skill for any system administrator. This lab is designed to provide you with a basic understanding of how to control who has access to various files on a system.

*Goal:*

Gain a foundational understanding of file permissions and learn how to control access to files on a system, essential for any system administrator.

*Concepts included in this scenario:*

* Understand the basics of file permissions in RHEL 9.
* Learn how file permissions affect user interactions with files.
* Master the use of the chmod command to modify file permissions.
* Practice changing file permissions using symbolic notation.
* Learn to change file permissions using absolute (numeric) notation.
* Understand how to change the ownership of files.
* Learn how to change the group ownership of files.
* Discover how to audit and verify file permissions for security and compliance.

*Lab Duration:*

10 minutes
