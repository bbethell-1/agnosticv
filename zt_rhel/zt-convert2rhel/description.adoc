*Overview*

Convert2RHEL is a command-line utility designed to simplify your migration from CentOS Linux 7 to a fully supported Red Hat Enterprise Linux (RHEL) system.

By converting existing CentOS systems to RHEL, Convert2RHEL ensures compatibility and a smooth transition. Since CentOS Linux is derived from RHEL sources, users can continue to use familiar techniques and elements with minimal retraining while also benefiting from enhanced features, tools, support, and value offered by RHEL.

*Goal:*

Convert a CentOS Linux system to Red Hat Enterprise Linux using the convert2rhel tool.

*Concepts included in this scenario:*

* Activate the Red Hat Convert2RHEL repositories
* Install the Convert2RHEL utility
* Analyze CentOS 7 with Convert2RHEL to confirm it's ready for conversion
* Convert CentOS 7 to RHEL 7 using Convert2RHEL

*Lab Duration:*

~30 minutes
