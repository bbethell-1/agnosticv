*Overview*

Red Hat Enterprise Linux System Roles provide a simplified and automated way to configure
system settings across multiple hosts using Ansible.
In this lab, we will focus on the firewall system role, which allows administrators to manage
firewall settings using a consistent and declarative approach. You will learn how to configure
firewall rules and port forwarding on a remote host using Ansible.

*Goal:*

Learn how to use the RHEL firewall system role to open specific ports and configure port forwarding on a target system.

*Concepts included in this scenario:*

* Installing and configuring the firewall system role on the control node
* Opening ports for web server access on a remote system using the firewall system role
* Opening an arbitrary port (port 9999) for inbound TCP connections on rhelvm
* Configuring port forwarding from port 9999 to port 12345 on rhelvm

*Lab Duration:*

15 minutes
