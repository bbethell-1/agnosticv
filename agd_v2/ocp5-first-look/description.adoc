== Environment Details

This lab provides a multi-node OpenShift 5 cluster (3 control-plane nodes) with the following pre-configured:

* *Authentication* provided by Red Hat build of Keycloak (admin user only)
* *Ingress certificates* controlled by cert-manager
* *OpenShift Data Foundation (ODF)* for persistent storage
* *OpenShift Lightspeed (OLS)* for AI-assisted cluster management

=== Agentic OpenShift Lightspeed

You can optionally enable Agentic OpenShift Lightspeed when ordering.
When enabled, you must provide your own OpenAI API key (`sk-...`).

=== Cloud Provider

* CNV — runs on OpenShift Virtualization
