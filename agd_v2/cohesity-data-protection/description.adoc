== Information

Hands-on lab demonstrating cyber resilience with Cohesity Data Protection
on Red Hat OpenShift Virtualization. Attendees deploy a virtual machine,
protect it with Cohesity DataProtect, simulate a disaster by deleting the
VM, and then recover it from backup — verifying data integrity end-to-end.
