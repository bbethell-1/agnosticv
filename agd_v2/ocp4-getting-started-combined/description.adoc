= Getting Started with OpenShift — Combined (WeAreDevelopers Booth)

This is the *combined catalog item* for the OpenShift Getting Started booth experience at WeAreDevelopers 2026.

A single order provisions a shared OCP cluster and runs all tenant workloads for N users. A PICKLIST parameter (`module`) selects which of the three Getting Started labs is deployed.

== Modules

[cols="1,3,2"]
|===
|Module |Title |What students do

|1
|3 Ways to Deploy an App
|Deploy DataSphere manually using CLI, console, and Helm

|2
|Apps That Never Go Down
|Observe and test resilience features (probes, HPA, resource limits)

|3
|Git Is Your Source of Truth
|Deploy DataSphere using a personal ArgoCD instance (GitOps)
|===

== How It Works

. Component provisions an OCP cluster from the `cnv-dedicated-shared` pool (`lab: ocp4-getting-started`)
. Cluster workloads run once: Keycloak authentication, Tekton Pipelines, Gitea, OpenShift GitOps
. Phase 0: `bootstrap-infra` ArgoCD application sets up cluster-level platform services
. Bridge role (`ocp4_workload_multi_tenant_loop`) loops per-user tenant workloads N times:
** Keycloak user, OCP namespaces, Gitea user
** `bootstrap-tenant-<username>` ArgoCD application (module-specific helm values)
** Showroom (with module-conditional UI tabs)

== Parameters

* `module` — `"1"` / `"2"` / `"3"` (string, required)
* `num_users` — number of tenants to provision (1–10)
