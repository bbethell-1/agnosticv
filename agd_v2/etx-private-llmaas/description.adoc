Deploys a private LLM as a Service platform on OpenShift.
This item is intended to be used for the Advanced ETX AI track in 2H 2025

== Products & Environment

* OpenShift 4.19
* OpenShift AI 2.22
* Instances:
** Single GPU (g6.2xlarge)
** Multi GPU (g6.12xlarge)

== Lab Guides:
The lab guides can be found at the following locations:

. https://redhat-ai-services.github.io/etx-serving-at-scale/modules/index.html
. https://redhat-ai-services.github.io/etx-agentic-ai/modules/index.html
. https://redhat-ai-services.github.io/etx-llm-optimization-and-inference-leveraging/modules/index.html

NOTE: These lab guides are not deployed as part of the environment.
