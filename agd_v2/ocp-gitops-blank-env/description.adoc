== OpenShift Cluster Size

Cluster size depends on the control plane size you select:

* *Single Node (sno)*: Provides a single node cluster with 32 CPU and 128Gi memory.
* *Multi Node (multinode)*: Provides 3 node control plane with 16 CPU and 64Gi memory each, plus worker nodes.

If you select the *multinode* control plane size, the number of worker nodes is user-defined, and each worker node has 8 CPU and 16Gi of memory.

== Provisioning Time

Deployment time can typically range from 15 to 90 minutes, depending on whether clusters are already available in the pool or need to be provisioned from scratch.

== Notes

This cluster runs on CNV (Container-native Virtualization).
