After deployment, find the OpenShift GitOps URL in the deployment details.

The ArgoCD instance includes a number of pre-installed applications, which you can choose to sync as needed.

Add your own applications in ArgoCD to extend this environment.

== OpenShift Cluster Size

Cluster size depends on the control plane nodes and number of users you select.

* *Control plane size 1*: Provides a single node cluster (SNO).
* *Control plane size 3*: Provides at least a 3-worker node cluster, with an additional worker node for every multiple of 3 users.

For example:

* Ordering 12 users results in 4 worker nodes.
* Ordering 15 users results in 5 worker nodes.

== Provisioning Time

Deployment time is approximately 90 minutes.

== Notes

This cluster runs on CNV (Container-native Virtualization).
