Red Hat Advanced Cluster Security for Kubernetes (RHACS) provides comprehensive security capabilities for containerized applications running on OpenShift. This hands-on demo environment showcases vulnerability management, compliance checking, runtime threat detection, and policy enforcement across your Kubernetes clusters.

== Featured Technology and Products

* Red Hat OpenShift Container Platform 4.20
* Red Hat Advanced Cluster Management 2.16
* Red Hat Advanced Cluster Security 4.10
* Red Hat OpenShift Virtualization
* Red Hat OpenShift GitOps
* Red Hat Quay 3.16
