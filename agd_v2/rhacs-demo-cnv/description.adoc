Red Hat Advanced Cluster Security for Kubernetes (RHACS) provides comprehensive security capabilities for containerized applications running on OpenShift. This hands-on demo environment showcases vulnerability management, compliance checking, runtime threat detection, and policy enforcement across your Kubernetes clusters.

== Featured Technology and Products

* Red Hat OpenShift Container Platform 4.20
* Red Hat Advanced Cluster Management 2.15
* Red Hat Advanced Cluster Security 4.9
* Red Hat OpenShift Virtualization
* Red Hat OpenShift GitOps
* Red Hat Quay 3.15

== Detailed Overview

* *Security and Compliance*
** Configure RHACS compliance checks and security insights
** Implement policy-as-code to block anomalous runtime behavior
** Generate violations and reporting for audit and compliance

* *Vulnerability Management*
** Scan container images for known vulnerabilities
** Monitor runtime behavior for security threats
** Enforce security policies across clusters

* *Multi-Cluster Management*
** Manage security policies across multiple OpenShift clusters
** Centralized visibility and control with RHACM
** GitOps-based configuration management
