Hands-on workshop teaching platform engineers to govern OpenShift clusters at scale using *Red Hat ACM*, *OpenShift GitOps (Argo CD)*, and the *AutoShift* IaC framework.

== Detailed Overview

* **Hub Cluster Bootstrap** — Install ACM and OpenShift GitOps on a compact OCP 4.22 cluster, then deploy AutoShift's Helm chart to establish the management plane.
* **Label-Driven Policy Model** — Learn AutoShift's core pattern: values files feed ConfigMaps, ConfigMaps feed ManagedCluster labels, labels drive Placements, and Placements dispatch policies — all without modifying policy code.
* **Operator Lifecycle Management** — Use PolicyGenerator with Kustomize to author governance policies that install and configure operators across fleet clusters.
* **Per-Cluster Configuration Overrides** — Apply targeted configuration to individual clusters using label selectors and overlay values without duplicating policy definitions.
* **OCI Publishing via Red Hat Quay** — Package and publish policy bundles as OCI artifacts for versioned, reproducible fleet-wide distribution.
* **Gradual Rollout Strategies** — Control policy propagation across cluster groups using placement decisions, canary labels, and progressive rollout patterns.
* **Hub-of-Hubs Patterns** — Explore multi-hub architectures for managing large-scale, geographically distributed OpenShift fleets.
* **Spoke Cluster Lifecycle on AWS** — Provision and join spoke clusters to the hub fleet, validating end-to-end policy delivery from hub to spoke.
