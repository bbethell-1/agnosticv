== Information

This demo demonstrates how to use OpenShift GitOps (ArgoCD) to manage Virtual Machines in OpenShift Virtualization using a GitOps approach. Participants will learn drift detection, VM recovery, Git-based infrastructure changes, and multi-environment promotion using Kustomize overlays.

The demo includes four hands-on demos:

* *Demo 1:* Manual change detection and drift correction
* *Demo 2:* VM recovery from data loss
* *Demo 3:* Adding new development VMs via Git
* *Demo 4:* Multi-environment VM management with Kustomize
