Provision an OpenShift Container Platform 5 cluster on AWS with basic customizations using AgnosticD V2.

This asset is the AWS cluster-provisioning component used by the OpenShift 5 multi-cloud catalog item.
It installs a generic cluster with cert-manager on the ingress. Authentication and other workloads are added by the parent item.

[IMPORTANT]
====
This environment deploys OpenShift Container Platform 5 from the latest candidate build.
Candidate payloads change frequently.
Operators, APIs, and installed components can break or behave differently from one candidate to the next.
Do not treat this as a stable or supported production-like release.
====

== Specifications

* Deployer: AgnosticD V2
* Cloud provider: AWS
* Cluster size options:
** SNO (Single Node OpenShift): 1 control-plane node
** Multinode: 3 control-plane nodes (compact)
* Cluster version: latest OpenShift 5 candidate
* Certificates enabled on Ingress controllers
