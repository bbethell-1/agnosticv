Trusted Software Factory ({TSFName}) is a customer-facing demo showing how Red Hat builds, signs, and ships software internally -- and how customers can adopt the same secure software supply chain standards. The demo uses a pre-provisioned OpenShift cluster with Konflux, Red Hat Trusted Artifact Signer (RHTAS), Red Hat Trusted Profile Analyzer (RHTPA), Quay, and GitLab already deployed and integrated. Presenters walk through creating an application in Konflux, triggering a secure build pipeline, verifying cryptographic signatures with SLSA Level 3 provenance, and analyzing SBOMs in RHTPA.

== Detailed Overview

* *Secure Software Factory Architecture*
** Show the deployed TSF environment: Konflux, RHTAS (Fulcio, Rekor, TUF), RHTPA, Quay, Keycloak
** Demonstrate how all components are wired together on a single OpenShift cluster
** Explain how this is the same platform Red Hat uses to build OpenShift

* *Build and Sign with Konflux*
** Create an application and onboard a component from GitLab
** Show how Konflux automatically generates pipeline definitions and configures webhooks
** Trigger a secure build pipeline that signs the image with RHTAS

* *Verify with SLSA Level 3 Provenance*
** Use cosign to verify the cryptographic signature against the Rekor transparency log
** Show the SLSA provenance attestation proving who built the image, when, from which source
** Demonstrate that no one can produce a valid signature without going through the pipeline

* *Software Bill of Materials and Vulnerability Analysis*
** Browse the SBOM in RHTPA showing all packages and dependencies
** View vulnerability scan results and CVE impact analysis
** Explain continuous scanning -- when a new CVE drops, affected images are identified immediately

* *Automated Release Pipeline*
** Show the release record created automatically after a successful build
** Review Conforma policy validation results
** Demonstrate the full audit trail from source commit to signed, released image
