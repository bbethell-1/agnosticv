= Trusted Software Factory

Trusted Software Factory (TSF) demonstrates deploying a complete secure software supply chain on Red Hat OpenShift using integrated tools for artifact signing, vulnerability analysis, and container registry management. This workshop uses the TSSC CLI to orchestrate deployment of interdependent Kubernetes components including Sigstore-based signing infrastructure, supply chain security analysis, and GitOps workflows. Learners configure signing and verification workflows, integrate container registries with object storage, and implement secure CI/CD pipelines with artifact attestation.

== Featured Technology and Products

* Red Hat Trusted Artifact Signer (RHTAS)
* Red Hat Trusted Profile Analyzer (RHTPA)
* Red Hat Quay
* Red Hat Build of Keycloak
* Red Hat OpenShift GitOps
* S4 Object Storage
* GitLab CE

== Detailed Overview

* *Deploy Core Infrastructure and Authentication*
** Configure Keycloak for unified single sign-on across TSF components
** Deploy S4 S3-compatible object storage for artifact persistence
** Integrate OpenShift OAuth with Keycloak for cluster authentication

* *Configure Container Registry with Signing Support*
** Deploy Red Hat Quay enterprise registry with S4 backend storage
** Configure Quay for container image signing integration
** Set up repository policies and access controls

* *Implement Artifact Signing with RHTAS*
** Deploy Sigstore components (Fulcio certificate authority and Rekor transparency log)
** Configure keyless artifact signing workflows
** Establish immutable provenance tracking with cryptographic verification

* *Enable Supply Chain Security Analysis*
** Deploy Trusted Profile Analyzer for vulnerability scanning
** Ingest and analyze Software Bill of Materials (SBOMs)
** Configure security policies and compliance checks

* *Establish GitOps-Based Delivery*
** Deploy GitLab CE for source control via OpenShift GitOps
** Configure ArgoCD for continuous delivery workflows
** Integrate signing and verification into CI/CD pipelines
