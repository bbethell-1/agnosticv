=== Step 1: SSH to Bastion Host

.From your local machine, connect to the bastion:
[subs=attributes+]
----
ssh {bastion_ssh_user_name}@{openshift_cnv_ssh_address} -p {bastion_ssh_port}
----

Password: `{bastion_ssh_password}`

=== Step 2: Access Internal Hosts from Bastion

Once logged into the bastion, you can SSH to internal hosts:

==== Registry Host (RHEL 9.6)

.From bastion, connect to registry:
[subs=attributes+]
----
ssh {registry_hostname}
----

Password: `{bastion_ssh_password}`

* *Registry URL:* http://{registry_hostname}:5000
* *Images:* 27 MicroShift and application images pre-mirrored

==== Target Host (RHEL 9.4)

.From bastion, connect to target:
[subs=attributes+]
----
ssh {target_hostname}
----

Password: `{bastion_ssh_password}`

* *Purpose:* Test environment for bootc appliance deployments
