= Building Self-contained Appliances with Red Hat Image Mode (bootc) & MicroShift

== Lab Overview

This hands-on lab teaches you how to build and manage edge appliances using Red Hat Enterprise Linux Image Mode (bootc) and MicroShift for running cloud-native applications at the edge.

== Lab Instructions

*Lab instructions are TBD and will be provided soon.*

== What You Will Learn

* Build self-contained appliances using RHEL Image Mode (bootc)
* Embed application containers directly into bootable OS images
* Deploy cloud-native applications with MicroShift
* Perform atomic, image-based system upgrades
* Manage edge appliances for disconnected environments

== Lab Environment

Your lab environment includes:

* *Bastion Host (RHEL 9.6)*: Build and development environment with all necessary tools
* *Registry Host (RHEL 9.6)*: Container registry with 27 pre-mirrored MicroShift and application images
* *Target Host (RHEL 9.4)*: Test environment for deploying bootc appliances

== Technologies Used

* Red Hat Enterprise Linux 9 (Image Mode / bootc)
* Red Hat Build of MicroShift (4.18, 4.19, 4.20)
* Container tools: podman, buildah, skopeo
* Virtualization: KVM/libvirt
