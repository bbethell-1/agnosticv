RHEL Image Mode and Red Hat build of MicroShift enable building self-contained edge appliances that solve critical operational challenges: configuration drift, risky updates, disconnected operations, and resource-constrained deployments. This hands-on lab uses a scenario to demonstrate building production-grade appliances that deploy and operate reliably across remote factory locations. Learners build bootc images with embedded applications, deploy to disconnected environments, perform atomic updates with instant rollback, and validate offline operation.

== Detailed Overview

* *Understanding edge challenges and preparing the lab*
** Identify key edge computing challenges and how RHEL Image Mode addresses them
** Explain the build, deploy, manage workflow for bootc-based appliances
** Navigate the lab environment and recognize key system components
** Understand how physically-bound images support disconnected deployments

* *Building self-contained appliances*
** Read and explain bootc Containerfiles for appliance definitions
** Understand EUS (Extended Update Support) for long-lived appliances
** Build MicroShift-enabled base image with embedded security hardening
** Build self-contained appliance with physically-bound application images
** Generate bootable ISO using bootc-image-builder

* *Deploying to edge locations*
** Create isolated network for disconnected environment simulation
** Deploy bootc image to virtual machine using KVM and Kickstart automation
** Configure kubeconfig for MicroShift access
** Verify appliance runs correctly with embedded images (no registry pull)

* *Safe updates and rollbacks*
** Explain the A/B boot model and atomic update process
** Build updated appliance image (4.20) with new MicroShift version
** Perform update using disconnected workflows (skopeo export, tar, scp)
** Verify successful updates using greenboot health checks
** Demonstrate manual rollback and understand automatic failure protection

* *Business outcomes and resources*
** Connect technical capabilities to business value and ROI
** Review quantified improvements: deployment speed, update stability, configuration drift
** Access comprehensive documentation and related training resources
