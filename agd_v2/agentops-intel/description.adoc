In this workshop, you take on the role of a senior engineer at a mortgage lending company whose multi-agent AI system is failing in production without any visibility into why. Using Red Hat OpenShift AI's integrated observability stack, you instrument and monitor a real LangGraph-based multi-agent application end-to-end — tracking metrics, logs, and distributed traces across five distinct AI agent personas and their Model Context Protocol (MCP) tool calls.

All AI inference in this lab runs on Intel Gaudi 3 accelerators via Red Hat OpenShift AI, demonstrating production-grade agentic AI on Intel's AI hardware platform.

This is a hands-on, scenario-driven lab that builds from foundational observability concepts through automated quality assurance pipelines. By the end, you can diagnose distributed failures, trace agent reasoning paths across multi-agent workflows, and run continuous LLM evaluations to catch quality regressions before they reach production.

== Featured Technology and Products

* Red Hat OpenShift Container Platform
* Red Hat OpenShift AI (RHOAI) — including MLflow Tracing, AI Pipelines, and Model Registry
* Intel Gaudi 3 AI Accelerators — high-performance AI inference hardware
* vLLM on Intel Gaudi — optimized LLM serving for Intel accelerators
* LangGraph multi-agent framework
* Model Context Protocol (MCP)
* Grafana and LokiStack (metrics and log aggregation)
* MLflow Prompt Registry and LLM-as-a-Judge evaluations
* OpenTelemetry-compatible distributed tracing

== Detailed Overview

*Module 1 — The Agentic App and Why Observability Matters* +
Explore the pre-deployed mortgage-ai multi-agent system running on Intel Gaudi 3 accelerators. Learn the architecture of five LangGraph agent personas and understand why traditional monitoring approaches fall short for distributed AI workflows.

*Module 2 — Observability Pillars, Concepts, and Personas* +
Build the conceptual vocabulary for AgentOps. Understand the three pillars of observability (metrics, logs, traces) and how each applies specifically to multi-agent AI systems.

*Module 3 — Metrics and Logs for Agentic Applications* +
Explore the pre-deployed Grafana dashboard, query application logs using LokiStack and LogQL, and identify the key metrics that matter most for agentic workloads.

*Module 4 — Tracing and MLflow* +
Trace requests end-to-end across LangGraph agents and MCP tool calls using MLflow's OpenTelemetry-compatible tracing.

*Module 5 — Agent and LLM Evaluations (Optional)* +
Launch a Jupyter workbench in RHOAI, register versioned prompts in the MLflow Prompt Registry, and run LLM-as-a-Judge scorers.

*Module 6 — From Development to Production (Optional)* +
Automate the evaluation workflow into a fully automated AI Pipeline and detect prompt regressions.
