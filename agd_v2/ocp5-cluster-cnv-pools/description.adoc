Provision an OpenShift Container Platform 5 cluster on OpenShift Virtualization (CNV) with basic customizations using AgnosticD V2.

This asset is the CNV cluster-provisioning component used by the OpenShift 5 multi-cloud catalog item.
It installs a generic cluster with cert-manager and OpenShift Data Foundation (ODF). Authentication and other workloads are added by the parent item.

[IMPORTANT]
====
This environment deploys OpenShift Container Platform 5 from the latest candidate build.
Candidate payloads change frequently.
Operators, APIs, and installed components can break or behave differently from one candidate to the next.
Do not treat this as a stable or supported production-like release.
====

== Specifications

* Deployer: AgnosticD V2
* Cloud provider: CNV
* Cluster size options:
** SNO (Single Node OpenShift): 1 control-plane node (32 cores, 128GB RAM)
** Multinode: 3 control-plane nodes (16 cores, 64GB RAM each)
* Cluster version: latest OpenShift 5 candidate
* Let's Encrypt certificates enabled on Ingress controllers
* OpenShift Data Foundation (ODF) for persistent storage

*Provisioning time:* Typically ~5 minutes for `sno` and ~15 minutes for `multinode`
