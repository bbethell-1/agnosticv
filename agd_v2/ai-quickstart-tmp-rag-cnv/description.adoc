
Deploys the RAG All-in-One QuickStart on OpenShift AI

This catalog item provisions a complete RAG (Retrieval-Augmented Generation) environment on OpenShift AI.

== What Gets Deployed

* *Keycloak SSO* -- OpenShift authentication with per-user accounts
* *ArgoCD (OpenShift GitOps)* -- App of Apps bootstrap for all components
* *OpenShift AI 3* -- Dashboard, pipelines, workbenches, model serving
* *RAG QuickStart* -- End-to-end RAG pipeline components
