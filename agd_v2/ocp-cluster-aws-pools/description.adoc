Provision an OpenShift Container Platform cluster on AWS with basic customizations using AgnosticD V2.

This asset provides an OpenShift Container Platform cluster with basic customizations on AWS for running hands-on-labs, workshops, and similar events where no specialized environment is available.

Refer to the catalog for specialized workshops such as Containers and Cloud-Native Roadshow, OpenShift Getting Started Workshops, and so on.

== Specifications

* Deployer: AgnosticD V2
* Cluster size options:
** SNO (Single Node OpenShift): 1 control-plane node
** Multinode: 3 control-plane node
* Cluster version: 4.16 - 4.20
* Certificates enabled on Ingress controllers
