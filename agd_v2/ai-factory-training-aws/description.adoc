== Overview

This catalog item provides a GPU-enabled OpenShift cluster specifically designed for **paid customer training** delivered by the Partner Training and Learning (PTL) organization.

This environment is part of the AI Factory training curriculum and is used exclusively for lessons that require GPU capabilities. The training platform ties specific classrooms to individual lessons, ensuring GPU clusters are only provisioned when genuinely needed for GPU-specific content.

== Training Context

The AI Factory training is structured in three distinct phases, each requiring different infrastructure:

1. **Non-GPU Content**: Basic AI Factory concepts (uses separate CNV catalog item)
2. **Inference Content**: Model serving and API integration (uses CNV + MaaS catalog item)
3. **GPU-Specific Content**: GPU configuration, slicing, monitoring, and optimization (**this catalog item**)

This catalog item is specifically for **Phase 3** - GPU-focused lessons for paying customers.

== What You'll Learn (GPU-Focused Topics)

This environment supports GPU-specific curriculum including:

* **GPU Configuration**: Properly configure NVIDIA GPU Operator on OpenShift
* **GPU Slicing**: Implement Multi-Instance GPU (MIG) and time-slicing strategies
* **GPU Monitoring**: Monitor GPU utilization, memory, and performance metrics
* **GPU Resource Management**: Allocate and manage GPU resources across workloads
* **GPU-Accelerated Model Training**: Train large language models with GPU acceleration
* **GPU-Accelerated Inference**: Deploy and serve models with optimal GPU utilization
* **Performance Optimization**: Tune GPU settings for production workloads
* **GPU Troubleshooting**: Diagnose and resolve GPU-related issues

== Troubleshooting

=== Long Provisioning Times

GPU clusters can take significantly longer to provision than standard clusters. This is expected behavior due to GPU resource constraints on the Demo Platform.

=== GPU Availability

If you encounter errors about GPU availability, this means the Demo Platform has exhausted its GPU quota. Contact your instructor or RHDP support.

=== Cost Tracking

Monitor your organization's GPU usage through the RHDP catalog. Costs are charged back monthly.
