
Per-tenant provisioning for the RAG Quickstart on OpenShift AI.

This catalog item deploys a complete RAG (Retrieval-Augmented Generation) environment for a single tenant on a shared base cluster via the OpenShift Sandbox API.

== What Gets Deployed

* *Keycloak user* -- Per-tenant OpenShift user via shared Keycloak
* *Tenant namespaces* -- Isolated namespaces for RAG workloads
* *ArgoCD (OpenShift GitOps)* -- Per-tenant GitOps bootstrap for RAG components
* *LiteLLM Virtual Keys* -- Managed LLM API access for this tenant
* *RAG Pipeline* -- End-to-end RAG pipeline via Helm (llm-service, llama-stack)
* *Showroom* -- Interactive lab guide with embedded OpenShift console

== Design

This tenant CI runs on a shared base cluster provisioned by `ai-qs-rag-cluster`.
Each tenant gets isolated namespaces, a dedicated Keycloak user, and its own
ArgoCD-managed RAG deployment.
