An OpenShift 5 based Red Hat Advanced Cluster Security Roadshow

== Lab Guide

You can find a preview version of the link:https://rhpds.github.io/ocp5-rhacs-showroom[lab guide^] here.

== Specifications

* Deployer: AgnosticD V2
* 3 Control-plane nodes
* 3 Worker nodes
* Cluster version: 5.0 Preview
* Certificates enabled on Ingress controllers

== Pre-installed Components

* Red Hat Advanced Cluster Security (ACS)
* OpenShift GitOps (Argo CD)
* OpenShift Virtualization with RHEL 9 VM
* OpenShift Lightspeed with MCP server integration
* Lightspeed Agentic Operator
* Cluster Observability Operator with Perses dashboards
* MCP Gateway (Red Hat Connectivity Link)
