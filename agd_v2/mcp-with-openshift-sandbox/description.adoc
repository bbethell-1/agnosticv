Model Context Protocol (MCP) provides a universal standard for AI applications to connect with external systems, eliminating the need for custom integration code. This hands-on workshop explores deploying MCP servers to production on Red Hat OpenShift, addressing enterprise challenges including authentication, access control, observability, and centralized governance. Learners configure MCP servers with ToolHive, implement least-privilege tool filtering, enable Prometheus telemetry, and deploy the Red Hat MCP Registry for centralized server discovery.

This is the sandbox version of the lab, deployed on a pre-provisioned shared cluster for instant access.

== Detailed Overview

* *Sovereign SRE Agent Demo*
** Experience an AI-powered SRE agent using MCP to interact with OpenShift
** Observe how MCP enables AI to execute Kubernetes operations safely
** Understand the integration between LibreChat and MCP servers

* *MCP Server Administration*
** Configure MCP server tool filtering for least-privilege access control
** Enable Prometheus telemetry and create ServiceMonitors for observability
** Deploy MCP servers using different transport protocols (SSE, streamable HTTP)

* *MCP Registry*
** Set up the Red Hat MCP Registry for centralized server discovery
** Configure governance policies for MCP server management
** Apply enterprise security patterns including RBAC and token-based authentication
