== Information

Hands-on workshop for migrating Red Hat OpenShift AI from 2.25 to 3.x.

Deploys a RHOAI 2.25 environment preloaded with workloads that require
manual intervention prior to migration to 3.3.x. Provides instructions
to guide the user through performing the upgrade.
