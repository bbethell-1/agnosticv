Red Hat sovereign cloud solutions enable enterprises to manage geographically-distributed OpenShift infrastructure while meeting strict regulatory and data residency requirements. This hands-on workshop demonstrates multi-cluster compliance management, workload placement strategies for geographic data constraints, and comprehensive audit trails for regulatory demonstrations. Learners deploy applications with built-in sovereignty enforcement, implement policy-as-code for runtime security, and establish secure software supply chains using Red Hat Trusted Artifact Signer.

== Detailed Overview

* *Operations and Security*
** Manage multi-environment OpenShift clusters and virtual machines
** Create and observe workloads across geographic regions
** Deploy applications using OpenShift GitOps

* *Assurance*
** Configure RHACS compliance checks and security insights
** Implement policy-as-code to block anomalous runtime behavior
** Generate violations and reporting for audit and compliance

* *Technology and Supply Chain*
** Sign and verify container images with Trusted Artifact Signer
** Rebuild applications with secure supply chain practices
** Analyze software composition with Trusted Profile Analyzer

* *Data and AI*
** Install and configure Red Hat OpenShift AI
** Access Jupyter notebooks for AI workloads
** Implement sovereign AI capabilities within data residency constraints
