*Sovereign Cloud*


Explore the management, storage and security features of Red Hat OpenShift Platform Plus.
Participants will work with Red Hat Advanced Cluster Management for Kubernetes to deploy clusters, leveraging Red Hat GitOps to deploy virtual machines and applications at scale and create governance policies.
Next, participants will build and push container images to Red Hat Quay, explore its dashboard, and deploy the application with OpenShift Pipelines.
Finally, participants will get hands-on with Red Hat Advanced Cluster Security for Kubernetes, analyzing vulnerabilities, examining compliance standards, and demonstrating runtime enforcement for security.
