Ansible Automation Platform Self-Service Automation Portal enables organizations to democratize automation by providing a simple, secure interface that maintains governance through RBAC while broadening who can use automation. This hands-on workshop demonstrates how to configure role-based access control, test different user personas, and create custom automation templates. Learners deploy and configure the Self-Service Portal on AAP 2.6, enabling cloud, network, and Linux subject matter experts to leverage automation without becoming Ansible specialists.

== Detailed Overview

* *Configure Ansible Automation Platform for Self-Service Portal*
** Configure role-based access control (RBAC) in AAP 2.6
** Validate content synchronization between AAP and the portal
** Set up RBAC permissions in the Self-Service Portal

* *User Persona Testing*
** Test the Self-Service Automation Portal from different user perspectives
** Validate that RBAC policies correctly control what each user can see and execute
** Understand the self-service experience for non-automation experts

* *Surveys and Custom Templates*
** Modify surveys and observe synchronization behavior
** Import a custom dynamic template into the portal
** Launch and validate the custom template execution
