= Introduction to Ansible Automation Platform Self-Service Automation Portal

== Overview

This lab provides hands-on experience with Red Hat Ansible Automation Platform (AAP) 2.5, focusing on the Self-Service Automation Portal and Event-Driven Ansible capabilities.

Each student receives their own dedicated AAP instance with full administrative access, allowing them to explore automation workflows, event-driven automation, and self-service portals.

== Lab Environment

* **OpenShift 4.18** cluster with CNV
* **Dedicated AAP 2.6 instance** per student
* **Automation Controller** - Create and execute automation workflows
* **Event-Driven Ansible (EDA)** - Respond to events automatically
* **Full admin access** to your AAP namespace

== What You Will Learn

* Navigate the AAP Self-Service Automation Portal
* Create and manage automation workflows
* Configure Event-Driven Ansible rulebooks
* Build self-service automation catalogs
* Integrate AAP with OpenShift

== Lab Components

=== Your AAP Instance

Each student gets:

* Isolated AAP deployment in OpenShift
* Admin credentials for full control
* Pre-configured Automation Controller
* Event-Driven Ansible Controller
* Direct access to your namespace via `oc` CLI

=== Access Information

Your AAP instance details will be provided in the lab guide:

* AAP Controller URL
* Admin username and password
* OpenShift namespace
* CLI access commands

== Prerequisites

* Basic understanding of Ansible
* Familiarity with OpenShift/Kubernetes concepts
* Web browser for AAP UI access
