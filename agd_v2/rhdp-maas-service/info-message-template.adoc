== Quick Start

Use any OpenAI-compatible client to interact with the models:

[source,bash]
----
curl {litellm_api_base_url}/v1/chat/completions \
  -H "Authorization: Bearer {litellm_virtual_key}" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "<model-name>",
    "messages": [{"role": "user", "content": "Hello!"}]
  }'
----

Replace `<model-name>` with one of the available models listed above.

Keys are deleted on destroy.
