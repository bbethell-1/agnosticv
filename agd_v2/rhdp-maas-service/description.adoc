RHDP's Model-as-a-Service (MaaS) platform provides on-demand access to AI models through an OpenAI-compatible API. This service provisions scoped MaaS virtual keys for the models you select, enabling immediate access to chat, code generation, embeddings, and safety classification endpoints. Use this to integrate AI capabilities into demos, workshops, or development workflows without managing model infrastructure.

[IMPORTANT]
====
This catalog item uses the MaaS Sandbox API and is currently restricted to RHDP administrators only. In the future, this CI may be opened as a self-service portal for all users to create their own API keys, enabling better usage tracking and cost attribution.
====

== Available Model Categories

* *Chat & Text Generation* — Granite 3.2 8B Instruct, Granite 4.0 H Tiny, Llama 4 Scout 17B, DeepSeek R1 Distill Qwen 14B, Microsoft Phi-4, Qwen 3 14B
* *Code Generation* — CodeLlama 7B Instruct
* *Safety & Moderation* — Llama Guard 3 1B
* *Embeddings* — Nomic Embed v1.5
* *External Models (Vertex AI)* — MiniMax M2, Qwen3 235B, GPT OSS 120B/20B, Gemini 2.5 Pro, Claude Sonnet 4.6, Claude Opus 4.6, Claude Sonnet 4.5, Claude 3.5 Haiku
