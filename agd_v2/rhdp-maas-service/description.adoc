= RHDP MaaS Service

Provisions LiteMaaS virtual keys for accessing AI models hosted on Red Hat's Model-as-a-Service platform.
Select the models you need and receive an OpenAI-compatible API endpoint with a scoped virtual key.

Available model categories:

* *Chat & Text* — Granite, Llama, DeepSeek, Phi-4, Qwen
* *Code* — CodeLlama
* *Safety* — Llama Guard
* *Embeddings* — Nomic Embed
* *External (Vertex AI)* — Gemini, Claude, MiniMax, GPT OSS

Keys are scoped to your selected models and deleted on destroy.
