This demo provisions *RHADS-TSSC (Red Hat Advanced Developer Suite – Trusted Software Supply Chain)* to showcase how Red Hat enables secure, automated, and policy-compliant application delivery using trusted components on OpenShift.

The deployment uses the *TSSC CLI* (https://github.com/redhat-appstudio/tssc-cli), a sophisticated Kubernetes installer that manages Helm Chart deployments with dependency awareness. Unlike standard Kubernetes deployments, TSSC CLI sequences installations in logical order and validates each phase before proceeding to the next, ensuring the integrity of interdependent resources.

It features *Red Hat Developer Hub (RHDH)* as the central developer portal with Red Hat Build of Keycloak-based authentication, integrated with both *Jenkins* and *Tekton (OpenShift Pipelines)* to support flexible CI/CD strategies. The demo highlights the use of *Pipeline as Code*, enabling version-controlled, auditable, and GitOps-aligned workflows.

The environment includes *GitLab* as the source control management system with pre-configured repositories for Developer Hub configuration, sample pipelines, and Jenkins integration. *OpenShift GitOps (ArgoCD)* provides GitOps-based continuous delivery with custom resource health checks for operators and subscriptions.

*Red Hat Devspaces* offers browser-based development environments, while *Red Hat Quay* provides secure container image storage and management. The deployment includes *Red Hat Advanced Cluster Management (RHACM)* for multi-cluster management capabilities and *Serverless Logic* for workflow orchestration through the RHDH Orchestrator plugin.

The TSSC CLI installer deploys core Trusted Software Supply Chain components including *Trusted Artifact Signer (TAS)* for cryptographic signing and verification of software artifacts using OIDC providers, and *Trusted Profile Analyzer (TPA)* which analyzes SBOMs, VEX, and CVE data to assess software supply chain risk profiles. These components integrate with CI/CD pipelines to automatically generate, sign, and validate build artifacts.

*Red Hat Advanced Cluster Security (RHACS)* provides comprehensive security protection across the container lifecycle with runtime policy enforcement and vulnerability management, while *Enterprise Contract* enforces Open Policy Agent (OPA)-based policies to validate builds against security, compliance, and provenance rules.

The demo can be presented with a Jenkins-centric narrative (for organizations with existing Jenkins usage) or a Tekton-first story (for Kubernetes-native CI/CD). A *Showroom* interface provides guided content delivery for workshop and demo experiences.

== Components Deployed

=== Infrastructure
* *OpenShift Cluster* - 4.20 on CNV with 3 workers (32 cores, 128GB RAM each)

=== TSSC CLI Core Components
* *Developer Hub* - Enterprise-grade internal developer portal built on Backstage (namespace: tssc-dh)
* *OpenShift Pipelines* - Cloud-native CI/CD solution built on Tekton (namespace: tssc)
* *OpenShift GitOps* - Git-centric declarative workflow automation (namespace: tssc-gitops)
* *Trusted Artifact Signer (RHTAS)* - Cryptographic signing/verification of software artifacts (namespace: tssc-tas)
* *Trusted Profile Analyzer (RHTPA)* - SBOM, VEX, and CVE analysis for supply chain risk assessment (namespace: tssc-tpa)
* *Advanced Cluster Security (RHACS)* - Comprehensive container lifecycle security platform (namespace: tssc-acs)

=== Additional Components
* *Red Hat Build of Keycloak* - Identity and access management for OpenShift and Developer Hub integration (namespace: tssc-keycloak)
* *Jenkins* - CI/CD automation server with custom agents (namespace: jenkins)
* *GitLab* - Source control management with pre-configured repositories (namespace: gitlab)
* *GitLab Runner* - CI/CD job execution for GitLab pipelines
* *Red Hat Devspaces* - Browser-based cloud development environments (namespace: openshift-devspaces)
* *Red Hat Quay* - Enterprise container image registry (namespace: quay-enterprise)
* *Red Hat Advanced Cluster Management (RHACM)* - Multi-cluster lifecycle and governance
* *Serverless Logic* - Workflow orchestration and automation (namespace: openshift-serverless-logic)
* *Enterprise Contract* - OPA-based policy validation for builds
* *Kubernetes Image Puller* - Pre-caches common development container images
* *Showroom* - Workshop and demo content delivery platform with zero-touch UI

== Key Configuration Details

* *TSSC CLI Deployment*:
  ** Repository: https://github.com/redhat-appstudio/tssc-cli (release-1.8)
  ** Method: Dependency-aware Helm Chart installer with sequenced deployments
  ** Validates each component phase before proceeding to next installation
  ** Core TSSC components deployed to dedicated namespaces (tssc-*)

* *User Configuration*:
  ** Configurable user count with GUID-based common password
  ** Admin user with centralized authentication via Red Hat Build of Keycloak
  ** GitLab users pre-configured with same password scheme

* *GitLab Repositories* (Group: rhdh):
  ** https://github.com/rhpds/tssc-developer-hub-configuration[tssc-developer-hub-configuration] - RHDH catalog and configuration
  ** https://github.com/rhpds/tssc-sample-pipelines[tssc-sample-pipelines] - Tekton pipeline examples
  ** https://github.com/rhpds/tssc-sample-jenkins[tssc-sample-jenkins] - Jenkins pipeline examples

* *Authentication*: Red Hat Build of Keycloak-based SSO for OpenShift and Developer Hub
* *Image Optimization*: Kubernetes Image Puller pre-caches development container images
