This catalog item deploys a fully configured Models-as-a-Service (MaaS) governance platform on Red Hat OpenShift AI 3.4, running on a multinode OpenShift 4.21 cluster (CNV).

== What Gets Deployed

* *OpenShift 4.21* -- Multinode cluster via CNV pool (control-plane nodes made schedulable)
* *Keycloak SSO* -- OpenShift authentication
* *Red Hat OpenShift AI 3.4* -- Operator, DataScienceCluster, Dashboard with MaaS enabled
* *MaaS Gateway* -- Kuadrant (RHCL), Authorino, Limitador, cert-manager, Istio gateway with passthrough TLS route
* *MaaS API + PostgreSQL* -- Token management, API key generation, subscription tracking
* *Inference Simulator* -- CPU-only test model (`facebook/opt-125m`) for validation without GPUs

== MaaS Endpoints

After provisioning, the cluster exposes:

* *MaaS API*: `https://maas.apps.<cluster-domain>/v1/models`
* *Model inference*: `https://maas.apps.<cluster-domain>/llm/<model>/v1/chat/completions`
* *RHOAI Dashboard*: Gen AI Studio > API Keys, Settings > Subscriptions

Authentication uses OpenShift bearer tokens for API browsing and `sk-oai-*` API keys (generated via the RHOAI dashboard) for model inference.

== Design

Models do *not* run on this cluster. They are accessed via ExternalModel CRs pointing to remote inference endpoints. The simulator provides a CPU-only test model for validating the full MaaS stack without GPU hardware.

== Use Cases

* MaaS governance platform for demos and workshops
* OpenShift AI 3.4 MaaS exploration and testing
* Foundation for adding GPU-backed models via ExternalModel CRs
