Provision an OpenShift Container Platform 5 cluster on AWS with basic customizations using AgnosticD V2.

This asset provides an OpenShift Container Platform 5 cluster with basic customizations on AWS for running hands-on-labs, workshops, and similar events where no specialized environment is available.

Refer to the catalog for specialized workshops such as Containers and Cloud-Native Roadshow, OpenShift Getting Started Workshops, and so on.

== Specifications

* Deployer: AgnosticD V2
* Cluster size options:
** SNO (Single Node OpenShift): 1 control-plane node
** Multinode: 3 control-plane node
* 2 Worker Nodes
* Cluster version: 5.0 Preview
* Certificates enabled on Ingress controllers
