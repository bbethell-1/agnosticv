Red Hat OpenShift provides the operational tooling that platform teams need to run Kubernetes in production — integrated monitoring, automated upgrades, built-in security policies, multi-cluster management, and developer self-service. This modular hands-on workshop puts learners in the driver's seat of a live OpenShift cluster to deploy real applications, configure enterprise authentication, break things on purpose and fix them, and explore Day 2 operations at scale. Each session is customized with a specific set of modules selected from the full catalog below.

== Detailed Overview

* *Platform Fundamentals*
** Explore what makes OpenShift different from upstream Kubernetes with integrated monitoring, routing, and operators
** Verify cluster health using ClusterOperators, node status, and the monitoring stack
** Understand installation methods and upgrade channels

* *Application Operations*
** Deploy, expose, scale, and troubleshoot workloads with Routes, TLS, and self-healing
** Configure the Ingress Controller with rate limiting, IP-based access control, and load balancing
** Implement OVN-Kubernetes NetworkPolicy, EgressFirewall, and EgressIP for network security

* *Identity & Access Management*
** Integrate LDAP authentication with OAuth, group sync, and role-based access control
** Deploy Red Hat build of Keycloak and configure OIDC authentication with automatic group synchronization
** Compare LDAP vs OIDC approaches and follow production security best practices

* *Day 2 Operations*
** Monitor clusters with Prometheus, Alertmanager, and the Loki logging stack
** Right-size workloads with VPA and handle variable load with HPA autoscaling
** Manage multi-cluster environments with ACM, hosted control planes, and policy-based governance

* *Advanced Capabilities*
** Run VMs alongside containers with OpenShift Virtualization including live migration, cloning, and snapshots
** Enable developer self-service with Red Hat Developer Hub golden paths and software catalogs
** Use OpenShift Lightspeed AI assistant for troubleshooting, YAML generation, and cluster guidance
** Scan and secure workloads with Red Hat Advanced Cluster Security
