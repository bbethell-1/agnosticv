
Deploys an OpenShift AI base cluster optimized for the deployment of QuickStarts AND deploys via make.

This catalog item is **currently** exposed to developers to order and test on directly

== What Gets Deployed

* *Keycloak SSO* -- OpenShift authentication with per-user accounts
* *ArgoCD (OpenShift GitOps)* -- App of Apps bootstrap for all components
* *OpenShift AI 3* -- Dashboard, pipelines, workbenches, model serving
