Catalog Item for the RH1 Lab *Agentic AI with Llama Stack and 3rd party Frameworks*

*Workshop Materials:* https://rhpds.github.io/showroom-agentic-ai-llamastack/modules/index.html

This hands-on workshop guides students through building production-ready agentic AI applications on Red Hat OpenShift AI using Llama Stack, LangGraph, Langfuse, Langflow and the Model Context Protocol (MCP). Students will progress from deploying a Llama Stack distribution to creating AI agents that interact with enterprise backend systems, implementing safety guardrails, RAG capabilities, and web search integration. The workshop culminates in deploying a complete full-stack AI agent application with tracing, evaluation, and feedback mechanisms, providing comprehensive experience in building and operating enterprise-grade AI systems.

What Students Will Learn and Experience

* Deploy and interact with Llama Stack on OpenShift using multiple inference APIs
* Build Retrieval-Augmented Generation (RAG) systems with vector stores and document search
* Implement AI safety shields and content moderation for enterprise compliance
* Integrate web search capabilities using Tavily to extend model knowledge
* Connect AI agents to backend microservices through the Model Context Protocol (MCP)
* Create autonomous agents using Llama Stack Client and LangGraph frameworks
* Deploy production AI applications with web-based chat interfaces
* Monitor and evaluate AI systems using Langfuse for traces, evaluations, and feedback
* Work with enterprise architecture including vLLM model serving and PostgreSQL-backed REST APIs


*Product(s):*

* Red Hat OpenShift Container Platform
* Red Hat OpenShift AI
