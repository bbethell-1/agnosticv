Lab 2 of the Getting Started with OpenShift series. Students start with a fully resilient DataSphere application already deployed and learn how OpenShift keeps applications running under failure and load. This lab demonstrates health probes, horizontal scaling, and autoscaling through hands-on exercises.

**Note**: This lab does not require completing Lab 1. The DataSphere application is pre-deployed with all resilience features configured.

== What Gets Deployed

* *Student Account* — Keycloak SSO user with access to dedicated namespaces
* *Gitea Repositories* — DataSphere source code for reference
* *Pre-deployed Resilient DataSphere* — Production-ready application with health probes, resource limits, and HPA pre-configured
* *Lab Workspace* — `{user}-lab2` namespace for additional exercises
* *Showroom Lab Guide* — Interactive tutorial with embedded terminal and console access

The DataSphere application is deployed WITH all resilience features enabled. Students observe and test how these features work.

== Lab Exercises

*Section 1: What Happens When Things Break?*

* Kill a pod and watch OpenShift automatically replace it
* Observe health probes detecting failures
* Test liveness and readiness probes in action
* Verify zero-downtime resilience

*Section 2: Horizontal Scaling*

* Scale the API deployment to multiple replicas
* Observe load balancing across pods
* Delete a pod and verify traffic continues to other replicas
* Understand how ReplicaSets maintain availability

*Section 3: Automatic Scaling with HPA*

* Examine the pre-configured Horizontal Pod Autoscaler
* Generate load on the API using Apache Bench
* Watch HPA automatically scale pods based on CPU usage
* Observe pods scaling back down when load decreases

== Pre-requisites

None. This lab can be taken independently of Lab 1.
