Troshka provides a personal nested virtualization environment for building and demonstrating Red Hat technologies. Each instance includes a pre-configured host for running nested VMs — ready to create OCP clusters, RHEL labs, and multi-VM demo environments immediately after provisioning.

== Featured Technology and Products

* Red Hat OpenShift Container Platform (nested)
* Red Hat Enterprise Linux 10
* Troshka (nested virtualization platform)
* KVM / KubeVirt nested virtualization

== Detailed Overview

* *Personal Isolated Environment*
** Dedicated Troshka instance with SSO login (your credentials only)
** Agent host VM with nested virtualization enabled
** Full resource isolation — your VMs do not share a host with others

* *Pre-loaded Image Library*
** RHEL 10.2 bastion image, KVM guest image, and install ISO ready to use
** No manual image download required

* *Self-Service Lab Operations*
** Create projects, deploy OCP clusters, and save/restore patterns
** Build reusable VM snapshots for rapid lab reprovisioning
