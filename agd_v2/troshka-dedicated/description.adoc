Troshka provides a personal nested virtualization environment for building and demonstrating Red Hat technologies. Each instance includes a pre-configured host for running nested VMs — ready to create OCP clusters, RHEL labs, and multi-VM demo environments immediately after provisioning.

== What You Get

* A dedicated Troshka instance with SSO login (your credentials only)
* An agent host VM with nested virtualization enabled
* Pre-loaded library with RHEL 10.2 bastion image, guest image, and install ISO
* Full self-service: create projects, deploy OCP clusters, save and restore patterns

== Use Cases

* Build and iterate on demo environments with nested VMs
* Develop and test agnosticD catalog items backed by Troshka
* Create reusable patterns (VM snapshots) for rapid lab provisioning
