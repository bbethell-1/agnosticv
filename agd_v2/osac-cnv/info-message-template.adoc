=== Red Hat cloud extensions

Red Hat cloud extensions have been deployed and pre-configured on this environment.

The Red Hat cloud extensions Console is available at: {osac_ui_url}

Administrator login is available with:

* *User*: `{osac_admin_user}`
* *Password*: `{osac_admin_password}`

Regular user password is `{osac_user_password}`.

Log into Red Hat cloud extensions:

[source,bash,subs="attributes"]
----
osac login --insecure \
    --issuer="https://keycloak-keycloak.$(oc get ingresses.config/cluster -o jsonpath='{.spec.domain}')/realms/osac" \
    --flow=password \
    --user={osac_admin_user} \
    --password={osac_admin_password} \
    "https://fulfillment-internal-api-osac.$(oc get ingresses.config/cluster -o jsonpath='{.spec.domain}')"
----

endif::[]
=== OpenShift Console Access

Your OpenShift console is available at: {openshift_console_url}

Administrator login is available with:

* *User*: `{openshift_cluster_admin_username}`
* *Password*: `{openshift_cluster_admin_password}`

The OpenShift API is available at: {openshift_api_url}

Log into OpenShift:

[source,bash,subs="attributes"]
----
oc login \
  -u {openshift_cluster_admin_username} \
  -p {openshift_cluster_admin_password} \
  {openshift_api_url}
----
