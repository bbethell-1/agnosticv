Red Hat cloud extensions enable enterprises to deploy sovereign cloud platforms on OpenShift that meet strict data residency and regulatory compliance requirements. This hands-on workshop puts you in the role of a Platform Engineer at Sovereign Cloud Corp, deploying a multi-tenant sovereign cloud for government clients. Learners explore the platform architecture, onboard tenants with federated identity via Keycloak, configure storage and VM provisioning through a service catalog, and deploy OpenShift clusters as a service.

== Featured Technology and Products

* Red Hat OpenShift Container Platform 4.22
* Red Hat cloud extensions (OSAC)
* Red Hat build of Keycloak
* Apache Kafka (event streaming)
* Red Hat OpenShift Virtualization (CNV)

== Detailed Overview

* *Module 1: Exploring the Red Hat cloud extensions Platform (30 min)*
** Verify platform operators and pods are healthy in the osac namespace
** Navigate the cloud extensions UI and explore Keycloak realm configuration
** Inspect the Kafka cluster and understand the event-driven architecture

* *Module 2: Tenant Onboarding and Identity Management (30 min)*
** Create tenants and verify automatic Keycloak organization provisioning
** Configure federated SSO with an external identity provider
** Assign tenant-admin and viewer roles and verify RBAC enforcement

* *Module 3: Virtual Machine as a Service — VMaaS (30 min)*
** Configure storage backends and create disk images for tenant workloads
** Author and publish ComputeInstanceCatalogItems for self-service VM provisioning
** Deploy VMs as a tenant administrator and verify RBAC prevents unauthorized operations

* *Module 4: Cluster as a Service — CaaS (30 min)*
** Create catalog items for cluster provisioning
** Deploy and manage OpenShift clusters as a service for tenants

== Target Audience

Platform Engineers and Cloud Architects who want to deploy and manage Red Hat cloud extensions, including multi-tenant environments and automated workload provisioning on OpenShift.
