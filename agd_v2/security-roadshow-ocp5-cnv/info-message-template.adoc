The roadshow is a hands-on environment for Kubernetes-native security. Modules cover foundations, hardening, and zero trust, then Advanced Cluster Security, OpenShift Virtualization, and Lightwell Trusted Software Supply Chain. Each module ends with a practical task.

The following components are pre-installed:

* Red Hat OpenShift Container Platform 5.0
* Red Hat Advanced Cluster Security (ACS)
* Red Hat OpenShift GitOps (Argo CD)
* Red Hat OpenShift Virtualization with a Red Hat Enterprise Linux 9 virtual machine
* Red Hat OpenShift Lightspeed with MCP server integration
* Lightspeed Agentic Operator
* Cluster Observability Operator with Perses dashboards
