This is the shared cluster infrastructure component for the Getting Started with OpenShift lab series. It provisions a multi-user OpenShift cluster with the platform services required to run the lab — authentication, GitOps bootstrap, and Gitea for per-student source repositories. This CI is intended for developers and administrators only; end users should order the matching tenant CIs: 

* Getting Started with OpenShift - Module 1
* Getting Started with OpenShift - Module 2
* Getting Started with OpenShift - Module 3

== What Gets Deployed

* *Keycloak SSO* — OpenShift authentication with per-student accounts
* *OpenShift GitOps (ArgoCD)* — App of Apps bootstrap that manages all cluster-level and per-tenant workloads
* *Gitea* — In-cluster Git server seeded with the DataSphere application source code for S2I and GitOps lab exercises
* *Developer Perspective* — Enabled cluster-wide so students see the correct OpenShift console view
* *DataSphere Helm catalog* — Pre-registered in the OpenShift developer catalog for the Helm install lab exercise
