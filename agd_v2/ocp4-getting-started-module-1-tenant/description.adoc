Lab 1 of the Getting Started with OpenShift series. Students learn to deploy applications three different ways: from a container image using `oc new-app`, building from source with Source-to-Image (S2I), and deploying with a Helm chart. The lab covers core OpenShift concepts including Pods, Services, and Routes using DataSphere, a purpose-built demo application.

== What Gets Deployed

* *Student Account* — Keycloak SSO user with access to dedicated namespaces
* *Gitea Repositories* — DataSphere source code (API and UI) for S2I builds
* *Empty Namespaces* — `{user}-lab` and `{user}-lab-helm` workspaces
* *Showroom Lab Guide* — Interactive tutorial with embedded terminal and console access

Students deploy DataSphere themselves during the lab exercises. No pre-deployed applications.

== Lab Exercises

*Module 1: Deploy from Container Image*

* Use `oc new-app` to deploy from a pre-built container image
* Explore Pods, Services, and Routes
* Understand how labels connect resources

*Module 2: Build from Source with S2I*

* Deploy the DataSphere API using Source-to-Image builds
* Connect to Gitea repositories
* Build directly from source code

*Module 3: Deploy with Helm*

* Use the OpenShift Developer Catalog
* Deploy the full DataSphere stack with a Helm chart
* Understand Helm values and templating
