Red Hat OpenShift Virtualization enables organizations to run containers and virtual machines together on a unified platform, allowing teams to modernize at their own pace. This hands-on workshop demonstrates how to integrate VMs into OpenShift Service Mesh for traffic management and observability, automate VM deployments with GitOps, and leverage OpenShift Lightspeed for AI-assisted troubleshooting. Learners explore canary deployments for VM-based services, declarative VM management with Argo CD, and self-service provisioning patterns with Developer Hub.

== Detailed Overview

* *VM Foundations with OpenShift Lightspeed*
** Create and manage virtual machines as Kubernetes objects
** Use OpenShift Lightspeed for AI-assisted VM troubleshooting
** Explore VM quick-create workflows and templates

* *Service Mesh Integration with Virtual Machines*
** Add VMs and containers to OpenShift Service Mesh
** Implement canary releases and authorization policies for VM-based services
** Explore Kiali dashboards for unified observability across hybrid workloads

* *Declarative Management of VMs with GitOps Automation*
** Deploy and manage VMs using Argo CD applications
** Validate GitOps self-healing for VM configurations
** Automate VM lifecycle operations with declarative manifests

* *Self-service VM Provisioning with Developer Hub*
** Explore self-service VM provisioning patterns (interactive video)
** Understand governance controls for self-service operations

* *OpenShift Virtualization in the Cloud*
** Deploy OpenShift Virtualization in multicloud environments (interactive video)
** Explore cloud-native VM operations at scale
