Modernize VM Operations with OpenShift Virtualization, Service Mesh, and GitOps.

*LB8685*: Accelerating Infrastructure Modernization with OpenShift Virtualization.

== Products

* Red Hat OpenShift
* Red Hat OpenShift Virtualization
* Red Hat OpenShift Service Mesh
* Red Hat OpenShift GitOps

== Audience

* Cloud Administrators seeking to integrate VMs into their OpenShift environment.
* DevOps Engineers aiming to automate VM deployments and configurations using GitOps.
* Security Architects looking to apply consistent security policies across VMs and containers.
* IT Leaders interested in modernizing legacy VM infrastructure without application rewrites.

== Lab Highlights

* Run VMs as Kubernetes objects within OpenShift, managed alongside containers.
* Integrate VMs into OpenShift Service Mesh for mTLS, traffic management, and observability.
* Implement canary deployments and circuit breakers for VM-based services.
* Automate VM configuration and deployments using GitOps principles with ArgoCD.
* Gain end-to-end visibility across VMs and containers through unified monitoring dashboards.
