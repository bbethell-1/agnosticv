
Per-tenant provisioning for the Data Governance Copilot on OpenShift AI.

This catalog item deploys a complete Data Governance Copilot environment for a single tenant on a shared base cluster via the OpenShift Sandbox API. Workloads are installed via Make.

== What Gets Deployed

* *Keycloak user* -- Per-tenant OpenShift user via shared Keycloak
* *Tenant namespaces* -- Isolated namespaces for Data Governance workloads
* *LiteLLM Virtual Keys* -- Managed LLM API access for this tenant
* *Data Governance Copilot* -- Deployed via Make (Helm-based)
* *Showroom* -- Interactive lab guide with embedded OpenShift console

== Design

This tenant CI runs on a shared base cluster provisioned by `ai-qs-data-gov-cluster`.
Each tenant gets isolated namespaces, a dedicated Keycloak user, and its own
Make-deployed Data Governance Copilot environment.
