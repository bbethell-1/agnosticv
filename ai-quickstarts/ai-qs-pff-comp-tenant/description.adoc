
Per-tenant provisioning for the PPE Compliance Monitor quickstart on OpenShift AI.

This catalog item deploys a complete PPE Compliance Monitor environment for a single tenant on a shared base cluster via the OpenShift Sandbox API.

== What Gets Deployed

* *Keycloak user* -- Per-tenant OpenShift user via shared Keycloak
* *Tenant namespaces* -- Isolated namespaces for PPE Compliance Monitor workloads
* *ArgoCD (OpenShift GitOps)* -- Per-tenant GitOps bootstrap for PPE Compliance Monitor components
* *LiteLLM Virtual Keys* -- Managed LLM API access for this tenant
* *PPE Compliance Monitor* -- Computer vision pipeline with YOLO detection, video streaming, MinIO, PostgreSQL, and LLM-powered chat via Helm
* *Showroom* -- Interactive lab guide with embedded OpenShift console

== Design

This tenant CI runs on a shared base cluster provisioned by `ai-qs-pff-comp-cluster`.
Each tenant gets isolated namespaces, a dedicated Keycloak user, and its own
ArgoCD-managed PPE Compliance Monitor deployment.
