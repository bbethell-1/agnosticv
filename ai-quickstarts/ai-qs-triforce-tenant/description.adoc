
Deploys the Triforce multi-agent AI platform on a shared base cluster via the OpenShift Sandbox API. Demonstrates polyglot agentic inference across Intel Xeon 6 CPU backends with healthcare, financial services, telco, and energy industry verticals. 15 pluggable optimization modules.

== What Gets Deployed

* *Healthcare Agent* -- Python/FastAPI clinical NLP agent (classification, NER, summarization) with 4-node LangGraph pipeline
* *FinServ Agent* -- Java/Quarkus fraud scoring and compliance checking with LLM + rule signals
* *Orchestrator* -- Go workflow coordinator with A2A agent discovery
* *Semantic Router* -- Embedding-based complexity routing (<1ms, no LLM call)
* *MCP Gateway* -- 8 federated tools (drug interactions, FHIR, formulary) via JSON-RPC
* *Frontend Dashboard* -- React 19 demo with 4 variants, 32 acts, 14 module deep-dives
* *PostgreSQL* -- Shared state (agent registry, inference log, audit trail)
* *Kafka (Redpanda)* -- Event streaming for batch processing and agent communication
* *LiteLLM Virtual Key* -- Scoped API key for MAAS model access (7-day TTL)
