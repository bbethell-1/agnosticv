
Base OpenShift Infra Cluster for PFF Compliance quickstart tenants.

This catalog item deploys shared platform services on top of an OpenShift cluster, preparing it to host PFF Compliance quickstart tenant environments via the OpenShift Sandbox API.

== What Gets Deployed

* *Keycloak SSO* -- OpenShift authentication with admin and per-user accounts
* *ArgoCD (OpenShift GitOps)* -- GitOps operator for tenant workload delivery
* *OpenShift AI 3* -- Dashboard, pipelines, workbenches, model serving, model registry

== Design

This catalog item is designed to be registered with the OpenShift Sandbox API.
Individual PFF Compliance quickstart tenants are provisioned on top of this base cluster.

== Requirements

Deploys on top of an OpenShift 4.20+ cluster with CNV (Container Native Virtualization) installed.
