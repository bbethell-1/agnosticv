
Per-tenant provisioning for the IT Self Service AI Quickstart on OpenShift AI.

This catalog item deploys a complete IT Self Service environment for a single tenant on a shared base cluster via the OpenShift Sandbox API. Workloads are installed via Make.

== What Gets Deployed

* *Keycloak user* -- Per-tenant OpenShift user via shared Keycloak
* *Tenant namespaces* -- Isolated namespaces for IT Self Service workloads
* *LiteLLM Virtual Keys* -- Managed LLM API access for this tenant
* *IT Self Service Quickstart* -- Deployed via Make (Helm-based)
* *Showroom* -- Interactive lab guide with embedded OpenShift console

== Design

This tenant CI runs on a shared base cluster provisioned by `ai-qs-it-self-service-cluster`.
Each tenant gets isolated namespaces, a dedicated Keycloak user, and its own
Make-deployed IT Self Service environment.
