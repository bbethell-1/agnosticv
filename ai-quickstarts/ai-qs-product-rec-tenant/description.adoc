
This AI quickstart application demonstrates how to deploy a secure, sovereign product recommender using OpenShift AI to maintain full control over your data. Features include hybrid semantic search, personalized AI-driven product recommendations, and scaleable AI-generated customer review summaries.

== What Gets Deployed

* *qwen3-14b LLM* -- Served by OpenShift AI behind MaaS (Model as a Service)
* *Product Recommender* application
* *Showroom* -- Interactive lab guide with embedded OpenShift console
