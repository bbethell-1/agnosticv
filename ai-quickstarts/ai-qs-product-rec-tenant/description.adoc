
Single seat of the Product Recommender Quickstart on OpenShift AI.

This catalog item deploys a complete Product Recommender environment for a single seat on a shared base cluster via the OpenShift Sandbox API. Workloads are installed via Make.

== What Gets Deployed

* *qwen3-14b LLM* -- Served by OpenShift AI behind MaaS (Model as a Service)
* *Product Recommender* application
* *Showroom* -- Interactive lab guide with embedded OpenShift console
