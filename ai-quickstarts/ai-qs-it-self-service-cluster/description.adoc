
Base OpenShift Infra Cluster for AI Quickstart IT Self Service tenants.

This catalog item deploys shared platform services on top of an OpenShift cluster, preparing it to host IT Self Service tenant environments via the OpenShift Sandbox API. Clients install their workloads via Make (no GitOps/ArgoCD).

== What Gets Deployed

* *Keycloak SSO* -- OpenShift authentication with admin and per-user accounts
* *OpenShift AI 3* -- Dashboard, pipelines, workbenches, model serving, model registry

== Design

This catalog item is designed to be registered with the OpenShift Sandbox API.
Individual IT Self Service tenants are provisioned on top of this base cluster.
Tenant workloads are installed by the client via Make rather than GitOps.

== Requirements

Deploys on top of an OpenShift 4.20+ cluster with CNV (Container Native Virtualization) installed.
