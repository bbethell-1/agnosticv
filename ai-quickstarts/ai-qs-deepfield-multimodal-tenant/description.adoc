
Deploys the DeepField Multimodal agentic signal classification engine on a shared base cluster via the OpenShift Sandbox API. Demonstrates three-tier agent cascade (nano/micro/macro) classifying enterprise signals on Intel Xeon 6 CPU — no GPU required for runtime.

== What Gets Deployed

* *DeepField Multimodal App* -- FastAPI backend + React frontend with OAuth proxy
* *17 Classification Agents* -- 7 nanoagents (deterministic), 5 microagents (rule-backed), 5 macroagents (reasoning)
* *Bootstrap Lab* -- Connect data sources, analyze with frontier model, validate and promote agents
* *Showroom Content* -- Presenter guide, demo script, lab guide, architecture docs
* *LiteLLM Virtual Key* -- Scoped API key for MAAS model access
