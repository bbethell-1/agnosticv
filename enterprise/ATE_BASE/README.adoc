== Overview

CI for the AWS Creds for ATE (Automate the Enterprise). Basically a mirror copy of AWS Sandbox is required. 
Making it a separate CI isolates ATE from changes to the original Sandbox CI

=== Developer Notes

The AWS Sandbox role would use an `accounts.yaml`, this CI will need that in `common.yaml` as the /enterprise directory is multi cloud blocking us usung one set of creds etc.
