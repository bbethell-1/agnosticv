== Overview

This will be the wrapping CI for the Automate the Enterprise Demo. It wraps the following CIs with, potentially, more to be added. EG a "AI_CREDS_VSPHERE"

* ATE_CI
* ATE_CREDS_AWS
* ATE_CREDS_AZURE

Ansible config ent-demo-ate-base will use the provision data vars defined in ATE_CI and the related CIs to do actions such as

* Get creds from the `ATE_CRED_<CLOUD>` CIs and then inject them into ATE_BASE
** eg create AAP2 controller creds
* Other sues could include (optionally)
** Normalizing passwords, users, ssh keys across separate CIs
