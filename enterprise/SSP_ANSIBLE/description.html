Shows how Red Hat® Ansible® Automation Platform scales skills to extend automation beyond IT.

This demo illustrates how Ansible Automation Platform can extend the purview of automation beyond IT by scaling in-house skills and leveraging the strength of the Ansible community. This foundational demo serves as a baseline script for future demos that cover additional Ansible Automation Platform features. Sales Speacialist Persons (SSPs) are encouraged to personalize and customize the demo to suit individual account and opportunity needs.

Specifications

Automation controller with these main components:

  • Preloaded AWS credentials
  • Preloaded Azure credentials
  • Preloaded projects, job templates, and workflows
  • Bastion host with SSH access
