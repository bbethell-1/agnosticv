This lab provides an AAP 2.5 environment on OpenShift for demo, development, and experimentation with the https://github.com/ansible/product-demos[Ansible Product Demos^] project. There are two recommended ways to use this asset:

* *Standard:* Using the project "as is" provides a community of demos for a variety of different use cases to minimize the required effort for high-impact customer demos.
* *Customized:* Not all customers are the same and may require customizations to meet their requirements. This environment is built to allow the use of gitops to rapidly prototype customer scenarios. See the project https://github.com/ansible/product-demos[documentation^] for details on how to use it in this way.

[NOTE]
====
This demo supports three **Open Envs**: **AWS (default)**, **Azure**, and **IBM Cloud**.

- **AWS** is the default Open Env and uses a **pooled setup**, so environments start **quickly**.
- If you choose **Azure**, **IBM**, or any **combination** of these, the environment will take **longer to provision** as it's not pooled.

*Please allow extra time if selecting non-default environments.*
====

=== Supporting Materials

==== Access Guide

After you complete provisioning, you will receive an email with a website containing a user credential and access to the following:

* Automation Controller Web UI
* OpenShift Console/API
* AWS Console
* RHEL bastion host

The website provided with this information is dynamically created upon provisioning. You will need to provision the type of cloud instances you require after the lab has been built.

==== Lab Materials

This sandbox is a "choose your own adventure" style lab. It is intended to provide you with the tools needed to deliver high-impact demos and automation solutions.
