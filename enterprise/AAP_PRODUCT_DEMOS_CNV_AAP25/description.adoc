This lab provides an AAP environment running on OpenShift for demo, development, and experimentation with the https://github.com/ansible/product-demos[Ansible Product Demos^] (APD) project. There are two recommended ways to use this asset:

* *Standard:* Using the project "as is" provides a community of demos for a variety of different use cases to minimize the required effort for high-impact customer demos.
* *Customized:* Not all customers are the same and may require customizations to meet their requirements. This environment is built to allow the use of GitOps to rapidly prototype customer scenarios. See the project https://github.com/ansible/product-demos[documentation^] for details on how to use it in this way.

== Products and Environment

* Red Hat Ansible Automation Platform

NOTE: We support N-1 versions of the AAP operator with this catalog item, currently `stable-2.6` and `stable-2.7`.

* Red Hat OpenShift 4.20
* RHEL 9.6 bastion with Ansible CLI tools
* Default Cloud Access: AWS  
* Optional Cloud Access: Azure

== Public Cloud Access

By default, the environment deploys **with AWS**.  
You can optionally enable **Azure** when placing your order.

NOTE: The Partner catalog item will not have access to open public cloud environments.  However, a partner's existing cloud credentials may be added to Ansible Automation Platform for accessing public cloud environments after provisioning this catalog item.

[IMPORTANT]
====
Provisioning will take longer **if you choose Azure when ordering**.
====
