Description:

The OHC demo is an executive level demo that can functionally illustrate the “art of the possible” for hybrid cloud portability related to core Red hat value proposition.

Originally requested for IBM Chairman and CEO Arvind Krishna, it has been developed by a world-wide collaboration between Red Hat's RHPDS, Chief Architects, GTM teams, and Business Units. It aligns with Open Hybrid Cloud Value Framework (10 pages) and the Open Hybrid Cloud Messaging Brief (4 pages).

This composable demo is targetted at executives and IT decision makers. Each section is independent. Deliver the whole thing in 20 minutes, or go deep and deliver in any order you like.

  • Agenda:
    • Segment 1 - Stability and Speed Anywhere
      • Whether deployed via managed services or self-managed, Red Hat provides a consistent experience everywhere your applications run
    • Segment 2 - Application Modernization and Developer Experience
      • Remove toil from developers inner and outer loops using a powerful, but familiar, set of open source tools to develop, test, modernize, and deploy applications
    • Segment 3 - Manage and Secure at Scale
      • Policy-based rules enforcement facilitates quick deployment of clusters across distributed locations for availability, capacity, and security
    • Segment 4 - Extend to the Edge
      • Applications extend to the edge, so does your sphere of management. Ansible and Red Hat Enterprise Linux extend beyond the datacenter and cloud
