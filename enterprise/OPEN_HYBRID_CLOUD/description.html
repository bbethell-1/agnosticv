An executive level demo that functionally illustrates the "art of the possible" in the core Red Hat value proposition.

The OHC demo is an executive level demo that can functionally illustrate the "art of the possible" for the open hybrid cloud related to core Red Hat value proposition.

WARNING At this time we do not recommend running this demo as a workshop. There is no workshop documentation, and has not been tested as such.

Originally requested for IBM Chairman and CEO Arvind Krishna, this demo was developed as a worldwide collaboration between Red Hat's Demo Platform staff, Marketing, Chief Architects, GTM teams, and Business Units. It aligns with Open Hybrid Cloud Value Framework (10 pages) and the Open Hybrid Cloud Messaging Brief (4 pages).

Agenda:

The demo consists of four independent segments each of approximately 20 minutes. You can deliver any one of the segments' parts in about 5-10 minutes. You can deliver segments and their parts in any order you like.

  • Segment 1 - Stability and Speed Anywhere
    • Whether deployed via managed services or self-managed, Red Hat provides a consistent experience everywhere your applications run
  • Segment 2 - Application Modernization and Developer Experience
    • Remove toil from developers inner and outer loops using a powerful, but familiar, set of open source tools to develop, test, modernize, and deploy applications
  • Segment 3 - Manage and Secure at Scale
    • Policy-based rules enforcement facilitates quick deployment of clusters across distributed locations for availability, capacity, and security
  • Segment 4 - Extend to the Edge
    • Applications extend to the edge, so does your sphere of management. Ansible and Red Hat Enterprise Linux extend beyond the datacenter and cloud
