Welcome to the demo of Red Hat Developer Hub! Red Hat Developer Hub is an enterprise-grade, open developer platform that helps organizations build and deploy applications faster, with better quality. Red Hat Developer Hub is based on Project Janus, a framework for building developer portals. Project Janus is a powerful and flexible framework that provides a solid foundation for building secure, scalable, and easy-to-use developer portals. In this demo, we will be using Red Hat Developer Hub to build a simple application using Backstage. Backstage is a tool for managing APIs and other developer artifacts. It provides a central location for developers to find, understand, and use the APIs that they need. We will also be using Red Hat SSO for authentication and local GitLab for SCM. Red Hat SSO is a single sign-on solution that allows developers to access resources across multiple applications and services. Local GitLab is a self-hosted Git repository manager.
