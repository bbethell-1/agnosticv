= On-Prem Red Hat Trusted Application Pipeline

== Description

This demo, titled "On-Prem Red Hat Trusted Application Pipeline," showcases the integration and application of Red Hat's diverse suite of tools and technologies, specifically designed to create a secure, efficient, and developer-friendly software development lifecycle (SDLC).

The demo now includes an option to provision with OpenShift AI, bringing AI themes and Large Language Models (LLMs) into the mix for advanced capabilities. This enhancement builds on the existing Secure Supply Chain foundation by incorporating AI integration.

When setting up the demo, you can choose to include the AI theme, which will utilize GPUs and incur additional costs. If you don't need the AI theme, simply order the environment without selecting it to save resources.

== Red Hat Products

* *Red Hat Developer Hub:* Provides a self-service portal to accelerate developer onboarding.
* *Red Hat Trusted Application Pipeline (RHTAP):* Central to ensuring security and efficiency in the SDLC.
* *Red Hat OpenShift AI:* Provides tools across the full lifecycle of AI/ML experiments and models, including training, serving, monitoring, and managing AI/ML models and AI-enabled applications.
* *Red Hat Trusted Artifact Signer:* Enhances the security and integrity of software artifacts.
* *Red Hat Trusted Profile Analyzer:* Analyzes and ensures robust security profiles for applications.
* *Red Hat Advanced Cluster Security (ACS):* Offers comprehensive security for Kubernetes clusters.
* *Red Hat OpenShift Pipelines:* Supports continuous integration and deployment with powerful CI/CD capabilities.
* *Red Hat GitOps:* Facilitates efficient and consistent software deployment through GitOps methodologies.
* *Red Hat Quay:* Provides a secure and scalable container image registry.
* *Red Hat OpenShift Dev Spaces:* Streamlines the setup of development environments.
* *Red Hat OpenShift:* A leading enterprise platform for container orchestration.

== AI with LLMs Integration

In addition to the existing features of the Trusted Application Pipeline demo, we are introducing a new AI and LLM integration option that leverages Red Hat OpenShift AI. This option adds advanced capabilities to the demo, including:

* *New Templates:*
** A "Secured Chatbot with a Self-Hosted Large Language Model (LLM)" template simplifies the creation of LLM-infused microservices.
** A "Secured Chatbot for accessing an External Large Language Model (LLM)" template that for accessing an existing LLM service.
** A "Secured Document Chatbot assistant using RAG" template that enables you to chat with your documentation.
* *AI and LLM Integration:* Leverage the power of AI and LLMs for natural language processing tasks, including chatbots and more.
* *Seamless Pipelines:* The demo showcases the synergy between the SDLC, managed by RHTAP, and the MDLC, managed by OpenShift AI, streamlining AI application development.
* *Effortless Deployment:* Pre-built templates and wizards guide you through the process, making it easier than ever to build, deploy, and manage AI-infused applications.

With open LLMs such as Llama, Mistral, or Granite, you can start with a foundation model that does not have to be trained from scratch. These models can be lifecycled, managed, served, and monitored by Red Hat OpenShift AI while your application lifecycle remains independent and potentially hosted on OpenShift.

This integration enables you to keep your private data within your datacenter or VPC, ensuring security and compliance with your organization's policies.
