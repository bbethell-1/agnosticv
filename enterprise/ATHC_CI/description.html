Explore deployment and remediation use cases for automating and managing the hybrid cloud.

This demo includes the following hybrid cloud scenarios:

  • Deploying a developer VM to a public cloud (Azure)
  • Deploying and configuring, from scratch, a LAMP (Linux/Apache/MySQL/PHP) demo application in parallel across Azure and AWS
  • Remediating a compliance issue on a cloud instance

Duration: 90 Minutes

Audience: VP, Director or Manager of IT; Infrastructure Manager

Product(s): Red Hat Ansible Automation Platform

Specifications

    • Preloaded Azure credentials
