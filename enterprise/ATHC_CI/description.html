This is the demo for the Sales Play for Automate and Manage the Hybrid Cloud

It includes a number of different Hybrid Cloud scenarios including:

  • Deploying a Developer VM to a Public Cloud (Azure)
  • Deploying and Configuring, from scratch, LAMP application demo in paralle across Azure and AWS
  • Remediating a Complaince issue on a Cloud Instance
