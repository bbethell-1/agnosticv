This demo is based on the DevSecOps architecture presented in the validated pattern at https://hybrid-cloud-patterns.io/patterns/devsecops/ . Its purpose is to serve as a sales asset for Red Hat's go-to-market teams, showcasing the benefits of using this approach to increase security and efficiency in software development and deployment processes.

Red Hat Products
  • Red Hat OpenShift Container Platform (Kubernetes)
  • Red Hat Advanced Cluster Management (Open Cluster Management)
  • Red Hat OpenShift GitOps (ArgoCD)
  • Red Hat OpenShift Pipelines (Tekton)
  • Red Hat Quay (container image registry with security features enabled)
  • Red Hat Open Data Foundation (highly available storage)
  • Red Hat Advanced Cluster Security (scanning and monitoring)
Other technologies & products
  • Hashicorp Vault community edition (secrets management)
  • VScode (IDE)
