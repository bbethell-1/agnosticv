== Overview

CI for the Azure Creds for ATE (Automate the Enterprise). Can be based on any CI, eg Azure OE or Azure Open Subscription that provides necessary creds that AAP2 can use to deploy to Azure.

Making it a separate CI isolates ATE from changes to the original Sandbox CI

=== Developer Notes

The Azure Sandbox role would use an `accounts.yaml`, this CI will need that in `common.yaml` as the /enterprise directory is multi cloud blocking us using one set of creds etc.
