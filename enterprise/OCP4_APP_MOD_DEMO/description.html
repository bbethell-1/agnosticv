Modernize Existing Applications - Sales Play Demo

This demo covers the top challenges addressed by the sales play:

  • Slow evolution
  • Supporting growth
  • Increasing cost
  • Security
  • Developer productivity

The demo is being broken down into THREE sections:

Rehost
How developers can maintain productivity by using the same application workloads and simply lifting and shifting them to a cloud platform without requiring modification.

Replatform
How to ease the impact of platform migration by incrementally replacing specific pieces of functionality with new applications and services. Doing this allows for a low-risk transition that is simple to rollback should the need arise.

Refactor
How to reevaluate with a business-value oriented mindset to prioritize feature sets, and perform inventory checks on unused code and services.
