Sales Play demo addressing top challenges to modernizing existing applications.

This demo covers the top challenges addressed by the Modernize existing applications sales play. These challenges include:

  • Slow evolution
  • Growth support
  • Cost increases
  • Security
  • Developer productivity

The demo consists of 3 sections:

  • Rehost: Show how developers can maintain productivity by lifting and shifting application workloads to a cloud platform without modification.
  • Replatform: Show how to ease the impact of platform migration by incrementally replacing specific pieces of functionality with new applications and services. This approach provides a low-risk transition that is simple to rollback if needed.
  • Refactor: Show how to use a business-value mindset to evaluate and prioritize feature sets, and to perform inventory checks on unused code and services.
