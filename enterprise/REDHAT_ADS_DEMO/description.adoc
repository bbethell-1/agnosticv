This demo provisions *RHADS-TSSC (Red Hat Advanced Developer Suite – Trusted Software Supply Chain)* to showcase how Red Hat enables secure, automated, and policy-compliant application delivery using trusted components on OpenShift.

It features *Red Hat Developer Hub (RHDH)* as the central developer portal, integrated with both *Jenkins* and *Tekton (OpenShift Pipelines)* to support flexible CI/CD strategies. The demo highlights the use of *Pipeline as Code*, enabling version-controlled, auditable, and GitOps-aligned workflows.

The CI/CD pipelines integrate *Trusted Application Pipeline (TAP)* components — including *Trusted Profile Analyzer* and *Trusted Artifact Signer* — to automatically generate SBOMs, sign artifacts via Sigstore, and produce build attestations.

*Enterprise Contract* enforces Open Policy Agent (OPA)-based policies to validate builds against security, compliance, and provenance rules — ensuring *SLSA Level 3* standards are met. Optional integrations include *Red Hat Advanced Cluster Security (RHACS)* for runtime policy enforcement and *Red Hat Quay* for secure image promotion and storage.

Depending on the customer's tooling preferences, this demo can be presented with a Jenkins-centric narrative (for organizations with existing Jenkins usage) or a Tekton-first story (for Kubernetes-native CI/CD).
