== Overview

CI for the VMWare Creds for ATE (Automate the Enterprise). Can be based on any CI, eg VMWARE Open Subscription that provides necessary creds that AAP2 can use to deploy to VMware.

Making it a separate CI isolates ATE from changes to the original Sandbox CI

=== Developer Notes

The VMWare Sandbox role would use an `accounts.yaml`, this CI will need that in `common.yaml` as the /enterprise directory is multi cloud blocking us using one set of creds etc.
