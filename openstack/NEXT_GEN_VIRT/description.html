Openshift Virtualization Demo running Elasticsearch on Mixed Pods (VMs and Containers)


Please find further details at https://github.com/purefield/opc-virt

The course provides the access credentials for the openshift console

Dependencies

  • OpenShift Baremetal cluster with ODF
    • ODF is default storage class set and profile applied

The following dependencies are setup during provision if requested.

  • Installed Operators
    • OpenShift Virtualization Operator
    • Cert Utils Operator
  • RHEL Subscription information (for Pod software installation)
    • Subscription Org
    • Subscription Key
