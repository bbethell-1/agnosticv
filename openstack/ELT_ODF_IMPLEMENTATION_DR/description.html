There are three CI’s working in combination to provide you an environment to implement regional disaster recovery on Red Hat OpenShift Container Platform using Red Hat OpenShift Data Foundation.

Following are the 3 CI’s :
1) ODF Disaster Recovery Management - Provides Advanced Cluster Manager to manage your Cluster’s. This OCP cluster also acts as Hub Cluster of ODF Regional DR.
2) ODF Disaster Recovery Site 1 - 1st of the two OCP cluster sites.
3) ODF Disaster Recovery Site 2 - 2nd of the two OCP cluster sites.

You will be able to do the following :
  • Configure and deploy OpenShift Data Foundation across two OpenShift Container Platform clusters
  • Set up regional disaster recovery across two cluster sites
  • Set up OpenShift multisite connectivity
  • Install the operator of OpenShift Data Foundation and set up the StorageCluster on both clusters/sites
  • Configure multisite storage replication
  • Verify RBD mirroring functionality
  • Back up and restore container-specific information from one site to another for a given application
Follow this course for detailed instructions on how to use this CI. OpenShift Data Foundation Disaster Recovery Course.
