The OCP and Container Storage for Admins workshop is designed to be a full-day experience introducing OpenShift 4 administrative concepts as well as OpenShift Container Storage administrative concepts. It contains several modules, most of which are stand-alone. Requesting this catalog item will provide you with a GUIDgrabber instance (to distribute clusters to your participants) and one OpenShift 4 cluster for each user specified.
The source material for the lab guide can be found here:
https://github.com/openshift/openshift-cns-testdrive/tree/ocp4-prod/workshop/content

An example rendered lab can be found here, however note that this is not what your participants should use and does not exactly match what your participants will see. It is provided for reference only:
http://ocp-ocs-admins-labguides.6923.rh-us-east-1.openshiftapps.com/

Instructions for how to conduct a workshop can be found here:
https://www.opentlc.com/keys/OCP_and_Container_Storage_for_Admins_Provisioning.pdf
