Red Hat Enterprise Linux 9: Using and Supporting Image Builder

This course introduces Image Builder, a Red Hat Enterprise Linux feature referred to internally as Composer. We cover how it works, how to use it, and how to troubleshoot issues with it. While the course covers both osbuild-composer and lorax-composer, the hands-on labs currently feature osbuild-composer on RHEL 9.

Current Labs

  • Install Image Builder and create blueprint and image
  • Edit blueprint, add and remove packages and create image
  • Modify blueprint, add new user and a public SSH key for root user and create image
  • Create image-installer iso image
