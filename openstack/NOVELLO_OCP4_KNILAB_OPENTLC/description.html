OpenShift Baremetal IPI (KNI) Workshop

This item is currently in "public beta". Please allow at least 24 hours for support, deploy your workshop with this limitation in mind, thanks.

This catalogue item provides you with the ability to come up to speed with the new OpenShift Baremetal IPI (KNI/Metal3) concepts. There are two variants, depending on your entrypoint; if you're using rhpds.redhat.com this catalogue item will create a fully-deployed OpenShift cluster for you, one deployed via the KNI/Metal3 baremetal IPI construct, where the expectations would be for you to demonstrate an already-deployed cluster to customers, perhaps scale it, show the baremetal integration. If you've come in via labs.opentlc.com then the cluster won't be automatically deployed for you, i.e. you'll be expected to deploy the cluster yourself (and all of the pre-requisites) via the provided instructions (https://github.com/RHFieldProductManagement/baremetal-ipi-lab), and is very comprehensive in showing how everything is stood up. When you order this item you'll receive an email with all of the environmental specific configurations.

Cluster Specification

  • Infrastructure: "Fake baremetal" running on OpenStack, with Nova/IPMI wrapper.
  • Nodes: 3 masters, 3 workers (but 2 deployed by default, so you can 'add' or 'scale' a third via the instructions)
  • Storage: NFS by default, but enough capacity to deploy OCS on-top should you choose.

Access Guide

You have full admin access to the provisioned workshop cluster and can find all details needed to access your cluster in the email that you’ll receive once the environment has been deployed. See here for the lab guide:
https://github.com/RHFieldProductManagement/baremetal-ipi-lab

Provisioning Time?
~20 min if deploying via labs.opentlc.com (OpenShift cluster not deployed - meant for *lab* purposes)
~60-80 min if deploying via rhpds.redhat.com (OpenShift cluster is deployed- meant for *demo* purposes)
