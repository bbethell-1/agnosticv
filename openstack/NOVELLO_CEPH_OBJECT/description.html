Set up and deploy a cluster in Red Hat Ceph Storage to offer an object storage solution.

At a time when digital transformation is increasing the complexity of storage, software-defined storage (SDS) is a simple, reliable, and powerful answer.

Red Hat® Ceph Storage is an open source SDS storage solution that is massively scalable and meets the needs of modern workloads by combining block, object, and file storage into one platform.

In this catalog item, Red Hat experts explain how easy it is to set up a cluster in Red Hat Ceph Storage using Ansible and then deploy this object storage cluster in a multisite active/active configuration that can expand several Geo data types and offer an effective disaster recovery solution for your object storage.
