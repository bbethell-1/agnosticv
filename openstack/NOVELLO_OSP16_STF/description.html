OpenStack 16.1 Service Telemetry Framework demo

OpenStack 16.1 Service Telemetry Framework provisions an OpenStack 16.1 standalone and an OpenShift Code ready containers with the Service Telemetry Framework installed. Service Telemetry Framework (STF) is an application that runs on Red Hat OpenShift Container Platform (OCP) that provides metrics and events data collection from OpenStack infrastructure, fast and reliable transport of data, and built-in data storage and alerting capabilities.
