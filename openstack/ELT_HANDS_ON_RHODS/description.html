This CI provides a  playground lab environment to explore product features related to Red Hat OpenShift Data Science.
It offers first-hand experience with how Red Hat OpenShift Data Science can simplify the onboarding of artificial intelligence/machine learning (AI/ML) projects, providing an easy-to-use solution for data scientists and data engineers.

You will be able to do the following :
  • Become familiar with an OpenShift Data Science environment
  • Understand and demonstrate product features by creating, deploying, and managing an ML use case
Follow this course for detailed instructions on how to use this CI.
