You are able to access the IBM Cloud using the CLI, APIs, or web UI.

NOTE: This link requires you to have already accepted the IBM Cloud invitation whhich is in your email inbox.
AND you also must have switched to the correct sandbox.

To logon via the CLI:

[source,bash,subs="attributes"]
....
export IBMCLOUD_API_KEY={sandbox_sid_apikey}

ibmcloud login
....

Change your region (example):

....
ibmcloud target -r us-south
....

To logon to the UI, visit https://cloud.ibm.com[cloud.ibm.com]

endif::[]
