= Backup and Recovery of Red Hat OpenShift Virtualization VMs using Trilio for Kubernetes

This demo showcases the powerful backup and recovery capabilities of Trilio for Kubernetes in the context of Red Hat OpenShift Virtualization. Built on the OpenShift platform, OpenShift Virtualization allows users to run and manage virtual machines (VMs) alongside containerized applications within a unified Kubernetes environment.

Participants will explore how Trilio's advanced data protection features can be used to back up and recover VMs running on Red Hat OpenShift Virtualization. The demo will focus on showcasing Trilio's capabilities without diving into the setup process. Key highlights of the demo include:

1. **Backup Process:** Demonstrating how to create consistent backups of VMs within the Red Hat OpenShift Virtualization environment using Trilio's intuitive interface.

2. **Recovery Process:** Showcasing how Trilio enables efficient recovery of VMs, ensuring minimal downtime and data loss.

3. **Trilio Integration with OpenShift Console:** Highlighting the seamless integration of Trilio's UI within the Red Hat OpenShift Console for simplified management of backup and recovery tasks.

This demo provides a practical look at protecting and recovering workloads on Red Hat OpenShift Virtualization, emphasizing ease of use and reliability with Trilio for Kubernetes.

== Technologies Featured

- Red Hat OpenShift 4.16
- Red Hat OpenShift Virtualization 4.16
- Red Hat OpenShift Data Foundation 4.16
- Red Hat OpenShift API for Data Protection (OADP) 1.4
- Trilio 4.0.x
