OpenShift Container Platform 4 on Google Cloud Platform

This catalog item deploys OpenShift 4 on Google (GCP) for the purposes of running workshops for qualified opportunities.

Cluster Specification

  • Master Nodes: 3
  • Master Instance Type: n2-standard-4 (4 cores and 16GB of RAM)
  • Worker Nodes: 3
  • Worker Instance Type: n2-standard-4 (4 cores and 16GB of RAM)

Access Guide
