Deploy Red OpenShift Container Platform 4 on Google Cloud Platform (GCP) to run workshops.

This catalog item deploys OpenShift Container Platform 4 on GCP for the purposes of running workshops for qualified opportunities.

Specifications

Cluster specification:

  • Master nodes: Three
  • Master instance type: n2-standard-8 (eight cores and 32GB of RAM)
  • Worker nodes: Three
  • Worker instance type: n2-standard-4 (four cores and 16GB of RAM)

Supporting Materials

Lab guide

Access guide: You have full admin access to the provisioned cluster and can find all details needed to access your cluster in the email that is generated after the cluster is deployed by Red Hat Product Demo System (RHPDS). In addition, 50 student accounts are created that do not have cluster admin access.

Provisioning time: Typically, approximately 45 minutes
