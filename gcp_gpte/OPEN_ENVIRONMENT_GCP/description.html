GCP Open Environment


This catalog item provisions an GCP Open Environment
When you provision an OPEN Environment, a project is created that has the environment's GUID in the name. Everything you create must be in this project.
When your OPEN Environment is deleted, your user will remain active in our organization but will no longer have access to the project. To get a project, you must order a new open environment.
When your OPEN Environment is deleted, the project is removed. This will clean up all resources you have deployed in your OPEN Environment and they will not be recoverable.
For more information, please refer to the GCP getting started guide or Google gcloud guide.

Default Lifespan of Environment?
  • 2 Days
  • Extensions Available - Yes
Default Runtime of Environment?
  • Environment does not Idle
