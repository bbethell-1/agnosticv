Learn about the top challenges in app development addressed by the sales play.

These challenges include the following:

  • The ability to win, serve, and retain customers depends on delivering new capabilities rapidly and continuously through secure software applications.
  • IT organizations need to provide their developers with the flexibility to securely build, deploy, run, and scale applications across the hybrid cloud.

The demo contains three sections:

Enabling Immediate Productivity

This section targets developers, describing how they can achieve immediate productivity with built-in capabilities using the languages they are already familiar with.

Automating Guardrails for Consistent Security and Operation Control

This section is for DevOps, platform engineers, site reliability engineers, and Ops. It describes how the solution from Red Hat eases the operation and management of clusters distributed across a hybrid cloud environment, while maintaining security, consistency, and operational control.

Building a Flexible Architecture

This section is for software and platform architects. It describes how to architect systems using microservices, APIs, and event-driven architectures, all on one platform.


You can run this as demo or as a multi-user deployment for a hands-on lab. Select a user count value higher than '1' (one) to run as a hands-on lab.

Environment Specifications

The environment consists of one OpenShift Cluster deployed in AWS with:

  • Leader nodes: 1 node when single user or 3 nodes otherwise
  • Worker nodes: minimum 2 and +1 for every 5 users assigned
Duration

Demo lasts 10-15 mins.

Hands-on labs can take from 1 to 2 hours to complete.
