== Ansible Automation Platform on Google Cloud - Open Environment

=== Welcome to the Red Hat Ansible Automation Platform on Amazon Google Cloud RHPDS

This Environment gives Red Hatters on demand access to a Google Cloud environment with access to the Ansible Automation Platform on Google Cloud service offering. This time bound sandbox offers access to experience the Ansible Automation Platform on Google Cloud. You as a Red Hat associate will be enabled to to test, create, and demo this offering! YOU will help make our customers and account teams successful. This Google Cloud sandbox will allow users to do things not previously offered.

Current Offering:

* Red Hat Ansible Automation Platform on Google Cloud.  (You will deploy AAP from the Google Cloud Marketplace in the Google Cloud account provided)

Provisioning Time? (To get the Google Cloud environment)

* ~ 30 Min
* Once you are in the Google Cloud environment it will take about 60 minutes to deploy AAP on Google Cloud from the Google Cloud Marketplace. The guide listed below provides you instructions on how to perform this deployment.

Default Lifespan of Environment?

* 2 Days
