If you already know the basics of Red Hat Ansible Automation Platform and want more, this lab is for you. In this hands-on lab, we will explore the advanced capabilities of automation controller to get even more value from Ansible Automation Platform. You will:

  • Automate the automation: Configure automation controller with Ansible.
  • Use controller workflows to allow teams to work more efficiently together.
  • Use surveys to provide self-service to your automation users.
  • Learn how to use dynamic inventories and the new constructed inventory feature for scale and flexibility.
  • Secure automation supply chain: Use content signing to make sure only approved content is run in automation controller.
  • Learn the intricacies of job output filters.

After this lab, you’ll be able to use Ansible Automation Platform more efficiently, cover more use cases, and enable separate teams to work together on your automation strategy.

Product(s): Red Hat Ansible Automation Platform
