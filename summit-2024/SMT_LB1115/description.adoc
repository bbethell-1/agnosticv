= LB1115 - Cloud-Native Integration with Red Hat build of Apache Camel

Based on the book(https://www.amazon.com/Cloud-Native-Integration-Apache-Camel-ebook/dp/B09DNV22J1), this lab will cover the main challenges of modern distributed systems in the hybrid-cloud era.
Attendees will implement containerized solutions on OpenShift using Red Hat build of Apache Camel.
The solutions will involve the creation of integration layers using technologies such as Apache Kafka, Keycloak, REST APIs and cloud-services.
The development environment will be provided using Red Hat OpenShift Dev Spaces.
