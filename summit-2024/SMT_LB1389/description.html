This lab covers how to build defense-in-depth in Red Hat Enterprise Linux by implementing key security technologies available in the latest version of Red Hat Enterprise Linux. A defense-in-depth approach implements security at all layers to build a strong foundation and proactively defend against security attacks and breaches. Lab activities include:

  • Providing security compliance by using technologies such as OpenSCAP, Audit, Audit Intrusion Detection Environment (AIDE), session recording, and system-wide cryptographic policies
  • Implementing network security with technologies such as firewalld, SELinux port security, and IPSec
  • Implementing access management with Red Hat Ansible® Automation Platform system roles and SELinux process isolation
  • Implementing data security with Linux Unified Key Setup (LUKS), Network Bound Disk Encryption (NBDE), and GNU Privacy Guard (GPG)
