Migrating JBoss EAP 8.0 to OpenShift Container Platform with Red Hat Service Interconnect

Overview:
This workshop focuses on leveraging Red Hat's cutting-edge technologies for modernizing applications. Attendees will learn to integrate various Red Hat components to enhance application delivery, ensuring continuous operation and maximizing the value of their Red Hat investments.

What You Will Learn:
The workshop offers an in-depth exploration of JBoss EAP 8's capabilities, targeting both developers and operations teams. Participants will engage in migrating an EAP 7 application to the cloud with EAP 8 and OpenShift, using the Migration Toolkit for Applications. The session also includes migrating applications to the Red Hat build of Apache Camel on OpenShift and maintaining uninterrupted service with Red Hat Service Interconnect during migrations.

Components Used in the Workshop:

  • Red Hat build of Apache Camel
  • JBoss EAP 7.4
  • JBoss EAP 8.0
  • JBoss EAP 8.0 Helm charts
  • Migration Toolkit for Runtimes
  • OpenShift Dev Spaces
  • Red Hat Service Interconnect
