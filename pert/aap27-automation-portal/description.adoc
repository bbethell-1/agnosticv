= What's New in AAP 2.7: Automation Portal & Execution Environment Builder

== Overview

The Ansible Automation Platform Portal with Ansible Automation Platform (AAP) 2.7 serves as a unified interface that shifts the platform focus from simple execution to a comprehensive "build, discover, and run" experience. This hands-on lab simplifies enterprise automation for users of all skill levels by exploring the new Automation Portal interface and the Execution Environment Builder capabilities.

Then, we have MCP. You will understand what the Model Context Protocol is, how it works, and how Ansible Automation Platform uses it to connect with AI tools.

Once the deployment is complete, you will have a guide to help you learn and explore the environment.

Duration: 1 hour

== What You'll Learn

In this lab, you'll gain practical experience with:

* Ansible Automation Platform 2.7 with the Automation Portal interface
* Execution Environment Builder capabilities
* Defining the Model Context Protocol and understanding its role in the AI ecosystem
* Understanding the architecture of MCP and how different components interact
* Explaining Ansible Automation Platform's MCP server and its capabilities

== Lab Environment

This lab provides a complete, hands-on environment that includes:

* Ansible Automation Platform 2.7 with Controller and Automation Hub (PAH)
* MCP and how different components interact using Open Code with Claude Code

== Topics Covered

* Automation Portal interface walkthrough
* Creating and managing Execution Environments using the UI
* Helm-based deployment strategies
* MCP integration with Ansible Automation Platform
