== Lab Access Details

All credentials and URLs are also available in the instructions where you need them.

* Log into the bastion:

[subs=attributes+]
----
ssh {bastion_ssh_user_name}@{bastion_public_hostname} -p {bastion_ssh_port}
----

Bastion password `{bastion_ssh_password}`

* Login to OpenShift cluster:

[subs=attributes+]
----
[lab-user: ~]$ oc login -u {openshift_cluster_admin_username} -p {openshift_cluster_admin_password} {openshift_api_url}
----
