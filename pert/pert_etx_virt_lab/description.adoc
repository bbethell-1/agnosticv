Welcome to the ETX Virtualization Lab!

This self-paced lab, adapted from the ETX Virtualization Delivery Workshop, teaches the fundamentals of OpenShift Virtualization. Through hands-on exercises, you will learn to create and manage virtual machines, utilize migration assessment tools, and execute a VM migration from VMware to OpenShift Virtualization using Ansible.

== Objectives

On completing this lab, you should be able to:

* Create Virtual Machines
* Manage Virtual Machines
* Migrate Virtual Machines
* Perform Template Management
* Use Virtualization Migration Assessment (VMA) Tools
* Migrate Virtual Machines from VMware to OpenShift Virtualization using Ansible

== Version Information

This edition of the ETX Virtualization Lab uses the following software versions:

* Red Hat OpenShift 4.18
* Red Hat OpenShift Virtualization 4.18
* Red Hat Migration Toolkit for Virtual Machines 2.7
* NMState Operator
* MetalLB Operator

== Target Audience

Technical Account Managers, Consultants and Architects

== Duration

6-8 Hours
