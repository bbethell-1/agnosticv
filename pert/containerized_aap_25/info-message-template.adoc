*VM Access Methods:*

1. *SSH Access:*
+
[source,bash,subs="attributes"]
----
{rhel10_ssh_command}
----

2. *OpenShift Console Access:*
   - Navigate to *Virtualization* → *VirtualMachines*
   - Select namespace: `aap-lab`
   - Click on `aap-lab-rhel10`
   - Use the *Serial* tab for terminal access.

3. *After AAP Installation:*
+
Access the AAP web interface at: `{rhel10_route_url}`
====

*OpenShift CLI Commands:*

[source,bash,subs="attributes"]
----
# Login to cluster
oc login -u admin -p {openshift_cluster_admin_password} {openshift_api_server_url}

# Check VMs
oc get vms -n aap-lab
oc get vmi -n aap-lab

# Check LoadBalancer service
oc get svc -n aap-lab

# Access VM console via virtctl
virtctl console aap-lab-rhel10 -n aap-lab
----
