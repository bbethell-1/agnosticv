This catalog provides a lab environment for deployment of OpenShift Mission Critical Application Platform (MCAP).

This lab will accommodate:

1. One Red Hat OpenShift Single Node Cluster (SNO) being used as a Hub cluster with Red Hat Advanced Cluster Management (RHACM).
2. Three Single Node OpenShift (SNO) clusters being used as Infrastructure clusters on bare metal using RHACM from the Hub cluster.
3. Three-Node OpenShift Compact Tenant cluster as OpenShift Virtualization VMs running on Infrastructure clusters using RHACM from Hub cluster.
4. One, single node Ceph Storage cluster.

This is for hands-on based training on Deployment of OCP MCAP setup.

This training has following parts:

1. Provision the base infrastructure (HW, Storage, Networking) for the hands-on lab environment.
2. Install utility services needed for the hands-on labs.
3. Configure the base Red Hat OpenShift Hub cluster.
4. Configure the Red Hat OpenShift Infrastructure cluster to host Virtual Machines.
5. Provision Red Hat OpenShift Tenant cluster on top of the infrastructure cluster.
6. Deploy and configure application and Virtual Machines on Tenant Clusters.
7. Test the high availability and resilience of deployed workloads.

**Training Duration:** 7 hours (including deployment wait time)
