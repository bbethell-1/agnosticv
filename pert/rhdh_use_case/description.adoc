Learn how to build an Internal Developer Platform (IDP) using Red Hat Developer Hub (RHDH) to streamline application delivery, standardize workflows, and improve developer experience across your organization. Red Hat Developer Hub enables platform engineering teams to deliver a self-service developer portal based on Backstage. With support for GitOps, golden templates, API discovery, and observability dashboards, RHDH is a powerful tool for building a scalable IDP.

This training walks you through a hands-on, phased approach to designing and deploying your IDP—from foundational components like authentication and GitOps, to workflow automation, documentation discovery, and centralized developer dashboards.

=== What Content Is Covered In This Lab?
* Deploying RHDH and Keycloak (RHBK) using Operators and GitOps
* Integrating authentication with GitHub
* Setting up ArgoCD for platform lifecycle management
* Creating and using golden templates (Spring Boot, React, PostgreSQL, etc.)
* Automating application deployments with ArgoCD
* Discovering and documenting internal APIs using OpenAPI and Tekton
* Creating developer dashboards for CI/CD, topology and APIs.
