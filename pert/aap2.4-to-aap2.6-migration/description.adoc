= Product Enablement: Fast-Track Ansible Automation Platform Migration

Welcome to the course on migrating your Ansible Automation Platform deployment. This curriculum is designed around the official Red Hat Ansible Automation Platform migration guide, which provides necessary steps and detailed considerations for moving existing deployments. The core objective of this migration process is to provide instructions for transferring your Ansible Automation Platform deployment from one installation type to another like Containerized or Operator based. Also to note that we emphasizes that you can only migrate to a different installation type of the same Ansible Automation Platform version. Please clik here for more information: https://redhatquickcourses.github.io/aap-migration/aap-migration/1/index.html[Fast-Track Ansible Automation Platform Migration,window=_blank]

=== What Content Is Covered In The Lab?

You’ll learn how to:

✔ Assess and prepare your source environment for migration.

✔ Create and validate a migration artifact (database dumps, secrets, configurations).

✔ Import and reconcile data in the target environment of Containerized or Operator based.

✔ Step to Step guide on performing the migration.

✔ Validate post-migration functionality.
