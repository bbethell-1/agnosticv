Welcome to the course on migrating your Ansible Automation Platform deployment. This curriculum is designed around the official Red Hat Ansible Automation Platform migration guide, which provides necessary steps and detailed considerations for moving existing deployments. The core objective of this migration process is to provide instructions for transferring your Ansible Automation Platform deployment from one installation type to another, such as like containerized or operator based deployments.

=== What Content Is Covered In The Lab?

You’ll learn how to:

✔ Assess and prepare your source environment for migration.

✔ Create and validate a migration artifact (database dumps, secrets, configurations).

✔ Import and reconcile data in the target environment of Containerized or Operator based.

✔ Step to Step guide on performing the migration.

✔ Validate post-migration functionality.
