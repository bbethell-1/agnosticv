== Introduction

This Catalog Item hosts a singe node openshift which is used to do the deployment of the Ansible Automation Platform 2.6.

This lab allows you to have a hands-on experience with Red Hat Ansible Automation Platform.

== Who Will Benefit Most from attending a lab?

Anyone with an Ansible understanding who wants to learn about how to deploy AAP 2.6 on openshift and then manage it using Ansible playbooks.

== What Content Is Covered In The lab?
On completing this course, you should be able to:

* Understanding of the Ansible Automation Platform’s (AAP) features, architecture, and components.
* Explore Ansible Automation Platform deployment and management on OpenShift. 
* Explore how to manage Ansible Automation Platform (AAP) configurations declaratively as code using Ansible playbooks

== Version Information

This edition of the OpenShift lab has been developed using the following software versions:

* Red Hat Ansible Automtion Platform 2.6
* Red Hat OpenShift Platform 4.20

*Duration:* 45 minutes

*Audience:* Technical Account Managers, Consultants, Specialist Solution Architects and Account Solution Architects.

*Products:* Red Hat OpenShift, Red Hat Enterprise Linux, Red Hat Ansible Automation Platform
