== Introduction

This Catalog Item hosts a singe node openshift which is used to do the deployment of the Ansible Automation Platform 2.5.

This lab allows you to have a hands-on experience with Red Hat Ansible Automation Platform.

== Who Will Benefit Most from attending a lab?

Anyone with an Ansible understanding who wants to learn about how to deploy AAP 2.5 on openshift.

== What Content Is Covered In The lab?
On completing this course, you should be able to:

* Understanding of the Ansible Automation Platform’s (AAP) features, architecture, and components.
* Discover how to evaluate the infrastructure needs and set up the environment for the deployment of AAP.
* Know the benefits of using the right Topology for the deployment.

== Version Information

This edition of the OpenShift lab has been developed using the following software versions:

* Red Hat Ansible Automtion Platform 2.5
* Red Hat OpenShift Platform 4.16
* Red Hat Enterprise Linux 9.4
