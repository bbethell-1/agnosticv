== Introduction

This Catalog Item hosts the Migrate from AWX to AAP 2.5 (AWS).

This lab allows you to have a hands-on experience with Red Hat Ansible Automation Platform.

== Who Will Benefit Most from attending a lab?

Anyone with an Ansible understanding who wants to learn about how to migrate from AWX to AAP 2.5.

== What Content Is Covered In The lab?

On completing this course, you should be able to:

* Implement the steps provided to guide application migration.
* Define and discuss the necessity for AWX to AAP 2.5 migration.
* Define the benefits of utilizing AAP 2.5 to migrate applications.
* Diagnose and rectify known issues in AWX application migrations.

== Version Information

This edition of the OpenShift lab has been developed using the following software versions:

* Red Hat Ansible Automtion Platform 2.5
* Red Hat OpenShift Platform 4.16
* Red Hat Enterprise Linux 9.4
