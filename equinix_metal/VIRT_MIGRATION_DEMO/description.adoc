This is a demo of migrating virtual machines from *VMware* to *OpenShift Virtualization*.

This demo has two parts:

1. Manually migrating virtual machines from VMware to OpenShift Virtualization with *Migration Toolkit for Virtualization (MTV)*
2. Automating the migration setup process using *Ansible Automation Platform (AAP)* to automate the migration process, showcasing what migrating VMs at scale looks like.
