This is a demo of migrating virtual machines from *VMware* to *OpenShift Virtualization*.

In this demo, we will migrate virtual machines from VMware to OpenShift Virtualization using the *Migration Toolkit for Virtualization (MTV)*.

We will also feature the use of *Ansible Automation Platform* to automate the migration process, showcasing what migrating VMs at scale looks like. (Note, this is work in progress and will be available soon).

== Demo Instructions

The demo instructions will be available after the deployment is complete. However, you can find the instructions source in the following GitHub repository:

* https://github.com/rhpds/virt-migration-demo
