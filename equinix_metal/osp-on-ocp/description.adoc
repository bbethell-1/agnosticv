Installation walkthrough of Red Hat OpenStack Services on OpenShift

This demo is designed to walk you through the installation of the OpenStack Operators, including the installation of several pre-requisites including NMState, MetalLB, and a Quay registery.

At the end of the demo you will have a working OpenStack environment that you can access via the OpenStack CLI.

We will utilize YAML files which have been pre-configured to meet the requirements of the demo environment but can be adjusted for use in your own environment to set up a small proof of concept environment.

Note: The demo instructions are based on creating a Quay repository within the environment but you can utilize your own.

Duration: 90-120 minutes

Audience: IT Managers, Cloud Architects, System Administrators

Products: Red Hat OpenStack Services on OpenShift

Supporting Materials: Follow along instructions, as well as example yaml files
can be found at: https://github.com/rh-osp-demo/dp-demo/tree/main/demo
