An environment for running a the Red Hat Summit 2024 workshop using the openshift virtualization roadshow workshop materials.

For details on the OpenShift Virtualization Roadshow, including how to deliver, latest updates, and where to go for help, please visit: https://source.redhat.com/groups/public/openshift_virt_roadshow_

Before running this as a workshop please visit: https://source.redhat.com/groups/public/rhdp/wiki/rhdp_user_wiki/workshop_service to become familiar with the process 

*Duration:* 4 hours

*Audience:* VMware Admins

*Products:* OpenShift, Migration Toolkit for Virtualization
