*Overview*

Create and apply standard configuration to systems using Ansible-based Red Hat Enterprise Linux system roles.

* Step 1: Configuring prerequisite repositories and packages.
* Step 2: Inspecting a pre-made example playbook and applying it.
* Step 3: Verify the system roles and configurations were applied.
* Step 4: Configuring and updating system configurations with System Roles.
* Step 5: Update an existing setting.

*Lab Duration*

10 minutes
