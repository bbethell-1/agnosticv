= Hands-on Lab: Unleashing containers to customize and manage Red Hat Enterprise Linux

In the ever-evolving landscape of information technology (IT), containers emerged as a fundamental component that revolutionized software development, deployment, and management. These lightweight and portable units encapsulate applications and their dependencies.

However, operating system customization remains a persistent challenge during day two configuration management and the initial creation of operating system (OS) images.

This workshop introduces image mode, a novel approach to address these issues using bootc images. This approach combines the capabilities of Open Container Initiative (OCI) container images with the power and flexibility of Red Hat Enterprise Linux.

During this workshop, you will learn how to:


* build and distribute RHEL images using standard container tools.
* customize the image for multiple different environments.
* manage updates to both the operating system and application components
* rollback to previous environments
* change system images to support rapid experimentation
