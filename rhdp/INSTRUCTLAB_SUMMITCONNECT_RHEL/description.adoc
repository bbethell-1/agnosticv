= Summit Connect 2024 AI InstructLab Parasol Workshop

This is a high-level overview of the components that will be included in the Summit Connect 2024 AI InstructLab Parasol Workshop. The workshop aims to provide attendees with an introduction to advanced machine learning and artificial intelligence concepts, using NVIDIA's HPC platform Summit as well as RHEL for AI-enabled applications.
