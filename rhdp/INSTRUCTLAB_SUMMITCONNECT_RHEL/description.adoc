== Workshop Overview

Welcome to our advanced InstructLab workshop, originally created and  used for Red Hat Summit Connect 2024 events. In this hands-on session, you'll learn about InstructLab and how to leverage it to improve a Large Language Model (LLM) in an accessible way.

== What You'll Learn

* What Large Language Models (LLMs) are and how they are trained
* Hands-on experience with InstructLab CLI
* Deploy and chat with an LLM locally with InstructLab
* Apply InstructLab to a real-world insurance application
* Structure and add knowledge to an LLM
* Use the InstructLab tooling to generate synthetic data and fine-tune a model

== Environment Specifications
* 1 x RHEL 9.4 VM with NVIDIA GPU and CUDA
** Python 3.11
** NVIDIA drivers and CUDA pre-installed
** NVIDIA L4 GPU

IMPORTANT: This catalog item requires AWS gpu instances, which may have limited availability in some regions. If you experience a deployment failure, please try provisioning again in a different region. The *us-east-1* and *us-east-2* regions currently have the best capacity.

**Please Note:** InstructLab is a core part of RHEL AI and we will be modifying this lab to be deployed as a RHEL AI image in the near-future. In the meantime, this lab environment is a typical RHEL 9.4 VM with InstructLab installed. When used for demos or sales conversations, InstructLab should be spoken about in the context of RHEL AI as our product.  

== Workshop Structure

1. Introduction to the Lab
** What is a Large Language Model?
** How are Large Language Models trained?
** How does this relate to InstructLab?

2. Getting started with InstructLab
** Install the ilab command line interface
** Configuring ilab
** Initialize ilab
** Download the model
** Serving the model
** Chat with the model

3. Integrating AI into an Insurance Application
** Using the Parasol Application
** Understanding the Taxonomy
** Generating Synthetic data
** Enhancing a LLM with InstructLab
** Verifying the Application

4. Conclusion
