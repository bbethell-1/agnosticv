.AWS g6 Instance Availability
====
This catalog item requires AWS g6 instances, which may have limited availability in some regions.

If you experience a deployment failure, please try provisioning again in a different region. The *us-east-1* and *us-east-2* regions currently have the best capacity.
====
= InstructLab with RHEL AI 

* RHEL AI (GA)
* InstructLab (version reflects RHEL AI release)
* Nvidia L4 (24GB) GPU (`g6.xlarge`)
** Optional 4 x L4 via dropdown (`g6.12xlarge`)
* `ssh` access

Note: The above configuration is a cost effective way of deploying and exploring RHEL AI.
However the GPU resources are *insufficient* to allow model training or running `ilab model generate`.
