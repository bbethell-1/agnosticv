Provides a RHEL AI VM with an NVIDIA GPU and several pre-installed models for you to explore and experiment with.
You can choose the version of RHEL AI (currently limited to 1.5) and the GPU type.

== Products and Environment

* RHEL AI
* NVIDIA GPU
** g6.xlarge (1x L4 with 24GB GPU memory)
** g6.12xlarge (4x L4 with 96GB GPU memory)
* Models
** granite-3.1-8b-starter-v2
** granite-3.1-8b-lab-v2
** mixtral-8x7b-instruct-v0-1
** prometheus-8x7b-v2-0

[WARNING]
====
GPU instances are still very expensive and sometimes have limited availability.
Choose the smallest GPU instance that will work for your use case.

If you experience a deployment failure, please try provisioning again in a different region.
The *us-east-1* and *us-east-2* regions currently have the best capacity.
====

== Guide
There is currently no prescribed demo to conduct with RHEL AI and this instance is suitable for other Instruct Lab and
Inference Server features.

Note that the instance types available here do not meet the
https://docs.redhat.com/en/documentation/red_hat_enterprise_linux_ai/1.5/html/hardware_requirements/hardware_requirements_rhelai#amazon-web-services-aws[documented^]
minimum requirements for performing the end-to-end SDG and fine tuning workflow, but it's unlikely that these would be
beneficial for a customer demonstration due to time.

There are a number of useful activities that can still be performed with this instance:

* https://docs.redhat.com/en/documentation/red_hat_enterprise_linux_ai/1.5/html/creating_skills_and_knowledge_yaml_files/index[Using the `ilab` CLI to work with taxonomies^]
* https://docs.redhat.com/en/documentation/red_hat_enterprise_linux_ai/1.5/html/updating/updating_system[Working with registries to perform/enable bootc updates for RHEL AI^]
* https://docs.redhat.com/en/documentation/red_hat_enterprise_linux_ai/1.5/html/building_and_maintaining_your_environment/serving_and_chatting[Serving and chatting with the pre-downloaded models^]
* https://docs.redhat.com/en/documentation/red_hat_ai_inference_server[Running Red Hat AI Inference Server with Podman^],
  taking advantage of the fact that the NVIDIA drivers and Container Toolkit are already configured in RHEL AI

[NOTE]
====
If you intend to use any `ilab` CLI commands, you should start with `ilab config init`, select `0` for no system
profile, and be sure to specify `--gpus $n` (where `$n` is a standin for the number of GPUs to use) for any subcommands
which would use the GPUs of your instance type, such as `ilab model serve` (which can serve the pre-downloaded models
using their short names as reported by `ilab model list`)
====
