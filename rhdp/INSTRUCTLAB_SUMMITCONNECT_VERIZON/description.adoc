== Workshop Overview - Verizon

Welcome to the RHEL AI and InstructLab workshop at Red Hat Summit Connect 2024. In this hands-on session, you'll learn about RHEL AI and how to leverage it to improve a Large Language Model (LLM) using InstructLab.

== What You'll Learn

* Understanding Large Language Models (LLMs) and their training process
* Hands-on experience with InstructLab CLI
* Integrating AI into a real-world insurance application
* Working with taxonomies and generating synthetic data
* Training, fine-tuning, and interacting with models

== Workshop Structure

1. Introduction to the Lab
** What is a Large Language Model?
** How are Large Language Models trained?
** How does this relate to InstructLab?

2. Getting started with InstructLab
** Install the ilab command line interface
** Installing ilab
** Initialize ilab
** Download the model
** Serving the model
** Chat with the model

3. Integrating AI into an Insurance Application
** Using the Parasol Application
** Understanding the Taxonomy
** Generating Synthetic data
** Training and Interacting with the Model
** Verifying the Application

4. Conclusion

This workshop is designed for AI Architects and Application Engineers interested in leveraging AI in their applications and understanding the process of fine-tuning LLMs.

== Duration

The workshop is designed to be completed within the Summit Connect session time. Some steps, like extensive model training, will be simulated due to time constraints.
