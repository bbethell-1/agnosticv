This item provides Red Hat AI Inference Server (RHAIIS) running on RHEL for you to experiment with.
This includes RHEL running on a GPU instance in AWS.
RHAIIS is already configured and running.
You can find some basic activities to do in the guide shown below, or you can use this to build something on your own.

== Environment Specifications

* RHEL 9.5
* RHAIIS (version)

== Deployment Time

~20 minutes

== Demo or Lab Guide

Your environmet will come with a customized and integrated guide.
You can find a rendered version of it https://rhpds.github.io/rhaiis-on-rhel-showroom/modules/index.html[here^].
