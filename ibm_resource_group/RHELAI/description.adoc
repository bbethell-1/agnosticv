=== RHEL AI on IBM Cloud

This environment is a single instance with GPUs on IBM Cloud.

It is provided as is, with no additional configuration or customization. The environment is designed to be used for development and testing purposes.

You'll be offered a choice for the instance type with GPU.

- `gx3-16x80x1l4`,  1x GPU L4, 16 vCPU, 80 GiB RAM
- `gx3-32x160x2l4`, 2x GPU L4, 32 vCPU, 160 GiB RAM
- `gx3-64x320x4l4`, 4x GPU L4, 64 vCPU, 320 GiB RAM
- `gx3-24x120x1l40s`, 1x GPU L40s, 24 vCPU, 120 GiB RAM
- `gx3-48x240x2l40s`, 2x GPU L40s, 48 vCPU, 240 GiB RAM

For information about the instance types with GPU, refer to link:https://cloud.ibm.com/docs/vpc?topic=vpc-profiles&interface=ui#gpu[GPU profiles].

*Provisioning Time*: ~ 10 Min

*Extensions Available*: Yes
