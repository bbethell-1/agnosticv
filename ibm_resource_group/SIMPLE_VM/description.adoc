=== IBM Cloud single instance

This environment is a single instance of IBM Cloud. It's an environment that is provisioned on demand and is available for 3 days. The environment is provisioned with a single instance of IBM Cloud and is available for use immediately after provisioning.

See https://cloud.ibm.com/docs/vpc?topic=vpc-profiles&interface=ui for available instance types.

*Provisioning Time*: ~ 10 Min

*Default Lifespan of Environment*: 3 Days

*Extensions Available*: Yes

*Support Options:* There is *no* support for the Open Environment Sandboxes.
