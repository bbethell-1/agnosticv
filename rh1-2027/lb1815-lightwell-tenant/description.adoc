
Lightwell: Patch to Production

Per-tenant environment for the Lightwell workshop.

This catalog item provisions a single tenant environment on a shared and onboarded Lightwell cluster. With the workshop UI enabled, it can also provision the shared cluster itself along with multiple tenant environments. Attendees explore two remediation paths -- a quick win using automated dependency updates, and full automation using AI-assisted remediation with Ansible Orchestrator -- detecting, triaging, and remediating CVEs in application dependencies using packages from the Lightwell Network.

== What Gets Deployed

* *Keycloak user* -- Per-tenant OpenShift login via the shared Keycloak SSO
* *Tenant namespaces* -- Isolated namespaces for SDLC tooling, CI pipelines, artifact management, app deployment, and Renovate
* *GitLab account* -- A personal account and group (`acme-{guid}`) with three sample applications and a deployment manifest repository
* *Nexus* -- Per-tenant artifact manager with Maven proxy, Lightwell remediation repository, and OCI container registry
* *TPA* -- Per-tenant Trusted Profile Analyzer instance with SBOM and vulnerability analysis
* *ArgoCD app-of-apps* -- Deploys the three sample applications to a per-tenant production namespace
* *Showroom* -- Interactive lab guide with embedded terminal and console tabs for OpenShift, Nexus, Renovate, TPA, GitLab, Ansible Orchestrator, ServiceNow, and ArgoCD

== Shared Cluster Services

The following are provided once by `lb1815-lightwell-cluster` and shared across all tenants:

* GitLab -- source code management
* Ansible Automation Platform (Controller + EDA) -- automation orchestration and event-driven automation
* Ansible Orchestrator -- workflow orchestration for AI-assisted remediation
* Red Hat Trusted Artifact Signer (RHTAS) -- keyless code signing via Tekton Chains
* OpenShift Pipelines (Tekton) -- CI/CD with Pipelines as Code
* OpenShift GitOps (ArgoCD) -- continuous deployment
* Keycloak -- shared SSO for all tenant services
* ServiceNow -- change management and audit trail

== Design

This tenant CI runs on a shared base cluster provisioned by `lb1815-lightwell-cluster`.
Each tenant gets isolated namespaces, a dedicated Keycloak user, a personal GitLab account and group, a per-tenant Nexus instance, and a per-tenant TPA instance.
