
Get Ready for Lightwell: Patch to Production at the Speed of AI

Per-tenant environment for the Lightwell Enterprise Demo.

This catalog item provisions a single demo seat on top of the shared Lightwell infrastructure cluster via the OpenShift Sandbox API. Attendees explore Red Hat's trusted software supply chain tooling -- detecting, triaging, and remediating CVEs in application dependencies using packages backed by the Lightwell Network.

== What Gets Deployed

* *Keycloak user* -- Per-tenant OpenShift login via the shared Keycloak SSO
* *Tenant namespace* -- An isolated `{user}-enterprise` namespace with a resource quota for pipeline and app workloads
* *GitLab account* -- A personal account on the shared cluster GitLab instance
* *Showroom* -- Interactive lab guide with embedded consoles for Jenkins, Artifactory, GitLab, the OpenShift console, Red Hat Quay, and AAP2

== Shared Cluster Services

The following are provided once by the `lb1815-lightwell-cluster` and shared across all tenants:

* GitLab -- source code management and CI/CD
* Jenkins -- build pipeline execution
* JFrog Artifactory -- enterprise artifact proxy to Lightwell Network repositories
* Red Hat Quay -- container image registry with Clair scanning
* Ansible Automation Platform (Controller + EDA) -- automation orchestration via a single Gateway login
* Red Hat Trusted Artifact Signer (RHTAS) -- code signing and attestation
* Red Hat Trusted Profile Analyzer (RHTPA) -- SBOM and vulnerability analysis

== Design

This tenant CI runs on a shared base cluster provisioned by `lb1815-lightwell-cluster`.
Each tenant gets an isolated namespace, a dedicated Keycloak user, and a personal GitLab account.
