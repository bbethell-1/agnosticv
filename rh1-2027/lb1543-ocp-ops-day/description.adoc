= LB1543: Deliver the OpenShift Ops Day Roadshow

== Overview

An overview of the OpenShift Ops Day Roadshow workshop including its features and how to deliver it and an opportunity to try important modules.

This is a comprehensive, modular workshop designed to showcase OpenShift operations across multiple domains including cluster management, security, GitOps, virtualization, and AI-assisted development.

== Workshop Features

* **Modular Design**: Enable/disable specific modules based on your delivery needs
* **Hands-on Labs**: Interactive exercises with real OpenShift cluster access
* **Modern Platform**: Built on OpenShift 4.21 running on CNV infrastructure
* **Integrated Lab Guide**: Showroom-based lab instructions with terminal access

== Key Modules

=== Getting Started
* Installation & Verification

=== Core Operations
* Application Management Basics
* Ingress & Load Balancing
* Network Security
* Debugging & Troubleshooting
* GitOps (ArgoCD)

=== Identity & Access
* LDAP Authentication
* OIDC Authentication

=== Day 2 Operations
* Observability & Logging
* Performance Tuning

=== Advanced Topics
* OpenShift Virtualization
* Red Hat Developer Hub
* OpenShift Lightspeed AI Assistant
* Advanced Cluster Management (ACM) with Hosted Control Planes
* Advanced Cluster Security (ACS/RHACS)
* Zero Trust Workload Identity Manager
* Secrets Management with Vault

== Technical Details

* **Platform**: OpenShift 4.20 on CNV (multinode cluster)
* **Authentication**: HTPasswd with admin user
* **Storage**: ODF (OpenShift Data Foundation) with external Ceph
* **Lab Guide**: Showroom with Wetty terminal and bastion SSH access
* **CI/CD**: OpenShift Pipelines (Tekton)

== Target Audience

This workshop is designed for:

* Platform administrators learning OpenShift operations
* DevOps engineers managing OpenShift clusters
* Solution architects planning OpenShift deployments
* Technical instructors preparing to deliver OpenShift training

== Deployment Time

* **Provisioning**: Approximately 60-90 minutes (includes cluster provisioning and workload deployment)
* **Workshop Duration**: Flexible based on selected modules (2-8 hours typical)
