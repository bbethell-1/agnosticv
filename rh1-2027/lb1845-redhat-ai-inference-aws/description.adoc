= LB1845: From Model to Model as a Service: Building Scalable AI Inference

A hands-on workshop experience taking attendees through the full inference lifecycle —
from model selection through large-scale production deployment on Red Hat AI Enterprise.

== Learning_objectives:
  * Deploy a model for inference on Red Hat AI Enterprise
  * Analyze model inference performance using EvalHub for evaluations
  * Configure a repeatable evaluation workflow for tracking model performance over time
  * Expose the deployed model as a Model-as-a-Service with access controls and scaling
  * Integrate a model service into an application using standard API patterns
  * Verify end-to-end request flow from application request to model response
  * Monitor model serving metrics through the observability dashboard
