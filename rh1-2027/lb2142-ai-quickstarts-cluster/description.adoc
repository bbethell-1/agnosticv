
Base OpenShift Infra Cluster for LB2142 - Selling with AI Quickstarts tenants.

This catalog item deploys shared platform services on top of an OpenShift cluster, preparing it to host LB2142 AI Quickstarts tenant environments via the OpenShift Sandbox API.

== What Gets Deployed

* *Keycloak SSO* -- OpenShift authentication with admin and per-user accounts
* *ArgoCD (OpenShift GitOps)* -- GitOps operator for tenant workload delivery
* *OpenShift AI 3* -- Dashboard, pipelines, workbenches, model serving, model registry

== Design

This catalog item is designed to be registered with the OpenShift Sandbox API.
Individual LB2142 AI Quickstarts tenants are provisioned on top of this base cluster.
Module 2 (RAG) is the first tenant module; additional AI Quickstart modules
will be added as further tenant catalog items on top of this same base cluster.

== Requirements

Deploys on top of an OpenShift 4.20+ cluster with CNV (Container Native Virtualization) installed.
