Red Hat OpenShift delivers a complete application platform above the Kubernetes API — not just container orchestration. This presenter-led demo follows the Parasol Insurance scenario across three progressive sections: foundational platform capabilities, advanced developer services, and intelligent applications. Sales engineers and solution architects use this demo to position OpenShift Platform Plus and Red Hat Advanced Developer Suite (RHADS) to customers evaluating container management, application modernization, or developer productivity and AI adoption strategies.

== Detailed Overview

* *Section 1: Foundational Application Platform*
** *Module 1: Developer experience* — Application modernization context via MTA, then one-click DevSpaces access from the OpenShift topology view with Quarkus live reload.
** *Module 2: CI/CD pipeline* — Tekton pipeline triggered on git push; Sonarqube quality gate fails on code smells; developer fixes with AI assistance and pipeline passes; GitOps delivery with Argo CD.
** *Module 3: Platform operations* — Service-to-service mTLS and traffic management with Service Mesh, real-time observability with Kiali, Vault for secrets, and Horizontal Pod Autoscaler for dynamic scaling.

* *Section 2: Advanced Developer Services*
** *Module 4: Developer Hub and catalog* — Developer Lightspeed for AI-assisted catalog Q&A, centralized component and API discovery, and self-service environment provisioning via golden path templates
** *Module 5: Secure development workflow* — Dependency Analytics in DevSpaces catches vulnerabilities before commit; secure pipeline with ACS scanning, Tekton Chains signing, and SLSA attestation
** *Module 6: Trusted software supply chain* — Use Red Hat Advanced Developer Suite to implement production deployment with admission control image verification, SBOM management and continuous compliance with Trusted Profile Analyzer, and full topology view in Developer Hub

* *Section 3: Intelligent Applications*
** *Module 7: AI-enhanced applications* — Scaffold an AI-powered email routing service from a Developer Hub golden path template, integrate an LLM endpoint to replace keyword-based triage with enhanced intelligence, and deliver through the same trusted supply chain pipeline
