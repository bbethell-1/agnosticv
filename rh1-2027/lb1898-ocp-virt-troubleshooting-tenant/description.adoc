== Information

This is the per-student tenant CI for LB1898: OpenShift Virtualization Troubleshooting Workshop. It looks up the shared cluster provisioned by `lb1898-ocp-virt-troubleshooting-cluster` and creates a per-student namespace, Keycloak user, Showroom lab guide, and GitOps bootstrap Application on it.

The cluster item must already be provisioned and registered as a shared sandbox before this item can be ordered.

== Featured Technology and Products

* Red Hat OpenShift Virtualization (KubeVirt), CDI/DataVolumes
* Red Hat OpenShift GitOps (ArgoCD)
* Red Hat OpenShift Container Platform 4.21

== Detailed Overview

A hands-on Day 2 operations workshop where participants troubleshoot intentionally broken OpenShift Virtualization environments that mirror real production incidents, using `oc`, `virtctl`, Kubernetes events, VirtualMachineInstance (VMI) objects, CDI resources, Multus networking, and virt-launcher logs.

* *VM Stuck in Starting* -- diagnose scheduling and initialization failures for virt-launcher pods
* *CDI Import Failures* -- resolve DataVolume imports that never complete
* *Live Migration Failures* -- troubleshoot node-to-node migration issues
* *Network Troubleshooting* -- fix VM connectivity problems using Multus, NMState, and NetworkPolicies
* *Guest Agent Failures* -- restore broken QEMU Guest Agent integration
