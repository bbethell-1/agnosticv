LB1353: Build, Sign, and Ship - Securing the Software Supply Chain with Konflux

Modern software supply chains demand more than just building and deploying code — they require cryptographic proof of provenance, automated vulnerability scanning, and policy-enforced releases. In this 2-hour hands-on lab, you'll experience the complete secure software lifecycle using Konflux, Red Hat's next-generation build and release platform.

Working in your own isolated tenant workspace on a shared OpenShift cluster, you'll onboard a real application from a GitLab repository, trigger automated builds via Pipelines-as-Code, and watch Konflux generate SBOMs, sign your artifacts with Red Hat Trusted Artifact Signer, and produce SLSA Level 3 provenance attestations — all without writing a single pipeline. You'll then verify your supply chain integrity using Conforma policy checks and promote your application through a controlled release pipeline to a production namespace, with images pushed to a self-hosted Quay registry.

== Lab Guide

After provisioning completes, access your lab guide through the Showroom URL provided in the post-provision message.

== What You'll Learn

* Configure an application in Konflux and connect it to automated Pipelines-as-Code builds triggered from GitLab
* Build a container image and analyze the SBOM in CycloneDX format generated automatically by the Konflux pipeline
* Verify cryptographic image signatures and SLSA Level 3 provenance attestations using cosign and Trusted Artifact Signer
* Analyze Conforma policy checks and observe how failed checks block artifact promotion between environments
* Deploy a policy-verified, signed artifact through a controlled release pipeline to a production Quay registry
* Verify end-to-end supply chain integrity from source commit to signed, provenance-attested production release

== Featured Technology and Products

* *Konflux* - Next-generation build and release platform
* *Red Hat Trusted Artifact Signer (RHTAS)* - Sigstore-based signing (Fulcio, Rekor, TUF)
* *Red Hat Quay* - Container image registry
* *Red Hat OpenShift Pipelines* - Tekton-based CI/CD
* *GitLab CE* - Source control with Pipelines-as-Code integration
* *Conforma* - Policy-as-code engine for supply chain verification

== Prerequisites

* Comfortable with OpenShift/Kubernetes: namespaces, pods, routes, and the `oc` CLI
* Basic Git skills: clone, commit, push, and open merge requests
* Basic container image knowledge: registries, tags, and what a build produces
* Familiarity with CI/CD pipeline concepts (triggers, stages, artifacts)
* No supply chain security knowledge required — SLSA, SBOMs, and signing are introduced in the lab

== Target Audience

* Security-minded practitioners adopting SLSA and Sigstore practices
