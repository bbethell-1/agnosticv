LB1353: Build, Sign, and Ship - Securing the Software Supply Chain with Konflux (Cluster Infrastructure)

This catalog item provisions the shared OpenShift cluster infrastructure for the Konflux Trusted Software Supply Chain lab. It deploys all cluster-wide components including Konflux, Red Hat Trusted Artifact Signer (RHTAS), Red Hat Quay, GitLab, and Keycloak.

*IMPORTANT:* This is the infrastructure/cluster item. Students should NOT order this directly. Students should order the tenant item (`lb1353-konflux-tsf-tssc-cnv-tenant`) which provisions their individual workspace on this shared cluster.

== Components Deployed

* *Konflux* - Next-generation build and release platform
* *Red Hat Trusted Artifact Signer (RHTAS)* - Sigstore-based signing infrastructure (Fulcio, Rekor, TUF)
* *Red Hat Quay* - Container image registry
* *GitLab CE* - Source control and CI/CD integration
* *Red Hat Build of Keycloak* - Identity and access management
* *Red Hat OpenShift GitOps* - ArgoCD for GitOps workflows
* *S4* - S3-compatible object storage for Quay backend

== Infrastructure

* *Platform:* OpenShift Container Platform 4.21
* *Topology:* Multinode (3 control plane, 6 workers)
* *Cloud Provider:* CNV (nested virtualization)
* *Compute:* 16 vCPU, 64GB RAM per node
* *Storage:* 200GB disk per worker
* *Max Concurrent Users:* 20 (via tenant provisioning)

== Usage

1. Order this catalog item once to provision the shared cluster
2. Wait for all cluster-wide components to deploy (approximately 60-90 minutes)
3. Share the cluster details with students or configure automatic tenant provisioning
4. Students order the tenant catalog item to get their isolated workspace
