Deploys a complete RAG (Retrieval-Augmented Generation) environment on a shared base cluster via the OpenShift Sandbox API. Prompts get grounded by retrieving context from a RAG pipeline, a browser-based RAG UI, and managed LLM access via LiteLLM on the shared platform.

This is Module 2 (RAG) of the LB2142 - Selling with AI Quickstarts lab. It requires the lb2142-ai-quickstarts-cluster catalog item to be deployed first.
