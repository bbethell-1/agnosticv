= OpenShift Dev Day Roadshow (Cluster)

A CI for OpenShift Dev Day Roadshow. Details to follow...

== Overview

This catalog item provisions the shared OpenShift cluster infrastructure for the OpenShift Dev Day Roadshow workshop.

*This is a cluster CI component* - it is not meant to be ordered directly by students. Use the corresponding tenant CI for student lab environments.

== Infrastructure Provided

* Multi-node OpenShift cluster (4 workers, auto-scaling enabled)
* Keycloak authentication (SSO realm)
* OpenShift GitOps (cluster-wide configuration)
* LiteLLM virtual keys for AI integration
* Console embed capabilities

== Technical Details

* *Platform*: OpenShift Container Platform 4.20
* *Infrastructure*: CNV-based (agd-v2/ocp-cluster-cnv-pools)
* *Cluster Size*: Multi-node with auto-scaling
* *Workers*: 4 (32 cores, 64Gi memory each)

== Related Components

This cluster CI is designed to work with:

* *lb2111-ocp-dev-day-tenant* - Per-user tenant deployment
