== Information

This is the per-student lab environment for LB1858: Operating Applications on OpenShift 5.

The shared cluster must already be provisioned using `lb1858-ocp5-container-mngmt-cluster` before this item can be ordered.

== Featured Technology and Products

* Red Hat OpenShift Container Platform 5
* Red Hat OpenShift GitOps (Argo CD)

== Detailed Overview

A hands-on lab where participants take the role of a platform team responsible for onboarding and operating applications on a shared OpenShift environment. The lab brings together GitOps, tenant isolation, resource management, and application troubleshooting.

* *GitOps Onboarding* -- deploy an application declaratively through Git and Argo CD
* *Multitenancy* -- apply access and network controls and verify isolation between tenants
* *Workload Management* -- manage resource contention and right-size application workloads
* *Incident Investigation* -- use metrics, logs, and events to diagnose application failures
* *Application Lifecycle* -- deliver fixes through GitOps and verify rollout health and recovery
