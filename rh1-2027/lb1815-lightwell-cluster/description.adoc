
Sandbox API Cluster for the Lightwell Trusted Software Supply Chain demo.

This catalog item deploys shared platform services on top of an OpenShift cluster, preparing it to host Lightwell demo tenant environments via the OpenShift Sandbox API.

== What Gets Deployed

* *Keycloak SSO* -- OpenShift authentication with admin and per-user accounts
* *Ansible Automation Platform (Controller + EDA)* -- Automation orchestration and event-driven automation
* *Red Hat Trusted Artifact Signer (RHTAS)* -- Code signing and attestation
* *Red Hat Trusted Profile Analyzer (RHTPA)* -- SBOM and vulnerability analysis
* *GitLab* -- Source code management and CI/CD
* *JFrog Artifactory* -- Enterprise artifact proxy to Lightwell Network repositories
* *Jenkins* -- CI/CD pipeline execution
* *SonarQube* -- Static code analysis and quality gates
* *Red Hat Quay* -- Container image registry with Clair vulnerability scanning
* *OpenShift GitOps (ArgoCD)* -- GitOps-driven workload delivery

== Design

This catalog item is designed to be registered with the OpenShift Sandbox API.
Individual Lightwell demo tenants are provisioned on top of this base cluster.

== Requirements

Deploys on top of an OpenShift 4.22+ cluster with CNV (Container Native Virtualization).
