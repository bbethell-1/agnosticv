
Lightwell: Patch to Production workshop.

This catalog item provisions a single tenant environment on a shared and onboarded Lightwell cluster. With the workshop UI enabled, it can also provision the shared cluster itself along with multiple tenant environments.

== What Gets Deployed

* *Keycloak SSO* -- OpenShift authentication with admin and per-user accounts
* *Ansible Automation Platform (Controller + EDA)* -- Automation orchestration and event-driven automation
* *Ansible Orchestrator* -- Workflow orchestration for AI-assisted remediation
* *Red Hat Trusted Artifact Signer (RHTAS)* -- Keyless code signing via Tekton Chains
* *OpenShift Pipelines (Tekton)* -- CI/CD with Pipelines as Code
* *GitLab* -- Source code management
* *Renovate Operator* -- Automated dependency update management
* *OpenShift GitOps (ArgoCD)* -- GitOps-driven workload delivery
* *CNPG* -- Cloud Native PostgreSQL for per-tenant TPA databases

== Per-Tenant Resources

When ordering with the workshop UI enabled, this catalog item provisions both the shared cluster and individual tenants. If you do not enable the workshop UI, it will provision a tenant only against a shared and onboarded cluster. Each tenant receives:

* *Keycloak* SSO user and isolated namespaces
* *GitLab* group with three sample applications and a deployment manifest repository
* *Nexus* -- per-tenant artifact manager (Maven proxy, Lightwell remediation repository, OCI container registry)
* *TPA* -- per-tenant SBOM and vulnerability analysis
* *Tekton Pipelines as Code* -- CI build, test, sign, SBOM upload
* *ArgoCD* app-of-apps deploying sample applications to a production namespace
* *Renovate* workspace for automated dependency scanning
* *Showroom* lab guide with embedded terminal and console tabs

See `lb1815-lightwell-tenant` for full tenant details.

== Design

This catalog item is designed to be registered with the OpenShift Sandbox API.
Individual Lightwell workshop tenants are provisioned on top of this base cluster.

== Requirements

Deploys on top of an OpenShift 4.22+ cluster.
