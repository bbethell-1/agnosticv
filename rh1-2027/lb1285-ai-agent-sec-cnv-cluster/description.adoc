= LB1285: AgentOps in Action: Evaluate, Secure, and Operate Enterprise AI Agents

Description:
  description: 
    A hands-on AgentOps lab that teaches participants how to evaluate, secure, observe, and operate enterprise AI agents on Red Hat OpenShift AI using runtime controls, 
    identity-aware authorization, automated testing, and policy tuning"

  Learning_objectives:
    - "Identify and assess common security and operational risks in tool-enabled AI agents by reviewing their permissions, traces, tool calls, and evaluation results"
    - "Apply runtime controls that restrict an agent's network, filesystem, process, and tool access without rebuilding or redeploying the agent application"
    - "Configure identity-aware authorization so that agents can access only the enterprise resources and MCP tools permitted for the requesting user"
    - "Use automated evaluations and red-team tests to detect unsafe behavior and verify that security controls are working as intended"
    - "Tune agent policies to balance security, usability, and required business functionality in an enterprise deployment"
    - "Interpret agent execution traces to distinguish model-level behavior from runtime and platform-level enforcement"
    - "Differentiate the enforcement responsibilities of sandbox isolation, execution policy, tool authorization, and inference guardrails"
