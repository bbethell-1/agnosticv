Explore how to back up and recover virtual machines (VMs) on OpenShift Virtualization using Trilio’s integrated data protection platform. This lab demonstrates key operational workflows like VM backup and restore through the OpenShift Console.

== Lab Overview

This hands-on workshop focuses on protecting workloads running on Red Hat OpenShift Virtualization using Trilio. Participants will interact with a pre-configured environment to perform backup and recovery operations, showcasing Trilio’s intuitive integration and enterprise-ready capabilities.

No installation steps are required — the lab focuses purely on Trilio’s usage and workflows within OpenShift.

== Lab Instructions

Full step-by-step instructions are available on the Showroom platform once your environment is provisioned:

https://rhpds.github.io/showroom_backup_recovery_ocp_virt_trilio/modules/index.html

Please review the instructions before starting to ensure a smooth experience.

== What You’ll Learn

* How to create consistent VM backups using Trilio's interface in OpenShift
* How to restore VMs with minimal downtime and data loss
* How Trilio integrates natively with the OpenShift Console
* How to leverage OpenShift API for Data Protection (OADP)

== Key Technologies

* Red Hat OpenShift 4.18
* Red Hat OpenShift Virtualization 4.18
* Red Hat OpenShift Data Foundation 4.17
* Red Hat OpenShift API for Data Protection (OADP) 1.4
* Trilio for Kubernetes 4.0.x

== Target Audience

This workshop is ideal for platform engineers, virtualization admins, and OpenShift practitioners looking to implement robust data protection for VM-based workloads.

== Duration

~45–60 minutes depending on pace
