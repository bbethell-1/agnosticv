= Red Hat Advanced Developer Suite - Software Supply Chain (Workshop)

This hands-on workshop is designed for developers and DevOps teams who want to build and deploy applications quickly—*without compromising security*.

You'll learn how to modernize your software delivery pipeline using the Red Hat Advanced Developer Suite - Software Supply Chain (RHADS), a powerful set of tools that bring automation, governance, and built-in security to every stage of the application lifecycle.

== What You'll Learn

You'll work directly with the following components:

* *Red Hat Developer Hub (RHDH)* – Scaffold secure, production-ready applications in minutes using pre-built templates.
* *Red Hat Trusted Profile Analyzer* – Automatically scan your code and dependencies for vulnerabilities within your workflow.
* *Red Hat Trusted Artifact Signer* – Apply cryptographic signatures to your artifacts to ensure authenticity and traceability.

== Hands-on CI/CD Paths

The lab includes two practical learning paths, both embracing a *pipeline-as-code* approach:

* *OpenShift Pipelines (Tekton)* – Build Kubernetes-native CI/CD workflows with Tekton.
* *Jenkins* – Integrate existing Jenkins pipelines with RHADS to add security and automation without starting from scratch.
