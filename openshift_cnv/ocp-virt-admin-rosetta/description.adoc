Red Hat OpenShift Virtualization provides enterprise-grade virtualization capabilities that map directly to traditional hypervisor features, enabling organizations to confidently migrate workloads to a modern container platform. This hands-on workshop creates a "Rosetta Stone" mapping between legacy virtualization platforms and OpenShift Virtualization, demonstrating feature parity through practical exercises. Learners explore live migration, resource overcommit, hot plugging, affinity rules, dynamic rescheduling, and node failure handling to confidently address customer questions about capability comparisons.

== Detailed Overview

* *Live Migration of Workloads*
** Perform zero-downtime VM movement between cluster nodes
** Execute compute migration to random or specific nodes
** Complete storage migration for VM persistent volumes

* *CPU and Memory Overcommit*
** Configure CPU overcommit ratios for resource optimization
** Implement memory overcommit across the cluster
** Understand implications for workload density and performance

* *Hot Plugging Resources*
** Add CPU and memory to running VMs without restarts
** Attach virtual disks dynamically to active workloads
** Add network interfaces to running virtual machines

* *Affinity and Anti-Affinity for VM Placement*
** Configure node affinity for targeted VM placement
** Implement pod affinity for co-located workloads
** Set up anti-affinity rules for high availability

* *Dynamic Rescheduling of Workloads*
** Enable platform-driven VM placement optimization
** Observe automated workload balancing across nodes

* *Fencing and Node Failure Handling*
** Understand workload resilience during infrastructure disruptions
** Test VM recovery procedures during node failures

* *Decentralized Live Migration (Bonus)*
** Explore cross-namespace workload migration
** Understand advanced migration patterns for complex environments
