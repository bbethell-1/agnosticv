Learn the key virtualization capabillities of OpenShift Virtualization in the context of other platforms.

== Introduction

OpenShift Virtualization is everywhere and has a major influence across our accounts.

The interest level is high, but there is always the unavoidable question; How does it compare with VMWare?

Moving beyond installation, configuration and VM creation, the rosetta stone builds a mapping between VMware and OpenShift Virtualization capabilities.

Let us take that mapping and put it into practice to supercharge your knowledge to tackle those customer questions.

== Agenda

. Live Migration of Workloads
. CPU and Memory Overcommit
. Hot Plugging Resources
. Affinity and Anti-Affinity for VM Placement
. Dynamic Rescheduling of Workloads
. Fencing and How to Handle Node Failure
. BONUS LAB! Decentralized Live Migration

== Lab Environment

.OpenShift
* A single node OpenShift Virtualization cluster with one control plane and two compute nodes.

.Bastion
* A single Red Hat Enterprise Linux 9 server with the `oc` command line tool installed.
