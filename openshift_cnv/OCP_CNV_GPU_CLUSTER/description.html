Provision a cluster in Red Hat OpenShift Container Platform on CNV for RHOAI with GPU to host LLM as a service, hence only dev env is created here.

Product(s): Red Hat OpenShift Container Platform

Specifications

  • Three controller nodes (8 cores and 16Gi RAM)
  • Total number of nodes dependent on the size ordered (12 cores and 32Gi RAM), after the lab is setup, GPU needs to be added to the cluster from CNV VirtualMachine setup
  • Cluster version: (The version which is selected at deployment)
  • Authentication enabled (refer to your provisioning email for details regarding the "htpasswd")
  • Let's Encrypt certificates enabled on Ingress controllers

Supporting Materials

You have full admin access to the provisioned workshop cluster and can find all details needed to access your cluster in the Access guide.

There is also an Access guide for Red Hat Partners.

Partners can also access partner support.

Provisioning time: Typically, ~40 min
