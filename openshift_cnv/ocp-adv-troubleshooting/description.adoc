Learn how to troubleshoot cryptic, cluster-wide issues in OpenShift.

== Introduction

This lab dives straight into the complex failure scenarios that require a deeper understanding of the OpenShift control plane and advanced diagnostic techniques.

This lab systematically unravel the toughest problems, elevating your skills from a cluster operator to a cluster hero.

== Key takeaways

* *Tools of the Trade* Review the most common tools and explain how you will be using these tools.
* *Triaging your Cluster using OpenShift Lightspeed* get an overview of the entire cluster to save time and to help start fixing the problem.
* *etcd: Slow Disks or Overload?*
Delve into the heart of your cluster's state: etcd.
We'll dissect metrics and logs.
* *API Overload*
If etcd isn't the issue then what is causing my API to be so slow?
Review the audit logs and pin point what's hogging all the attention.
* *OVN Debugging* what really happens under the hood during the creation of pods or virtual machines, secondary networks and network policies.
Introduce tools to trace and debug network traffic in OVN, and learn how to look inside the OVN databases to see what is really happening.
