The **Advanced Automation Bootcamp** empowers associates with an immersive, hands-on learning experience focused on the **Red Hat Ansible Automation Platform (AAP)**.  
This workshop enables participants to deepen their automation skills, explore advanced use cases, and gain the technical confidence needed to design and deliver Red Hat’s latest automation solutions.

== What’s Included
The bootcamp environment includes the following Red Hat technologies:

* **Red Hat Ansible Automation Platform (AAP)** – The enterprise automation framework used to create, manage, and scale automation across hybrid environments.
* **Red Hat OpenShift Platform** – A Kubernetes-based platform that hosts and scales AAP services securely and consistently.
* **Red Hat OpenShift Dev Spaces** – A browser-based IDE offering ready-to-use development environments for building and testing automation content.

== Learning Outcomes
By completing this bootcamp, participants will:

* Gain hands-on experience with **Red Hat Ansible Automation Platform**.
* Learn to design, deploy, and execute complex automation workflows.
* Understand how to integrate AAP with OpenShift for enterprise automation.
* Build practical, production-ready automation skills aligned with Red Hat’s best practices.
