Deploy a full Red Hat OpenShift Container Platform 4 cluster on Equinix Metal.

This catalog item shows you how to deploy a full OpenShift Container Platform 4 cluster on Equinix Metal using OpenShift All-in-One (AIO), with the lab for Red Hat OpenShift Virtualization predeployed.

https://docs.google.com/document/d/16oqhjWVrtzT6ku1ziQ1Qopgs5ym_iDke2rQfxVoAqoQ/edit?usp=sharing[demo.redhat.com OCP Virtualization Offerings Explainer Doc^]

=== Specifications

This environment contains:

* Three controller nodes
* Three worker nodes
* An OpenShift bare metal installer-provisioned installation (IPI) with Red Hat OpenShift Data Foundation predeployed
