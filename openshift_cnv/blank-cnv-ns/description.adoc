## Blank Namespace on CNV


### Who is this for?
This namespace is for developers who need a sandbox environment to experiment with CNV.

### What You Get:

* **An OpenShift Namespace**: A private space for your projects.
* **Service Account Credentials**: For programmatic access to the OpenShift API
* **Generic User Credentials**: For logging into the OpenShift Web Console.
* **additional deployer variables**: Check the "details" tab for more information.

With those variables you should be able to work locally on agnosticd to develop for RHDP CNV.


### Resource Quota

Your namespace comes with the following resources:
