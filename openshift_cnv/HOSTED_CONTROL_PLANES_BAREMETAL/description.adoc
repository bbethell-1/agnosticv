Hosted Control Planes on Baremetal - An environment to run the hands-on exercises

This hands-on lab will provide you with instructions so you can deploy a Hosted Clusteri using baremetal infrastructure. The goal is to help you understand Hosted Control Planes internals, its value proposition, and make sure you can easily replicate the workflow.

The cost of this lab will be charged back to your cost center.

The lab deployment time is ~1h. Once deployed you will get the access details in your inbox.

NOTE : The usage behaviour of this Catalog Item is not to stop the environment until retirement.
       If the instance is stopped, and started then the "OpenShift Management Cluster OCP Console" link would not be accessible.
