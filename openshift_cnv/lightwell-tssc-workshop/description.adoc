= Lightwell Software Supply Chain Security Workshop

Hands-on workshop that walks one trusted software supply chain on a dedicated OpenShift claim: verify and mirror a Hummingbird (Red Hat Hardened Images) base, consume Lightwell Network dependencies through an enterprise Nexus proxy, own application source (including a live Renovate PR), build hermetically with OpenShift Pipelines and BuildConfig, sign and attest with RHTAS and Conforma, promote stage then prod via GitOps with admission, and prove continuous compliance with Lightwell GAV-bound VEX in Trusted Profile Analyzer. Java is the scored application. Python and Artifactory appear as in-module callouts, not a second path.

== What you will learn

* Trust-policy verification of a published Hummingbird image, then learner-run `oc-mirror` so image, signatures, and SBOM land in the in-cluster dest
* Enterprise Maven consumption of Lightwell Validated and Remediated through a Nexus proxy (`settings.xml` you author)
* Exact-version `.rhlw-*` pins driven by a Lightwell OSV fixed event
* Binding source to the mirrored Hummingbird digest and Lightwell pins, then merging a live Renovate PR on in-cluster Gitea (not a hand-edit)
* Hermetic build controls: source forbid-list, dependency prefetch, and a tightened build-namespace NetworkPolicy
* OpenShift BuildConfig image plus SBOM; keyless signing (RHTAS), Enterprise Contract / Conforma gates, and disconnected (mirrored-TUF) verify
* GitOps promotion with unsigned-deny admission (stage), then commit of the signed digest to a separate prod GitOps remote
* Ingest of Lightwell GAV-bound VEX/SBOM into RHTPA and reporting the CVE as remediated via the Lightwell pin, with RHACS in the blast-radius story

== Lab modules

* Trusted supply chain (ungated intro)
* Track 1 -- Hummingbird: verify the published image; mirror into the trust boundary
* Track 2 -- Lightwell dependencies: enterprise Maven proxy; remediated exact-version pin
* Track 3 -- Source: Developer Hub golden path; bind base and deps; live Renovate
* Track 4 -- Hermetic build: forbid-list, prefetch, NetworkPolicy, BuildConfig + SBOM
* Track 5 -- Signed and attested image: keyless sign, Conforma, disconnected verify
* Track 6 -- Production container: GitOps + admission; promote to the prod repo
* Track 7 -- Continuous compliance: SBOM system of record (RHTPA); VEX blast radius + ACS

== Environment

* OpenShift Container Platform 4.20+ (multi-node, per-student)
* GitOps App-of-Apps delivering: RHDH, RHTAS, RHTPA, RHACS, Nexus, Gitea, Renovate, Showroom
* Showroom split-screen lab guide with embedded terminal
