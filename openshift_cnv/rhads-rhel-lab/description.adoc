This specialized self-paced workshop provides hands-on experience with the Red Hat Advanced Developer Suite (RHADS) components that are supported on Red Hat Enterprise Linux (RHEL).
Focused specifically on Trusted Profile Analyzer (TPA) and Trusted Artifact Signer (TAS), this workshop is designed for Platform Engineers, Developers, and technical leaders who work in RHEL environments and need to implement security-first development practices.

== What You'll Get

Through practical exercises, you'll learn how to deploy, configure, and integrate these critical RHADS components on RHEL systems, gaining expertise in artifact signing, policy enforcement, and security scanning workflows that are essential for maintaining secure software supply chains in enterprise Linux environments.

== Use Cases

This workshop complements the https://catalog.demo.redhat.com/catalog?item=babylon-catalog-dev/pert.redhat-rhads.prod&utm_source=webapp&utm_medium=share-link[broader RHADS OpenShift product enablement] by providing RHEL-specific implementation guidance for organizations that rely on traditional Linux infrastructure alongside or instead of containerized platforms.
