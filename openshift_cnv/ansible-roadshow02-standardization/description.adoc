== Ansible Automation Platform Roadshow 02 - Standardization - Lab

Imagine you're part of a company that has grown rapidly and with that growth came inconsistency. Different teams have been setting up servers, network devices, and applications their own way, using different configurations, operating system versions, and security policies. Essentially, these teams have created their own silos. Now, you're facing a major challenge—troubleshooting is a nightmare, deployments vary across teams, and security gaps are everywhere. You need a way to standardize deployments across the entire infrastructure.
