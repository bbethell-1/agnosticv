Deploy a baremetal server on cnv with link:https://access.redhat.com/documentation/en-us/red_hat_enterprise_linux/9[RHEL 9] installed.

SSH access to the server and administrator priviledge (via `sudo`) is included.

*Please be aware that this service will be charged back to your cost center.*
