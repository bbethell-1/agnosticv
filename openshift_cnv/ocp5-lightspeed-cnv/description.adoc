This environment provides an OpenShift 5 cluster with OpenShift Lightspeed deployed. OpenShift Lightspeed is an AI virtual assistant
that runs in the OpenShift web console. This environment supports Agentic OLS on top of the classic OLS experience, with the LLM API key provided automatically via MaaS.

== Product List

* OpenShift Container Platform 5 (SNO)
* OpenShift Lightspeed (with optional Agentic OLS)
* OpenShift Virtualization
* Cluster Observability Operator

== Support

NOTE: If you get an error when connecting to backend AI service, please try to *delete* the 'lightspeed-app-server-xxxxxx' pod in 'openshift-lightspeed' project.
A new pod will be provisioned automatically to connect to the backend AI services.

For other issues, please open a ticket or visit the link:https://redhat.enterprise.slack.com/archives/C04N203SNUW[#forum-demo-redhat-com^] Slack channel.
