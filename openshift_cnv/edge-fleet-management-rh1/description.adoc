Edge Manager Test Drive: Hands-on Fleet Management

== Introduction

Managing fleets of devices at the edge presents unique challenges from provisioning and onboarding, to maintaining security, consistency, and lifecycle operations at scale.
In this hands-on lab, you’ll get behind the wheel with Red Hat Edge Manager, Red Hat’s fleet management solution for edge devices.

== Goals

. Install and configure Red Hat Edge Manager
. Onboard and monitor edge devices
. Connect and utilize Git repositories
. Create and manage device fleets
. Add new applications to existing devices
. Decommission devices

== Agenda

* Deploy Edge Manager
* High Level Architecture
* Fleet Creation
* Drone VM Creation
* Fleet Membership
* Device Monitoring

By the end of this lab, participants will have first-hand experience using Edge Manager to simplify fleet operations, reduce manual effort, and deliver applications to edge environments.
