Red Hat Edge Manager provides declarative fleet management for edge devices at scale, enabling organizations to define desired OS images, host configurations, and application sets for individual devices or entire fleets. This hands-on workshop demonstrates deploying Edge Manager on OpenShift, creating device fleets, onboarding edge VMs, and monitoring device health and compliance. Learners experience how a local agent on each device executes configuration changes, detects drift, and automatically initiates corrective actions.

== Detailed Overview

* *Deploy Edge Manager*
** Install and configure Red Hat Edge Manager on OpenShift
** Understand the Edge Manager architecture and components
** Access the Edge Manager console interface

* *Fleet and Device Creation*
** Explore the high-level distributed architecture
** Create device fleets for grouped management
** Deploy drone VMs as simulated edge devices

* *Device Monitoring and Management*
** Configure fleet membership for device grouping
** Monitor device health, status, and compliance
** Connect Git repositories for configuration management
