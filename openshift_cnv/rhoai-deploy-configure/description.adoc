This environment provides a hands-on workshop for deploying, configuring, and operating Red Hat OpenShift AI on OpenShift Container Platform.
The lab covers the full lifecycle from installation through model serving, governance, scaling, and observability — all using CPU-only inference to keep costs down.

Each participant gets their own dedicated cluster (SNO with an additional worker node) for operator installation and platform configuration.

== Products

* OpenShift Container Platform 4.22 (SNO + 1 worker node)
* Red Hat OpenShift AI 3.4 / 3.5
* Red Hat OpenShift GitOps 1.21

== Topics Covered

* Installing RHOAI in connected and disconnected (air-gapped) environments
* Configuring the model-serving platform (KServe, ServingRuntime)
* Serving LLMs with vLLM on CPU (Qwen2.5-0.5B-Instruct)
* Governing access with Models-as-a-Service (Technology Preview)
** External models via MaaS with llm-katan simulator
* Scaling with Distributed Inference using llm-d and KEDA (Technology Preview)
* Observability and monitoring for served models
* GitOps-driven cluster configuration and bootstrap
