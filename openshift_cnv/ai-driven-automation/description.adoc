Ansible Automation Platform combines with Red Hat AI and Ansible Lightspeed to create intelligent, self-healing infrastructure that can detect, analyze, and remediate failures automatically. This hands-on lab demonstrates AIOps principles across three domains: service remediation, network automation, and Windows event-driven automation. Learners build Event-Driven Ansible workflows that use AI to generate remediation playbooks without writing any Ansible code manually.

== Detailed Overview

=== Section 1: AIOps with Apache Remediation

EDA detects Apache service failures, triggers a workflow that collects logs, uses AI for root cause analysis, notifies Mattermost, and generates a remediation playbook via LLM. A second workflow commits the fix to Gitea, validates in check mode, and executes after human approval.

=== Section 2: Network AIOps with Splunk and OSPF

Splunk collects Cisco router syslogs and fires webhooks to EDA on OSPF neighbor state changes. The Network AIOps workflow uses an LLM to generate Cisco IOS remediation playbooks for three scenarios (interface down, network type mismatch, hello timer mismatch) with human-in-the-loop approval.

=== Section 3: Windows Events and AI-Driven Ticketing

Winlogbeat forwards Windows security events (AD account creation, firewall rule changes) to EDA via Kafka. EDA triggers automated ticketing to Mattermost, with optional AI enrichment that analyzes raw events and generates actionable security intelligence.

=== Section 4: Red Hat Lightspeed and Agentic IDE Workflow

Students use Red Hat Lightspeed on console.redhat.com to identify CVEs and Advisor recommendations across their RHEL fleet, generate remediation playbooks in a developer IDE, push them to Git, and execute from AAP.

=== Section 5: Autonomous AIOps with Self-Healing RHEL

AI-driven cron failure remediation using Splunk log forwarding, EDA event detection, LLM-based routing to select the correct fix template, human-in-the-loop approval, and automated dispatch.

=== Section 6: AI-Driven Incident Response

A CrewAI agent running on the bastion connects to AAP via MCP to triage, remediate, and report on infrastructure incidents autonomously.
