This is The Definitive Red Hat Enterprise Linux 10 Hands-On Lab. 

Presented  by your favorite Red Hat Field Solution Architects, each attendee will have access to live exercises to build familiarity with the new features and capabilities of Red Hat's most advanced release of RHEL ever. A blended mix of self-paced and guided exercises will cover both core and new capabilities, including:

- Ease of use: WebConsole, DNF, systemd, firewalld, and Stratis
- Security: Simple system-level disk encryption, session recording with tlog, nft-tools
- Performance: Tracing with extended Berkeley Packet Filter (eBPF) and performance co-pilot (PCP)
- Management: Automation fundamentals and system roles; virtualization with Kernel-based Virtual Machine (KVM), libvirt, and imagebuilder; and containers with Podman, Skopeo, and Buildah.

This lab includes:

- Red Hat Enterprise Linux 10
- Red Hat Enterprise Linux Virtualization / Libvirt
- ImageBuilder
- Podman
