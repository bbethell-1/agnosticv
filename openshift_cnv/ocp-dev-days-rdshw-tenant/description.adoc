= OpenShift Dev Day Roadshow (Tenant)

A CI for OpenShift Dev Day Roadshow. Details to follow...

== Overview

This catalog item provisions a dedicated tenant environment on a shared OpenShift cluster for the OpenShift Dev Day Roadshow workshop. Each student receives their own isolated namespace with GitOps, authentication, and lab guide.

== What's Included

* *Personal Keycloak User* - Dedicated user account in the SSO realm
* *OpenShift GitOps* - Tenant-scoped GitOps (ArgoCD) instance
* *LiteLLM Virtual Keys* - AI model access tokens (1-day duration)
* *Lab Guide* - Interactive Showroom lab instructions with WeTTY terminal
* *E2E Testing* - Solve and validate buttons in lab guide for automated testing

== Technologies

Students will work with:

* *GitOps/ArgoCD* - Declarative application deployment and management
* *Keycloak* - Modern authentication and authorization
* *OpenShift Pipelines* - CI/CD automation (via GitOps bootstrap)
* *AI Integration* - LiteLLM virtual keys for AI models

== Lab Environment

* *Terminal Type*: WeTTY (browser-based terminal)
* *Namespace Pattern*: user-{guid}-*
* *GitOps Bootstrap*: Automated tenant application deployment
* *Duration*: Standard lab lifetime (configurable)

== Access

After provisioning, you will receive:

* OpenShift cluster console URL
* Your personal username and password
* Lab guide URL with integrated terminal
* LiteLLM API credentials (if enabled)

== Technical Details

* *Config Type*: namespace (tenant pattern)
* *Multi-user*: Yes (isolated per-student namespaces)
* *Sandbox Pattern*: OcpSandbox with cloud_selector lab=ocp-dev-days-roadshow
* *Cluster CI Required*: ocp-dev-days-rdshw-cluster
