== Overview

Customer-facing training environment for AI Factory topics, designed for Product Training and Learning (PTL) delivery. 
This stable catalog provides a consistent OpenShift AI 3.3 development platform with MaaS integration for building and deploying enterprise AI applications.

== What You'll Learn

This training environment supports comprehensive AI Factory curriculum including:

* **Building and Deploying AI Agents**: Develop secure agentic AI applications using Llama Stack and Gen AI Playground
* **Retrieval-Augmented Generation (RAG)**: Implement context-aware AI applications with document retrieval
* **AI Development Tools**: Work with Red Hat OpenShift AI workbenches, model registry, and deployment tools
* **Model Management**: Deploy and manage LLMs using vLLM, KServe, and Model-as-a-Service (MaaS)
* **AI Safety and Reliability**: Implement guardrails, validation, and automated testing for production AI

== Environment Features

=== OpenShift AI 3.3 Platform

* Single Node OpenShift (SNO) cluster optimized for training
* Red Hat OpenShift AI 3.3 with all components enabled:
** Data Science Pipelines
** KServe model serving
** Model Registry
** Ray distributed computing
** TrustyAI for model monitoring
** Training Operator
** Workbenches for development
** Feast feature store
** Llama Stack Operator
** AI Pipelines

=== Authentication & Access

* Keycloak-based authentication for secure multi-user access
* Pre-configured admin and user accounts
* OpenShift console access with workshop integration

=== AI Development Tools

* **Gen AI Playground**: Quickly prototype AI agents and applications
* **Llama Stack**: Development infrastructure for custom AI agents
* **OpenShift Lightspeed (OLS)**: AI-powered OpenShift assistance
* **Model-as-a-Service (MaaS)**: Virtual API keys for AI models including:
** Granite 4 Tiny Hybrid
** Qwen 3 14B

=== Networking & Integration

* MetalLB load balancer for service exposure
* OpenShift Pipelines (Tekton) for CI/CD
* OpenShift Serverless (Knative) for event-driven architectures
* Authorino for API security and authorization

== Technical Specifications

* **Platform**: Single Node OpenShift 4.20
* **Infrastructure**: OpenShift CNV (Container Native Virtualization)
* **OpenShift AI Version**: 3.3 (stable channel)
* **MaaS Access**: 3-day virtual keys for AI model inference
* **Storage**: 20Gi PVC for notebooks and workbenches
