=== Using Your MaaS Key

Example Python code to use your virtual key:

[source,python]
----
from openai import OpenAI

client = OpenAI(
    api_key="{litellm_virtual_key}",
    base_url="{litellm_api_base_url}"
)

response = client.chat.completions.create(
    model="granite-4-0-h-tiny",
    messages=[
        {"role": "user", "content": "Explain AI agents in simple terms"}
    ]
)

print(response.choices[0].message.content)
----

=== MaaS Best Practices

* Store your API key securely - do not commit to version control
* Monitor your usage through the key's limited duration
* Use `granite-4-0-h-tiny` for chat completions and instruction following
