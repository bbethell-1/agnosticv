GPUaaS using Kueue with Fake GPUs

Experience GPU-as-a-Service (GPUaaS) on OpenShift without physical GPU hardware. This hands-on lab uses Kueue — OpenShift's batch workload management system — combined with a fake GPU device plugin to simulate GPU resource scheduling and management at scale.

Each attendee gets a dedicated Single-Node OpenShift (SNO) 4.20 cluster pre-configured with Kueue and a fake GPU device plugin, so you can learn GPU resource management concepts without the cost or availability constraints of real GPU hardware.

This lab covers:

- GPU resource scheduling with Kueue
- ClusterQueue and LocalQueue configuration
- Resource flavors and GPU workload prioritization
- Fake GPU device plugin setup and validation
- Submitting and managing GPU batch jobs on OpenShift
- Observing workload queuing behavior in the OpenShift console

This lab includes:

- Red Hat OpenShift 4.20 (Single-Node OpenShift)
- Kueue batch workload manager
- Fake GPU device plugin
- OpenShift GitOps (ArgoCD) for cluster automation
- Showroom lab guide with embedded OpenShift console
