Ansible Automation Platform on Red Hat OpenShift requires operational knowledge to diagnose and resolve deployment issues effectively. This troubleshooting lab takes you inside the AAP Operator, teaching you to interpret Operator logs and Custom Resource statuses to identify root causes of deployment and runtime failures. Learners work through intentionally misconfigured environments, diagnosing real-world issues related to persistent storage, networking, and resource contention using native OpenShift diagnostic tools.

== Detailed Overview

* *Automation Hub Issues*
** Diagnose pods stuck in Pending state
** Investigate PVC and storage-related failures
** Resolve persistent volume claim issues

* *Gateway Issues*
** Review Gateway pod logs for connectivity failures
** Diagnose missing services in OpenShift networking
** Resolve dual issues affecting AAP Gateway access

* *Gateway Pod Issues*
** Identify failing pods using `oc describe`
** Diagnose pod startup failures and resource issues
** Resolve configuration problems preventing pod scheduling

* *Hub Content Synchronization*
** Attempt Community repository synchronization
** Analyze Hub pod logs for sync failures
** Resolve content synchronization issues

* *Controller Job Issues*
** Launch job templates and identify failures
** Inspect automation-job pod logs
** Fix job template configuration issues

* *ALIA Issues*
** Diagnose missing Lightspeed chat icon
** Review lightspeed-api and chatbot pod logs
** Configure LLM connection for AI assistant functionality
