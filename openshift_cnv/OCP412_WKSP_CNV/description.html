This asset shows how to provision an OpenShift Container Platform cluster with basic customizations on an AWS infrastructure for running hands-on-labs, workshops, and similar events where no specialized environment is available.

Refer to the catalog for specialized workshops such as Containers and Cloud-Native Roadshow, OpenShift Getting Started Workshops, and so on.

Product(s): Red Hat OpenShift Container Platform

Specifications

  • Three controller nodes (AWS instance type: m5a.2xlarge)
  • Total number of nodes dependent on the size ordered (AWS instance type: m5a.4xlarge)
  • Cluster version: 4.12.x
  • Authentication enabled (refer to your provisioning email for details regarding the "htpasswd")
  • LimitRanges enabled
  • Let's Encrypt certificates enabled on Ingress controllers

Supporting Materials

You have full admin access to the provisioned workshop cluster and can find all details needed to access your cluster in the Access guide.

There is also an Access guide for Red Hat Partners.

Partners can also access partner support.
