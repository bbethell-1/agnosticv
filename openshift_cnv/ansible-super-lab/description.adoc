The **Ansible Super Lab** provides attendees with an immersive, hands-on learning experience that touches upon many of the patterns for utilizing **Red Hat Ansible Automation Platform (AAP)** in an enterprise environment. The exercises are aligned to showcase the key components and strategies that have proven to be successful in some of Red Hat's largest customers. Topics covered include:

* Utilizing Ansible development workspaces (OpenShift Dev Spaces) to develop Ansible content.
* Ansible Developer tooling
* Operating Ansible Automation Platform on Red Hat OpenShift
* Windows focused automation with Ansible
* Workflows for build and consuming Ansible Automation Content in Ansible Automation Platform
* Managing Ansible Automation Platform declaratively using Config as Code (CaC)
* Event-Driven Ansible concepts and patterns

 Looking ahead, attendees will also experience the intersection of AI and the emerging features and capabilities that are becoming available within Ansible Automation Platform
 
This comprehensive look of the Ansible Automation Platform ecosystem enables participants to deepen their automation skills, explore advanced use cases, and gain the technical confidence needed to design and deliver Red Hat's latest automation solutions.

== What's Included
The Super Lab environment includes the following Red Hat technologies:

* **Red Hat Ansible Automation Platform (AAP)** - The enterprise automation framework used to create, manage, and scale automation across hybrid environments.
* **Red Hat OpenShift Platform** - A Kubernetes-based platform that hosts and scales AAP services securely and consistently.
* **Red Hat OpenShift Dev Spaces** - A browser-based IDE offering ready-to-use development environments for building and testing automation content.

== Learning Outcomes
By completing this Super Lab, participants will:

* Gain hands-on experience with **Red Hat Ansible Automation Platform**.
* Learn to design, deploy, and execute complex automation workflows.
* Develop workflows for building and consuming Ansible Automation Content.
* Understand how to integrate AAP with OpenShift for enterprise automation.
* Build practical, production-ready automation skills aligned with Red Hat's best practices.
* Explore event-driven automation concepts and patterns.
* Discover emerging AI capabilities within Ansible Automation Platform.
