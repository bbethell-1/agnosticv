= LB7774: Ansible Automation Superlab: The Enterprise Edition

== Overview

The Ansible Automation Superlab enables attendees with hands-on exercises that demonstrate enterprise grade automation usage and patterns with a glimpse at the current and future AI integrations.

=== Lab Themes

* *Automation Productivity* - Enabling automation: from basic development activities to runtime at scale
* *Enterprise Automation Patterns* - Methodologies and approaches for delivering automation within Enterprise environments
* *AI Driven Automation* - A glimpse into the AI integrations, workflows and tools

=== Lab Modules

* *Platform* - Enabling automation developers and administrators with the tools they need to be productive
* *Content* - Developing and delivering repeatable automation
* *Events* - Reactive automation based on the current state of the environment
* *AI* - The increasing integration of AI in Ansible Automation Platform
