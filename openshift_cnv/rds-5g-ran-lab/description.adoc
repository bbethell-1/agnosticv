== Overview

This lab guides you through deploying a RAN-ready infrastructure on OpenShift, using a pre-configured bastion host with nested OpenShift 4.21 running on OpenShift Virtualization.

== Featured Technology

* Red Hat OpenShift Container Platform 4.21
* 5G RAN Reference Design Specification (RDS)
* OpenShift Virtualization (CNV)

== Lab Details

* *Deployment time:* ~1h40m
* *Access:* SSH to bastion + HTTPS routes
* *Student user:* `lab-user`
