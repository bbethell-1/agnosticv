= Service Enablement: App Platform Runtime

A dedicated OpenShift 4.21 cluster for the ETX App Platform training event.
This cluster serves as the application runtime environment — the deployment target
for applications built and promoted through the Software Factory cluster.

== Environment Details

* OpenShift 4.21 (3 worker nodes — 4 CPU, 8Gi memory each)
* Red Hat OpenShift GitOps (ArgoCD) — cluster-admin scoped
* HTPasswd authentication configured

== Notes

This catalog item is restricted to lab developers during the development phase.
Do not order this item directly for event participants.
Order alongside the *App Platform Software Factory* catalog item.
