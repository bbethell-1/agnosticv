Description: Provision an OpenShift cluster with the Migration Toolkit for Applications (MTA) installed on it.

This asset takes you step-by-step to successfully run MTA in an OpenShift environment. With example seed data, you will learn how to build a modernization strategy, identify risks, assign application priority and find and fix issues in your source code to support modernization.

Provisioning Time: Approximately 45 minutes

Duration: 2 hours
