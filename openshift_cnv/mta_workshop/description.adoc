== Description

The catalog item launches a fully configured, single-node OpenShift cluster equipped with the Migration Toolkit for Applications (MTA), ready for you to explore.

This hands-on workshop provides a step-by-step guide to performing an application assessment using MTA. With pre-loaded example data, you’ll learn to craft a comprehensive modernization strategy, identify potential risks, prioritize applications, and discover how to efficiently locate and resolve issues in your source code to ensure a smooth modernization journey.
