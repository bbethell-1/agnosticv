Ansible Automation Platform (AAP) enables enterprise-scale automation of Red Hat Enterprise Linux (RHEL) in-place upgrades using the Leapp framework. This hands-on workshop demonstrates a prescriptive approach to automating RHEL upgrades from RHEL 7 to RHEL 8, RHEL 8 to RHEL 9, and RHEL 9 to RHEL 10. Learners gain practical experience with pre-upgrade analysis, automated remediation, snapshot-based rollback capabilities, and custom Leapp actors for organization-specific requirements.

== Detailed Overview

=== Section 1: Pre-upgrade Analysis

* *Run Pre-upgrade Jobs*
** Execute Leapp pre-upgrade analysis using AAP job templates
** Learn the three-phase workflow: Analysis, Upgrade, Commit
** Understand Leapp actors and message-driven architecture

* *Review Pre-upgrade Reports*
** Use RHEL Web Console to review Leapp findings
** Filter reports by risk level and inhibitor status
** Understand high-risk findings vs. blocking inhibitors

* *Perform Recommended Remediation*
** Use infra.leapp remediate role for automated fixes
** Manage Leapp answer files with Ansible variables
** Resolve inhibitors at scale across RHEL estate

* *Custom Pre-upgrade Checks (Optional)*
** Install Leapp custom actors for additional checks
** Implement organization-specific policy enforcement
** Generate reports with custom inhibitor findings

=== Section 2: RHEL OS Upgrade

* *Run OS Upgrade Jobs*
** Launch upgrade workflow job template
** Create snapshots for rollback capability
** Perform RHEL in-place upgrades across all hosts

* *Understanding Snapshots*
** Learn snapshot/rollback architecture
** Understand why automated rollback enables "fail fast" approach
** Review snapshot merge and commit operations

* *Validate Upgrade Results*
** Verify upgraded RHEL versions via Web Console
** Check kernel versions and system health
** Validate application functionality post-upgrade

=== Section 3: Rolling Back

* *Rollback Demonstration*
** Execute automated snapshot rollback
** Verify hosts are restored to previous RHEL version
** Understand when and why to rollback vs. remediate

* *Conclusion and Next Steps*
** Review key learnings and best practices
** Explore upgrade paths (RHEL 7→8→9 chaining)
** Access upstream resources and community repositories
