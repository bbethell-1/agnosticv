Red Hat OpenShift as a complete application platform delivers integrated development environments, automated CI/CD, a trusted software supply chain, a developer portal with self-service, and AI-ready application delivery above the Kubernetes API. Through the Parasol Insurance scenario, this presenter-led demo walks sales engineers and solution architects through three progressive sections — foundational platform capabilities, advanced developer services, and intelligent applications — each building on the previous. The progression helps position the complete application platform value to customers evaluating container management, application modernization, or developer productivity and AI adoption strategies.

== Detailed Overview

* *Section 1: Foundational Application Platform*
** *Module 1: Developer experience* — MTA migration context, one-click DevSpaces access from the topology view, Quarkus dev mode live reload, and platform engineer governance via the DevSpaces operator
** *Module 2: CI/CD pipeline* — Tekton pipeline triggered on git push, SAST/Sonarqube quality gate enforcement, AI-assisted test generation in DevSpaces, and GitOps delivery with Argo CD
** *Module 3: Platform operations* — Service-to-service mTLS with Service Mesh, real-time traffic observability with Kiali, and broader platform capabilities

* *Section 2: Advanced Developer Services*
** *Module 4: Developer Hub and catalog* — Developer Lightspeed for AI-assisted modernization, centralized catalog exploration with Lightspeed Q&A, and self-service environment and component provisioning via golden path templates
** *Module 5: Secure development workflow* — Dependency Analytics in the IDE, secure build pipeline with ACS scanning and Tekton Chains signing and SLSA attestation, and external secrets management with Vault
** *Module 6: Trusted software supply chain* — Production deployment with admission control image verification, SBOM management with TPA for continuous compliance, and application topology in Developer Hub

* *Section 3: Intelligent Applications*
** *Module 7: AI-enhanced applications* — Scaffolding an AI-powered email routing service with DevHub templates, LLM endpoint integration via Red Hat OpenShift AI, Kafka data processing, and delivery through the trusted supply chain
