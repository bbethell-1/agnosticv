Turn complex VMware migrations into your next big customer win.

== Introduction

This 4-hour super lab, recommended for our Consulting and Tech Sales teams, moves beyond theory and puts you in command of the automated migration factory.
We’ve concentrated the most critical, high-value content and labs from the ETX Virt Delivery course into one powerful, hands-on session.

You will master:

* Key foundational design and sizing considerations from the VMA
* Hands-on provisioning and executing the automated factory playbooks

== Goals

* Learn how to turn complex VMware migrations into your next big customer win.
* Master the key foundational design and sizing considerations from the VMA.
* Learn how to provision and execute the automated factory itself.

You'll leave this session with the practical skills and confidence to de-risk projects, accelerate customer adoption, and successfully deliver large-scale transformations.

== Agenda

* Running a VMa Tool Analysis
* Openshift Virtualization Migration Installation
* Preparing for Migrations
* Running a Migration
* Running a Customized Migration
* BONUS: VMs and GitOps

== Lab Environment

.OpenShift
* A single node OpenShift Virtualization cluster
* Three compute nodes

.Bastion
* A single Red Hat Enterprise Linux 9 server with the `oc` command line tool installed.

NOTE: You are also encouraged to use your laptop in this lab.
You'll be able to have your own copy of some still-proprietary tools use them on your customer engagements.
