Complete activities as a regular Kubernetes user and as an experienced Camel developer. This catalog item presents a real world-inspired base scenario, where you impersonate both a regular Kubernetes user and an experienced Camel developer. You complete a series of exercises, ranging from simple data flows, to medium and advanced use cases, to fully event-driven and archiving capabilities enabled with Red Hat OpenShift Data Foundation. This asset covers the following topics:

* Building integration flows as a Kubernetes user
* Building integration flows as a Camel developer
* Extending and amplifying connectivity using Camel K constructs
* Understanding different levels of control with Camel
* Evolving an architecture towards maturity
* Playing with an event-driven collaboration use case

Relevant information is sent in the final email.

*Duration:* Each module can typically be completed in 60-90 minutes, with an additional 20 minutes for the slides introducing the content.

*Audience:* Developers, architects, data integrators

*Product(s):* Red Hat OpenShift Data Foundation, Red Hat OpenShift Container Platform 4.x

*Technologies:* Camel K, Camel Quarkus, AMQ Streams
