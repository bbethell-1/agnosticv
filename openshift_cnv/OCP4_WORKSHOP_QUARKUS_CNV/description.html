This workshop is designed to be a half-to-full day hands-on experience introducing Quarkus to Java developers. The workshop has participants use CodeReady Workspaces to develop Quarkus apps and deploy them to OpenShift 4, and covers several other developer topics such as:
  • Dependency Injection
  • Testing Quarkus Apps
  • Debugging Quarkus Apps
  • Native compilation of Quarkus Apps
  • Deploying to OpenShift
  • Developing Cloud Native with Quarkus
  • Using Quarkus extensions
  • Hibernate ORM with Panache
  • Event-driven Messaging
  • Streaming Data with Quarkus and AMQ Streams/Kafka
  • Monitoring with Prometheus and Grafana
  • Tracing Quarkus Apps with Jaeger and MicroProfile Tracing
  • Securing apps using MicroProfile JWT and Red Hat SSO
  • Spring Web to Quarkus Qute
  • Spring DI to Quarkus CDI
  • Spring Data JPA to Quarkus Hibernate ORM with Panache
  • Strangling the Spring Monolith with Quarkus
  • Spring to Kubernetes Native with Quarkus

Here is 24/7 public instruction of each module that you will deliver in the Quarkus workshop:
  • Module 1: Basic Quarkus Lab
  • Module 2: Advanced Quarkus Lab
  • Module 3: Quarkus for Spring Developers

Requesting this catalog item will provide you with a single dedicated OpenShift 4 cluster which each participant will share, using per-participant credentials for OpenShift and CodeReady Workspaces. Each participant's developer workspace will be pre-provisioned and started up in CodeReady Workspaces so they'll be able to get started quickly. Once you order this catalog item, you'll receive an email with links to connect to the workshop which you will share with participants, along with admin credentials in case you need to log in and do housekeeping or other changes. Note that developer workspaces are started in the background and depending on how many participant seats you order, it may take longer to complete provisioning.
