== Participants Can't Launch VMs

As participants start more and more VMs, resources on the cluster are exhaused.
This leads to participants being unable to launch new VMs.

As facilitator, before ALL the participants move from one module to the next, you can stop all VMs in the cluster, quite easily.

CAUTION: Make sure you announced to your participants that their VMs will be stopped.

Users would then start ONLY the VMs they need for the particular module.

.Stop All VMs in the cluster
. Log into the bastion:
+
----
ssh {bastion_ssh_user_name}@{bastion_public_hostname} -p {bastion_ssh_port}
----
+
Bastion password `{bastion_ssh_password}`
. Run the following command to stop all VMs in the cluster
+
WARNING: This command will stop ALL VMs in the cluster, immediately and without warning.
+
----
oc get vms -A -oyaml | oc patch -f - --type='json' -p='[{"op":"replace", "path": "/spec/running","value": false}]'
----
