This demo showcases Red Hat OpenShift Container Platform as a comprehensive container management solution, covering the console experience, application deployment patterns, security controls, cluster operations, and observability tooling.

Presenters walk a technical audience through the OpenShift Console across five chapters, deploying applications via Operators and Helm, demonstrating security policies in action, triggering an over-the-air cluster upgrade, and correlating monitoring and logging signals using the Troubleshooting Panel — all on a live Single Node OpenShift cluster.

== Lab Details

Duration: ~235 minutes (full); presenters typically curate 2-3 chapters for a ~90-120 minute session

Difficulty: Beginner

== What You Will Learn

* Navigate OpenShift Console capabilities across multiple perspectives, including topology views, the embedded web terminal, the Software Catalog, quick starts, and user management
* Deploy applications on OpenShift using Operators (Crunchy PostgreSQL), Helm Charts (SQL Server), and existing containerized workloads (Online Boutique)
* See OpenShift's secure-by-default posture in action through Security Context Constraints, Role-Based Access Control, and NetworkPolicy enforcement
* Walk through cluster lifecycle operations, including a full-stack over-the-air upgrade, self-healing through continuous reconciliation, and AI-assisted troubleshooting with OpenShift Lightspeed
* Correlate cluster signals using Prometheus monitoring, LokiStack centralized logging, and the Troubleshooting Panel

== Products and Technologies

* Red Hat OpenShift Container Platform
* Red Hat OpenShift Lightspeed
* Red Hat OpenShift Logging / Loki Operator
* Red Hat Cluster Observability Operator
* Red Hat OpenShift GitOps (ArgoCD)

== Prerequisites

* Basic familiarity with containers and Kubernetes concepts
* No prior OpenShift experience required

== Environment

Presenters access a pre-provisioned Single Node OpenShift cluster with cluster-admin access and OpenShift Lightspeed pre-configured against Azure OpenAI Service. OpenShift GitOps is installed and bootstrapped so cluster-scoped resources are managed declaratively. During the relevant chapters, the presenter live-installs the Crunchy Postgres, Logging, Loki, and Cluster Observability operators from OperatorHub, and deploys the SQL Server and Online Boutique workloads via Helm.
