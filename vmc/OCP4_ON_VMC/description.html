OpenShift Container Platform 4 on VMware Cloud

This catalog item deploys OpenShift 4 on VMWare Cloud aka VMC (VMware SDDC that integrates vSphere, NSX and vSAN) for the purposes of running workshops for qualified opportunities.

Cluster Specification

  • Master Nodes: 3
  • Worker Nodes: 3

Access Guide

You have full admin access to the provisioned cluster and can find all details needed to access your cluster in the email that is generated after it is deployed by RHPDS. In addition there are 50 student accounts created which do not have cluster admin.
