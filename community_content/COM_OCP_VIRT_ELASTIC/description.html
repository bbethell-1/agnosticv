Practice installing Red Hat® OpenShift® 4 on RHDP's VMware Cloud Open Environment service.

This community catalog item enables installation of Red Hat OpenShift Container Platform 4 with User Provisioned Infrastructure (UPI). It is built on the VMware Cloud Open Environment service from RHDP.

The VMware Cloud Open Environment service provides a few things:

  • A bastion host running Red Hat Enterprise Linux® 8 on VMC, with SSH access via username/password.
  • vCenter portal access, with a sandbox user account. This user has limited access to a folder named Workloads/sandbox-${guid}
  • Wildcard DNS pointing to your bastion host with the record: *.${guid}.dynamic.opentlc.com

This content is designed to work within the constraints listed above while providing an experience of installing Red Hat OpenShift 4 in a VMware environment. Because the sandbox user has limited permissions, you cannot use Installer-Provisioned Infrastructure (IPI). You can, however, expect to gain an understanding of the install process and how to prepare for customer environments where granting the permissions required for IPI is not achievable.
