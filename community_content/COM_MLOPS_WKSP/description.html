Shows a Red Hat® solution pattern that implements key aspects of MLOps architecture

This demo is based on Red Hat OpenShift® Container Platform, and it incorporates various MLOps components using Red Hat technologies optimized for cloud-native use.

This demo is a Red Hat solution pattern that implements key aspects of a modern MLOps pipeline architecture. It provides an end to end solution for MLOps and covers all aspects of the pipeline right from Data engineering, ML model training and then deploying that ML model

The MLOps demo is provisioned in multiple steps, each step is run from a script contained in a git repo. The reason for separate git repos is that each one contains a core unit of work which can be used as a template for customizing specific requirements for your environment at a later date if required.

Duration: 60 minutes

Audience: Consultants, Architetcs, IT managers, Software Developers, VP operations

Products: Red Hat OpenShift Container Platform, Red Hat OpenShift Serverless, Red Hat AMQ (AMQ streams component based on Apache Kafka), Argo CD, Openshift Pipelines, Crunchy Postgres, Openshift Data Foundation, OpenShift Logging, Prometheus, Seldon, Red Hat Openshift Data Science, Sealed Secrets, OpenDataHub, Grafana, OpenShift GitOps and Elasticsearch

Supporting Materials

Please follow the instructions in https://github.com/rh-datascience-and-edge-practice/mlops-demo-getting- started.git to install the demo onto the cluster

Deploy the MLOps demo from the command line after logging into the Openshift cluster with oc login, as the admin, and run the following commands:

# git clone https://github.com/rh-datascience-and-edge-practice/openshift-cluster-bootstrap-gitops.git
# ./bootstrap.sh
# git clone https://github.com/rh-datascience-and-edge-practice/mlops-demo-tenant-gitops.git
# ./bootstrap.sh
# git clone https://github.com/rh-datascience-and-edge-practice/mlops-demo-application-gitops.git
# ./bootstrap.sh

Before running the script to start setting up the cluster, you will need a Sealed Secret to unlock existing sealed secrets needed for this demo. This file cannot be checked into git. If you do not have this file, you will need to obtain it from a member of the Red Hat Data Science and Edge Practice
