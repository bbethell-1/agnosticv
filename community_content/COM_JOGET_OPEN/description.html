Shows a Red Hat® solution pattern that implements key aspects of IoT/Edge architecture.

This demo is based on Red Hat OpenShift® Container Platform, and it incorporates various middleware components optimized for cloud-native use.

Bobbycar is a Red Hat solution pattern that implements key aspects of a modern IoT/Edge architecture in an exemplary manner.

Bobbycars are actually vehicle simulators, implemented in Quarkus, that simulate cars and send telemetry data to an IoT cloud gateway. The data is then used in different data processing flows for visualization, realtime analytics, and other use cases.

This architecture can serve as a foundation for an IoT/Edge or a Software Defined Vehicle Hybrid Cloud environment supporting various use cases such as OTA deployments, driver monitoring, AI/ML, and others.

Bobbycar aims to showcase an end-to-end workflow, from connecting in-vehicle components to the cloud backend, processing telemetry data in batch or as a stream, training AI/ML models and deploying containers through a DevSecOps pipeline, and by leveraging GitOps to the edge.

Note: The demo currently does not include AI/ML training and the DevSecOps pipeline.

Duration: 20 minutes

Audience: Enterprise architetcs, IT managers, VP operations

Products: Red Hat OpenShift Container Platform, Red Hat OpenShift Serverless, Red Hat build of Quarkus, Red Hat AMQ broker (MQTT), Red Hat AMQ (AMQ streams component based on Apache Kafka), Red Hat Fuse (Apache Camel-K), Red Hat Data Grid (distributed caching), Red Hat build of OpenJDK, Ionic Angular (Google Maps), and OpenWeather API (IBM Weather API)
