==== What can you do?

* Set up your blank Google Cloud environment to deploy a Red Hat OpenShift Dedicated cluster
* Deploy an OpenShift Dedicated cluster on Google Cloud
* Perform Day 1 and Day 2 operations.

==== Who is this for?
Red Hat associates who want to demonstrate or learn about the installation and day-2 operations of an OpenShift Dedicated cluster on Google Cloud.

==== Provisioning Time
Approximately 20 minutes

Once you are in the Google Cloud environment, it will take about 60 minutes to deploy OSD by following the step-by-step guide linked below.

==== Default lifetime of the environment
48 hours
