This community catalog item serves as an enablement for OpenShift 4 installation with User Provisioned Infrastructure (UPI). It's built on the VMware Cloud Open Environment service from RHDP.

The VMware Cloud Open Environment service gives us a few things:

  • A bastion host running RHEL8 on VMC, with SSH access via username/password.
  • vCenter portal access, with a sandbox user account. This user has limited access to a folder named Workloads/sandbox-${guid}
  • Wildcard DNS pointing to your bastion with the record: *.${guid}.dynamic.opentlc.com

    • This lab is designed to work within those constraints to offer participants the opportunity to build experience installing OpenShift 4 in a VMware environment. Because our sandbox user has limited permissions, we can't use Installer-Provisioned Infrastructure (IPI). On the bright side, this lab will give you a better understanding of the nuts and bolts of the install, and prepare you for customer environments where granting the permissions required for IPI is not achievable.

    To get started, order this service and head over to https://github.com/andykrohg/vmc-openshift-install-lab to view the labguide.
