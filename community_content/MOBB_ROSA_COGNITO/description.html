MOBB ROSA Workshop - 4 hour (pre-deployed with cognito idp)

Welcome to the Building a Modern Application Platform workshop which contains select labs designed to be able to be delivered within a 4 hour timeframe.

In this workshop you will learn about modern application platforms and managing them using Amazon Web Services (AWS) and Red Hat OpenShift Service on AWS (ROSA).

To reduce time this workshop has pre-deployed ROSA and configured AWS Cognito as the identity provider for the cluster.

This workshop includes labs on:

  • Managing ROSA compute resources using the ROSA cli
  • Deploying an application to ROSA using internal tooling
  • Limiting access to the application using NetworkPolicy
  • Extending the ROSA application platform through self-service
  • Using GitOps to manage an an application
  • (optional) Using OpenShift pipelines for CI/CD

Provisioning Time:

Approximately 1 hour 20 mins per environment
