This provides an environment to run the Telco CoE (Center of Excellence) AI use cases.
These are strategically designed to host and implement advanced Generative AI (Gen AI) solutions 
that empower field teams to proactively address customer requirements and optimize service delivery.

=== Use Cases

For a full active lists, please see the Telco CoE repository https://gitlab.consulting.redhat.com/coe-telco-ai-demos/gen-ai[here^]

=== Environment

* OpenShift 4.18
* OpenShift AI
* OpenShift GitOps

=== Deployment Time

~90 minutes

Workloads are controlled using GitOps.
