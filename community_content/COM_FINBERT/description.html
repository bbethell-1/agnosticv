FinBERT is a Intel Habana Gaudi and Red Hat OpenShift Data Science (RHODS) solution pattern that demonstrates high powered computing capabilities for AI/ML workloads.

The FinBERT demo utilizes Intel's Habana Gaudi processors accessed through AWS EC2 DL1 instances for a HPC cloud native approach that is accessible within the RHODS interface.

FinBERT is a BERT natural language processing model, trained using financial and economic text for financial sentiment classification. This demo is designed to show how fast and simple it is to train models using partnering technologies that are integrated into RHODS.

The goal of the FinBERT demo is to demonstrate how HPC impacts the model lifecycle. From training and creating the data set to modeling and inferencing, FinBERT shows how this is all possible within RHODS and how our partnership with Intel Habana Gaudi can impact model development for AI/ML workloads.

Audience: Data Scientists, Machine Learning Experts, Enterprise Architects, IT Managers, VP Operations

Duration: 30 minutes
