Provides a technical use-case series of labs to showcase everything that differentiates Red Hat OpenShift AI and makes it unique.

== Products

- A Single Node OpenShift (SNO) deployed in AWS using a g6.8xlarge (32 cores, 128GB, 24GiB NVRAM L4 GPU)
- Red Hat Advanced Cluster Manager (ACM)
- Red Hat OpenShift AI (RHOAI)
- Red Hat OpenShift GitOps (ArgoCD)

== Lab Guide

Find a rendered version of the guide here: https://eformat.github.io/rhoai-roadshow-v2/#/

== Lab Overview

- Self contained labs designed to showcase a defined set of RHOAI features and noteworthy patterns that everyone is excited about
- The Modules are standalone and not interconnected
- Each Lab/Section is expected to take about an hour max each
- They are predominantly written wih Jupyter Notebooks and use a "Follow the bouncing ball" style of learning
