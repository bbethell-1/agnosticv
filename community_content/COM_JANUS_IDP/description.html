OpenShift Janus IDP Demo provides an OpenShift cluster with basic customizations on AWS infrastructure for showcasing the Janus Project and an MVP Internal Developer Platform.

This demo is suitable for pre-sales situations for customers that are interested in Backstage/Janus IDP.

Cluster Specification

  • 3 Masters Nodes (AWS instance type: m5a.2xlarge)
  • Number of nodes dependant on the size ordered (AWS instance type: m5a.4xlarge)
  • Cluster Version: 4.12.x
  • Authentication Enabled (htpasswd - refer to your provisioning e-mail for details)
  • Let's Encrypt Certificates enabled on Ingress Controllers
  • Red Hat SSO for authentication (providing SSO for OpenShift and Backstage)
  • OpenShift pipelines as pipeline orchestrator
  • Hashicorp Vault for secret management
  • OpenShift gitops for infrastructure as code.
  • Backstage for IDP portal
  • OpenShift Dev Spaces for supporting the Inner Loop

Setup Instructions

This is a community demo, so after the cluster provisioning the demo itself is not ready. Once the cluster is provisioned, continue with the configuration by following the instructions.
