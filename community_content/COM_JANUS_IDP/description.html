Provides a Red Hat® OpenShift® cluster on AWS that showcases the Janus Project and an MVP IDP.

This demo is suitable for pre-sales situations where customers are interested in Backstage/Janus IDP. It provides a Red Hat OpenShift cluster with basic customizations on AWS infrastructure.

Specifications

  • 3 leader nodes (AWS instance type: m5a.2xlarge)
  • Number of nodes dependant on the size ordered (AWS instance type: m5a.4xlarge)
  • Cluster version: 4.12.x
  • Authentication Enabled (htpasswd - refer to your provisioning email for details)
  • Let's Encrypt Certificates enabled on Ingress controllers
  • Red Hat's single sign-on technology for authentication (provides SSO for Red Hat OpenShift and Backstage)
  • Red Hat OpenShift pipelines as the pipeline orchestrator
  • HashiCorp Vault for secret management
  • Red Hat OpenShift GitOps for infrastructure as code
  • Backstage for the IDP portal
  • Red Hat OpenShift Dev Spaces for supporting the Inner Loop
