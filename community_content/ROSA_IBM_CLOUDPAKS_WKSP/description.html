ROSA IBM Cloudpak for Integration Workshop

Note:

This Workshop depends on the following external requirements,

  • The CloudPak for integration module links to an external git repository which is not managed by Red Hat
  • An IBM entitlement key for CloudPak (you will need an IBM partner account login for this)
Please ensure that these are met prior to provisioning this demo. For more information please contact mobb-apac@redhat.com

Welcome to the Building a Modern Application Platform workshop. In this workshop you will learn the building blocks of modern application platform and leverage Amazon Web Services (AWS) and Red Hat OpenShift Service on AWS (ROSA) to deploy CloudPak for Integration on a modern application platform.

Who this workshop is for: This workshop is aimed at Platform Engineers, DevOps Engineers, CLoud Operations, Architects, and Developers who will use IBM workloads on their application platforms.

What to expect: During the workshop, we will take you through a series of hands on exercises to help you understand some of the concepts of deploying IBM CloudPak for integration on ROSA.

Attendees will learn:

  1. How to deploy a Red Hat OpenShift Service on AWS (ROSA) cluster
  2. Complete Day 2 operations such as scaling the cluster to ensure there are adequate compute resources to run IBM CloudPak for Integration.
  3. Configure ROSA for RWX storage in the form of cloud-native Elastic File System (EFS).
  4. Deploy IBM CloudPak for Integration
After completing this workshop, attendees will understand the concepts of modern application platforms, and will have deployed IBM CloudPak for Integration.

Provision Duration
