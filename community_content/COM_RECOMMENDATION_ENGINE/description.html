Solution Pattern: Recommendation Engine using Event Streaming

Streaming data is the continuous flow of real-time information, and the foundation of the event-driven architecture software model. Modern applications can use streaming data to enable data processing, storage, and analysis.

Businesses can use large, fast-moving data sets to build a system that can respond to the data in real-time. This solution pattern deals with building an event streaming platform using Red Hat AMQ Streams based on Apache Kafka to track user activity on an ecommerce website so as to find out the most popular products in the store.

Duration: Typically 40 minutes for the OCP cluster, plus 20 minutes for the Ansible playbook.

Audience: Enterprise architects, Solution Architects, Developers

Products:

  • Red Hat AMQ Streams/Apache Kafka

  • Red Hat OpenShift

  • Red Hat build of Quarkus

    • Quarkus

To deploy the Solution Pattern:

  • What you need on your workstation:
    • oc OpenShift CLI (v 4.13)
    • Ansible CLI (tested with v2.9), with Ansible kubernetes.core module
    • git
  • In a terminal, log in with oc into the OpenShift cluster as user admin (or another user with cluster-admin privileges.)
  • Run the following commands: 
        
$ https://github.com/rh-solution-pattern-event-streaming/ansible.git
$ cd ansible
$ ansible-playbook playbook.yml

Refer to the installation prerequisites for more details.
