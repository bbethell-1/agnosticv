A Red Hat® solution pattern which shows how API Management and Service Mesh are complementary technologies and can be used together to deliver a complete service management architecture.

App modernization resulting in cloud-native technologies need a way to manage their services. Service mesh provides well defined management of service-to-service communication.
Organizations are implementing strategies to manage their APIs so they can respond to rapid changes in customer demands. An API management solution allows secure access to their services and APIs, so that the internal teams and external partners and clients can access these APIs in a structured way.

Refer to Solution Pattern: Comprehensive Service Architecture with API Management and Service Mesh for a detailed discussion of this solution pattern.

Duration: Typically 40 minutes for the OCP cluster, plus 20 minutes for the Ansible playbook.

Audience: Enterprise architects, Developers

Products: Red Hat OpenShift Container Platform, 3scale API Management, OpenShift Service Mesh

Supporting Materials

To deploy the Solution Pattern:

  • What you need on your workstation:
    • oc OpenShift CLI (v 4.12)
    • Ansible CLI (tested with v2.9), with Ansible kubernetes.core module
    • git
  • In a terminal, log in with oc into the OpenShift cluster as user admin (or another user with cluster-admin privileges.)
  • Run the following commands: 
        $ git clone https://github.com/redhat-servicemesh-apim-demo/3scale-OSSM-TravelDemo-Playbooks
    $ cd 3scale-OSSM-TravelDemo-Playbooks/ansible
    $ ansible-playbook playbooks/install.yml -e"ACTION=install"
Refer to the installation instructions for more details.
