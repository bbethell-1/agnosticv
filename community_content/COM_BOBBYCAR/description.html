Bobbycar is a Red Hat solution pattern that implements key aspects of a modern IoT/Edge architecture in an exemplary manner

This demo is based on Red Hat’s Kubernetes Distribution, Red Hat OpenShift Container Platform, and uses various middleware components optimized for a cloud-native usage.

Bobbycars are actually vehicle simulators implemented in Quarkus, simulating cars and sending telemetry data to an IoT Cloud Gateway. The data is then being used in different data processing flows for visualization, realtime analytics, and other use cases.

Duration: 20 minutes

Audience: Enterprise Architetcs, IT Managers, VP Operations

  • This architecture can serve as a foundation for an IoT/Edge or a Software Defined Vehicle Hybrid Cloud environment supporting various use cases like OTA deployments, Driver monitoring, AI/ML and others*.
  • Bobbycar aims to showcase an end-to-end workflow, from connecting In-Vehicle components to the cloud backend, processing telemetry data in batch or as stream, training AI/ML models and deploying containers through a DevSecOps pipeline and by leveraging GitOps to the edge*.

Deploy Bobby Car:

From the bastion host, as root, run the following commands: 
# git clone https://github.com/sa-mw-dach/bobbycar.git
# ./bobbycar/install.sh
