Dotnet Showcase on OpenShift

The demo showcases how to deploy *Dotnet application* on OpenShift. This demo takes a standard microsoft dotnet reference architecture and shows how to deploy it on OpenShift. This demo shows both s2i and docker strategies to deploy the dotnet artifacts on Openshift.

*Duration:* Typically 40 minutes for the OCP cluster, plus 10 minutes for the Ansible playbook.

*Audience:* Enterprise architects, Developers

*Products:* Red Hat OpenShift Container Platform

===== Supporting Materials

* What you need on your workstation:
** oc OpenShift CLI (v 4.12)
** git
* In a terminal, log in with oc into the OpenShift cluster as user admin (or another user with cluster-admin privileges.)
