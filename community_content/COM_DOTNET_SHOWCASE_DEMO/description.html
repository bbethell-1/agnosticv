Shows a Red Hat® solution pattern for scenarios where services integration must happen through data integration without impact to the existing stack.

The architecture demonstrates how the Change Data Capture (CDC) design pattern and event-driven architectures supports the extension of existing capabilities with no changes to legacy apps where new features can be delivered by cloud-native microservices and can deliver with zero impact new search capabilities through the integration of legacy and new services with specialized search index services.

Refer to Solution Pattern: Using Change Data Capture for Stack Modernization for a detailed discussion of this solution pattern.

Duration: Typically 40 minutes for the OCP cluster, plus 10 minutes for the Ansible playbook.

Audience: Enterprise architects, Developers

Products: Red Hat OpenShift Container Platform, Red Hat Build of Quarkus, Red Hat AMQ Streams, Debezium, Red Hat Fuse (Apache Camel), PostgreSQL, ElasticSearch

To deploy the Solution Pattern:

  • What you need on your workstation:
    • oc OpenShift CLI (v 4.12)
    • Ansible CLI (tested with v2.9), with Ansible kubernetes.core module
    • git
  • In a terminal, log in with oc into the OpenShift cluster as user admin (or another user with cluster-admin privileges.)
  • Run the following commands: 
        $ git clone https://github.com/solution-pattern-cdc/ansible.git
    $ cd ansible
    $ ansible-playbook playbooks/install.yml
Refer to the installation prerequisites for more details.
