DEMO Info:

  • Category: Middleware Solution Demos
  • Name: RHDM7-AMQ Streams: Real Time Event Decisioning
  • Short Description: Reacting to the Real-time Streaming Banking Events at Scale using Red Hat AMQ Streams and Red Hat Decision Manager
  • Long Description: Demo shows how real time events as they occur can be analyzed using Red Hat Decision Manager to produce the next best action for the customer. Red Hat AMQ Streams provides for the infrastructure for the streaming application. The demo makes use of kstreams to process the events and create meaningful decisions based on RHDM.
