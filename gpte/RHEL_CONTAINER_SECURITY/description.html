Run a hands-on, technical Red Hat Enterprise Linux (RHEL) container security workshop.

Overview

This demo provides an overview of the materials and context needed to run a hands-on, technical RHEL container security workshop. The workshop lets you explore the latest low-level features and technology in RHEL 8.4 while learning tangible lessons that can be applied to your job roles.

The lab was initially created for the 2016 Red Hat Summit and has evolved and been presented each year since then. It provides a hands-on introduction to container security using the container tools included with RHEL 8.4. It is intended to be performed as a series of self-paced exercises with instructor guidance. Topics include working with user namespaces, secure registries, isolation, SELinux, image inspection, building, and the podman API service.

Audience

This demo is intended for:

  • Developers of cloud-native applications
  • Architects with a technical background
  • System administrators

No prep work is required prior to peforming the demo. To complete this demo, you must have:

  • A basic understanding of working with Linux systems from the command line
  • A laptop with Chrome 73+, Firefox 60+, Edge 40+, or Safari 12+ installed
  • Fundamental working knowledge Linux containers is helpful but not required

For the lab described in the demo, instructors and lab assistants must have:

  • Basic familiarity with RHEL container tools (podman, skopeo, and buildah) and SELinux
  • Experience troubleshooting container-related failures.

Delivering the Lab

For the lab, students work at their own pace and ask questions when they get stuck. For the Introduction and Registry Configuration labs, students need two working registries. The other labs can be completed on the bastion host.
