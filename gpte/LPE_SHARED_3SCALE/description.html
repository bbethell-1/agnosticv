3Scale API Management on OpenShift 4.x

This catalog item provisions 3Scale API Management in a project on the shared RHPDS OpenShift 4.x Cluster. The operator is used to create a 3Scale API Mangement environment with a tenant installed along with a separate stage and production gateway. The default API (Echo API) will be deployed on the staging gateway at the end of the provisioning.

The final provisioning e-mail will have information on accessing 3Scale:

  • The URL and credentials of your Master, Admin and Tenant Admin portal
  • The URL for your stage and production 3scale gateways
