Provision a project with an operator and custom resource definitions in Red Hat Data Grid.

Using the latest product environment (LPE), this catalog item provisions the "lpe-datagrid-{{ guid }}" Data Grid project with the Red Hat Runtimes - Data Grid operator installed. All Data Grid definitions and applications are deployed within this namespace.

The project is instantiated with all the componentes that are needed to test Data Grid with a custom application.

The Data Grid custom resource definitions (CRDs) used to create the infrastucure are Infinispan and Cache.

The latest CSV file and channel will be installed for the operator.

The final provisioning email includes information on accessing the required applications. Please use your Red Hat Product Demo System (RHPDS) credentials if prompted to do so.
