OpenShift 4 Shadowman Sprint Demo

Description

The premise of open source is that all of us together are smarter than any one of us, and through collaboration and competition anything is possible! This is why Red Hat was created and has thrived, but is there anything collaboration cannot do? Come find out first hand and be part of an experiment as we collectively battle in real time and put this to the test. This demo will support hundreds of audience members working together through dissimilar input methods. This includes using taps on personal phone screens to natural language processing, and all translated simultaneously into the game. There will be multiple teams whose goal includes both being the first through an interactive maze, but also not being killed by the zombie that resides inside. The commands you issue (up, down, left, and right) to your avatar will be queued in an AMQ Streams topic and consumed by a Fuse route, which uses Decision Manager’s Drools engine to determine the consensus for each step based on the majority of the inputs received. The Fuse route will translate the consensus into an input for our game, which was built using a modified Unity game engine tutorial, running on the WebGL engine. Fuse will also cache consensus data in Data Grid, so we can perform useful analysis about the reliability of individual contributors, like how often they agreed with the consensus.

Business Value

This demo is an interactive, high speed implementation of the distributed consensus problem. Carrying applicability to use cases like clock synchronization, block chain, and smart power grids, distributed consensus addresses the problem of establishing agreement between individual contributors in the absence of a central authority. Powered by Red Hat technologies and solutions, our implementation incorporates a high-performance, scalable solution for fielding data from different input sources (AMQ Streams), a framework for interpreting and enriching that data (Fuse), an engine for executing high speed decisions at critical intervals (Decision Manager), and a distributed cache for performing real world analysis on data as it’s in motion (Data Grid).
