This demo shows how OptaPlanner/Business Optimizer can assign employees to working shifts, taking into account various constraints such as the employee's skills, contract and availability.

The demo comes with out-of-the-box datasets to optimize working schedule in various settings, for example a hospital, factory or a call center.

The demo is built around a back-end OptaPlanner solver engine deployed in Spring Boot and a React front-end application.
