Provision multiple projects with Red Hat Integration operators and other components.

Using the latest product environment (LPE), this catalog item provisions the following projects. For each project, the final provisioning email includes information on accessing the required applications. Please use your Red Hat Product Demo System (RHPDS) credentials if prompted to do so.

Red Hat Fuse

This catalog item provisions two projects:

  • The "lpe-fuse-camelk-{{ guid }}" Camel K project with the Red Hat Integration - Camel K operator installed. All Camel K integrations are deployed within this namespace.
  • The "lpe-fuse-{{ guid }}" Fuse project with the Red Hat Integration - Red Hat OpenShift API Designer, Fuse Console, and Red Hat Fuse Online installed. Red Hat Fuse image streams and templates are deployed to this project. All Source-to-Image (S2I) projects utilizing Red Hat Fuse image streams and templates use this project.

The latest CSV and channel are installed for each operator above. Red Hat Fuse v.7.10.1 image streams and templates are available for use.

Red Hat AMQ Online

This catalog item provisions the "lpe-amq-online-{{ guid }}" Red Hat AMQ Online project with the Red Hat Integration - AMQ Online operator installed. All Red Hat AMQ Online definitions and applications are deployed within this namespace.

The project is instantiated with all the components that are needed to test Red Hat AMQ Online with a custom application.

The Red Hat AMQ Online custom resource definitions (CRDs) used to create the infrastucure are AuthenticationService, StandardInfraConfig, AddressPlan, AddressSpacePlan, AddressSpace, Address, and MessagingUser.

The latest CSV and channel are installed for the operator. Red Hat AMQ Online v.1.7.0 is available for use.
