Create a quota in our shared cluster and create projects and apps within those parameters. There is not a guide to follow, just be creative and keep in mind you don't have admin access to shared clusters. Enjoy!

Accessing the shared cluster:
  • The Web Console URL for this cluster is https://console-openshift-console.apps.shared-na46.openshift.opentlc.com/
  • The API URl for this cluster is https://api.shared-na46.openshift.opentlc.com:6443
You can use your OpenTLC/RHPDS User ID and Password to log into the cluster.
Guidance For Different OCP Versions:
  • If you need an OCP version other than 4.6 for Demo Purposes - Openshift 4.7 or 4.8 workshop are available in the RHPDS Catalog “Openshift Workshop” Folder with pre-configuration
  • Deploy your own version in the Red Hat Open Environments on AWS in the “Red Hat Open Environment” Catalog folder
