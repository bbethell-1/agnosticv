Provision the Quay Operator to create an instance of Red Hat Quay for running demos.

This catalog item provisions the Quay Operator in a project on the shared Red Hat Product Demo System (RHPDS) Red Hat OpenShift Container Platform 4.4 cluster. The Operator is used to create an individual instance of Red Hat Quay to run demos with.

The final provisioning email includes information on accessing Red Hat Quay:

  • The URL of your Red Hat Quay instance.
  • The super user ID and password. Note that users can self-register at the home page for Red Hat Quay, and they need to register as a super only for very specific tasks.

Product(s): Red Hat Quay
