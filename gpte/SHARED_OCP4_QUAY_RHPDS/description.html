Quay 3.3 on OpenShift 4.4

This catalog item provisions the Quay Operator in a project on the shared RHPDS OpenShift 4.4 Cluster. The operator is used to create an individual instance of Quay to run demos with.

The final provisioning e-mail will have information on accessing Quay:

  • The URL of your Quay Instance
  • The SuperUser user id and password
  • Note that users can self-register for Quay at the Quay Homepage and the super user should only be necessary for very specific tasks.
