Red Hat Enterprise Linux 9: Simple Desktop Application Management Using Flatpak

This course introduces Flatpak in Red Hat Enterprise Linux. We cover what it is, how it works and how to use it.

Current Labs

  • Define flatpak and terminologies related to flatpak
  • Install flatpak
  • Install, search, list, uninstall flatpak applications using flatpak command and GNOME
  • Understand unsupported uses of flatpak
