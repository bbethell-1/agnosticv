Set up Red Hat 3scale API Management on a cluster in Red Hat OpenShift Container Platform.

Using the latest product environment (LPE), this catalog item provisions 3scale API Management in a project on a shared OpenShift Container Platform 4.x cluster.

You use an operator to create a 3scale API Mangement environment with a tenant installed along with a separate stage and production gateway.

The default API, Echo API, is deployed on the staging gateway at the end of provisioning.

The final provisioning email includes information on accessing 3scale API Management:

  • The URL and credentials for your master, admin, and tenant admin portals
  • The URL for your stage and production 3scale API Management gateways

Product(s): Red Hat 3scale API Management
