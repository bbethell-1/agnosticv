Red Hat Integration on OpenShift 4.x

This catalog item provisions the following:

  • Fuse:-
  • A Camel K project, lpe-fuse-camelk-{{ guid }}, with the Red Hat Integration - Camel K operator installed. All Camel K integrations should be deployed within this namespace.
  • A Fuse project, lpe-fuse-{{ guid }}, with the Red Hat Integration - API Designer, Fuse Console and Fuse Online installed.
  • Red Hat Fuse image streams and templates will be deployed to the lpe-fuse-{{ guid }} project. All s2i projects utilizing Fuse image streams and templates should use this project.

The latest CSV and channel will be installed for each operator highlighted above. Fuse v7.10.1 image streams and templates will be available for use.

The final provisioning e-mail will have information on accessing the above applications. Please use your RHPDS credentials if prompted to do so.

  • AMQ Online:-
  • A Amq Online project, lpe-amq-online-{{ guid }}, with the Red Hat Integration - Amq Online operator installed. All AMQ Online definitions and applications should be deployed within this namespace.
  • The Amq Online project, lpe-amq-online-{{ guid }}, as instanciated all the componentes that are needed to test Amq Online with a custom application
  • The Amq Online CRD used to create the infrastucure were AuthenticationService, StandardInfraConfig, AddressPlan, AddressSpacePlan, AddressSpace, Address and MessagingUser

The latest CSV and channel will be installed for the operator highlighted above. Amq Online v1.7.0 will be available for use.

The final provisioning e-mail will have information on accessing the above applications. Please use your RHPDS credentials if prompted to do so.

  • AMQ Streams:-
  • A Amq Streams project, lpe-amq-streams-{{ guid }}, with the Red Hat Integration - Amq Streams operator installed. All AMQ Online definitions and applications should be deployed within this namespace.
  • The Amq Streams project, lpe-amq-streams-{{ guid }}, as instanciated all the componentes that are needed to test Amq Streams with a custom application
  • The Amq Streams CRD used to create the infrastucure were Kafka, KafkaTopic, KafkaUser

The latest CSV and channel will be installed for the operator highlighted above. Amq Streams v2.0.1 will be available for use.

The final provisioning e-mail will have information on accessing the above applications. Please use your RHPDS credentials if prompted to do so.

  • AMQ Broker:-
