OpenShift 4 Cluster (Hosted Control Plane) provisions an OpenShift cluster with basic customizations on AWS infrastructure. This particular catalog item deploys the OpenShift cluster using a Hosted Control Plane instead of dedicated control plane virtual machines.

This catalog item is beta!

For specialized workshops (such as Containers and Cloud-Native Roadshow, OpenShift Getting Started Workshops, etc.) please use the dedicated catalog item.

Cluster Specification

  • Cluster Version: 4.14.x
  • Hosted Control Plane on deployment cluster with Single Redundancy
  • 2 worker nodes of type m6a.2xlarge
  • Authentication Enabled (htpasswd - refer to the service info for details after provisioning has completed)
  • Operators deployed: Red Hat OpenShift Serverless, Red Hat OpenShift Gitops, Red Hat OpenShift Pipelines, cert-manager Operator for Red Hat OpenShift
  • Let's Encrypt Certificates enabled on Ingress Controllers

Access Guide

You have full admin access to the provisioned OpenShift cluster.

Provisioning Time?
~5 min - with another 10-15 minutes to stabilize after provisioning finishes.
