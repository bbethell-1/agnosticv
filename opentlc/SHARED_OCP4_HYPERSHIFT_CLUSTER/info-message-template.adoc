=== Access your OpenShift Cluster

OpenShift cluster console URL:
{shared-ocp4-hypershift-cluster--openshift_cluster_console_url}

[NOTE]
====
The NodePools need to finish provisioning and cluster operators need to stabilize after the cluster has been created.

Therefore it will take 10 to 15 minutes for the OpenShift console URL to be available after the catalog item has finished deploying!

Once the web console is available with proper certificates the environment is fully ready.
====
