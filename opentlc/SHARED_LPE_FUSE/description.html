Red Hat Fuse on OpenShift 4.x

This catalog item provisions the following:

  • A Camel K project, lpe-fuse-camelk-{{ guid }}, with the Red Hat Integration - Camel K operator installed. All Camel K integrations should be deployed within this namespace.
  • A Fuse project, lpe-fuse-{{ guid }}, with the Red Hat Integration - API Designer, Fuse Console and Fuse Online installed.
  • Red Hat Fuse image streams and templates will be deployed to the lpe-fuse-{{ guid }} project. All s2i projects utilizing Fuse image streams and templates should use this project.

The latest CSV and channel will be installed for each operator highlighted above. Fuse v7.10.1 image streams and templates will be available for use.

The final provisioning e-mail will have information on accessing the above applications. Please use your RHPDS credentials if prompted to do so.
