= Lab 06: Event-driven Ansible with OpenShift and Insights Demo

== Learning Objectives
* Understand the benefits of utilizing Event-Driven Ansible with Red Hat Insights.
* Enable compliance and vulnerability management driven by Insights.
* Use Ansible Automation Platform (AAP) with Event-Driven Ansible (EDA) to build remediation playbooks in Insights and execute them via AAP.

== Session Agenda

=== Introduction (10 Minutes)
* Customer Problem addressed.
* Overview of the session objectives.
* Lab details and common issues.

=== Module 01 (10 minutes)
* Explore the fundamentals of Event-Driven Ansible.
* Discuss new Event-Driven features in AAP 2.5.
* Explore Insights for compliance and vulnerability management and its connection as an event source for Event-Driven Ansible.

=== Module 02 (20 minutes)
* Create a rulebook with the Insights source plugin.
* Configure Insights notifications to trigger Event-Driven Ansible.
* Simulate a payload to test interactions.

=== Module 03 (30 Minutes)
* Create a remediation in Insights and sync it to the controller.
* Develop a playbook for automating remediation creation, managing inventories, and remediating issues.


=== Round-up Discussion (10 Minutes)
* Summary of activities.
* Open Q&A on customer interests and possible applications.

== Abstract
Event-Driven Ansible provides a way to automate mission-critical incidents and tasks. Vulnerability management driven by Red Hat Insights enables customers to understand infrastructure risks. Leveraging Ansible Automation Platform and Event-Driven Ansible, organizations can automate risk management at scale.

== Related Products
* Red Hat OpenShift
* Ansible Automation Platform
* Red Hat Insights
