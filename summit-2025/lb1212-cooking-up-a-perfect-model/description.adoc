== Introduction

These labs are being made available until May 31, 2025 with limited support.
If you believe this lab should remain after this time and would like to be involved with developing or supporting it, please contact nstephan@redhat.com.

In this Lab we add a Coding Assistant to Visual Studion Code, which will help us write better code by providing suggestions based on the context of our project.
We'll setup and use Granite 3 running on RHEL AI 1.2 for this purpose.

== What You'll Learn

* How to use RHEL AI 1.2 for coding assistance
** Download a Granite LLM
** Run it as a service on RHEL AI
* How to install Visual Studio Code <> extension
* How to configure the <> extenstion to use an External LLM
* How to write better code with the assistance of AI-powered coding assistant

== Environment Specifications

Your lab consists of

* `code` - a RHEL 9.4 development machine complete with Visual Studio Code
* `rhelai` - a RHEL 1.2 instance with an Nvidia L4 GPU
