Have you always wanted to take advantage of Insights, but been hampered by regulations that don't allow you to process data in Red Hat's Hybrid Cloud Console? Red Hat Insights is now available as an on-premise footprint for Red Hat Satellite customers.

This lab will let you have a hands-on walkthrough on two of the services of Insights on the Hybrid Cloud Console, then use the Advisor service inside of Satellite, then show you how to set up Insights On-Premise with an existing Satellite installation, allowing you to take advantage of recommendations that will improve the security, performance, and availability of your Red Hat Enterprise Linux hosts.

The lab presentation will walk through the architectural design, provide details on data flows and processing, and provide the knowledge you'll need to leverage Insights with this new footprint.
Anyone interested in using Insights to support Red Hat Enterprise Linux is encouraged to take this lab.
