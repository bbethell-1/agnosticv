. Log into the bastion:
+
----
ssh {bastion_ssh_user_name}@{bastion_public_hostname} -p {bastion_ssh_port}
----
+
Bastion password `{bastion_ssh_password}`
. Run the following command to stop all VMs in the cluster
+
WARNING: This command will stop ALL VMs in the cluster, immediately and without warning.
+
----
oc get vms -A -oyaml | oc patch -f - --type='json' -p='[{"op":"replace", "path": "/spec/running","value": false}]'
----
