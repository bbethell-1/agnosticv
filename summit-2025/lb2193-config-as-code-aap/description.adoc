== LB2193: Config as code for Red Hat Ansible Automation Platform 2.5 with Validated Collections

The Ansible Automation Platform Configuration as Code (CasC) is the way to maintain all your infrastructure. The approach provided in this lab will show how to use CasC to maintain every aspect of AAP. The given code will serve as a starting point and will walk you through the process of using and customizing it. Configuring the controller, private automation hub, execution environments, and creating workflows without the GUI will be covered in this lab, 

This approach will allow you to do version control, track changes, and automate the deployment of your infrastructure configurations. 

NOTE: This lab is suitable for anybody with intermediate Ansible Automation Platform and playbook writing experience.
