= LB2193: Config as Code for Red Hat Ansible Automation Platform 2.5 with Validated Collections

[NOTE]
====
This lab is part of *Red Hat Summit 2025* and will be available for a finite period with limited support.
====

Welcome to our interactive lab on using **Configuration as Code (CasC)** to configure the Ansible Automation Platform.

CasC is the way to maintain all your infrastructure. This lab provides code to demonstrate how to use CasC to maintain all aspects of AAP. The provided code will be a starting point and will guide you through how to utilize the code and make it your own.

This lab will cover:
- Configuring the controller
- Configuring the private automation hub
- Configuring execution environments
- Creating workflows without the GUI

These principles will help to:
- Prevent drift in configuration
- Allow changes to require approval before implementation
- Maintain both a development and production deployment
