== Red Hat Summit Lab 2656 - Intelligent Coding: Building a Code Assistant with Red Hat AI

In this Lab we add a Coding Assistant to Visual Studion Code, which will help us write better code by providing suggestions based on the context of our project. 
We'll setup and use Granite 3 running on RHEL AI 1.3 for this purpose.

== What You'll Learn

* How to use RHEL AI 1.3 for coding assistance
** Download a Granite LLM
** Run it as a service on RHEL AI
* How to install Visual Studio Code <> extension
* How to configure the <> extenstion to use an External LLM
* How to write better code with the assistance of AI-powered coding assistant

== Environment Specifications

Your lab consists of 

* `code` - a RHEL 9.4 development machine complete with Visual Studio Code
* `rhelai` - a RHEL 1.3 instance with an Nvidia L4 GPU

== Workshop Structure

1. Introduction to the Lab
** What is a Large Language Model?
** How are Large Language Models trained?
** How does this relate to InstructLab?

4. Conclusion

This workshop is designed for AI Architects and Application Engineers interested in leveraging AI in their applications and understanding the process of fine-tuning LLMs.
