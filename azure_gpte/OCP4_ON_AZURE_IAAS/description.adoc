Deploys OpenShift 4 on Microsoft Azure using the Full Stack Installation (IPI) method. This catalog item deploys Red Hat® OpenShift® Container Platform 4 on Microsoft Azure using the openshift-installer’s Full Stack Installation (IPI) method. This environment is intended for use when running workshops for qualified opportunities. IMPORTANT! READ AND UNDERSTAND THE https://red.ht/ocp4azureRHPDS[LAB GUIDE^] BEFORE DEPLOYING THE ENVIRONMENT.

*Products:* Red Hat OpenShift Container Platform 4

===== Specifications

* 3 leaders (D8s_v3), a customizable number of workers (D4s_v3, dependent on the user number entered in dialog).
* Cluster features: Persistent storage, HTpasswd authentication, Let's Encrypt certificates, and Terminal enabled.
* You can demonstrate upgrades.
* Regions: North America, Europe, and APAC

===== Supporting Materials

*Full documentation:* https://red.ht/ocp4azureRHPDS[Lab Guide^]

* Credentials for kubeadmin and other relevant information are in your final provisioning email.
* After ordering your environment, you can manage it by logging into this system and selecting Services -> My Services -> [This service] -> App Control.
* Your ordered environment will cease to run unless you use the Extend Runtime option in App Control.
* Your ordered environment will cease to exist at the time specified in the Expiration Date unless you use the Extend Lifetime option in App Control.
