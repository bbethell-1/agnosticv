= Parasol Insurance (On ARO) - Putting predictive and generative AI to work

Explore how the fictional insurance company Parasol is using OpenShift AI to improve its claims processing. 
During this immersive experience, you'll get to use and deploy different AI models, as well as use multiple features of OpenShift AI. 
You will get exposed to LLMs and RAG, Image Detection, as well as deploy the application that ties it all together.

[NOTE]: Wait for 10 to 15 minutes post deployment for ArgoCD to setup all the users and related workloads on the cluster.
