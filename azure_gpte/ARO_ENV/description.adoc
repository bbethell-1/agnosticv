Deploy ARO for Workshops or Demos. Formerly MOBB.

== Lab Guide

* https://github.com/rhpds/bookbag-aro-mobb/
* Branch: `showroom`

== Technical Specifications

* ARO Version PRIOR to current latest.
Example: Current latest ARO version is 4.13.23.  This deploys 4.12.25
* 1 bastion with Showroom
* 3 control plane nodes `Standard_D8s_v3`
* 3 computes nodes `Standard_D4s_v3`
