Build your own environment with an Azure subscription from our pool.

= Details

When you provision this OPEN Environment, your Red Hat account in the redhat0.onmicrosoft.com domain will be temporarily granted 'Contributor' access to a subscription from a pool in this domain.

You must use the assigned subscription for anything you do in Azure or you will get access denied errors.

When your OPEN Environment is deleted, your user will remain active in the organization but will no longer have access to the subscription and any resource groups in the subscription will be deleted.

= Azure Quotas

You can request quota increases directly from Azure via the Azure portal.
