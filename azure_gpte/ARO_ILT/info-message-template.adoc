
=== Azure Subscription

An Azure subscription was assigned to your Red Hat ID from Red Hat's pool of Azure subscriptions.

WARNING: When this OPEN environment is deleted, all resources will thoroughly deleted.
All data will be irrecovably removed.
Please regularly back up your data and script your changes in case you need to rebuild.
Please see this page for more information: https://www.opentlc.com/azure/openenv_documentation.html

=== Azure Portal Access: `az login`

Your Azure account should be SSO enabled, so please log into the portal with your Red Hat credentials.
https://portal.azure.com/

If this is your first time accessing the Azure portal, you will receive an invitation.

Simply enter `az login` to begin your login to the portal.
The `az` client will offer your a confirmation code.
Follow the link and use the confirmation code to enable association of the temporary subscription with your identity.

Your account now has full access to this subscription.

== ARO Clusters

Use the environment variables above.
`az login` will have you confirm your identity on the Azure portal.
Only then can you proceed with ARO cluster creation.

You'll to well to have your *OCP Pull Secret* in `$HOME/pull-secret.txt`.
=== ARO CLI Quickstart

Example ARO installation commands

[source,bash,subs="+macros,+attributes"]
----
az login

AZR_RESOURCE_LOCATION=eastus
AZR_RESOURCE_GROUP=openenv-{guid}
AZR_CLUSTER=cluster-{guid}
# bastion pull-secret.txt location
AZR_PULL_SECRET=/home/azure/pull-secret.txt
# mac pull-secret.txt location
AZR_PULL_SECRET=~/Downloads/pull-secret.txt

az provider register -n Microsoft.RedHatOpenShift --wait
az provider register -n Microsoft.Compute --wait
az provider register -n Microsoft.Storage --wait
az provider register -n Microsoft.Authorization --wait

az group create --name $AZR_RESOURCE_GROUP \
 --location $AZR_RESOURCE_LOCATION

echo "network create"
az network vnet create --address-prefixes 10.0.0.0/22 \
 --name "$AZR_CLUSTER-aro-vnet-$AZR_RESOURCE_LOCATION" \
 --resource-group $AZR_RESOURCE_GROUP

az network vnet subnet create --resource-group $AZR_RESOURCE_GROUP \
 --vnet-name "$AZR_CLUSTER-aro-vnet-$AZR_RESOURCE_LOCATION" \
 --name "$AZR_CLUSTER-aro-control-subnet-$AZR_RESOURCE_LOCATION" \
 --address-prefixes 10.0.0.0/23

az network vnet subnet create --resource-group $AZR_RESOURCE_GROUP \
 --vnet-name "$AZR_CLUSTER-aro-vnet-$AZR_RESOURCE_LOCATION" \
 --name "$AZR_CLUSTER-aro-machine-subnet-$AZR_RESOURCE_LOCATION" \
 --address-prefixes 10.0.2.0/23

az network vnet subnet update \
 --name "$AZR_CLUSTER-aro-control-subnet-$AZR_RESOURCE_LOCATION" \
 --resource-group $AZR_RESOURCE_GROUP --vnet-name "$AZR_CLUSTER-aro-vnet-$AZR_RESOURCE_LOCATION" \
 --disable-private-link-service-network-policies true

az aro create --resource-group $AZR_RESOURCE_GROUP --name $AZR_CLUSTER \
 --vnet "$AZR_CLUSTER-aro-vnet-$AZR_RESOURCE_LOCATION" \
 --master-subnet "$AZR_CLUSTER-aro-control-subnet-$AZR_RESOURCE_LOCATION" \
 --worker-subnet "$AZR_CLUSTER-aro-machine-subnet-$AZR_RESOURCE_LOCATION" \
 --pull-secret @$AZR_PULL_SECRET
----

Installation will take upwards of an hour.

See https://learn.microsoft.com/en-us/cli/azure/aro?view=azure-cli-latest for more information on using `az aro`
