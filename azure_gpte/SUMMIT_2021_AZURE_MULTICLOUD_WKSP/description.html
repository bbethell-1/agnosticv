This session will guide you through the process of building a cloud-native application that utilises two OpenShift clusters. You’ll get hands on experience using: Red Hat OpenShift Container Platform Red Hat OpenShift Service Mesh (Istio etc) Red Hat OpenShift Serverless (Knative & CamelK) Red Hat AMQ Streams (Apache Kafka)

After the session you’ll understand the benefits of using a Service Mesh for MicroServices, how to use CamelK for event-processing data from AMQ Streams, and how Knative can drive efficient resource utilisation on OpenShift Container Platform.
