Base RHODS on ARO (Azure Red Hat OpenShift)

This workshop creates Base RHODS environment on ARO (Azure Red Hat OpenShift) You can use this base environment for creating and running RHODS related use cases.

This workshop includes :

OpenShift Container Platform : 4.11.44

Red Hat OpenShift Data Science : Latest

OpenShift Pipelines: 1.10

Gitea Operator: 1.20.0

ARO - Azure Red Hat OpenShift

Access Information:

You will receive an email with both the cluster admin credentials as well as administrative credentials and the URL to access Red Hat OpenShift Data Science portal.

Provisioning Time:

Approximately 1 hour
