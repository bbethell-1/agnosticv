Azure Blank Open Environment


This catalog item provisions an Azure Blank Azure Open Environment
If you have never used the RHPDS/OPEN Azure org, you will recieve an email inviting you to it. You will need to accept the invitation.
When you provision an OPEN Environment, a Resource Group is created that has the environment's GUID in the name. Everything you create must be in this resource group. If you do not do this, you will get access denied errors.
When your OPEN Environment is deleted, your user will remain active in our organization but will no longer have access to any resource groups. To get a new resource group, you must order a new open environment. You will not need to accept an invitation again.
When your OPEN Environment is deleted, the resource group is removed. This will clean up all resources you have deployed in your OPEN Environment and they will not be recoverable.
Please refer to the Microsoft Azure documentation for any other questions on how to use Azure.
