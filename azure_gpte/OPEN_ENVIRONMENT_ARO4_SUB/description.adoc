== Azure Red Hat OpenShift Workshop Environment

This catalog item deploys an https://docs.microsoft.com/en-us/azure/openshift/intro-openshift[Azure Red Hat OpenShift (ARO)] cluster for the purpose of running workshops for qualified opportunities.

[IMPORTANT]
====
*READ AND UNDERSTAND THE LAB GUIDE BEFORE DEPLOYING.*
Lab Guide Available at: https://red.ht/ARORHPDS
====

=== Environment Specifications

* **Cluster Size:** 3 master nodes (Standard_D8s_v3) and 3 worker nodes (Standard_D4s_v3).
* **Available Regions:** North America, Europe, APAC.

=== Environment Lifespan

* **Default Lifespan:** 2 Days
* **Extensions Available:** Yes
* **Idle Policy:** The environment does not idle.

=== Accessing the Environment

Once your order is successfully provisioned, you will receive a confirmation email. This email contains all the necessary links to get started.

Cluster web console credentials are provided in the Lab Guide.
