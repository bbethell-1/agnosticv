In this hands-on lab, we'll introduce you to some advanced capabilities of automation controller so can benefit even more from using Ansible Automation Platform.
This lab is suitable for anybody with basic Ansible Automation Platform experience.

=== Lab Content

* Automate the automation: Configure automation controller resources with Ansible 
* Use Controller workflows to allow teams to work more efficiently together 
* Learn about the new RBAC system introduced with 2.6 
* Create a Self-Service experience for your automation users 
* Learn how to use dynamic inventories to scale your automation 
* Experience how the constructed inventory feature enables more flexibility 
* Secure automation supply chain: Use content signing to make sure only approved content is run in automation controller 
* Ensure compliance with the new Policy Enforcement feature 

NOTE: You will receive a customized lab guide. You can also find a https://rhpds.github.io/adv-feature-of-aap-showroom/[generically rendered version of the guide^] for a sneak peek.

=== Products

* Ansible Automation Platform 2.6

~30 minutes
