Ansible Automation Platform's advanced capabilities enable teams to scale automation delivery, enforce governance, and build self-service experiences across the enterprise. This hands-on lab is ideal for anyone with basic AAP experience who wants to expand their automation skills using the latest AAP features including the unified UI, Self-Service Automation Portal, and Policy Enforcement.

== Featured Technology and Products

* Ansible Automation Platform
* Automation Execution (formerly Automation Controller)
* Self-Service Automation Portal (SSAP)
* Open Policy Agent (OPA)

== Detailed Overview

* *Introduction to Unified UI*
** Navigate the new AAP unified interface
** Understand the shift from Automation Controller to Automation Execution terminology

* *Configure Resources with Ansible*
** Configure automation execution resources programmatically with Ansible
** Employ workflows so teams can collaborate more efficiently

* *Self-Service and Access Control*
** Use surveys and the revamped RBAC system for self-service access
** Use dynamic inventories and constructed inventories to scale automation

* *Supply Chain Security and Policy Enforcement*
** Secure the automation supply chain with content signing
** Enforce enterprise policies using the AAP Policy Enforcement feature and OPA

* *Self-Service Automation Portal (SSAP)*
** Explore the new SSAP RHEL appliance
** Build self-service automation experiences for end users
