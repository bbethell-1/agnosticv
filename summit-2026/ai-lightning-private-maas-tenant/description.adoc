== Information

This is the tenant CI for the Private Model as a Service lightning lab. It provisions per-user namespaces, Showroom content, and tenant-level workloads on a shared OpenShift cluster.

== Featured Technology and Products

* Red Hat OpenShift AI
* Red Hat OpenShift Container Platform
* Llama Stack
* Private Model as a Service (MaaS)
