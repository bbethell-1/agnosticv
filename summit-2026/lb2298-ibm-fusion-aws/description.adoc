IBM Fusion integrated with Red Hat OpenShift Virtualization provides enterprise-grade storage and data protection for virtual machine workloads on OpenShift. This hands-on workshop teaches architects, SREs, and infrastructure engineers how to modernize virtualization using OpenShift Virtualization backed by IBM Fusion storage — covering VM lifecycle operations, live migration, persistent storage management, and backup and restore using IBM Fusion Recipes.

== Detailed Overview

* *Module 1: Exploring the Environment*
** Familiarize with the OpenShift Virtualization and IBM Fusion console
** Review pre-deployed storage classes and IBM Fusion Administration Console

* *Module 2: VM Lifecycle Management*
** Create and manage virtual machines on OpenShift Virtualization
** Work with IBM Fusion-backed persistent storage for VM workloads

* *Module 3: VM Live Migration*
** Perform live VM migrations across cluster nodes
** Validate zero-downtime migration with IBM Fusion storage

* *Module 4: IBM Fusion Backup and Restore*
** Create application-consistent backups using IBM Fusion Recipes
** Restore virtual machines and validate data integrity after recovery
