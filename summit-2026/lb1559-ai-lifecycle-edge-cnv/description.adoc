Red Hat OpenShift AI and Red Hat Device Edge enable a complete AI/ML lifecycle at the edge for autonomous vehicle battery management. This demo showcases how AI and edge computing address real-world challenges in resource-constrained environments using lightweight platforms such as Single Node OpenShift (SNO) and MicroShift. Learners deploy AI inference servers on MicroShift, configure Red Hat OpenShift AI for model retraining on SNO, build automated data science pipelines, and enable model monitoring with TrustyAI.

== Detailed Overview

* *AI & Edge Use Case*
** Explore a real-world automotive battery management scenario for autonomous vehicles
** Understand edge computing strengths and challenges for AI workloads
** Review the end-to-end architecture spanning MicroShift and SNO

* *Autonomous Vehicle Infrastructure*
** Deploy MinIO object storage and AI models using GitOps on MicroShift
** Configure KServe inference servers for stress detection and time-to-failure prediction
** Deploy the Battery Monitoring System with real-time telemetry and alerting

* *RHOAI Configuration and Model Training*
** Install Red Hat OpenShift AI and configure KServe RawDeployment mode with TrustyAI
** Create data science projects, workbenches, and data connections to vehicle storage
** Train and validate stress detection and time-to-failure models using Jupyter notebooks

* *Model Serving and Pipeline Automation*
** Deploy model serving endpoints on SNO and query inference APIs
** Import and execute Kubeflow retraining pipelines with automated model comparison
** Schedule recurring pipeline runs for continuous model improvement

* *Model Monitoring*
** Enable TrustyAI for bias detection and data drift monitoring
** Configure Prometheus user workload monitoring for model observability
