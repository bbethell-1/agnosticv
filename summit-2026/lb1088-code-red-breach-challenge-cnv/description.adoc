= LB1088: Code Red: The Breach Challenge!

== Overview

This workshop offers a fun, hands-on experience to explore and learn
DevSecOps concepts in a low-pressure, high-energy environment.

Structured as a gamified experience, this Capture-The-Flag game proposes
an immersive investigation into the simulated security breach of an
application running on OpenShift.

Applying their current skills, participants will discover product features
and capabilities and get to know security best practices on the go while
having fun competing against each other and against the clock.

== Featured Products and Technologies

* Red Hat OpenShift Container Platform 4.20
* Red Hat OpenShift GitOps (ArgoCD)
* Red Hat OpenShift Pipelines (Tekton)
* Red Hat Advanced Cluster Security for Kubernetes (RHACS)
* Red Hat Trusted Artifact Signer (RHTAS)
* Red Hat Trusted Profile Analyzer (TPA)
* SonarQube
* Gitea

== Workshop Details

* *Event*: Red Hat Summit 2026
* *Lab Code*: LB1088
* *Duration*: Approximately 2 hours
* *Format*: Hands-on, gamified Capture-The-Flag
* *Audience*: Developers, DevOps Engineers, Security Professionals

== Learning Objectives

Participants will:

* Investigate a simulated security breach
* Discover DevSecOps product capabilities
* Learn security best practices
* Apply skills in a competitive, time-based challenge
