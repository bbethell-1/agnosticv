Code Red: The Breach Challenge is a gamified, hands-on Capture-The-Flag workshop where participants step into the role of a DevSecOps expert investigating a simulated security breach of a cloud-native application on OpenShift. Structured as a competitive game with a Main Quest (6 sequential missions) and a Side Quest (2 parallel missions), the challenge teaches real-world attack vectors in CI/CD pipelines, secret management failures, and container supply chain vulnerabilities. Participants use Red Hat security tools to investigate, replicate the breach, and ultimately contain the attacker — all while competing against the clock and each other.

== Detailed Overview

* *Mission Briefing*
** Step into the role of a DevSecOps expert investigating a real-world-style breach
** Replicate the attacker's actions to rebuild the malicious application and trace the intrusion path
** Understand the Poisoned Pipeline Execution (PPE) attack pattern in CI/CD environments

* *Game Rules & Scoring*
** Navigate a Point Zero recon mission (optional), 6 sequential Main Quest missions, and 2 parallel Side Quest missions
** Collect flags by exploiting security weaknesses — credentials, IP addresses, and sensitive artifacts
** Compete on a live leaderboard; estimated completion time is 2 hours

* *Getting Started & Environment Setup*
** Access OpenShift cluster with RHACS, Pipelines, Gitea, and a Quarkus-based target application pre-deployed
** Navigate the environment using the lab guide embedded in Showroom
** Use provided credentials to begin reconnaissance across the CI/CD stack

* *Reference & Tools*
** Consult the corporate security standards and pipeline/webhook configuration docs
** Use the REST client and application architecture reference for the target Customers API
** Learn about PPE attack background before launching investigations

* *Conclusion*
** Debrief on security principles discovered: defense in depth, least privilege, secure CI/CD, and secret management
** Review how each mission mapped to a real-world attack vector
** Understand how to prevent similar breaches using the Red Hat security portfolio
