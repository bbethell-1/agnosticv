== Important Notes

* *CTF Challenge*: This is a Capture-The-Flag competition - explore the environment to find security issues!
* *Time Limit*: Challenges are time-based, so work efficiently
* *Collaboration*: While competitive, feel free to discuss approaches with other participants
* *Resources*: Use the Showroom guide for instructions and hints

1. Access the Showroom lab guide (link above)
2. Log into OpenShift with your user credentials
3. Follow the CTF scenario instructions
4. Investigate, discover, and capture the flags!
