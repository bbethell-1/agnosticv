== Detailed Overview

Accelerate your journey from code to cloud with AI-powered modernization tools in the Red Hat Advanced Developer Suite. This hands-on demo showcases how to leverage OpenShift Lightspeed, Migration Toolkit for Applications (MTA), OpenShift Virtualization, and Dev Spaces to modernize legacy applications at unprecedented speed.

Learn how AI-assisted development accelerates application migration, containerization, and deployment on OpenShift, enabling developers to focus on innovation rather than manual refactoring.

Key technologies demonstrated:

* **Migration Toolkit for Applications (MTA 8)**: Analyze and migrate legacy applications with AI-powered insights
* **OpenShift Dev Spaces**: Cloud-native development environments with integrated tooling
* **OpenShift Virtualization**: Run VMs alongside containers for hybrid modernization scenarios
* **OpenShift GitOps**: Automated deployment and lifecycle management
* **Gitea**: Lightweight Git service for source code management
