== What Gets Deployed

* *Keycloak SSO* -- OpenShift authentication with per-user accounts
* *ArgoCD (OpenShift GitOps)* -- App of Apps bootstrap for all components
* *OpenShift AI 3* -- Dashboard, pipelines, workbenches, model serving

This AWS variant runs on Amazon Web Services infrastructure for cloud-native AI agent operations.
