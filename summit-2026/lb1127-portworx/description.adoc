== LB1127: Unifying VMs and Containers on Red Hat OpenShift with Portworx

Portworx Data Platform manages persistant storage in an OpenShift 4 cluster. This hands-on lab provides a Portworx deployment on OpenShift Container Platform and covers the following topics
with a focus on using Portworx for either containerized or virtualized workloads.

* Portworx and OpenShift Container Platform integration
* Portworx OpenShift Operator
* Application deployments
* Live migrations
* VM snaphots
