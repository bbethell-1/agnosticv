= LB2010 - RHADS & OLS Modernization

== Overview

This workshop provides a hands-on experience with application modernization using Migration Toolkit for Applications (MTA) 8, enhanced with AI-powered assistance from Red Hat Advanced Developer Suite (RHADS) and OpenShift Lightspeed (OLS).

== What You'll Learn

* Application analysis and migration planning with MTA 8
* AI-assisted code modernization using OpenShift Lightspeed
* Developer productivity with Red Hat Advanced Developer Suite
* Container migration workflows using OpenShift Virtualization
* GitOps-based deployment strategies with OpenShift GitOps
* Modern development workflows with Red Hat Dev Spaces

== Workshop Components

This workshop includes:

* *Migration Toolkit for Applications (MTA) 8* - Analyze and migrate legacy applications
* *OpenShift Lightspeed (OLS)* - AI-powered assistance for OpenShift operations
* *Red Hat Dev Spaces* - Cloud-native development environment
* *OpenShift GitOps* - GitOps-based application delivery
* *OpenShift Virtualization* - VM-based workload migration
* *Gitea* - Git repository management
* *Keycloak* - Identity and access management
* *LiteLLM Virtual Keys* - AI model access and management

== Architecture

This catalog item uses a *tenant/namespace-based architecture* running on shared pre-provisioned OpenShift clusters. Each user receives isolated namespaces with dedicated resources for hands-on exercises.

=== Multi-User Support

* Supports 2-40 concurrent users
* Per-user namespace isolation
* Dedicated Dev Spaces workspaces
* Individual Gitea repositories
* Keycloak-based authentication

== Prerequisites

* Basic understanding of Kubernetes/OpenShift
* Familiarity with container concepts
* Basic Git knowledge
* Web browser with internet access
