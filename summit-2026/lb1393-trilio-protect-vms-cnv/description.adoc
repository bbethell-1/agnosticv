Trilio for Kubernetes provides enterprise-grade backup and recovery for virtual machines on Red Hat OpenShift Virtualization. This hands-on workshop demonstrates key data protection workflows — VM backup creation, point-in-time restore, and OpenShift API for Data Protection (OADP) integration — all through the OpenShift Console without any installation steps required.

* Red Hat OpenShift Container Platform

== Detailed Overview

* *VM Backup with Trilio*
** Create consistent VM backups using Trilio's interface in the OpenShift Console
** Configure backup policies and retention settings for VM workloads

* *VM Restore and Recovery*
** Restore VMs with minimal downtime and data loss from Trilio snapshots
** Validate data integrity after recovery operations

* *OpenShift API for Data Protection (OADP)*
** Leverage OADP for Kubernetes-native backup orchestration
** Integrate Trilio with OpenShift's data protection framework

== Target Audience

Platform engineers, virtualization admins, and OpenShift practitioners looking to implement robust data protection for VM-based workloads.
