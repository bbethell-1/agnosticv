== Information

Combined CI for Demystifying AAP on OCP (LB1216). Provisions an OCP cluster,
cluster-level workloads, and per-user AAP + tenant workloads using the
multi-tenant loop bridge role.

== Featured Technology and Products

* Red Hat Ansible Automation Platform
* Red Hat OpenShift Container Platform
