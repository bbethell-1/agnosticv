== Information

Combined CI for Private Model as a Service (LB2860). Provisions an OCP cluster,
cluster-level workloads, and per-user namespaces with Showroom content and
tenant-level workloads using the multi-tenant loop bridge role.

== Featured Technology and Products

* Red Hat OpenShift AI
* Red Hat OpenShift Container Platform
* Llama Stack
* Private Model as a Service (MaaS)
