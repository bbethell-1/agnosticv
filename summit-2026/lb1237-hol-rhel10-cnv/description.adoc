= LB1237: The Definitive Red Hat Enterprise Linux 10 Hands-On Lab

This hands-on lab provides direct, practical experience with Red Hat Enterprise Linux 10 through a structured series of self-paced and guided exercises. Attendees work across fundamental, intermediate, and advanced skill levels — covering core system administration capabilities alongside key new features introduced in RHEL 10. Each exercise is designed to build real familiarity with the platform in 10 to 15 minutes, using official Red Hat software running on live RHEL 10 systems.

== Detailed Overview

Exercises are organized into three learning paths:

*RHEL 10 Spotlight* — Covers the most significant capabilities new or enhanced in RHEL 10, including RHEL Lightspeed, Image Mode (bootc), Image Builder, Web Console, and in-place upgrades via Leapp.

*All Exercises by Skill Level* — Three tiers: Fundamentals, Intermediate, and Advanced. Covers package management, storage, services, containers, virtualization, and troubleshooting.

*All Exercises by Category* — Same exercises organized by functional area for topic-focused navigation.

Each unit is independent and completes in 10 to 15 minutes. The lab uses only official Red Hat software.
