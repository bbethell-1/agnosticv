= LB2863 - Unlocking OpenShift's Full Value - Using Application Platform Capabilities (Tenant)

== Lab Overview

You've invested in Red Hat OpenShift—now it's time to unlock its full value. This hands-on lab is tailored for customers using Red Hat OpenShift primarily for container management and missing out on the platform's advanced capabilities. We will focus on the core "application platform" features such as OpenShift Dev Spaces, OpenShift Application Runtimes, OpenShift Pipelines, and builds. By the end of this session, you will know how to use these advanced features you already own to bring return on investment (ROI)—accelerating development, enhancing security, and turning your platform into an engine for cloud-native application modernization.

== Tenant Structure

This catalog item deploys **per-user application platform workloads** for the LB2863 lab. It uses the **tenant pattern** which:

* Runs on a shared, pre-provisioned OpenShift cluster (no cluster provisioning)
* Creates isolated namespaces for each user
* Deploys user-specific resources and workloads
* Uses Keycloak for user authentication and access control
* Operates in a sandbox environment for cost efficiency and multi-tenancy

This tenant item requires a companion **cluster** catalog item (`lb2863-openshift-app-platform-roi-cluster`) that provides the base OpenShift infrastructure.

== Architecture

This catalog item uses a *tenant/namespace-based architecture* running on shared pre-provisioned OpenShift clusters. Each user receives isolated namespaces with dedicated resources for hands-on exercises.
