Beyond the Basics: Operationalizing Red Hat OpenShift Virtualization explores advanced operational capabilities including live migration, resource hot-plugging, dynamic scheduling, and node failure remediation. This hands-on lab teaches platform engineers and virtualization administrators how to manage virtual machine workloads at scale using Kubernetes-native tools across single and multi-cluster environments.

== Detailed Overview

* *Live Migration of Virtual Workloads*
** Perform live VM migrations across nodes with zero downtime
** Validate workload continuity during cluster maintenance operations

* *Resource Management and Hot-Plugging*
** Hot-plug CPU and memory resources to running virtual machines
** Apply affinity and anti-affinity rules for intelligent VM placement

* *Dynamic Scheduling and Node Failure Remediation*
** Configure the Kube Descheduler for dynamic workload balancing
** Simulate node failures and validate automatic VM remediation with Self Node Remediation

* *Cross-Cluster Live Migration*
** Migrate VMs across clusters using Migration Toolkit for Virtualization
** Explore multi-cluster virtualization management scenarios
