== Information

Beyond the Basics: Operationalizing Red Hat OpenShift Virtualization (Summit 2026).

This hands-on lab explores advanced operational capabilities of OpenShift Virtualization including live migration, resource hot-plugging, dynamic scheduling, and node failure remediation.
Participants will learn how to manage virtual machine workloads at scale using Kubernetes-native tools and paradigms across single and multi-cluster environments.
This CI provisions the cluster with all necessary configurations to support the lab environment.

[WARNING]
====
Do not order this item unless you are a developer and are working on the CI.
====

== Information

This is a fallback cluster CI for the Beyond the Basics: Operationalizing Red Hat OpenShift Virtualization lab (Summit 2026). It provisions a Red Hat OpenShift Container Platform cluster with OpenShift Virtualization and the necessary configurations to support the lab environment.

== Lab Guide

Preview: https://rhpds.github.io/balance-virt-showroom/

== Topics Covered

* OpenShift Virtualization Fundamentals
* Live Migration of Virtual Workloads
* Resource Management of Virtual Machines
* Hot-Plugging Virtual Machine Resources
* Affinity and Anti-Affinity for Virtual Machines
* Dynamic Scheduling of Virtual Workloads
* Fencing and Node Failure Remediation Scenarios
* Cross-Cluster Live Migration and Multicluster Scenarios
