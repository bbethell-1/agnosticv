This workshop invites attendees to discover the power and tools of Apache Camel in combination with more capabilities from OpenShift and Application Foundations. Participants will progress through a series of simple exercises, ranging from basic to advanced data flows to build from the ground up a real-world enterprise messaging platform unifying diverse commercial systems into a centralised hub.

Designed for developers and architects, this event-driven lab offers participants gain practical experience in modern application development utilising Camel's integration designer, Kaoto, a visual UI to prototype, test, build and deploy enterprise integrations.

Key technologies in the workshop include: *Apache Camel, Kafka, OpenShift, DevSpaces, OpenShift Data Foundations, RHDP MaaS, Red Hat Connectivity Link*.

The workshop integrates AI capabilities via *RHDP MaaS* — each participant receives a scoped AI virtual key giving access to the `qwen3-14b` model for AI-powered data flow enrichment. AI traffic is routed through *Red Hat Connectivity Link* (Kuadrant), providing per-user rate limiting, budget enforcement, and API gateway security.

The workshop chapters cover the following topics:

* Gain familiarity with Camel JBang
* Build your first flows visually with Kaoto
* Learn how to create reusable components
* Upgrade the platform to be event-driven (connected with Kafka)
* Easily and rapidly integrate new channels and plug-in services
* Switly deploy all the components on OpenShift


=== Key Takeaways

* Construct an open, scalable platform with minimal effort
* Adopt the visual approach with Low-Code / No-Code tools for efficient integration development
* Experience hands-on the power of event-driven architectures
* Build AI-powered data flows with per-user scoped access to RHDP MaaS
