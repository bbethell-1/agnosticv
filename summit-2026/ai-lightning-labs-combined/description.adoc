= AI Lightning Labs - Combined

A single catalog item that provisions the shared AI Lightning Labs OpenShift cluster and
deploys one of the three lightning lab experiences per tenant user, selected at order time.

== Labs Available

Choose one lab at order time via the *Lab* dropdown:

* *fft* — Factory Floor Tycoon Agentic Lab (LB3017): AI agents manage a simulated factory floor
* *wordswarm* — Wordswarm (LB3018): Real-time word generation powered by inference workloads
* *voice-agents* — Pizza Voice Agent (LB3019): Conversational AI ordering experience via voice

== Architecture

This combined CI:

. Provisions one shared OpenShift cluster via the CNV pool component
. Installs shared cluster infrastructure: Keycloak authentication, OpenShift GitOps (ArgoCD), platform services
. Loops per-tenant workloads for each user (num_users): namespace, Keycloak user, GitOps bootstrap, Showroom
. Showroom content is driven by the lab selection — every tenant gets the same lab

== Order Form Parameters

|===
| Parameter | Description | Default

`https://showroom-user-<guid>-showroom.<cluster-ingress-domain>`
