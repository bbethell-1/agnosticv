
Per-tenant provisioning for the Summit LB2645 Agentic DevOps lab on OpenShift AI.

This catalog item deploys a complete Agentic DevOps environment for a single tenant on a shared base cluster via the OpenShift Sandbox API.

== What Gets Deployed

* *Keycloak user* -- Per-tenant OpenShift user via shared Keycloak
* *Tenant namespaces* -- Isolated namespaces for lab workloads
* *ArgoCD (OpenShift GitOps)* -- Per-tenant GitOps bootstrap for lab components
* *LiteLLM Virtual Keys* -- Managed LLM API access for this tenant
* *RAG Pipeline* -- End-to-end RAG pipeline via Helm (llm-service, llama-stack)
* *Showroom* -- Interactive lab guide with embedded OpenShift console

== Design

This tenant CI runs on a shared base cluster provisioned by `lb2645-agentic-devops-cluster`.
Each tenant gets isolated namespaces, a dedicated Keycloak user, and its own
ArgoCD-managed deployment.
