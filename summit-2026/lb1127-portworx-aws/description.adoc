Portworx by Pure Storage provides enterprise-grade persistent storage for OpenShift, enabling high availability, live migrations, and snapshots for both containerized and virtualized workloads. This hands-on lab deploys Portworx on OpenShift Container Platform with OpenShift Virtualization, covering storage operations, VM management, and automated storage optimization with Autopilot.

== Detailed Overview

* *Install Portworx and Configure Storage*
** Deploy Portworx via the OpenShift Operator
** Configure storage classes for containerized and virtualized workloads

* *Create and Manage Virtual Machines*
** Deploy virtual machines backed by Portworx persistent storage
** Manage VM lifecycle operations through the OpenShift console

* *Live Migrations and High Availability*
** Perform live VM migrations across nodes with zero downtime
** Validate high availability behavior with Portworx storage

* *Virtual Machine Snapshots*
** Create point-in-time snapshots of running VMs
** Restore VMs from snapshots for recovery and cloning scenarios

* *Automatic Storage Management with Autopilot*
** Configure Portworx Autopilot rules for dynamic volume expansion
** Monitor and validate automatic storage scaling in action
