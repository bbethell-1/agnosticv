== Sandbox API Registration

To register the cluster with Sandbox API:

[source,bash,subs=attributes]
----
cd ~/Development/agnosticv/summit-2026/lb2211-ai-ibm-fusion-aws-cluster

oc login --insecure-skip-tls-verify \
  --server={openshift_api_url} \
  --token={openshift_cluster_admin_token}

sandbox-cli cluster onboard cluster-{guid} --config cluster-config-dev.json
----
