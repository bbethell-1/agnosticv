Red Hat Edge Manager provides declarative fleet management for edge devices at scale, enabling organizations to define desired OS images, host configurations, and application sets for individual devices or entire fleets. This hands-on workshop demonstrates deploying Edge Manager on Red Hat Enterprise Linux, creating device fleets, onboarding edge VMs, and monitoring device health and compliance. Learners experience how a local agent on each device executes configuration changes, detects drift, and automatically initiates corrective actions.

== Featured Technology and Products

* Red Hat Edge Manager (GA)
* Red Hat OpenShift Container Platform 4.20
* Red Hat OpenShift Virtualization


== Detailed Overview

* *Deploy Edge Manager*
** Install and configure Red Hat Edge Manager on Red Hat Enterprise Linux
** Configure Edge Manager Authentication
** Access Edge Manager via CLI and UI

* *Fleet and Device Creation*
** Build device image utilizing Image Mode (bootc) and bootc-image-builder
** Explore Architecture and create Fleet
** Deploy and enroll drone VM as simulated edge device

* *Device Monitoring and Management*
** Configure fleet membership
** Monitor device health, status and configure custom resource monitors
** Create Edge Manager repositories and utilize git integration
