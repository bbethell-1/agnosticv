== Information
This environment/cluster is running on AWS infra.

This is a base cluster CI for the Securing GenAI Applications with Guardrails as a Service lab.
It provisions a Red Hat OpenShift Container Platform cluster with the necessary infrastructure
resources (GaaS detectors, TrustyAI operator config, User Workload Monitoring) to support the lab environment.

It does not include per-user tenant resources, which are provisioned separately.
