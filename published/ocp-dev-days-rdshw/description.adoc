Red Hat OpenShift delivers a unified developer platform that connects an internal developer portal, cloud development environments, automated CI/CD pipelines, and GitOps-driven deployments into a single cohesive workflow. OpenShift Dev Day is a 90-minute hands-on workshop that takes developers through this complete journey using the Parasol Insurance application as a real-world working context. Learners discover services in Red Hat Developer Hub, write a feature in Dev Spaces with AI assistance, ship it through an automated pipeline with quality gates, and promote to production using GitOps.

== Lab Guide

You can find a preview version of the link:https://rhpds.github.io/ocp-dev-days-rdshw-showroom[lab guide^] here.

== Featured Technology and Products

* Red Hat Developer Hub (RHDH)
* Red Hat OpenShift Dev Spaces
* Red Hat OpenShift Pipelines
* Red Hat OpenShift GitOps (Argo CD)

== Detailed Overview

* *Meet the Platform*
** Log into Red Hat Developer Hub and explore the software catalog, APIs, and Lightspeed AI assistant
** Discover the Parasol Insurance application components, ownership, and documentation

* *Your Mission*
** Find your assigned feature task via the Developer Hub catalog
** Provision an isolated cloud development environment using a self-service Dev Spaces template

* *Build the Feature*
** Open Dev Spaces and explore the browser-based IDE with pre-configured workspace
** Implement the assigned feature using an AI coding assistant for suggestions

* *Ship It*
** Push code and observe the automated Tekton CI pipeline running in Developer Hub
** Diagnose and resolve a SonarQube quality gate failure from the pipeline view

* *Call in the AI*
** Use an agentic AI assistant to identify and fix code smells in a single interaction
** Push the fix and watch the pipeline pass end-to-end

* *Go Live*
** Create a release tag to trigger the GitOps production promotion workflow
** Approve the Argo CD sync and verify the deployed feature in the OpenShift console
