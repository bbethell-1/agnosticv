Red Hat Ansible Development Tools (ADT) brings a complete, cloud-based authoring environment into OpenShift Dev Spaces. This hands-on lab walks through the full Ansible content development lifecycle — from writing and linting collections in VS Code to testing with Molecule and pytest-ansible, orchestrating tests with tox-ansible, packaging Execution Environments with ansible-builder, and securing the supply chain with ansible-sign.

== Detailed Overview

* *Section 1 — Authoring with VS Code and ADT*
** Create and structure an Ansible collection using the VS Code extension
** Set up and use the Ansible Development Environment (ADE) container tool
** Add and validate a custom module within a collection

* *Section 2 — Testing with Molecule, pytest-ansible, and tox-ansible*
** Write and run unit tests for Ansible roles using Molecule
** Run functional tests against live infrastructure with pytest-ansible
** Orchestrate the full test suite across multiple scenarios with tox-ansible

* *Section 3 — Packaging and Supply Chain Security*
** Build a custom Execution Environment with ansible-builder
** Sign and verify automation content with ansible-sign for supply chain security
