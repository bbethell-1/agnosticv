Get hands-on with Red Hat OpenShift through a self-paced lab experience for learning core OpenShift concepts. Select one of three modules — each builds on a pre-deployed sample application called DataSphere, which you will deploy, scale, and automate using real OpenShift tooling. No cluster setup required. Your environment is ready when you arrive.

== What You'll Get

Each user receives a dedicated environment on a shared OpenShift cluster:

* A dedicated OpenShift namespace scoped to your login, isolated from other users
* A pre-deployed OpenShift cluster with Gitea, GitOps, and Pipelines ready to use
* A Gitea repository pre-seeded with the DataSphere application source
* A Showroom lab guide accessible in your browser — step-by-step instructions alongside your terminal
* OpenShift web console access with a personal Keycloak login

== Featured Technology

* Red Hat OpenShift Container Platform
* OpenShift GitOps (ArgoCD)
* OpenShift Pipelines (Tekton)
* Gitea (in-cluster Git server)
* Keycloak (SSO / identity)
* Helm

== Detailed Overview

* *Module 1 — 3 Ways to Deploy the App*
** Use `oc new-app` to deploy DataSphere from the CLI
** Deploy the same application from the OpenShift web console using the Developer perspective
** Package the app as a Helm chart and install it with `helm install`
** Inspect pods, services, routes, and image streams created by each method

* *Module 2 — Apps That Never Go Down*
** Add liveness and readiness probes to the DataSphere deployment
** Configure an HPA to scale pods automatically under CPU load
** Set resource requests and limits to enforce fair scheduling
** Simulate pod failure and observe OpenShift self-healing behavior in real time

* *Module 3 — Git Is Your Source of Truth*
** Create an ArgoCD Application pointing to your personal Gitea repository
** Sync DataSphere from Git and verify the deployed state in the ArgoCD UI
** Edit a manifest in Gitea and push the change
** Watch ArgoCD detect drift and reconcile the cluster — zero manual `oc apply` required
