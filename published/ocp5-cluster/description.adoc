An OpenShift Container Platform 5 cluster with basic customizations and a choice of cloud providers.
It is an empty and generic cluster with no apps or workloads deployed on it, other than what is listed below.
It is for you to explore, show-off, and build on.

If you are interested in building demo or workshop content on OpenShift, check out the link:https://catalog.demo.redhat.com/catalog?item=babylon-catalog-prod/published.ocp-field-asset.prod[Field Sourced Content^] catalog item.

If you are looking for specialized workshops or demos, please search in the RHDP catalog.

[IMPORTANT]
====
This environment deploys OpenShift Container Platform 5 from the latest candidate build.
Candidate payloads change frequently.
Operators, APIs, and installed components can break or behave differently from one candidate to the next.
Do not treat this as a stable or supported production-like release.

If you have a problem with the deployment of this CI, please post in the link:https://redhat.enterprise.slack.com/archives/C04N203SNUW[#forum-demo-redhat-com^] Slack channel.

If you have a problem or question about OpenShift 5, please post in the link:https://redhat.enterprise.slack.com/archives/C0A1R7LDSUV[#forum-openshift-5^] Slack channel.
====

== Environment Details

You can choose from some limited options for how you want OpenShift deployed.
The defaults are the least expensive option and should only be changed if you need more.
If you choose to change these, be aware that this will increase the cost to run.
All costs are charged back to your cost center.

You have the following options to choose from:

=== Cloud Providers

* CNV (default)
** Runs on OpenShift Virtualization and is your cheapest option
** Usually very fast to deploy - typically ~5 minutes for `sno` and ~15 minutes for `multinode`
* AWS
** More expensive
** Longer to deploy - typically 60+ minutes for a cluster deployment
+
[NOTE]
====
If you only need OpenShift and don't need any AWS integration, keep the default.
You can do almost all of the same things regardless of which cloud provider you are running on.
====

=== Cluster Size

* Single Node OpenShift (sno)
** A single instance with 32 CPU and 128GB of memory - more than enough for basic usage, testing, and development
* Multi-node OpenShift (multinode)
** 3 control-plane nodes
** 2-10 worker nodes

=== OpenShift Version

This catalog item installs the latest OpenShift 5 candidate (`latest`).
There is no version picker for z-streams.
Each order can land a newer candidate than the last, and that candidate can change or break without notice.

=== Additional Configuration

All clusters come with the following enabled by default or with an option to enable when you order:

* Authentication provided by Red Hat build of Keycloak
** You can choose the number of users to deploy, or provision with an admin user only
* Ingress certificates controlled by cert-manager
* OpenShift Data Foundation (ODF) for persistent storage on CNV
* Open Environment credentials for AWS (optional)
