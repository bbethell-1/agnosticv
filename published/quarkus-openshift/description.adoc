Red Hat Build of Quarkus brings Kubernetes-native Java to OpenShift, combining fast startup, low memory footprint, and a developer-friendly live reload experience. This hands-on lab covers Quarkus from first principles through advanced production patterns — running in Dev Mode on OpenShift DevSpaces, deploying to a live cluster, building native images with GraalVM, and extending with REST APIs, Panache ORM, Kafka messaging, and OpenTelemetry tracing.

== Detailed Overview

* *Module 1 — Quarkus Fundamentals*
** Explore Quarkus basics, dependency injection (CDI), and cloud-native configuration
** Debug and test applications live in Dev Mode with hot reload
** Deploy a Quarkus application to OpenShift and build a native binary with GraalVM

* *Module 2 — Advanced Quarkus Development*
** Document and expose REST APIs using OpenAPI and Swagger UI
** Persist data with Hibernate ORM and Panache with minimal boilerplate
** Build reactive pipelines with asynchronous messaging and Kafka streams
** Secure APIs using OpenID Connect, and add distributed tracing with OpenTelemetry
