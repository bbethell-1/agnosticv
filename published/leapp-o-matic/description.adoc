= Leapp-O-Matic: The One-Click Path to RHEL 10

== Overview

Leapp-O-Matic is an end-to-end automation framework that transforms the complex RHEL 9 to RHEL 10 in-place upgrade into a push-button experience. Powered by Ansible Automation Platform and the `leapp` utility — with *no Satellite dependency* — it delivers a modular, fail-fast pipeline that any team can adopt.

== What You'll Get

* *One RHEL 9 VM* — the upgrade target, running a pre-configured leapp pipeline via AAP Job Templates
* *Ansible Automation Platform* pre-loaded with the Leapp-O-Matic execution environment, inventory, and job templates
* A *Showroom guide* walking through the preflight, remediation, and post-upgrade gatekeeper phases

== Key Features

* *Preflight Suite* — validates hardware requirements (x86-64-v3/AVX2) and surfaces inhibitors before the upgrade begins
* *Automated Remediation* — resolves known leapp blockers automatically
* *Post-Upgrade Gatekeeper* — verifies system integrity and performs final cleanup
* *Centralized Logging* — all upgrade output captured and available in the AAP job output

== Differentiators vs. RIPU

|===
| | Leapp-O-Matic | RIPU Workshop

| Satellite Required | No | Yes
| RHEL Versions | RHEL 9 → RHEL 10 | RHEL 7/8/9 → 10
| Focus | AAP-driven push-button upgrade | Workshop with manual exploration
| Execution Environment | Custom leapp EE | Standard supported EE
|===
