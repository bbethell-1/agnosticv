Fast-paced, hands-on AI lab experiences. Choose one of three options. Labs are designed to complete in 15–30 minutes and require no prior AI or machine learning background.

== Choose Your Lab

*Factory Floor Tycoon: Agentic AI* (`fft`) +
An AI agent manages a simulated factory floor — scheduling machines, handling incidents, and optimizing throughput. You will interact with the agent, inspect its tool calls, and observe how agentic workflows coordinate real workloads using Red Hat OpenShift AI and LLM inference via MaaS.

*Wordswarm* (`wordswarm`) +
A real-time, multiplayer word game powered by LLM inference at low latency. See how lightweight language models handle rapid, competitive interaction on OpenShift AI — no GPU required on your workstation.

*Pizza Voice Agent* (`voice-agents`) +
A conversational AI agent takes your pizza order by voice. Speech-to-text, LLM reasoning, and text-to-speech run end-to-end on OpenShift AI. Swap toppings, change your mind, and watch the agent maintain context across turns.

== What You'll Get

* A shared OpenShift cluster with pre-deployed AI infrastructure (RHOAI, MaaS inference, Keycloak)
* A dedicated tenant namespace per user, isolated from other participants
* Showroom lab guide with step-by-step instructions and browser-based access
* OpenShift web console access for inspecting running workloads

== Featured Technology

* Red Hat OpenShift Container Platform
* Red Hat OpenShift AI (model serving, inference endpoints)
* Agentic workflows with MCP servers
* Voice AI (speech-to-text / text-to-speech)
* Keycloak (SSO / identity)

== Detailed Overview

* *Factory Floor Tycoon (fft)*
** Deploy an agentic AI controller that receives real-time telemetry from a simulated factory
** Observe the agent's tool selection: it calls REST endpoints to query machine state and issue commands
** Trigger incidents (machine fault, supply shortage) and watch the agent reason through recovery
** Inspect agent traces to understand decision-making at each step

* *Wordswarm (wordswarm)*
** Join a live word game session where LLM inference ranks word associations in real time
** Examine the inference request/response cycle between the game client and OpenShift AI
** Understand how the LiteMaaS proxy routes requests and enforces per-user token budgets
** Compare model response latency under concurrent player load

* *Pizza Voice Agent (voice-agents)*
** Speak a pizza order into the browser — the agent transcribes, reasons, and responds in voice
** Change your order mid-conversation and verify the agent maintains context across turns
** Inspect the SSE event stream from the agent backend to see each reasoning step
** Review how OpenShift AI serves the STT, LLM, and TTS models as independent inference endpoints
