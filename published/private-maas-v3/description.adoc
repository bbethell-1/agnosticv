Red Hat OpenShift AI provides a Models-as-a-Service architecture that enables centralized model management, secure API gateways, and developer-friendly access without GPU complexity. This hands-on workshop rotates participants through three personas: as a developer, access model credentials and integrate AI code assistants into your workflow; as an SRE/DevOps practitioner, explore agentic AI with Model Context Protocol (MCP) servers to interact with OpenShift and Slack using natural language; as a decision maker, monitor model usage analytics with Grafana to understand cost, capacity, and business impact.

== Lab Guide

You can find a preview version of the link:https://rhpds.github.io/private-rh1-llmaas-showroom[lab guide^] here.

== Featured Technology and Products

* Red Hat OpenShift AI 3.0
* Red Hat OpenShift 4.20
* Llama Stack
* Model Context Protocol (MCP) Servers

== Detailed Overview

* *Introduction to Models-as-a-Service Infrastructure*
** Understand the challenges of infrastructure-as-a-service for AI workloads
** Navigate OpenShift AI dashboard to view model deployments
** Retrieve MaaS endpoint URL and API token for model access

* *AI-Assisted Development with OpenShift Dev Spaces*
** Set up a cloud IDE with OpenShift Dev Spaces
** Install and configure Continue AI code assistant
** Connect Continue to your private MaaS model endpoint

* *Game Time: Build Applications with AI Assistance*
** Choose from Rock Paper Scissors, Word Scramble, or Quiz Game projects
** Use Continue to scaffold, edit, and debug code
** Run and test AI-assisted applications in Python or Bash

* *System Administration with Agentic AI*
** Use Llama Stack with MCP servers for natural language cluster interaction
** Query OpenShift resources using conversational prompts
** Post messages and logs to Slack using AI-driven automation

* *Usage Analytics and Reporting*
** Explore Grafana dashboards for model usage metrics
** Track token consumption, costs, and usage patterns by user and tier
** Understand capacity planning and chargeback models for AI services
