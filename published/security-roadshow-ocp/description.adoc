The OpenShift Security Roadshow provides field and technical teams a hands-on environment for Kubernetes-native security on OpenShift 5. Learners work through foundations, hardening, and zero-trust modules, then product paths for Advanced Cluster Security, OpenShift Virtualization, and Lightwell Trusted Software Supply Chain. Each module ends with a practical task so you apply what you learned before moving on.

== Lab Guide

The lab instructions are available in the Showroom instance after a successful installation.

You can preview the guide at link:https://rhpds.github.io/ocp5-rhacs-showroom[ocp5-rhacs-showroom on GitHub Pages^].

== Featured Technology and Products

* Red Hat OpenShift Container Platform 5.0
* Red Hat Advanced Cluster Security (ACS)
* Red Hat OpenShift GitOps (Argo CD)
* Red Hat OpenShift Virtualization
* Red Hat OpenShift Lightspeed with MCP server integration
* Lightspeed Agentic Operator
* Cluster Observability Operator with Perses dashboards
* MCP Gateway (Red Hat Connectivity Link)

== Detailed Overview

* *101 Foundations*
** OpenShift secure-by-default posture
** Projects, RBAC, SCC guardrails, and NetworkPolicy
** Secrets, image provenance, etcd encryption, and audit logging

* *201 Intermediate*
** Custom RBAC, workload hardening, and file integrity monitoring
** Shift-left pipelines, external secrets, and compliance tailoring
** Admission governance and a STRIDE control map

* *301 Advanced*
** Platform policy governance and GitOps of a digest-pinned image
** AdminNetworkPolicy, runtime enforcement, and incident response
** Supply-chain admission, encryption inventory, and SPIFFE workload identity

* *Advanced Cluster Security*
** Vulnerability management, policy, and deploy-time enforcement
** CI/CD gates, compliance, notifications, and API
** Network and runtime security, plus ACS 5 capabilities (VM scanning, file activity monitoring, MCP, and init containers)

* *OpenShift Virtualization Security*
** HyperConverged feature gates and virtualization RBAC
** VM, storage, and network isolation
** Host firmware and kernel controls from the OpenShift Virtualization hardening guide

* *Lightwell and Trusted Software Supply Chain*
** Hummingbird verification and Lightwell remediated pins
** Hermetic build, keyless signing, and GitOps admission
** Trusted Profile Analyzer and ACS compliance
