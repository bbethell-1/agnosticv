5G RAN RDS Deployments on OpenShift — A hands-on lab environment for deploying Radio Access Network (RAN) infrastructure following the Red Hat 5G Reference Design Specification (RDS).

This lab guides you through deploying a complete RAN-ready infrastructure on OpenShift, using a pre-configured bastion host with nested OpenShift 4.21 running on OpenShift Virtualization.

== Featured Technology

* Red Hat OpenShift Container Platform 4.21
* 5G RAN Reference Design Specification (RDS)
* OpenShift Virtualization (CNV)

== What You Will Learn

* Deploy a RAN-ready infrastructure following Red Hat's 5G Reference Design Specification
* Validate RAN node configuration against CNF team specifications
* Understand the architecture of a 5G RAN deployment on OpenShift
