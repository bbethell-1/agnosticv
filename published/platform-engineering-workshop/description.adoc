== Introduction

Welcome to the Platform Engineering Workshop!

A hands-on workshop that can be delivered to customers and interested parties.

This workshop provides a practical, learn-by-example experience with platform engineering disciplines on Red Hat OpenShift. Participants assume the role of platform engineers at "Parasol Insurance," a fictional company facing real-world developer productivity challenges — slow onboarding, inconsistent environments, manual processes, and software supply chain compliance gaps.

You'll build and configure an Internal Developer Platform (IDP) using OpenShift as the foundation, demonstrating how modern platform engineering practices — including AI-assisted development, software catalog modeling for agents, and zero-YAML self-service — improve developer experience, security, and operational efficiency.

== Who Will Benefit Most from Attending This Workshop?

*Platform Engineers* -- Those responsible for building and managing Internal Developer Platforms (IDPs). These users will design golden paths, configure self-service capabilities, and establish platform standards that balance developer freedom with organizational guardrails.

*DevOps/SRE Leaders* -- Those responsible for developer productivity, tooling, and platform operations. These users will learn how to reduce toil, improve onboarding time, and enable developers to self-serve on OpenShift while maintaining security and compliance.

*Development Team Leads* -- Those seeking to understand what modern OpenShift Application Platform and Trusted Software Supply Chain capabilities can do for their teams. These users will see how golden paths, automated security scanning, and AI-assisted development can accelerate delivery without sacrificing quality.

*Technical Decision Makers* -- Those evaluating OpenShift as the foundation for an Internal Developer Platform. These users will see a production-ready reference architecture with GitOps, secrets management, identity integration, software catalog, and secure supply chain practices.

== Key Workshop Themes

Throughout the workshop, we emphasize four core themes:

* *Platform Engineering fundamentals* — golden paths, self-service, Internal Developer Platforms, and reducing cognitive load
* *GitOps-driven platform management* — everything deployed and managed through Git and Argo CD reconciliation
* *Software supply chain security* — automated SBOM generation, vulnerability scanning (SonarQube, ACS), compliance enforcement, and Trusted Profile Analyzer monitoring
* *AI/Agentic integration* — MCP server for Developer Hub catalog context, Lightspeed for RHDH, and LiteLLM virtual keys for standardized model access

== What Content Is Covered In The Workshop?

The workshop includes nine modules that can be completed in any order. Modules are not mandatory and can be skipped based on your audience's interests:

* The platform engineering challenge
* Explore the application platform
* GitOps fundamentals with Argo CD
* Secrets management with Vault
* Namespace as a product
* Deploy Developer Hub
* Connect Developer Hub to the platform
* Build Context for Agents and Developers
* Enable self-service with templates

For detailed module descriptions, visit the https://redhat-pe-workshop.github.io/showroom-roadshow-v2/modules/index.html[workshop content preview^].
