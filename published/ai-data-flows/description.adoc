Apache Camel combined with Red Hat OpenShift Application Foundations enables teams to build scalable, event-driven enterprise integration platforms. This instructor-led workshop guides developers and architects through building a real-world enterprise messaging hub — from basic data flows to AI-powered integrations using Kaoto's visual designer, Kafka, and RHDP MaaS with per-user scoped AI access via Red Hat Connectivity Link.

[IMPORTANT]
====
This Red Hat Summit 2026 lab is being released as-is with little change from the version delivered in person at the event. == Featured Technology and Products

* Apache Camel with Kaoto (visual integration designer)
* Red Hat OpenShift
* Red Hat OpenShift Data Foundations
* Red Hat Dev Spaces
* Apache Kafka
* RHDP MaaS
* Red Hat Connectivity Link (Kuadrant)

== Detailed Overview

* *Camel JBang and Kaoto Foundations*
** Gain familiarity with Camel JBang for rapid integration development
** Build and deploy first flows visually using the Kaoto low-code designer
** Create reusable integration components

* *Event-Driven Architecture*
** Upgrade the platform to event-driven using Kafka
** Integrate new channels and plug-in services rapidly
** Deploy all components on OpenShift

* *AI-Powered Data Flows*
** Integrate RHDP MaaS for AI-powered data enrichment (qwen3-14b)
** Route AI traffic through Red Hat Connectivity Link (Kuadrant) for per-user rate limiting
** Build and validate AI-enriched enterprise integrations
