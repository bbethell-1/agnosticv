This hands-on workshop guides developers and architects through building a modern, AI-enabled integration platform — from secure data ingestion to governed
AI consumption. You'll solve real-world challenges: transforming EDI purchase orders, bridging disparate messaging platforms, enabling AI-assisted
customer support, and implementing controls that govern how AI models are accessed and consumed across your organization.

Using Red Hat Application Foundations, you'll build flows that connect isolated systems securely, orchestrate multi-channel communication, and add intelligent
automation through agentic workflows powered by large language models. The final phase tackles a critical production concern: ensuring AI usage stays
within defined boundaries through authentication and rate limiting.

By the end, you'll have practical experience with event-driven architectures, visual flow design with Kaoto and Apache Camel, message streaming with Kafka, AI agent
orchestration via MCP servers, and policy-driven AI governance — all running on Red Hat OpenShift.

== Featured Technology and Products

* Red Hat OpenShift
* Red Hat OpenShift Data Foundations
* Red Hat Dev Spaces
* Apache Kafka
* Red Hat Connectivity Link (Kuadrant)
* Red Hat Service Interconnect (Skupper)
* RHDP MaaS
* Apache Camel with Kaoto (visual integration designer)

== Detailed Overview

* *Secure Data Ingestion & Transformation*
** Connect to isolated backend systems via Service Interconnect
** Transform EDI using visual mapping
** Generate PDF invoices and upload to S3
** Build flows visually with Kaoto low-code designer

* *Multi-Channel Communication & Event Streaming*
** Bridge disparate messaging platforms for unified communication
** Implement event-driven architecture with Kafka
** Deploy integration platform on Red Hat OpenShift

* *AI-Assisted Workflows & Governance*
** Enable natural language interactions with backend systems
** Build agentic flows using MCP servers and LangChain4j
** Implement authentication and rate limiting with Red Hat Connectivity Link
