Red Hat Advanced Cluster Security (RHACS) delivers comprehensive Kubernetes-native security across the full application lifecycle—from build-time image scanning to runtime threat detection and policy enforcement. This demo environment is purpose-built for field and technical teams to walk customers through RHACS use cases on a pre-configured OpenShift cluster. Presenters demonstrate vulnerability management, compliance reporting, network policy simulation, and CI/CD security integration using realistic workloads and scenarios.

== Demo Guide

== Detailed Overview

* *Vulnerability Management*
** Scan containerized workloads, cluster nodes, and OpenShift Virtual Machines for CVEs
** Prioritize vulnerabilities by deployment risk: running containers, privileged configurations, and external exposure
** Drill into image details, affected deployments, and fixable CVE remediation paths

* *Risk Assessment*
** View all deployments ranked by risk score combining vulnerability severity, runtime activity, and network exposure
** Inspect process discovery timelines and baseline deviations for each running pod
** Use runtime filters to identify deployments executing shells, package managers, or other attacker-useful tools

* *Network Policy*
** Visualize active traffic flows between deployments with the Network Graph
** Detect anomalous connections against established baselines
** Generate OpenShift-native NetworkPolicy objects from observed traffic using the Network Policy Simulator

* *Policy Management and Enforcement*
** Browse built-in policies spanning build, deploy, and runtime lifecycle stages
** Demonstrate the unified policy engine: combine CVEs, runtime behavior, and configuration in a single policy
** Enforce policies via Kubernetes Admission Controller to block non-compliant deployments at the API level

* *Compliance*
** Scan the environment against industry standards including PCI-DSS, CIS, and STIG
** Browse namespace-level compliance gaps and drill into specific control failures
** Export evidence as CSV for auditors and configure automated scheduled compliance scans

* *CI/CD Integration with OpenShift Pipelines*
** Walk through a developer introducing a vulnerable dependency in Red Hat Developer Hub
** Show roxctl pipeline tasks performing image scan, image check, and deployment check in a Tekton pipeline
** Demonstrate a policy-enforced build failure when a prohibited CVE is detected in the pipeline
