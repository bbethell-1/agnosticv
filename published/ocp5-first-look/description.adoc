OpenShift 5 First Look explores agentic AI capabilities on the next generation of Red Hat OpenShift. Using a multi-node OpenShift 5 cluster with OpenShift Virtualization, learners work through automated troubleshooting driven by alerts, build MCP servers that connect AI agents to cluster and security APIs, and configure federated MCP access through Red Hat Connectivity Link. The environment includes AI model access via MaaS and authentication via Red Hat build of Keycloak.

[IMPORTANT]
====
This environment deploys OpenShift Container Platform 5 from the latest candidate build.
Candidate payloads change frequently.
Operators, APIs, and installed components can break or behave differently from one candidate to the next.
Do not treat this as a stable or supported production-like release.

== Featured Technology and Products

* Red Hat OpenShift Container Platform 5
* Red Hat OpenShift Virtualization
* Red Hat build of Keycloak
* Red Hat Connectivity Link (MCP Gateway)
* Red Hat Advanced Cluster Security (ACS)
* Model Context Protocol (MCP)

== Detailed Overview

* *Agentic Troubleshooting*
** Automated root-cause analysis of application issues triggered by cluster alerts
** AI-driven remediation workflows that diagnose and resolve problems
** Integration with OpenShift monitoring and alerting subsystems

* *MCP Server*
** Deploy Model Context Protocol servers for OpenShift and ACS
** Enable AI agents to interact with cluster management and security APIs
** Extend agent capabilities with cluster-native tool access

* *MCP Gateway*
** Configure Red Hat Connectivity Link for federated MCP access
** Enforce team isolation, authentication, and policy across MCP endpoints
** Manage multi-tenant AI agent access to shared infrastructure
