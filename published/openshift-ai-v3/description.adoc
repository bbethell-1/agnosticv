This environment provides OpenShift 3 (latest) deployed on a Single-Node OpenShift (SNO) running on a GPU instance.
With OpenShift AI 3 now generally available, you can use this to demonstrate explore this version of OpenShift AI.

There is a guide provided that will walk you through how to deploy and configure this on your own.

[NOTE]
====

IMPORTANT: This CI is currently facing issues during stop / start operations. Once deployed, please disable auto-stop if you are planning to keep the environment.

If the CI deployment workflow fails due to GPU unavailability in the current AWS region, please attempt to reprovision in an alternate available region.

OpenShift AI 3 is GA, but this is an early release of this catalog item so that you can use it sooner.
The demo guide and experience will be refined and updated over the coming days and weeks.


====

== Products

* OpenShift Container Platform 4.20 (SNO)
** OpenShift LightSpeed enabled
* OpenShift AI 3 
** stable-3.x channel

[IMPORTANT]
====
GPU instances cost more to run.
Please order the size you need and do not keep your environment running.
