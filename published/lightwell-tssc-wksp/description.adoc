Red Hat Lightwell Network extends enterprise open source maintenance to third-party application dependencies, supplying surgical security remediations on the versions you already run. This hands-on workshop walks one complete trusted software supply chain on a dedicated OpenShift cluster — from verifying a Hummingbird base image through hermetic builds, keyless signing, and GitOps promotion to proving continuous compliance. Java is the scored application; Python and Artifactory appear as in-module callouts.

== Detailed Overview

* *Track 1 — Hummingbird: Verify and Mirror*
** Verify the published Hummingbird image signature with cosign
** Run oc-mirror to land image, signatures, and SBOM in the in-cluster registry
** Confirm digest provenance in the trust boundary

* *Track 2 — Lightwell Dependencies: Enterprise Proxy and Remediation*
** Configure enterprise Maven consumption of Lightwell Validated and Remediated via Nexus proxy
** Apply exact-version `.rhlw-*` pins driven by a Lightwell OSV fixed event
** Validate remediated artifact integrity and repository tier selection

* *Track 3 — Source: Golden Path, Base Binding, and Renovate*
** Scaffold a project with Red Hat Developer Hub golden path templates
** Bind the mirrored Hummingbird digest and Lightwell pins in source
** Merge a live Renovate PR on in-cluster Gitea for automated dependency updates

* *Track 4 — Hermetic Build: Forbid-list, Prefetch, and SBOM*
** Author a source forbid-list and configure Hermeto dependency prefetch
** Tighten the build namespace with a NetworkPolicy
** Generate a CycloneDX SBOM alongside the BuildConfig image

* *Track 5 — Signed and Attested Image*
** Perform keyless signing with RHTAS (cosign)
** Run Enterprise Contract / Conforma attestation gates
** Verify signatures in a disconnected (mirrored-TUF) configuration

* *Track 6 — Production Container: GitOps and Admission*
** Configure unsigned-deny admission policy in the stage namespace
** Promote the signed digest to a separate prod GitOps remote
** Validate end-to-end promotion with OpenShift GitOps

* *Track 7 — Continuous Compliance: SBOM System of Record and VEX*
** Ingest Lightwell GAV-bound VEX and SBOM into RHTPA
** Report the CVE as remediated via the Lightwell pin
** Correlate blast-radius analysis with RHACS runtime policy
