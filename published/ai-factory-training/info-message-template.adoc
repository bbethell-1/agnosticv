Example Python code to use your virtual key:

[source,python,subs="attributes"]
----
from openai import OpenAI

    api_key="{litellm_virtual_key}",
    base_url="{litellm_api_base_url}"

response = client.chat.completions.create(
    model="granite-4-0-h-tiny",

)

print(response.choices[0].message.content)

== Important: GPU Cost Management

[IMPORTANT]
====
*GPU instances are expensive and resources are limited!*

* This environment costs significantly more than CPU-only clusters
* GPU availability on the Demo Platform is limited and not guaranteed
* *Stop or destroy this environment when not actively using it*
* Coordinate with your training instructor for optimal scheduling
* GPU usage costs will be charged back to your organization

*Best Practices*:

* Only provision for GPU-specific training lessons
* Stop immediately after completing GPU exercises
* Destroy when GPU work is complete
* Switch to CPU-only CNV version for non-GPU content
====
