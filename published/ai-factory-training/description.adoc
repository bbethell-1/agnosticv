AI Factory Training environment for AI Factory topics delivered by the Partner Training and Learning (PTL) organization. Provides stable OpenShift AI environments for building and deploying enterprise AI applications with paid customers and partners. Choose between CPU-only (CNV) for concept and agent development, or GPU-accelerated (AWS) for GPU configuration, slicing, and optimization lessons.

[IMPORTANT]
====
*GPU (AWS) Cost Guidance*: Only order AWS for GPU-specific lessons (Phase 3 of the curriculum). Use CNV for all other content. Destroy GPU environments immediately after use — GPU costs are charged back to your organization and availability on the Demo Platform is limited.
====

== Featured Technology and Products

* Red Hat OpenShift AI 3.3 (CNV variant — stable channel)
* Red Hat OpenShift AI 3.4 (AWS variant — stable-3.4, pinned for training stability)
* Red Hat OpenShift 4.20
* NVIDIA L4 GPU with GPU Operator v25.3 (AWS only)
* LiteLLM / Model-as-a-Service — Granite 4 Tiny, Qwen 3 14B (CNV only)

== Detailed Overview

* *CNV (CPU-Only) — Phases 1 & 2*
** Build and deploy AI agents using Llama Stack and Gen AI Playground
** Implement Retrieval-Augmented Generation (RAG) with MaaS virtual API keys
** Manage models with KServe, Model Registry, and TrustyAI

* *AWS (GPU-Enabled) — Phase 3*
** Configure NVIDIA GPU Operator and Node Feature Discovery on OpenShift
** Implement GPU slicing: Multi-Instance GPU (MIG) and time-slicing strategies
** Monitor GPU utilization and optimize performance for production workloads
