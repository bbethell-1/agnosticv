This environment provides an OpenShift cluster with OpenShift Lightspeed deployed. OpenShift Lightspeed is a AI virtual assistant
that runs in the OpenShift web console so that you can easily use it. This environment has introspection enabled, so you also get a built-in
MCP server that lets you interact and control your OpenShift cluster.

== Product List

* OpenShift Container Platform (SNO)
* OpenShift Lightspeed (latest-stable)

== Support

NOTE: If you get an error when connecting to backend AI service, please try to *delete* the 'lightspeed-app-server-xxxxxx' pod in 'openshift-lighspeed' project.
A new pod will be provisioned automatically to connect to the backend AI services.

For other issues, please open a ticket or visit the link:https://redhat.enterprise.slack.com/archives/C04N203SNUW[#forum-demo-redhat-com^] Slack channel.
