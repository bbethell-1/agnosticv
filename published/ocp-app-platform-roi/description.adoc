Experience Red Hat OpenShift as a production application platform through the lens of Parasol Insurance. This hands-on lab guides developers from platform exploration to feature delivery to AI-powered application enhancement — using Dev Spaces for cloud-based development, an AI coding assistant to ship a real feature, and OpenShift AI to replace keyword matching with an LLM-powered email classification service that scales automatically under production load.

== Featured Technology and Products

* Red Hat OpenShift Container Platform
* Red Hat OpenShift Dev Spaces
* Red Hat OpenShift AI
* Argo CD (GitOps)
* Tekton Pipelines

== Detailed Overview

* *Module 1 — Exploring the Platform*
** Navigate OpenShift's Administrator and Developer perspectives
** Explore your build, dev, and prod namespaces and the running Parasol Insurance app
** Understand how ExternalSecrets sync credentials, and how GitOps drives deployments via Argo CD

* *Module 2 — Your First Feature*
** Launch a cloud development environment with OpenShift Dev Spaces and a devfile
** Use the Continue AI coding assistant to explore and modify the application
** Push a code change and watch it flow through the Tekton CI/CD pipeline to production

* *Module 3 — Building Intelligent Applications*
** Replace keyword-based email classification with an LLM-powered service
** Deploy and promote the AI classification service to production
** Observe OpenShift's Horizontal Pod Autoscaler scale the service under load
