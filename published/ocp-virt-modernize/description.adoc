Red Hat OpenShift Virtualization enables organizations to run containers and virtual machines together on a unified platform, letting teams modernize infrastructure at their own pace. This hands-on lab walks through integrating VMs into OpenShift Service Mesh for traffic management and observability, automating VM deployments with GitOps and Developer Hub, and using OpenShift Lightspeed for AI-assisted troubleshooting across four progressive modules.

== Detailed Overview

* *Module 1 — VM Foundations with OpenShift Lightspeed*
** Create and manage virtual machines as Kubernetes objects using OpenShift Virtualization
** Use OpenShift Lightspeed for AI-assisted VM troubleshooting and quick-create workflows
** Explore VM templates, live migration, and VM-specific console tools

* *Module 2 — Service Mesh Integration with Virtual Machines*
** Add VMs and containers to OpenShift Service Mesh alongside each other
** Implement canary releases and authorization policies for VM-based services
** Explore Kiali dashboards for unified observability across hybrid workloads

* *Module 3 — Declarative Management and Automation with DevHub and GitOps*
** Deploy and manage VMs declaratively using Argo CD and Red Hat Developer Hub
** Automate VM lifecycle operations with self-service provisioning patterns
** Apply GitOps self-healing to VM configurations in multi-tenant environments

* *Module 4 — OpenShift Virtualization in the Cloud*
** Explore how OpenShift Virtualization extends to public cloud environments
** Review demonstrations across AWS, Google Cloud, IBM Cloud, Azure, and Oracle Cloud
** Understand hybrid VM deployment options across Red Hat's cloud partner ecosystem
