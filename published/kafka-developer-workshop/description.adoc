Build, Stream, and Scale Real-Time Apps with Streams for Apache Kafka. Learn Apache Kafka end-to-end with short, practical modules. You willproduce & consume events, validate schemas, build stream processors, connect to external systems, add implement security—and explore more use cases. 

This workshop goes through all the basics of Apache Kafka. No prior Kafka experience required.

== Modules

* Module 1: Learn the basics (Event Streaming, Topics, Producers, Consumers, Partitions, Replication, Rebalancing, etc.)

* Module 2: Coding a Producer/Consumer - Learn about the producer and consumer APIs, and how to use them to send and receive messages and the different configurations available.

* Module 3: Streams API - Enrich(Process and analyse) the data using Kafka Streams API

* Module 4: Build new functionality with Change Data Capture (CDC)- Learn how Debezium streams data change events to Kafka and some practical use cases

* Module 5: Schema Registry & Validation - Use Schema Registry to manage Kafka topic schemas. Create, register, and use a new schema in producer/consumer apps. Briefly cover Schema Registry compatibility rules.

* Module 6: Security - Configuring user security mechanisms. Authentication, Authorization using ACLs

* Module 7: Observability - Coming Soon!

* Module 8: Kafka and AI - Coming Soon!
