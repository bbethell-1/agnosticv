Step into the role of a lead developer at ACME Corp tasked with modernizing a legacy Java application portfolio. This hands-on lab guides you through the full AI-accelerated modernization workflow — using the Migration Toolkit for Applications (MTA) to assess and classify the codebase at scale, Red Hat Developer Lightspeed to generate modernized code with AI assistance, and Solution Server to encode company-specific policies and tribal knowledge so every developer follows organizational standards at migration speed.

== Featured Technology and Products

* Migration Toolkit for Applications (MTA)
* Red Hat Developer Lightspeed
* Red Hat OpenShift Container Platform
* Red Hat OpenShift DevSpaces
* OpenShift Lightspeed Solution Server

== Detailed Overview

* *Module 1 — Assessing the Landscape*
** Navigate MTA to build an application inventory and define business services
** Use archetypes and tagging to classify large application portfolios at scale
** Run containerization assessments and static code analysis to map migration risk and effort

* *Module 2 — AI-Assisted Code Modernization*
** Use Red Hat Developer Lightspeed to generate modernized code from legacy Java
** Validate AI-generated changes and scale migration work through Agent Mode
** Experience how AI accelerates the actual transformation work beyond assessment

* *Module 3 — Policy and Tribal Knowledge with Solution Server*
** Teach Solution Server your organization's coding standards and best practices
** Enforce company-specific patterns across all AI-assisted migrations
** Scale modernization across dozens of applications while maintaining consistency

* *Module 4 — Deploying to OpenShift (Optional)*
** Deploy the modernized application to OpenShift
** Validate the cloud-native deployment and runtime behavior
