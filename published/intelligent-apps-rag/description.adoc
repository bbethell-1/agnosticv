Build a production-ready Retrieval-Augmented Generation (RAG) application using Python and Red Hat OpenShift AI. This hands-on lab walks through the full RAG pipeline — deploying a mock ServiceNow API, standing up a Milvus vector database, importing a data science pipeline, querying the RAG system, and extending it with event-driven automation. Learners gain practical experience connecting LLM inference with enterprise data through OpenShift AI pipelines.

* Red Hat OpenShift AI
* Milvus Vector Database

* LLM inference via MaaS

== Detailed Overview

* *Section 1 — RAG Foundations*
** Understand the knowledge gap that RAG addresses in enterprise AI applications
** Explore the proposed RAG architecture connecting LLMs with structured enterprise data

* *Section 2 — Building the RAG Pipeline*
** Deploy a mock ServiceNow API as the enterprise data source
** Stand up Milvus as the vector database for semantic search
** Import and configure a data science pipeline in OpenShift AI
** Run the pipeline, monitor execution, and query the RAG system

* *Section 3 — Event-Driven RAG*
** Extend the pipeline with event-driven triggers
** Trace an event through the automated data ingestion pipeline
