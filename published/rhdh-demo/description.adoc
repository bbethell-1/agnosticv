Red Hat Developer Hub is an enterprise-grade, open developer platform that helps organizations build and deploy better applications faster. Red Hat Developer Hub is based on Backstage, the open-source framework for building developer portals originally created at Spotify. Backstage provides a solid foundation for building secure, scalable, and easy-to-use developer portals. Red Hat Developer Hub augments Backstage with enterprise support, curated plugins, and streamlined deployment.

This demo shows how Red Hat Developer Hub smoothes development, coordinates tasks and targets, and makes team policies and best practices not just the right way but the easiest way to get things done. Developer Hub provides a central location to discover, understand, and select software components, APIs, and templates. Red Hat SSO authenticates access, and an in-cluster GitLab deployment provides the source management foundation of GitOps processes.
