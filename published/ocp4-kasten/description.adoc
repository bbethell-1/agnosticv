In this Red Hat OpenShift Container Platform (OCP) workshop, we'll explore how Kasten K10 provides enterprise DevOps teams with an easy to use, scalable, and secure system for backup/restore, disaster recovery and application mobility for Kubernetes applications.
With an application-centric approach and deep integrations with relational and NoSQL databases, storage systems, and Kubernetes distributions, Kasten K10 delivers flexibility and freedom of choice across cloud & on-prem infrastructures, virtual machines and container application stacks.

Kasten K10 provides data mobility and transform capabilities and can be leveraged by Red Hat OpenShift customers to move their cloud native workloads and data deployed on other Kubernetes platforms, whether on-premises, at the edge, or in the cloud to Red Hat OpenShift.

This short workshop provides a fully deployed and running Kasten K10 deployment on OCP and will cover the following topics:

* Deploy an application with persistent data
* Configure Kasten K10
* Backup the application
* Simulate a data loss event
* Restore the application

== What Content Is Covered In This Lab?

These are the *five* main sections that will be covered:

* *Installing Veeam Kasten:* In this section we will provide a review of how to install the product on any OpenShift cluster. Since the product is already installed in the lab environment this section will be a review only.
* *Creating Location Profiles:* In this section, we will use setup the Kasten K10 product with a location profile to specify storage for the virtual machine backups.
* *Protecting Virtual Machines:* In this section we will perform several backup and restore operations with virtual machines.
* *Optional: Configuring Multi Cluster:* In this section you will learn how to set up Kasten Multi-Cluster Manager. Since our lab environment is a single cluster this section will be review only.
* *Optional: Migrating Workloads:* This section addresses restoring backups to different clusters. Since our lab environment is a single cluster this section will be review only.
