
This example demonstrates how to build a production-ready RAG (Retrieval-Augmented Generation) application using LiteMaaS on OpenShift.

== Products

* Red Hat OpenShift Container Platform 4.20
* LiteMaaS (LiteLLM as a Service)
* PostgreSQL 16 with pgvector extension

== What is RAG?

RAG combines information retrieval with AI generation. Instead of the AI answering from memory (which can hallucinate), RAG:

* Retrieves relevant documents from a knowledge base
* Provides those documents as context to the LLM
* Generates accurate, grounded answers

== Architecture

This example uses:

* *Nomic Embed v1.5* - Converts text to 768-dimensional vectors via LiteMaaS
* *PostgreSQL + pgvector* - Stores document embeddings for vector similarity search
* *Granite 3.2 8B* - Generates answers from context via LiteMaaS
* *Flask API* - Simple Python application for ingestion and question answering

== What You Will Learn

* How to integrate LiteMaaS embedding and chat models
* How to use pgvector for semantic search in PostgreSQL
* How to build a complete RAG pipeline on OpenShift
* How to test and validate RAG applications

== Important Notes

* The application is deployed in the `maas-rag-demo` namespace
* You have full admin access to the OpenShift cluster
* SSH access to the bastion host is provided for deployment
* LiteMaaS Virtual Keys are pre-configured with the required models
