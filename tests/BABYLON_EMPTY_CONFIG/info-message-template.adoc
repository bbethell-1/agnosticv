Welcome to Babylon Empty Config!
-------------------------------

This is a sample service and this messages comes from an asciidoc template that contains lists such as:

* Item *one*.
* Item *two*.

Variables
~~~~~~~~~
There is only one component in this service called *babylon-empty-config*

To use the variables produced by the component you need to concatenate the component, two hyphens and the variable name.
For example:

* random_string: {babylon-empty-config--random_string}
