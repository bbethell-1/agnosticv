== Advanced Usage

=== View Full Benchmark Logs

----
# View complete benchmark output
oc logs -n {guid} -l app=litemaas-benchmark

# Follow live progress
oc logs -n {guid} -l app=litemaas-benchmark -f

# Check job status
oc get job litemaas-benchmark -n {guid}

# Describe job for events
oc describe job litemaas-benchmark -n {guid}
----

=== Re-run Benchmark

To re-run the benchmark with different parameters:

1. Destroy this catalog item
2. Order a new one with updated configuration

=== Troubleshooting

If the benchmark fails:

[source,bash,subs="attributes+"]
----
# Check pod status
oc get pods -n {guid} -l app=litemaas-benchmark

# View error logs
oc logs -n {guid} -l app=litemaas-benchmark

# Describe pod for events
oc describe pod -n {guid} -l app=litemaas-benchmark
----

*Common Issues:*

* **LiteMaaS endpoint unreachable**: Check network connectivity
* **Invalid API key**: Ensure virtual keys workload succeeded
* **Model not available**: Verify model is deployed in LiteMaaS
* **Context length exceeded**: Reduce max_tokens parameter
* **Timeout**: Reduce conversation count or turns

== Using Your API Key

=== Example curl Request

[source,bash,subs="attributes+"]
----
curl {litellm_api_base_url}/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer {litellm_virtual_key}" \
  -d '{
    "model": "granite-3-2-8b-instruct",
    "messages": [
      {
        "role": "user",
        "content": "Explain what TTFT means in LLM inference."
      }
    ],
    "max_tokens": 200
  }'
----

=== Example Python Code

[source,python,subs="attributes+"]
----
from openai import OpenAI

client = OpenAI(
    base_url="{litellm_api_base_url}",
    api_key="{litellm_virtual_key}"
)

response = client.chat.completions.create(
    model="granite-3-2-8b-instruct",
    messages=[
        {"role": "user", "content": "What is prefix caching in LLMs?"}
    ],
    max_tokens=200
)

print(response.choices[0].message.content)
----
