=== Using Your API Key

Example API call with curl:

[source,bash,subs="attributes"]
----
curl {litellm_api_base_url}/chat/completions \
  -H "Authorization: Bearer {litellm_virtual_key}" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/granite-3-2-8b-instruct",
    "messages": [{"role": "user", "content": "What is OpenShift?"}]
  }'
----

=== Python Example

[source,python,subs="attributes"]
----
from openai import OpenAI

client = OpenAI(
    api_key="{litellm_virtual_key}",
    base_url="{litellm_api_base_url}"
)

response = client.chat.completions.create(
    model="openai/granite-3-2-8b-instruct",
    messages=[{{"role": "user", "content": "What is Red Hat OpenShift?"}}]
)

print(response.choices[0].message.content)
----
