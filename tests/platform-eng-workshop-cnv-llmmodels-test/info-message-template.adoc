== Multi-User Setup

This deployment supports *{litellm_user_count} users* (user1, user2, user3, etc.).

TIP: The `{litellm_virtual_key}` variable above automatically shows YOUR key based on your Showroom login. Each user sees their own key - no manual lookup needed!

*How it works:*

* When you log in as `user1`, `{litellm_virtual_key}` shows user1's key
* When you log in as `user2`, `{litellm_virtual_key}` shows user2's key
* When you log in as `user3`, `{litellm_virtual_key}` shows user3's key
* Same variable name, personalized value for each user!

== How to Use Your Key

=== Using curl

[source,bash,subs="attributes+"]
----
curl {litellm_api_base_url}/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer {litellm_virtual_key}" \
  -d '{
    "model": "granite-3-2-8b-instruct",
    "messages": [
      {
        "role": "user",
        "content": "Hello! How are you?"
      }
    ]
  }'
----

=== Using Python (OpenAI SDK)

[source,python,subs="attributes+"]
----
from openai import OpenAI

client = OpenAI(
    base_url="{litellm_api_base_url}",
    api_key="{litellm_virtual_key}"
)

response = client.chat.completions.create(
    model="granite-3-2-8b-instruct",
    messages=[
        {"role": "user", "content": "Hello! How are you?"}
    ]
)

print(response.choices[0].message.content)
----

=== Using Tool Calling (Granite 4.0 H Tiny)

Granite 4.0 H Tiny supports tool calling for function execution:

[source,bash,subs="attributes+"]
----
curl {litellm_api_base_url}/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer {litellm_virtual_key}" \
  -d '{
    "model": "granite-4-0-h-tiny",
    "messages": [
      {
        "role": "user",
        "content": "What is the weather in Boston?"
      }
    ],
    "tools": [
      {
        "type": "function",
        "function": {
          "name": "get_weather",
          "description": "Get the current weather for a location",
          "parameters": {
            "type": "object",
            "properties": {
              "location": {
                "type": "string",
                "description": "City name, e.g., Boston, MA"
              },
              "unit": {
                "type": "string",
                "enum": ["celsius", "fahrenheit"],
                "description": "Temperature unit"
              }
            },
            "required": ["location"]
          }
        }
      }
    ],
    "tool_choice": "auto"
  }'
----
