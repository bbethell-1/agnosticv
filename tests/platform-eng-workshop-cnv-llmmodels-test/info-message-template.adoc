=== Usage Examples

==== Chat/Text Generation Models

Use these models for chat and text generation:

[source,bash,subs="attributes"]
----
# Granite 3.2 8B Instruct
curl {litellm_api_base_url}/chat/completions \
  -H "Authorization: Bearer {litellm_virtual_key}" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "granite-3-2-8b-instruct",
    "messages": [{"role": "user", "content": "Explain Kubernetes"}]
  }'

# Mistral 7B Instruct
curl {litellm_api_base_url}/chat/completions \
  -H "Authorization: Bearer {litellm_virtual_key}" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "mistral-7b-instruct",
    "messages": [{"role": "user", "content": "What is DevOps?"}]
  }'
----

==== Code Generation Models

[source,bash,subs="attributes"]
----
# Granite 8B Code Instruct (chat completions)
curl {litellm_api_base_url}/chat/completions \
  -H "Authorization: Bearer {litellm_virtual_key}" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "granite-8b-code-instruct-128k",
    "messages": [{"role": "user", "content": "Write a Python function to sort a list"}]
  }'

# CodeLlama 7B (completions - note different endpoint)
curl {litellm_api_base_url}/completions \
  -H "Authorization: Bearer {litellm_virtual_key}" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "codellama-7b",
    "prompt": "def fibonacci(n):\n    ",
    "max_tokens": 100
  }'
----

==== Python Example (Chat)

[source,python,subs="attributes"]
----
from openai import OpenAI

client = OpenAI(
    api_key="{litellm_virtual_key}",
    base_url="{litellm_api_base_url}"
)

# Chat completion
response = client.chat.completions.create(
    model="granite-3-2-8b-instruct",
    messages=[{{"role": "user", "content": "What is Red Hat OpenShift?"}}]
)
print(response.choices[0].message.content)

# Embeddings
embedding = client.embeddings.create(
    model="nomic-embed-text-v1-5",
    input="Text to embed"
)
print(f"Embedding dimension: {{len(embedding.data[0].embedding)}}")
----
