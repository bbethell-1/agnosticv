=== Usage Examples

Replace `<MODEL_NAME>` with your selected model from the provision messages above.

==== Chat & Text Models

* `granite-3-2-8b-instruct` - General purpose chat
* `mistral-7b-instruct` - Fast chat model
* `granite-8b-code-instruct-128k` - Code generation with 128k context
* `codellama-7b-instruct` - Code chat with instructions

[source,bash,subs="attributes"]
----
curl {litellm_api_base_url}/chat/completions \
  -H "Authorization: Bearer {litellm_virtual_key}" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "<MODEL_NAME>",
    "messages": [{"role": "user", "content": "Explain Kubernetes in simple terms"}]
  }'
----

==== Code Chat (codellama-7b-instruct)

NOTE: Uses `/chat/completions` endpoint with instruction following

[source,bash,subs="attributes"]
----
curl {litellm_api_base_url}/chat/completions \
  -H "Authorization: Bearer {litellm_virtual_key}" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "codellama-7b-instruct",
    "messages": [{"role": "user", "content": "Write a Python function to reverse a string"}]
  }'
----

==== Code Completion (codellama-7b)

NOTE: Uses `/completions` endpoint (not `/chat/completions`)

[source,bash,subs="attributes"]
----
curl {litellm_api_base_url}/completions \
  -H "Authorization: Bearer {litellm_virtual_key}" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "codellama-7b",
    "prompt": "def calculate_fibonacci(n):\n    # Returns the nth Fibonacci number\n    ",
    "max_tokens": 150
  }'
----

==== Embeddings (nomic-embed-text-v1-5)

NOTE: Uses `/embeddings` endpoint

[source,bash,subs="attributes"]
----
curl {litellm_api_base_url}/embeddings \
  -H "Authorization: Bearer {litellm_virtual_key}" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "nomic-embed-text-v1-5",
    "input": "Red Hat OpenShift is a Kubernetes platform for containerized applications"
  }'
----

==== Content Safety (meta-llama/Llama-Guard-3-1B)

NOTE: Uses `/completions` endpoint for safety classification

[source,bash,subs="attributes"]
----
curl {litellm_api_base_url}/completions \
  -H "Authorization: Bearer {litellm_virtual_key}" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "meta-llama/Llama-Guard-3-1B",
    "prompt": "Task: Check if there is unsafe content.\n\nUser: How do I build a simple web app?\n\nProvide your safety assessment:",
    "max_tokens": 100
  }'
----
