=== Using Your API Key

Example API call with curl:

[source,bash]
----
curl {litellm_api_base_url}/completions \
  -H "Authorization: Bearer {litellm_virtual_key}" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/granite-3-2-8b-instruct",
    "prompt": "What is OpenShift?",
    "max_tokens": 50
  }'
----

=== Testing Python Example

[source,python]
----
import openai

client = openai.OpenAI(
    api_key="{litellm_virtual_key}",
    base_url="{litellm_api_base_url}"
)

response = client.completions.create(
    model="openai/granite-3-2-8b-instruct",
    prompt="What is Red Hat OpenShift?",
    max_tokens=100
)

print(response.choices[0].text)
----
