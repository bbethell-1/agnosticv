= LiteMaaS Test - AI Model Virtual Keys

*THIS IS FOR TESTING PURPOSES ONLY*

== Overview

Get access to AI models through LiteLLM with a personalized virtual key.

== What You Get

* **Virtual API Key**: A unique `sk-` key for accessing AI models
* **Model Selection**: Choose from chat, code, and embedding models
* **Flexible Duration**: Select validity from 3 to 30 days
* **OpenAI-Compatible API**: Works with any OpenAI SDK

== Using Your API Key

After provisioning, find your credentials in the *Information* tab:

[source,bash]
----
LiteLLM API Endpoint: https://litellm-rhpds.apps.cluster.com/v1
LiteLLM Virtual Key: sk-abc123xyz...
Available Models: granite-3-2-8b-instruct, mistral-7b-instruct, ...
Key Duration: 3d
----

=== Example API Call (Chat)

[source,bash]
----
curl https://litellm-rhpds.apps.cluster.com/v1/chat/completions \
  -H "Authorization: Bearer YOUR_VIRTUAL_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "granite-3-2-8b-instruct",
    "messages": [{"role": "user", "content": "What is OpenShift?"}]
  }'
----

=== Example Code Completion

[source,bash]
----
curl https://litellm-rhpds.apps.cluster.com/v1/completions \
  -H "Authorization: Bearer YOUR_VIRTUAL_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "codellama-7b",
    "prompt": "def fibonacci(n):\n    "
  }'
----

=== Example Embeddings

[source,bash]
----
curl https://litellm-rhpds.apps.cluster.com/v1/embeddings \
  -H "Authorization: Bearer YOUR_VIRTUAL_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "nomic-embed-text-v1-5",
    "input": "Text to embed"
  }'
----

=== Python Example

[source,python]
----
from openai import OpenAI

client = OpenAI(
    api_key="sk-YOUR-KEY-HERE",
    base_url="https://litellm-rhpds.apps.cluster.com/v1"
)

response = client.chat.completions.create(
    model="granite-3-2-8b-instruct",
    messages=[{"role": "user", "content": "Hello!"}]
)

print(response.choices[0].message.content)
----
