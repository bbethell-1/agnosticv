= LiteMaaS Test Environment

*THIS IS FOR TESTING PURPOSES ONLY*

== Overview

This catalog item provisions:

* Single Node OpenShift (SNO) cluster
* LiteLLM virtual key for AI model access

== AI Model Access

Your environment includes access to AI models via LiteLLM. After provisioning, you will receive:

=== Access Information

* *LiteLLM API Endpoint*: API base URL for model access
* *Virtual Key*: Your personal API key (format: `sk-xxxxx`)
* *Available Models*: List of AI models you can access
* *Key Duration*: How long your key is valid

=== Using Your API Key

After provisioning, find your credentials in the *Information* tab:

[source,bash]
----
# Your credentials will be displayed like this:
LiteLLM API Endpoint: https://litellm-rhpds.apps.cluster.com/v1
LiteLLM Virtual Key: sk-abc123xyz...
Available Models: openai/granite-3-2-8b-instruct, openai/mistral-7b-instruct
Key Duration: 30d
----

Example API call:

[source,bash]
----
curl https://litellm-rhpds.apps.cluster.com/v1/completions \
  -H "Authorization: Bearer YOUR_VIRTUAL_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/granite-3-2-8b-instruct",
    "prompt": "What is OpenShift?",
    "max_tokens": 50
  }'
----

== OpenShift Access

Standard OpenShift cluster access will also be provided in the *Information* tab.

== Custom Configuration (Advanced)

If you select *custom* package, you can specify:

* *Custom Models*: Comma-separated list (e.g., `openai/granite-3-2-8b-instruct,openai/mistral-7b-instruct`)
* *Custom Duration*: Any duration in days (e.g., `60d` for 60 days)
