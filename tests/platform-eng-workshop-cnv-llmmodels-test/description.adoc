= LiteMaaS — AI Model Virtual Keys

*TESTING CATALOG* — Provisions a LiteMaaS virtual key scoped to the models you select.
Access production AI models running on OpenShift AI via an OpenAI-compatible API.

Select your models and duration below. The lab guide with full API examples opens in the *Lab* tab after provisioning.

Lab guide: link:https://rhpds.github.io/litemaas-virt-key-usage-showroom/[rhpds.github.io/litemaas-virt-key-usage-showroom]

Key duration: 3, 7, 10, or 30 days. Keys are deleted on destroy.
