= LiteMaaS Test - AI Model Virtual Keys

*THIS IS FOR TESTING PURPOSES ONLY*

== Overview

Get access to AI models through LiteLLM with a personalized virtual key.

== What You Get

* **Virtual API Key**: A unique `sk-` key for accessing AI models
* **Model Selection**: Choose IBM Granite and/or Mistral AI
* **Flexible Duration**: Select validity from 3 to 30 days
* **OpenAI-Compatible API**: Works with any OpenAI SDK

== Available Models

[cols="1,3"]
|===
|Model |Description

|*IBM Granite 3.2 8B*
|IBM's open-source enterprise AI model (`openai/granite-3-2-8b-instruct`)

|*Mistral 7B*
|High-performance open-source model (`openai/mistral-7b-instruct`)
|===

== Duration Options

* **3d**: 3 days - Quick testing
* **7d**: 7 days - Short workshops
* **10d**: 10 days - Extended learning
* **30d**: 30 days - Full development cycle

== Using Your API Key

After provisioning, find your credentials in the *Information* tab:

[source,bash]
----
LiteLLM API Endpoint: https://litellm-rhpds.apps.cluster.com/v1
LiteLLM Virtual Key: sk-abc123xyz...
Available Models: openai/granite-3-2-8b-instruct, openai/mistral-7b-instruct
Key Duration: 30d
----

=== Example API Call

[source,bash]
----
curl https://litellm-rhpds.apps.cluster.com/v1/chat/completions \
  -H "Authorization: Bearer YOUR_VIRTUAL_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/granite-3-2-8b-instruct",
    "messages": [{"role": "user", "content": "What is OpenShift?"}]
  }'
----

=== Python Example

[source,python]
----
from openai import OpenAI

client = OpenAI(
    api_key="sk-YOUR-KEY-HERE",
    base_url="https://litellm-rhpds.apps.cluster.com/v1"
)

response = client.chat.completions.create(
    model="openai/granite-3-2-8b-instruct",
    messages=[{"role": "user", "content": "Hello!"}]
)

print(response.choices[0].message.content)
----
