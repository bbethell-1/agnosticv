= LiteMaaS — AI Model Virtual Keys

*TESTING CATALOG* — Provisions a LiteMaaS virtual key scoped to the models you select.
Access production AI models running on OpenShift AI via an OpenAI-compatible API.

Full documentation: link:https://rhpds.github.io/rhpds.litemaas/[RHDP LiteMaaS Docs] |
Lab guide with examples opens in the *Lab* tab after provisioning.

== Available Models

[cols="2,1,2",options="header"]
|===
|Model |Type |API name

|Granite 3.2 8B Instruct |Chat (default) |`granite-3-2-8b-instruct`
|Granite 4.0 H Tiny |Chat, tool calling |`granite-4-0-h-tiny`
|Llama 4 Scout 17B |Chat, 400K context |`llama-scout-17b`
|DeepSeek R1 Distill 14B |Chat, reasoning |`deepseek-r1-distill-qwen-14b`
|GPT OSS 120B |Chat, large |`gpt-oss-120b`
|Microsoft Phi-4 |Chat, compact |`microsoft-phi-4`
|Qwen 3 14B |Chat, multilingual |`qwen3-14b`
|CodeLlama 7B Instruct |Code chat |`codellama-7b-instruct`
|Llama Guard 3 1B |Safety |`Llama-Guard-3-1B`
|Nomic Embed v1.5 |Embeddings |`nomic-embed-text-v1-5`
|Granite Docling 258M |Document conversion |enable via checkbox
|===

Key duration: 3, 7, 10, or 30 days. Keys are deleted on destroy.
