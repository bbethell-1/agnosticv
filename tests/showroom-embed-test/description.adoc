
Deploys a Showroom lab environment with the OpenShift Console, ArgoCD, AAP, DevSpaces, and OpenShift AI embedded as iframe tabs -- all managed via ArgoCD App of Apps.

The OCP Console embedding works without disabling the authentication operator. A mutating webhook intercepts the operator's route writes to enable iframe embedding while keeping the operator fully Managed and the cluster healthy.

== What Gets Deployed

* *Keycloak SSO* -- OpenShift authentication with per-user accounts
* *ArgoCD (OpenShift GitOps)* -- App of Apps bootstrap for all components
* *Ansible Automation Platform* -- Controller instance
* *Dev Spaces* -- Cloud-based IDE
* *OpenShift AI 3* -- Dashboard, pipelines, workbenches, model serving
* *Showroom* -- Lab guide with embedded iframe tabs and panel toggle
* *OCP Console Embed* -- Webhook + Job to enable console iframe embedding

== Modes

* *Multi-user* (`num_users=N`): Deploys `showroom-user1` through `showroom-userN`, each in its own namespace with dedicated storage
* *Admin only* (`num_users=0`): Deploys a single `showroom-admin` instance

== Configurable Options

* *Showroom content repo and branch* -- Point to any Showroom content repository
* *Terminal type* -- In-pod OCP shell (default), Wetty SSH to bastion, or tmux
* *Number of users* -- 1 to 5 concurrent users with Keycloak SSO

== How It Works

The Showroom UI includes a view switcher toolbar (Instructions / Split / Tabs) so users can toggle between reading the lab guide and working in the console. The panel toggle, keyboard shortcuts (Ctrl+1/2/3), and view state are handled client-side with no server overhead.

For technical details on the console embedding approach, see the https://github.com/prakhar1985/showroom-ocp-console-embed[repository README].
