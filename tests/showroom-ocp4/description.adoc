This catalog item demonstrates the Showroom collection deployed on an OpenShift cluster.
It is intended for testing and development of the Showroom collection itself.

== Environment

* OpenShift cluster (SNO or multinode, selectable at order time)
* Showroom content deployed from the `showroom_template_nookbag` repository
* Wetty terminal with auto-SSH to the bastion host
* Cluster admin access provided on the environment details page
* OpenShift console embedded in the Showroom UI
