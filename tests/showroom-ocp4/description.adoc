
This catalog item provisions a Single Node OpenShift (SNO) 4.20 cluster and deploys a Showroom collection so you can run curated demos and workshops directly on the cluster.

== Products

* Red Hat OpenShift Container Platform 4.20
* Showroom (guided demo/workshop experience)

== Demo Guide

After deployment, your step-by-step instructions are delivered by Showroom at {showroom_primary_view_url}.

== What’s included

* A Single Node OpenShift cluster configured for demos and workshops
* Cluster administrator access (console URL, username, and password are provided on the environment details page)
* Showroom content preloaded from a Red Hat-maintained Git repository
* A landing page to navigate available scenarios and track progress

== Important Notes

* Please read all information before starting the demo. These environments are costly; use only when needed.
* Environments are only available for a limited time after provisioning. Be mindful of stop and delete times.
