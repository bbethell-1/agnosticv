This catalog item provisions a pair of RHEL virtual machines and deploys the Showroom collection to deliver a demo directly from the bastion host.
It is intended for testing and development of the Showroom collection itself.

== Environment Details

Your environment includes:

* *Bastion* — RHEL 9.6 VM (4 vCPU, 8 GB RAM) with Showroom pre-installed and two browser-based terminal sessions
* *Worker* — RHEL 10.0 VM (4 vCPU, 8 GB RAM) accessible from the bastion
