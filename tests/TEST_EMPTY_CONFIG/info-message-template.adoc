Variables
~~~~~~~~~
There is only one component in this service called *test-empty-config*

To use the data produced by the component using `agnosticd_user_info` is exposed as AsciiDoc attributes.
These may be included in the info message by name or more specifically by using the component name and the
data item name joined by two hyphens.
For example:

* `random_string`: {random_string}
* `test-empty-config--random_string`: {test-empty-config--random_string}
