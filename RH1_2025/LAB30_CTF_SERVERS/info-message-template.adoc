= LAB30 - Servers for Capture the Flag activity (NOT FOR PARTICIPANTS)

== Lab Access Details

* Log in to the bastion:

[subs=attributes+]
----
ssh {bastion_ssh_user_name}@{bastion_public_hostname}
----

Bastion password `{bastion_ssh_password}`

== Access other instances from Bastion

* Log in to the CTF Dashboard server from bastion:

[subs=attributes+]
----
[lab-user@bastion ~]$ ssh -i ~/.ssh/{guid}key.pem ec2-user@ctfdashboard
----

* Log in to the Ansible Automation Platform server from bastion:

[subs=attributes+]
----
[lab-user@bastion ~]$ ssh -i ~/.ssh/{guid}key.pem ec2-user@aap
----

* Log in to the Audit server from bastion:

[subs=attributes+]
----
[lab-user@bastion ~]$ ssh -i ~/.ssh/{guid}key.pem ec2-user@audit
----

* Log in to the Miscellaneous server from bastion:

[subs=attributes+]
----
[lab-user@bastion ~]$ ssh -i ~/.ssh/{guid}key.pem ec2-user@misc
----
