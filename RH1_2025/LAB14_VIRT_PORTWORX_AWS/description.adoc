## OpenShift Virtualization and Portworx 

In this hands-on lab, you'll gain practical experience operating OpenShift Virtualization with Portworx 
to enable high availability (HA), live migrations, intelligent automation, and VM-level data protection.

You will:

. **Install Portworx**  
  - Deploy the Portworx Operator and StorageCluster on OpenShift  
  - Understand the architecture and requirements

. **Create a Virtual Machine**  
  - Provision a persistent VM using OpenShift Virtualization and Portworx  
  - Explore storage class and volume configuration

. **Live Migration and High Availability**  
  - Trigger node evacuations and observe VM live migration  
  - Validate Portworx HA and failover capabilities

. **VM Snapshots**  
  - Take Kubernetes-native snapshots of a virtual machine  
  - Restore workloads from snapshots to simulate recovery

. **Autopilot**  
  - Create intelligent rules to auto-scale or self-heal storage resources  
  - Monitor and react to real-time storage conditions

You can preview the lab guide https://code.purestorage.com/pxe-osv-rhdp-lab/modules/index.html[here]
