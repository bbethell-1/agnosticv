Review key tasks using Red Hat Ansible Automation Platform with Red Hat Enterprise Linux.

This catalog item presents a quicker, 90-minute version of the original Red Hat Enterprise Linux (RHEL) asset for those who are new to Ansible Automation Platform. It includes select exercises that focus on cloud provisioning, converting bash/shell commands to Ansible Automation Platform, and using RHEL system roles.

Access guide: After you complete provisioning, you receive an email with a website containing a user credential and access to the following:

  • Automation controller web UI
  • Visual Studio Code (including a terminal)
  • Backup direct SSH access

The website provided with this information is dynamically created upon provisioning. The web address is your four-digit unique identification number plus the GPTE DNS "open.redhat.com"--for example: http://87f8.open.redhat.com/
