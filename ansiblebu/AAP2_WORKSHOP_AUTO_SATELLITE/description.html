AAP 2 - Automate Satellite Workshop

This is the Ansible / Satellite Workshop.

Workshop Description

The Ansible Satellite Workshop is a half-day, hands-on workshop covering Ansible Automation with respect to Red Hat Ansible Automation Platform, Red Hat Satellite, Red Hat Enterprise Linux and CentOS Linux. Attendees will learn how to use Ansible to automate configuration of Red Hat Ansible Controller and Red Hat Satellite, and acquire the skills needed to implement Ansible Automation at their organizations.

This workshop focuses on 4 main customer pain points:
  • How to implement Infrastructure as Code automation with Red Hat solutions
  • Compliance (OpenSCAP Scanning) and Vulnerability Management
  • OS Patch/Package Management
  • CentOS to RHEL conversion + upgrade

In this workshop, you will:

  • Explore the Red Hat Ansible Automation Platform and Red Hat Satellite environments
  • Explore Infrastructure as Code configuration of Satellite
  • Explore Infrastructure as Code configuration of Ansible Controller
  • Patch RHEL systems via Ansible Workflow
  • Scan RHEL systems via OPENSCAP policy
  • Mass convert EL-like systems to RHEL via convert2rhel, in conjunction with pre/post-conversion smoke tests
This workshop also includes exercises for Red Hat Insights, requiring a Red Hat account to do so, and is well suited for showcasing via the workshop instructor or single demo workbench deployments.

Workbench Infrastructure

  • 1 x Automation controller on RHEL 8
  • 1 x Satellite system on RHEL 8
  • 3 x Red Hat Enterprise Linux 7.X hosts
  • 3 x CentOS Linux 7.8 hosts

Access Guide

Upon completion of provisioning you will receive an email with a link to an attendance website where individual workshop environments can be claimed. Upon claiming a workshop environment, students will receive login credentials in addition to links providing access to:

  • Automation controller web UI
  • Satellite web UI
  • Visual Studio Code (including a terminal)

The website provided with this information is dynamically created upon provision and will be your 4-digit unique identification number + the GPTE DNS open.redhat.com for example: http://87f8.open.redhat.com/
