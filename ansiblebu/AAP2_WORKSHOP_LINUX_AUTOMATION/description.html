Use command line activities to implement automation controllers for enterprise use cases.

This asset describes the workshop for Red Hat Ansible Automation Platform and Red Hat Enterprise Linux (RHEL).

This workshop consists of two parts:

  • For users who are new to Ansible Automation Platform, it describes the basics of understanding foundational command line activities.
  • It then walks you through applying what you’ve learned to implement an Ansible automation controller to enterprise use cases. You start off by writing your first Ansible playbook, work on Jinja templates, and implement higher-level Ansible roles. The workshop then explains working with an automation controller and discusses inventory and credential management, projects, job templates, surveys, workflows, and more.
