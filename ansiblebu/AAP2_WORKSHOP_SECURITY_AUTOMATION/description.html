Review security automation in Red Hat Ansible Automation Platform 2 and third-party tools.

In this catalog item, you get started with security automation in Ansible Automation Platform with hands-on exercises that guide you through automating existing third-party security solutions including Check Point, IBM QRadar, and Snort IDPS. The asset then guides you through three security use cases:

  • Investigation enrichment
  • Threat hunting
  • Incident response

Specifications

  • One automation controller on Red Hat Enterprise Linux (RHEL) 8
  • One Snort
  • One Check Point Next Generation Firewall (NGFW)
  • One attacker host on RHEL 8
  • One IBM QRadar (SIEM)

Supporting Materials

Access guide: After you complete provisioning, you receive an email with a website containing a user credential and access to the following:

  • Automation controller web UI
  • Visual Studio Code (including a terminal)
  • Backup direct SSH access

The website provided with this information is dynamically created upon provisioning. The web address is your four-digit unique identification number plus the GPTE DNS "open.redhat.com"--for example: http://87f8.open.redhat.com/
