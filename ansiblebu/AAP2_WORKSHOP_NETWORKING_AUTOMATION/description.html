Discover how to automate popular network data center devices using Ansible playbooks.

This catalog items is a comprehensive beginners guide to automating popular network data center devices from Arista, Cisco, and Juniper using Ansible playbooks. You learn how to pull facts from devices, build templated network configurations, and apply these concepts at scale with the automation controller in Red Hat Ansible Automation Platform. You put it all together by exploring the controller’s job templates, surveys, access controls, and more.

Specifications

  • One automation controller on Red Hat Enterprise Linux 8
  • Two Arista EOS
  • One Cisco IOS
  • One Juniper Junos

Supporting Materials

Access guide: After you complete provisioning, you receive an email with a website containing a user credential and access to the following:

  • Automation controller web UI
  • Visual Studio Code (including a terminal)
  • Backup direct SSH access

The website provided with this information is dynamically created upon provisioning. The web address is your four-digit unique identification number plus the GPTE DNS "open.redhat.com"--for example: http://87f8.open.redhat.com/
